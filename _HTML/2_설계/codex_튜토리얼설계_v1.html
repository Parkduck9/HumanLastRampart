# 튜토리얼 설계 제안 v0.2



작성 Codex / T-CX-044 / 2026-10-15. **사용자 검토 전 초안이며 게임 구현·새 API·튜토리얼 전용 경제·씬 추가 승인 아님.** Claude의 전투/아트 연결과 병행해 자기 문서와 HTML만 작성한다.



## 사용자 결정 반영 (2026-10-15)



- **실전과 분리한 연습으로 만든다.** 근거: 사용자 “연습으로 만들자”.

- **연습 중에는 모든 성벽이 피해를 받지 않는다.** 근거: 사용자 “여기서는 성벽에 데미지 안입게 따로 해두는게 좋겠네”.

- 확정은 위 두 요구다. 9단계 전체·시간·병사/영웅 피해·보상·재시도·저장·자원 정책·건너뛰기·첫 정비 흐름까지 일괄 확정한 것으로 해석하지 않는다. 구현 방식/API/실제 연습 전투는 아직 없다.



## 권장 구성



**복귀 지휘관의 성벽 인수인계 → 짧은 별도 연습 → 첫 실전 → 첫 정비의 상황별 안내.** 별도 연습 채택은 사용자 결정이며, 인수인계 연출·단계 수·목표 시간과 정비 안내 세부는 제안이다. 연습 목표 4~6분(측정 전 기획 목표), 첫 정비 안내 목표 1~2분.



## 연습 전용 성벽 피해 방지 요구



1. 연습에서만 모든 성벽의 시작 체력을 유지한다. 피해를 적용했다가 매 프레임 회복시키는 방식이나 UI의 체력 숫자만 고정하는 것으로 대신하지 않는다. 실제 성벽 체력 감소를 막아야 한다.

2. 직접 공격·등반 뒤 공격·그 밖의 실제 성벽 피해 경로를 모두 점검한다. 적 이동/공격과 병사의 사격은 계속 진행해 학습 장면은 볼 수 있게 한다. 피격 연출을 유지할지는 제안이며 손상 수치로 오해되지 않아야 한다.

3. 실제 전투의 성벽 피해·패배 조건은 그대로다. 연습에서 나가면 보호가 실전으로 새지 않아야 한다. 구현은 Claude가 App/Core/Combat 상태 분리와 명시적 연습 판별 방식을 검토한다. 전역 무적 토글이나 기존 난이도 값으로 대체하는 API를 이번 문서에서 확정하지 않는다.

4. **성벽만 보호한다.** 병사/주인공/마법사 무적, 돈 무제한, 스킬 대기 없음은 결정되지 않았다. 병력 손실로 학습을 못 하는 경우 해당 연습을 다시 할 수 있게 하는 안은 별도 제안이다.

5. 성벽이 파괴되지 않는다고 연습을 무한히 이어가지는 않는다. 단계 목표 성공/재시도/건너뛰기·종료의 명시적 완료 경로가 필요하다. 성벽이 버틴 시간만으로 조준·명령 학습을 자동 완료하지 않는다.

6. 수리는 **첫 실제 전투 후** 안내한다. 연습 성벽을 일부러 손상시키거나 실전 성벽에 손상을 옮겨 수리 예시를 만들지 않는다. 첫 실전에도 손상이 없으면 “수리할 필요 없음”을 확인하고 넘어간다.



주인공은 장교 훈련을 받고 귀향한 인물이다. 신병에게 지휘법을 처음 가르치는 설정보다 현지 부관이 병력·성벽·새 장비를 보고하는 연출을 추천한다. 첫 문장 예: “지휘관님, 정면 성벽의 병력과 장비 배치를 보고드리겠습니다.” 초상·성우·부관 신규 캐릭터는 이번 제안으로 확정하지 않는다.



첫 메시지는 **병사는 자동으로 공격하고, 플레이어는 이동·명령·대포 조준·마법 사용을 지휘한다**는 역할 설명이다. 현재 1회차는 주인공 직접 공격/스킬이 빠져 있으므로 공격 버튼이나 직접 칼싸움을 가르치지 않는다.

|---|---|---|---|---|

| T01 인수인계 | 지휘관/자동 공격 역할 | “병사들은 사거리 안의 적을 자동으로 공격합니다. 지휘관님은 전장을 살피고 명령을 내려 주십시오.” | 역할 안내 읽고 연습 시작 선택 | 전체 건너뛰기 허용 제안 |

| T05 마법 | 지도에서 마법 선택→범위 지정 | “이 무리는 마법으로 막아 주십시오.” | 유효 시전이 접수되고 효과가 실제 발동 | 재사용 대기/사거리 실패는 이유와 재시도. 첫 연습은 같은 성벽 쪽을 선택해 이동 대기 부담 줄임 |

T01~T06은 채택된 별도 연습의 세부 흐름 제안이다. 실전 1번 전투는 기존 밸런스를 그대로 사용한다. 연습 적 수/체력/자원/종료 조건은 아직 수치를 정하지 않았으며 실전 웨이브를 임의로 줄이는 승인이 아니다.



## 안내 방식



- 한 단계에 목표 하나, 안내 1~2문장, 화면에서 대상 하나만 강조한다. 이미 익힌 이동은 계속 허용한다.

- 설명 읽기와 학습 성공을 구분한다. “다음”을 누른 것만으로 명령 적용/사격/마법 성공으로 기록하지 않는다. HTML의 이전/다음은 시안 탐색 버튼이다.

- 연습에서는 설명 중 안전하게 정지하고, 행동 확인이 필요할 때만 진행하는 방식 제안. 정지 중 명령 접수와 실제 발동을 구분한다. 기존 쉬움 지도 정지에서 조준 후 실제 사격을 보려면 지도를 닫아야 한다.

- 실전 난이도는 그대로 유지한다. 쉬움은 기존 지도 정지 규칙, 현실은 지도 중에도 시간이 흐른다. 별도 승인 없이 현실을 튜토리얼 팝업 때문에 자동 정지시키지 않는다.

- 목표를 잘못 눌러도 비용을 반복 차감하거나 진행을 잠그지 않는다. 실제 구매/마법 자원·재사용 대기는 현재 규칙을 따른다.

- 설명 재보기·닫기·연습 건너뛰기·다시 연습하기 제안. 재시작/완료 저장 범위는 미정이며 전역 저장 키나 CampaignState 필드를 새로 만들지 않는다.



## 처음부터 넣지 않을 것



전령/소리 지르기 차이, 우회 적 보고, 망원경 상세, 시야·날씨·시체 더미, 대포병 결원 복구, 고급 우선순위/표적 고정은 실제로 필요한 상황에서 짧게 알려준다. 우회 발견 안내는 기존 발견 사건이 발생할 때만 띄우고, 연습을 위해 실제 캠페인에 새 우회 적을 강제 생성하지 않는다. 마법사가 다른 성벽으로 이동하는 시간은 그 상황에서 “이동 후 발사”로 설명한다(D-058).

## QA 계획 — 아직 수행하지 않은 게임 시험



1. 명령만 선택하고 취소한 경우 단계가 완료되지 않는다. 조준 설정과 실제 첫 사격을 구분한다.

2. 쉬움 지도에서 시간을 정지한 채 시전 접수했을 때 효과 대기 안내가 막히지 않는다.

3. 잘못된 목표·재사용 대기·사거리 밖·부족 골드·설치 불가/점유 칸에서 안내와 입력이 복구된다.

4. 연습 재시도/건너뛰기/종료 뒤 실제 골드·병력·성벽·함정·전투 번호가 연습 전과 같다.

5. 결과 상세·정비를 다시 열어도 안내/보상/구매가 중복 실행되지 않는다.

6. 현실 난이도의 실전 시간을 몰래 정지시키지 않는다. 학습과 무관한 디버그 키를 안내하지 않는다.

7. 긴 한글·작은 화면·확대된 글꼴에서 안내가 목표/UI를 가리지 않는다. 실제 Unity에서 확인한다.

8. 연습의 네 성벽에 모든 피해 경로로 반복 공격을 가해도 실제 HP가 시작 값과 같다. UI만 고정됐거나 사후 회복된 것이 아닌지 검사한다.

9. 동일 공격을 실제 전투에 가하면 기존 피해가 정상 적용된다. 연습 종료/재시도/건너뛰기/중간 종료 후 새 실전에서도 피해 방지가 남지 않는다.

10. 성벽 보호 상태에서도 적 이동·공격·사격과 단계 완료/종료가 정상 진행된다. 손상 없는 첫 정비가 수리 구매를 요구하며 멈추지 않는다.
