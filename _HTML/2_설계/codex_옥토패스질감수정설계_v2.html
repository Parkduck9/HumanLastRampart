    # 옥토패스 방향 배경 질감 수정 설계 v2 — T-CX-050

- 작성: Codex / 2026-10-15 / 상태: **수정 설계 제안, 사용자 검토 전**.
- 요청: 현재 질감이 옥토패스 트래블러 방향에 맞는지 검토한 뒤 어떻게 고칠지 설계.
- 범위: 성벽 바깥면·통로 바닥·들판 풀 3종을 먼저 개선하는 제작·비교 계획. 이번에는 이미지 재생성, Game·셰이더·모형·규격·확정 계약 변경 없음.
- 기존 v1/노멀 견본 및 G-CX-035·036 파일 목록은 보존. v1 기술 규격 통과와 최종 아트 승인 여부는 구분한다.

## 1. 목표와 판단 한계

목표는 **도트 표면이 실제 3D 공간에서 돌·풀처럼 읽히고, 그 앞의 작은 캐릭터가 또렷하게 보이는 성벽**이다. 새 질감을 만든 뒤 같은 카메라·조명으로 비교한다. 원작의 조명이나 화면 효과를 질감 자체에 강하게 그려 넣지 않는다.

참고는 [옥토패스 공식 HD-2D 소개](https://www.jp.square-enix.com/octopathtraveler/about/)와 사용자가 처음 보낸 마을 화면이다. 공식 소개는 도트와 3DCG 효과의 결합을 설명한다. 아래 명암·돌 크기·색 제안은 우리 게임을 위한 작업 기준이며 원작에서 측정한 수치가 아니다. 원작 원본 텍스처·픽셀 밀도·노멀 제작법과 동일하다고 주장하지 않는다.

현재 원안은 미러 대칭이 반복되고 줄눈이 강해 전체가 평평한 패턴으로 읽힌다. 풀은 고대비 잔무늬가 촘촘하다. 완성 게임 화면과 평면 알베도를 직접 비교해 조명까지 같다고 판단할 수는 없지만, 이 반복·명암 문제는 질감 단계에서 먼저 줄일 수 있다.

## 2. 유지할 것

| 기준 | 유지 |
|---|---|
| 도트 밀도 | 32px/m, 기존 제작 기준. 원작 규격이라는 뜻 아님 |

| 표현 | 픽셀 군집·계단형 윤곽 유지, 확대용 부드러운 보간으로 도트를 흐리지 않음 |
| 소유권 | 질감·레퍼런스 Codex, 모형·전투 조명·실제 게임 캡처 Claude |

## 3. 질감별 수정안

### A. 성벽 바깥면 — 먼저 고칠 대상

- **줄눈:** 돌마다 검은 외곽선을 두르지 않는다. 주변 돌보다 한 단계 어두운 회녹/회갈색으로 연결한다. 주된 줄눈 폭은 약1px, 깨진 부분만 국소적으로 넓힌다. 실제 화면에서 너무 가늘면 다시 조정한다.
- **돌 크기:** 첫 시안 가이드로 높이12~24px(약0.38~0.75m), 폭16~40px(약0.5~1.25m)를 섞는다. 모든 줄을 자로 잰 같은 직사각형으로 채우지 않고 가로 줄맞춤은 대체로 유지한다. 모형 크기를 바꾸는 제안이 아니다.
- **표면:** 타일 전체에는 완만한 큰 명도 변화, 돌마다 소폭 색 차이, 일부 모서리에 깨짐/마모를 준다. 모든 픽셀을 잡티로 채우지 않는다.
- **이끼:** 모든 줄눈마다 같은 녹색 표시를 반복하지 않는다. 아래쪽·틈 일부에 모아 두고 드문드문 끊는다. 최종 이끼 비율은 시안에서 결정한다.
- **조명:** 밝은 면·그림자를 원안 전체에 고정해 그리지 않는다. 알베도는 재료색, 노멀은 모서리와 틈의 표면 방향을 담당한다.

### B. 성벽 통로 — 캐릭터 아래는 읽기 쉽게

- 벽돌 벽과 같은 패턴을 눕혀 쓰지 않고, 밟고 닳은 바닥 돌 전용 구성을 만든다.
- 바닥 돌 간격과 크기를 조금 섞고, 틈은 벽보다 덜 도드라지게 한다. 넓은 안정된 중간색 면을 남긴다.
- 작은 균열·흙·마모는 일부에만 배치한다. 캐릭터의 신발/검은 옷과 경쟁하는 검은 줄무늬를 줄인다.
- 통로가 폭2m라는 사실은 UV 범위로 맞춘다. 4×4m 타일을2m 폭에 억지로 전부 축소해 도트 밀도를 두 배로 만들지 않는다.

### C. 들판 풀 — 잔무늬 대신 큰 덩어리와 여백

- 바탕 중간색 → 4~12px 정도의 풀 덩어리 → 드문1px 잎/밝은 끝 순으로 만든다. 수치는 첫 원안 가이드다.
- 지금처럼 전역에 같은 밝은 풀 싹을 촘촘하게 반복하지 않는다. 낮은 대비의 조용한 구역과 성긴 풀 구역을 섞는다.
- 노란 밝은 점·검은 틈의 대비를 줄인다. 조명 없이도 노이즈가 강하면 재생성한다.
- 큰 흙길·언덕의 형태를 한 반복 타일에 그려 넣지 않는다. 풀/흙/언덕의 넓은 구역 배치는 Claude의 모형·재질 배치 검토에서 다룬다. 새 혼합 셰이더를 지금 필수 조건으로 추가하지 않는다.

## 4. 미러 대칭을 없애는 제작 방식

1. 기존 원안을 재사용해 색만 흐리는 방식 대신, 위 기준으로 **새 원안 3종 각1안**을 만든다. 필요할 때만 대안을 추가한다.
2. 경계가 자연스럽게 이어지는 주기 타일을 목표로 한다. 좌우/상하를 반사해 맞추는 방식을 최종 출력의 기본으로 쓰지 않는다.
3. 타일을 가로·세로 절반씩 오프셋해 원래 외곽 연결부가 중앙에 오도록 확인한다. 중앙 연결부를 고칠 때 맞춰 둔 바깥 경계의 연속성도 유지한다.
4. 3×3 반복으로 긴 선·십자 대칭·동일 이끼 무늬가 튀는지 확인한다. 색뿐 아니라 돌 줄눈·바닥 패턴·풀 덩어리도 이어져야 한다.
5. 첫·마지막 픽셀값을 무조건 같게 만드는 것만을 무이음 합격으로 보지 않는다. 경계를 가로지르는 명도 변화가 내부 변화보다 튀지 않는지, 노멀 경계에서 밝은 선이 생기지 않는지 함께 확인한다.
6. 아직 반복이 강하면 억지로 숨기지 않고 원안을 다시 만든다. A/B 변형 타일이나 모형별 이끼/마모 구역은 기본3종 승인 뒤 필요성을 검토한다. 추가 파일/셰이더/API는 별도 협업 범위로 정한다.

## 5. 노멀맵 수정 기준

- 새 색 그림에 맞는 **표면 높이·굴곡 기준을 함께 정리**한다. 완성 알베도의 밝기를 그대로 높이로 바꾸지 않는다. 어두운 이끼·색 얼룩이 반드시 홈인 것은 아니다.
- 돌은 평평한 면 + 낮은 모서리 굴곡 + 들어간 틈, 바닥은 더 약한 마모, 풀은 약한 덩어리 굴곡으로 시작한다. 광택 강한 플라스틱처럼 부풀리지 않는다.
- 동일 UV/크기의 높이 기준에서 노멀을 출력해 표면 구조를 맞추는 방식을 우선 검토한다. 생성형 노멀 원안만 쓰면 색·굴곡 정렬을 별도로 확인한다. 어느 방식이든 사용자 시안 검토 후 규격 출력한다.
- +Y/선형 노멀·색 sRGB·Point·Repeat·32px/m는 기존 요청 기준을 유지한다. 축 반전·단위벡터·크기·반복 경계 검사는 계속 수행한다.
- 빛을 좌/우/위로 돌렸을 때 돌의 같은 모서리가 합리적으로 밝아지는지, 모서리만 번쩍이는지 확인한다. 세기 수치는 실제 게임 비교 뒤 정하며 기존0.55를 새 확정값으로 고정하지 않는다.

## 6. 질감과 렌더를 분리해 확인

| 검사 | 고정할 것 | 확인할 것 |
|---|---|---|
| 무조명 원색 비교 | 동일 크기·32px/m·반복 수 | 줄눈/반복/잔무늬가 개선됐는가 |
| 평면 노멀 ↔ 새 노멀 | 같은 광원·재질·색 그림 | 표면 방향이 맞고 과하게 부풀지 않는가 |
| v1 ↔ v2 실제 장면 | 같은 40m 성벽 모형·카메라·광원·병력 배치·노출 | 질감 교체만으로 돌/풀/캐릭터 구분이 좋아졌는가 |
| 낮 ↔ 밤/횃불 | 각 시간대에서 v1/v2 조건 동일 | 어둠·밝은 빛에서 뭉개짐/번쩍임이 없는가 |
| 정지 ↔ 이동 | 같은 카메라 움직임·속도 | 줄눈·풀의 지글거림과 반복이 거슬리지 않는가 |

실제 3D 장면의 광원·그림자·약한 화면 효과는 Claude 담당이다. 질감을 비교하는 동안에는 효과 강도를 같이 바꾸지 않는다. 알베도 개선을 블룸·흐림으로 가려 합격시키지 않는다. 화면 효과의 구체 설정·성능을 새로 확정하는 문서가 아니다.

## 7. 실행 순서와 승인 지점

1. **이번:** MD/HTML 수정 설계 검토. 새 질감·Game 수정 없음.
2. 사용자 방향 확인 후 Codex가 성벽/통로/풀 새 레퍼런스3종을 만든다. 원안·프롬프트·무조명 반복 비교 HTML로 제시한다.
3. 사용자가 외형을 고르면 동일32px/m 규격의 타일·노멀을 출력한다. 기존 파일을 덮어쓰지 않고 새 v2 자료로 보관한다.
4. 파일·반복·노멀 검사를 마치고 별도 경로 목록으로 Git 허가를 요청한다. 기존 G036은 v1 보관 요청으로 유지한다.
5. Claude가 승인된3종만 시험 장면에 연결하고 같은 조건의 실제 전후 캡처를 준비한다. Codex가 시안과 비교하고 사용자가 최종 판단한다.
6. 통과한 기준을 난간 위/옆·탑벽/지붕·흙/언덕6종으로 확장한다. 캐릭터 노멀 견본 승인과는 별개다.

## 8. 합격 체크리스트

- 3×3 반복에서 미러 십자·이끼 도장·길게 이어진 검은 줄이 먼저 눈에 띄지 않는다.
- 가까운 화면에서 픽셀 군집과 돌의 마모가 읽히고, 보통 전투 거리에서는 캐릭터가 먼저 읽힌다.
- 색·노멀의 틈/모서리가 맞고, 빛 방향을 바꿔도 경계에 밝은 이음선이 튀지 않는다.
- 32px/m·물리 크기·UV·색/노멀 해상도가 일치한다. Point/Repeat/NPOT 설정으로 규격이 바뀌지 않는다.
- 같은 장면의 v1/v2 비교에서 사용자에게 '더 비슷한 방향'이라는 판단을 받는다. 이를 객관적 원작 일치율로 표현하지 않는다.
- 체크리스트는 앞으로 할 검증이다. 현재 개선 완료·Unity 검증 통과로 기록하지 않는다.
