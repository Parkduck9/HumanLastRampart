배경과 인물, 화면 아래 대사창

승인된 공통 스타일의 스토리 탭을 기존 5번 화면에 적용했습니다. 아래는 구현 배치를 설명하는 HTML 목업이며 실제 Unity 캡처가 아닙니다.

스토리
마법사

성벽을 지키기 위한 여정이 시작됩니다.

기존 진행 계약 유지

  • 일반 스토리는 기존 문구와 다음 버튼을 유지합니다.
  • 패배 엔딩은 기존 문구와 메인으로 버튼을 유지합니다.
  • 버튼은 기존 Complete(ScreenOutcome.Done)을 호출합니다. 화면 전환과 중복 완료 차단은 기존 ScreenEntryBase / App이 담당합니다.
  • 선택지·대사 기록·건너뛰기·저장 규칙이나 제안 상태 스토리 API는 추가하지 않았습니다.

아트와 파일 범위

기존 Art/Characters/Static/wizard_static.png를 수정하지 않고, Story 소유 Resources 폴더에 바이트 그대로 복사했습니다. 새 그림·새 캐릭터 설정은 없습니다. 런타임에서 씬 수정 없이 참조할 수 있습니다.

배경은 승인 시안의 공간 구분을 색면으로 표현했습니다. 최종 배경 그림을 새로 제작한 결과는 아닙니다. 기존 3인자 ScreenView 생성 경로는 유지하고 스토리 전용 생성 경로만 추가했습니다.

검증과 남은 확인

정적 검사와 별도 C# 컴파일 결과는 qa.json에 기록합니다. 카드 폴더에서는 Unity를 실행하지 않았습니다.

통합 후 일반 스토리 → 다음 → 전투, 패배 엔딩 → 메인으로, 버튼 연타 중복 차단, 키보드 포커스, 16:9·넓은 화면·작은 창의 대사창과 인물 가림을 실제 화면에서 확인해야 합니다.
