1-새. 설치 — 공식 안티그래비티 명령줄 도구 agy (2026-10-20 바뀜)

  • 왜 바뀌었나: 제미나이 명령줄 도구에 구글 로그인을 하면 "개인용은 더 이상 지원하지 않음, 안티그래비티로 옮기라"는 안내가 나온다. 구글은 2026년 5월 제미나이 명령줄 도구를 안티그래비티 명령줄 도구(agy) 로 옮겼다(공식, 토큰 꺼내 쓰기 아님).
  • 설치(파워셸, 구글 공식 설치 문서의 명령): irm https://antigravity.google/cli/install.ps1 | iex → 기본 위치 %LOCALAPPDATA%\agy\bin
  • 확인: 새 창에서 agy --version, 그다음 agy 를 한 번 대화형으로 실행해 로그인·작업 폴더 신뢰를 마친다(헤드리스 실행은 저장된 로그인을 쓴다).
  • 실행 도구 ask.ps1은 agy가 있으면 agy를 쓴다: agy -p <지시> --sandbox --output-format text. 허가가 필요한 도구(파일 쓰기·명령)는 헤드리스에서 기본으로 실행되지 않는다 — "모든 허가 건너뛰기" 옵션은 절대 쓰지 않는다.
  • 쓸 수 있는 양: 공식 문서의 "모델 할당량" 쪽 — 첫 사용 뒤 agy 안 사용량 화면으로 확인해 여기에 적는다.

1. (예전) 제미나이 명령줄 도구 설치 — 개인 로그인 막힘, 기록용

winget install OpenJS.NodeJS.LTS
npm install -g @google/gemini-cli
gemini
  • 마지막 줄을 처음 실행하면 로그인 방법을 묻는다 → 구글로 로그인을 고르면 브라우저가 열린다. 로그인 뒤 창을 닫으면 끝.
  • 무료 사용량(개인 구글 계정, 2025년 기준 안내): 분당 약 60번·하루 약 1,000번 — 설치 뒤 실제 값은 도구의 안내로 다시 확인.
  • 확인: gemini -p "say ok" 가 글을 돌려주면 준비 완료.
  • 설치 때 겪은 것 (2026-10-20):
  • 노드는 이미 깔려 있었다(24판) — 설치 전에 열어 둔 터미널은 경로를 몰라 npm·node를 못 찾는다 → 새 창을 열거나 $env:Path = "C:\Program Files\nodejs;$env:APPDATA\npm;" + $env:Path
  • 파워셸 실행 정책이 gemini.ps1을 막는다 → 보안 설정은 바꾸지 않고 gemini.cmd 로 부른다 (실행 도구도 이렇게 함)

2. Claude가 맡기는 방법

powershell -NoProfile -ExecutionPolicy Bypass -File Tools\GeminiHelper\ask.ps1 -Task <지시.md> -Out <결과.md>
  • 지시 파일은 영어(AI끼리는 영어 — 사용자 규칙). Tools/GeminiHelper/RULES.md가 자동으로 앞에 붙는다: 읽기만, 파일 수정 금지, 모든 주장에 파일:줄 또는 주소, 모르면 UNSURE.
  • 결과 첫 줄이 QUOTA_EXHAUSTED(종료 코드 3)면 할당량 소진 → Claude가 같은 일을 직접 한다.
  • 실행 기록: Tools/GeminiHelper/runs.log.

4. 검증 규칙 (Claude가 받은 결과를 쓰기 전에)

  1. 파일:줄 주장은 전부 또는 무작위 3개 이상을 직접 열어 확인한다. 하나라도 틀리면 그 결과 전체를 다시 확인한다.
  2. 웹 주장은 주소가 있는 것만 쓴다. 숫자·날짜는 원문 확인 전까지 "확인 안 됨"으로 표시.
  3. UNSURE 항목은 Claude가 직접 찾거나 사용자에게 묻는다.
  4. 같은 종류의 일에서 2번 틀리면 그 종류는 맡기지 않는다(5장에 기록).
