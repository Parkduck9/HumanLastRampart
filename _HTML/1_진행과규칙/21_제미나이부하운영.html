  • 목적: 조사·읽기·초안은 제미나이가, Claude는 검증만 → Claude 토큰 절약. 제미나이 할당량이 떨어지면 그때부터 Claude가 직접 한다.

1. 설치 (사용자가 한 번만 — 다운로드·로그인은 사용자 몫)

winget install OpenJS.NodeJS.LTS
npm install -g @google/gemini-cli
gemini
  • 마지막 줄을 처음 실행하면 로그인 방법을 묻는다 → 구글로 로그인을 고르면 브라우저가 열린다. 로그인 뒤 창을 닫으면 끝.
  • 무료 사용량(개인 구글 계정, 2025년 기준 안내): 분당 약 60번·하루 약 1,000번 — 설치 뒤 실제 값은 도구의 안내로 다시 확인.
  • 확인: gemini -p "say ok" 가 글을 돌려주면 준비 완료.

2. Claude가 맡기는 방법

powershell -NoProfile -ExecutionPolicy Bypass -File Tools\GeminiHelper\ask.ps1 -Task <지시.md> -Out <결과.md>
  • 지시 파일은 영어(AI끼리는 영어 — 사용자 규칙). Tools/GeminiHelper/RULES.md가 자동으로 앞에 붙는다: 읽기만, 파일 수정 금지, 모든 주장에 파일:줄 또는 주소, 모르면 UNSURE.
  • 결과 첫 줄이 QUOTA_EXHAUSTED(종료 코드 3)면 할당량 소진 → Claude가 같은 일을 직접 한다.
  • 실행 기록: Tools/GeminiHelper/runs.log.

4. 검증 규칙 (Claude가 받은 결과를 쓰기 전에)

  1. 파일:줄 주장은 전부 또는 무작위 3개 이상을 직접 열어 확인한다. 하나라도 틀리면 그 결과 전체를 다시 확인한다.
  2. 웹 주장은 주소가 있는 것만 쓴다. 숫자·날짜는 원문 확인 전까지 "확인 안 됨"으로 표시.
  3. UNSURE 항목은 Claude가 직접 찾거나 사용자에게 묻는다.
  4. 같은 종류의 일에서 2번 틀리면 그 종류는 맡기지 않는다(5장에 기록).
