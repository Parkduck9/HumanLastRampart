# 마법사 뒷모습 정적 에셋 v1

- 작성 Codex / T-CX-037. 사용자 기존 규칙·서 있기 지시, M-CL-048 요청.
- 상태: 제작·파일 규격 검사 완료. 사용자 외형 검토와 Claude 게임 연결/Unity 검증 대기. 정적 데모이며 최종 게임 검증 완료 에셋으로 기록하지 않는다.

## 유지한 설정

기존 정면 마법사를 참조한 백발, 약2.2등신의 짧은 몸, 보라색 금테 의상, 갈색 벨트·부츠, 파란 수정 나무 지팡이. 완전한 뒷모습으로 성벽 밖을 바라보며 양발을 딛고 선다. 지팡이는 기존과 같은 해부학적 오른손(후면의 화면 오른쪽)에 든다. 얼굴·모자·새 장비를 추가하지 않았다. 걷기·공격·시전 프레임은 없다.

## 격자 규격

- wizard_back_static_grid.png: RGBA 투명256×384, 1열×1행, 프레임0, FPS0.
- 공통 발 기준 (128,352), Unity 아래 기준 pivot(.5,32/384), aspect256/384.
- SheetLayout.Make(1,1,.5f,32f/384f,256f/384f). 반드시 프레임0으로 표시한다.
- 기존 정면·다른 캐릭터 파일을 변경하지 않았다. 새 생성 원본은 wizard_back_source.png에 보관하며 build_sheet.py는 알파 내용 경계 자르기·최근접 축척·공통 칸 배치만 한다. 새 색이나 새 그림을 그리지 않는다.
- 부츠 영역으로 몸 발 중심을 추정했다. 실제 Unity 크기/피벗·지팡이 가독성은 Claude가 확인한다.

## 확인한 것과 남은 것

후면 포즈·기존 의상/장비·단일 정적 상태를 육안 확인했다. 파일 치수/알파/테두리 잘림 없음/발 기준점/최근접 색 보존/저장 후 픽셀 일치 검사 통과. PNG/JSON 해시와 생성 프롬프트를 보관했다. HTML 그림/다운로드를 내장하여 서버 없이 열 수 있다. 실제 브라우저 시각 QA 및 Unity 실행/화면 캡처는 수행하지 않았다.

Game/Art·Data/Combat 연결은 Claude 소유라 수정하지 않는다. 사용자 외형 검토 후 Claude에게 원본이 아닌 wizard_back_static_grid.png를 복사해 연결/검증하도록 요청한다. 게임 연결 승인과 검증을 대신 확정하지 않는다.

## 후속 외형 수정 — 플레이어와 구분되는 머리색

- 사용자 지시: 마법사는 플레이어와 외형 차이가 있어야 하는데 현재 둘 다 백발이라 구분이 약하다. 지금은 문서만 수정하고 머리색 변경은 나중에 진행한다.
- 현재 백발은 데모의 임시 외형이며 최종 머리색 승인으로 취급하지 않는다. 새 머리색은 미정이다.
- 색이 확정되면 마법사 정면·후면과 이후 제작되는 동작 프레임의 머리색을 함께 맞춘다. 기존 보라색 금테 의상·지팡이·약2.2등신 및 격자/발 기준은 유지한다. 다른 외형 변경은 별도 검토한다.
- 현재 원본 PNG·격자 PNG·규격 JSON·게임 에셋은 변경하지 않는다. 다음 외형 작업에서 이 항목을 먼저 확인하고 색을 사용자에게 검토받는다.
- 이 지시는 현 데모의 최종 외형 승인이나 자동 게임 연결 승인으로 확대하지 않는다.

## 공통 후속 아트 원칙 — 플레이어와 다른 인물 구분

- 사용자 지시: 마법사뿐 아니라 다른 인물들도 플레이어와 구분되게 만든다. 대상은 병사(궁수·총병·대포병), 마법사, 장교·조연·스토리 인물 등 플레이어 이외의 인물이다.
- 약2.2등신과 도트 표현은 공통으로 유지하되, 머리색/머리 모양·의상 배색·장비·실루엣을 구분 요소로 검토한다. 특히 작은 전투 크기와 뒷모습에서도 플레이어를 알아볼 수 있어야 한다.
- 모든 인물의 머리색을 각각 다르게 강제하는 규칙은 아니다. 병종 안의 공통 외형도 허용하며, 플레이어와 구별되는 것이 목적이다. 구체적인 캐릭터별 색/디자인은 추후 사용자 검토로 확정한다.
- 정면·후면·향후 동작 프레임에 같은 인물의 외형을 일관되게 적용한다. 현재 PNG는 임시 데모로 유지한다. 지금은 문서 기록만 갱신하며 재생성/재색칠/게임 에셋 변경을 하지 않는다.
