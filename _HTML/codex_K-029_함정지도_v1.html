1판 / D-064 사용자 확정 전 시안 / 게임 미연결

01 / 조합 지도와 격자

1칸 5m = 32×32화소. 북쪽이 위입니다. 지도는 160×120m 설명용 견본이며 실제 게임의 지형·설치 규칙을 재현한 화면이 아닙니다.

그림을 읽고 있습니다.

클릭 또는 방향키로 선택 칸을 옮깁니다. 선택은 그림 비교용이며 설치·구매·저장을 실행하지 않습니다. 설치 불가 표시는 예시입니다.

02 / 다섯 격자 상태와 두 함정 표시

반투명 겉칠은 지형 위 별도 층입니다. 설치 불가는 빗금과 ×, 선택은 굵은 금빛 테두리, 설치됨은 파란색과 ✓로 구분합니다. 묻힌 함정의 금빛 마름모는 위치 기록용 지도 기호입니다.

03 / 반복과 연결

풀·언덕은 공통 한 화소 경계를 씁니다. 언덕은 각 칸 안의 독립 둔덕이며, 여러 칸에 걸친 연속 등고선은 이번 시안 범위 밖입니다. 길은 북·동·남·서 연결 16종으로 같은 방향끼리 맞춥니다. 한 화소 경계 일치가 자연스러운 반복 외형을 보장하지는 않습니다.

04 / 성 둘레 · 네 면

40×40m, 8×8칸 완성 견본과 원위치 조립용 32×32 조각을 함께 제공합니다. 전체 지도에서는 같은 조각을 원위치에 조립합니다. 네 면과 모서리는 원안 그대로 이어지고, 그림 크기를 바꿔 성벽 길이를 늘리는 용도는 검증하지 않았습니다.

생성 원안에 아래쪽 옆면이 조금 보입니다. 엄격한 수직 도면 느낌으로 더 평평하게 다듬을지 사용자 검토가 필요합니다. 색감·수관·석재는 K-024·K-025와 기존 Game 그림을 참고했습니다.

지도 규격 6.4화소/m는 전투용 그림의 32화소/m와 다릅니다. 중심 피벗·점 필터 제안. 노멀맵·Unity 임포트·실제 전투 연결·Play·게임 캡처는 수행하지 않았습니다. 원안·정확한 프롬프트·파일 규격·남은 질문은 Docs/References/codex_k029_v1/와 루트 CARD_RESULT.md에 보관합니다. 이 페이지는 모든 그림을 내장하여 서버 없이 직접 열 수 있습니다.
