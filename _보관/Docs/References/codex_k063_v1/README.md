# K-063 아군 서기 기준 그림 1판

2026-10-19 / Codex / **개별 그림 사용자 검토 대기**

궁수·총병·대포병·마법사의 뒷모습 서기와 앞모습 서기를 각각 제작했다. 주인공은 새로 그리지 않았다. 비교 페이지의 주인공은 사용자가 채택한 6판 원본이다.

검토 페이지: [`codex_K-063_아군6판방향_v1.html`](../../../_HTML/4_그림_캐릭터/codex_K-063_아군6판방향_v1.html). 이미지·스타일·스크립트를 모두 내장했으므로 서버 없이 직접 열 수 있다. [`전체_4배_비교.png`](전체_4배_비교.png)에서도 8장을 한눈에 볼 수 있다.

## 규격과 파일

| 구분 | 값 |
|---|---|
| 1배 칸 | 56×112, RGBA PNG |
| 인물 높이 | 머리카락 꼭대기부터 발바닥까지 96점 |
| 칸 가운데 | x=28, 생성 원본의 몸 중심축을 기준으로 배치 |
| 발선 | y=104, 불투명 그림은 y=8~103에 위치 |
| 알파 | 0 또는 255만 사용, 투명 픽셀 RGB도 0 |
| 4배 보기 | 224×448, 최근접 보간, 1배의 각 점을 4×4로 확대 |

파일 접두어는 `archer` 궁수, `gunner` 총병, `cannon_crew` 대포병, `wizard` 마법사다. `back`은 뒷모습, `front`는 앞모습이다.

- `*_back_56x112.png`, `*_front_56x112.png`: 최종 서기 8장.
- `*_back_4x.png`, `*_front_4x.png`: 최종 그림의 최근접 4배 8장.
- `*_generated.png`: 선택한 고해상도 생성 원본 8장. 게임용 원본은 위 56×112 파일이다.
- `*_previous_back.png`, `wizard_previous_front.png`: 기존 그림의 동일 높이 비교용 축소본.
- `hero_v6_reference.png`: 기존 주인공 6판의 바이트 동일 비교 사본.
- `*_palette.png`, `팔레트.json`: 기존 병종별 실제 색상과 출처 SHA-256.
- `생성기록.json`: 내장 이미지 도구에 사용한 정확한 생성·수정 프롬프트와 원안 경로.
- `검사결과.json`: 최종 그림의 크기·발선·알파·팔레트 소속·4배 확대 검사와 해시.
- `HTML_검사결과.json`, `verify_review.cjs`: 내장 PNG 42개와 배경·화면 높이 전환 로직의 정적 검사 결과·검사 자료. 브라우저 렌더링 시험은 아니다.
- `build_review.py`: 생성된 그림의 규격·색상 정리와 검토 페이지 재생성용 자료. 그림의 형태 제작은 내장 이미지 생성 도구로 수행했다.

마법사는 지팡이를 포함해 칸 안에 들어가도록 가로 위치를 최대 2점 조정했다. 발선과 인물 높이는 다른 병종과 같다. 각 그림의 실제 가로 배치와 불투명 영역은 검사결과에 적었다.

## 기준과 병종 외형

방향 기준은 `../codex_hero_octopath_review_v6/APPROVED_DIRECTION.md`, `corrected.png`, `hero_idle_56x112.png`이다. 작은 머리·작은 눈, 분리되는 어깨/몸통/다리, 절제된 장식과 계단식 명암을 목표로 했다. 첫 생성에서 큰 머리를 확인하고 앞·뒤 모두 별도로 보정했다. 정지 한 장을 방향만 바꾼 것으로 처리하거나 동작 칸에 복제하지 않았다.

| 병종 | 유지한 외형 | 실제 팔레트 출처: `Game/Assets/_Project/Art/Characters/Static/` 아래 |
|---|---|---|
| 궁수 | 밝은 갈색 머리, 남색·크림 제복, 갈색 장갑·장화, 나무 활, 등에 화살통 | `archer_static.png` |
| 총병 | 짙은 갈색 머리, 남색·크림 제복, 회색 어깨 보호대, 나무 개머리판·금속 총열 | `gunner_static.png` |
| 대포병 | 검회색 머리, 남색·크림 제복, 갈색 멜빵·장갑·장화, 빈손 | `cannon_crew_static.png` |
| 마법사 | 따뜻한 밤색 머리, 보라·금색 로브, 갈색 장화·지팡이, 푸른 보석 | `wizard_back_static.png`, `wizard_static.png` |

원본 시트는 읽기만 했다. 총병의 긴 대각선 총은 칸을 넘겨서, 같은 머스킷을 옆에 세워 내리는 서기 자세로 보정했다. 궁수 앞모습은 화살통이 가슴 앞으로 나온 오류를 수정해 어깨 뒤에서 화살깃이 보이게 했다. 대포병은 불붙이는 막대를 제외했다. 마법사 지팡이는 오른손에 들며 정면에서 화면 왼쪽, 뒷면에서 화면 오른쪽에 보인다.

## 팔레트와 픽셀 정리

원본 시트에서 알파 250 이상인 실제 RGB만 추출했다. 외곽선, 무채색 금속, 파랑, 보라, 크림, 황동, 피부, 검회색 머리, 갈색을 색군으로 나눴다. 작은 보석이나 어깨 보호대가 면적이 작다는 이유로 누락되지 않게 했다. 보통 색군당 4색, 외곽선 2색, 머리·가죽·나무를 함께 포함하는 갈색군 8색을 선정했다. 대표색은 보간색을 쓰지 않고 원본에 실제 존재하는 RGB로 되돌렸다.

생성 원본을 알파 128 기준으로 잘라 최근접 보간으로 인물 96점에 맞춘 뒤, 병종별 추출 팔레트로 대응했다. 갈색 가죽이 황동으로 변하지 않도록 색상각도 함께 비교한다. 새 색을 임의로 추가하지 않았다. 최종 알파는 0/255로 정리했다. 최종 그림의 모든 불투명 RGB가 해당 원본 팔레트에 속하는지 검사했다.

단색군마다 3~4단의 주 명암을 지향했지만, 색군을 재질의 손그림 마스크로 분리한 것은 아니다. 1점 외곽선의 일정함, 작은 눈·화살깃·버클 정보, 재질 경계의 색 대응은 4배 그림에서 사용자 검토가 필요하다. 6판과 동일한 채도를 수치로 증명한 것은 아니며 기존 확정 색 보존을 우선했다.

## 비교 페이지

각 병종에 주인공 6판, 기존 뒷모습, 새 뒷모습, 새 앞모습을 같은 56×112 칸·같은 발선으로 1배와 4배 표시한다. 기존 앞모습 서기가 있는 마법사는 앞모습 전후도 제공한다. 궁수·총병·대포병은 기존 정적 파일이 뒷모습이므로 앞모습 전후 비교라고 표시하지 않았다. 밝은 배경·어두운 배경·격자 배경으로 투명 가장자리를 볼 수 있다.

축소 목업은 화면 높이 540/1080을 선택하며 인물 높이는 각각 70.2/140.4화소, 즉 화면 높이의 13%다. 발선은 모든 인물에 동일하다. 목업의 바닥·들판은 가독성 비교용 단순 배경이며 실제 게임 화면이나 카메라 검증이 아니다.

## 확인과 남은 것

- 최종 8장: 56×112, 불투명 높이 96점, 발바닥 아래 y=104, 알파 0/255 확인.
- 최종 8장의 실제 원본 팔레트 소속, 최근접 4배 파일의 픽셀 단위 일치 확인.
- 고해상도 선택 원안과 최종 4배 접촉판을 직접 시각 확인. 보석 파랑·금속 회색·대포병 빈손 확인.
- 주인공 6판 사본과 원본의 바이트 일치, 팔레트 출처 5개 원본의 SHA-256 유지 확인.
- 브라우저 연결 도구가 사용 가능한 브라우저를 반환하지 않아 실제 브라우저 렌더링 확인은 수행하지 못했다. HTML 이미지 내장·구문·크기 전환 로직은 별도 정적 검사로 확인한다.
- 앞·뒤는 독립 생성으로 머리 실루엣과 제복 주름에 차이가 남아 있다. 사용자 외형 확인 후 필요하면 맞추고 동작 제작으로 진행한다.
- Unity 실행, 실제 카메라/배경/가림/조명/노멀 확인, 게임 연결은 수행하지 않았다. 동작 시트·노멀은 이번 카드 범위 밖이다. 연결은 Claude가 D-074와 기존 칸·피벗 규약을 확인해 진행해야 한다.

Game, 기존 문서·아트·공용 HTML 목록·협업 기록을 수정하지 않았고 Git 쓰기를 하지 않았다.
