# 주인공 선택본 — 4프레임 복원

- 작성자: Codex
- 날짜: 2026-10-13
- 사용자 지시: "플레이어 다시 4프레임으로 줄이자 너무 프레임 높으니까 별로다 고블린도 4프레임으로 변경해"

주인공의 네 방향 걷기를 눈까지 수정한 승인 v6의 네 포즈로 복원했다. 정면·후면 원본은 `codex_hero_walk_v6_front_back.png`, 측면 원본은 `codex_hero_walk_v4_side.png`를 그대로 사용한다. 눈 밖 변경 0으로 검증했던 정면 네 번째 눈 수정도 유지한다.

최신 HTML은 기존 `codex_hero_walk_preview_v1.html` 경로, 선택본 JSON은 `codex_hero_walk4_v8.json`이다. 방향당 4장, 기본 6 FPS이며 기존 왕복 비교도 유지한다. 12프레임 추가 계획은 현재 선택에서 제거했다.

사용자의 정리 지시에 따라 이전 버전·12프레임 실험·중복 미리보기와 작업 스크립트는 삭제했다. 현재 선택한 4프레임 원본과 JSON·HTML만 사용한다. 기존 외형 레퍼런스 HTML은 최신 걷기 미리보기로 연결한다.

PNG 원본의 머리·눈·팔다리를 이번 복원에서 수정하지 않았다. 변경은 표시 HTML과 선택 상태 기록이다. Game·Unity Play·Git 쓰기 없음.
