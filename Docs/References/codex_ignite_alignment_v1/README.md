# K086 점화 배치 보정 — 실제 게임 촬영

2026-10-21. 승인된 점화병 6칸과 도화선 대포 그림을 실제 Game PNG 두 개에 연결했다. 기존 GUID는 유지했으며 Unity가 .meta 플랫폼 설정을 정규화했다. 새 그림 생성과 Git 작업은 하지 않았다.

## 배치 원인과 수정

대포 그림은 논리 대포 자리보다 바깥으로 0.25m 이동해 그린다. 점화 사격병을 논리 자리에 그대로 두면 투영된 불꽃이 도화선보다 아래에 보였다. 같은 깊이로 맞추자 대포가 불꽃을 가려, 사격병만 대포보다 0.02m 뒤에 두었다. 최종 사격병 앞뒤 이동량은 **0.25−0.02=0.23m**다.

확장 2592×384 점화 시트를 사용하는 사격병에만 적용한다. 보조병과 구형·없는 점화 시트는 기존 위치를 유지한다. 생성과 대포 이동 도착이 같은 위치 계산을 사용한다. 대포 논리 위치·사거리 수치·좌우 간격·인물 키는 유지한다.

## 결과

- 시도 1: Unity NUnit이 제공하지 않는 NonParallelizable 특성으로 컴파일 실패. 해당 특성 제거, 공유 UnitDef 복원 유지.
- 시도 2: Play 46/47. TrapFlow가 확률 자동 폭발을 부적절하게 실패 처리했고, 점화 불꽃의 동일 깊이 가림을 확인했다.
- 시도 3: Edit 116개 중 115 통과·기존 1 유보·실패 0. Play 47/47 통과. 실제 A·B·C 촬영에서 불꽃 표시와 도화선 접점 투영 범위 포함을 확인했다.
- TrapFlow는 실제 ConsumedTrapIds 전체 제거, 비소모 함정의 표시·처음 칸·지형 보존, 전체 개수 일치를 검사한다. 다른 지형의 대조 함정을 추가해 보존 검사가 빈 검사가 되지 않게 했다. 자동 폭발 확률은 유지한다. 이번 실제 기록은 Victory이므로 결과 검사가 실행됐다. 기존 if Victory 분기로 인해 향후 패배 시 결과 검사가 생략될 수 있는 시험 한계는 남아 있다.
- 별도 SimProbe.FrameCost 1건은 정원 초과로 측정 전 중단됐다. FrameTiming 초반 평균 7.74ms, GPU 원시 계수 0. 전투가 22.4초에 끝나 75초 중반 조건에 도달하지 못했다. 성능 향상·FPS 보장의 근거로 사용하지 않는다.

정적 접촉을 확인한 결과다. **3→4 자루 길이 연속성과 전체 동작 자연스러움의 최종 선택은 별도**다. 오른쪽 횃불대 주변 과노출도 별도 기존 QA 항목이다.
