# K-072 전투 효과 6판

사용자가 고른 주인공 6판의 **처음 생성본 `generated.png`**을 기준으로 만든 교체 후보입니다. 굵은 어두운 외곽선, 큰 도트 덩어리, 재질별 세 단계 명암, 상아색·금색·갈색·회색 계열을 사용했습니다. 기존 게임 파일은 변경하지 않았습니다.

검토 페이지: [`codex_K-072_효과6판_v1.html`](../../../_HTML/5_그림_전장/codex_K-072_효과6판_v1.html). 인터넷과 서버 없이 직접 열 수 있습니다. 현재 게임 파일과 새 시안을 나란히 재생하며, 속도·정지·한 칸 이동·배경·기준점을 바꿀 수 있습니다. 64화소 축소 보기는 판독성 비교용이고 실제 전투 캡처가 아닙니다.

## 구성

| `dust_puff.png` | 1536×256 | 6 | (128, 256) | 신규 쓰러짐 먼지, 한 번 |

모든 동작은 왼쪽에서 오른쪽 순서입니다. 기존 효과의 6칸·초당 10칸 약속을 유지했습니다. 투사체는 원본과 같은 1칸입니다. 프레임별 의미와 알파 영역은 `manifest.json`에 있습니다.

- `sheets/`: Claude가 연결할 최종 PNG. 기존 파일명·시트 크기를 유지했습니다.
- `native/`: 64×32 또는 64×64 셀의 원래 도트 크기. 최종 시트는 이것을 최근접 보간으로 4배 확대했습니다.
- `previews/`: **최종 시트에서 다시 4배** 확대한 검토 PNG. 원래 도트 기준으로는 16배입니다. 게임 연결용이 아닙니다.
- `generated/`: 기본 제공 이미지 생성 도구로 만든 원본. 생성 원본의 여섯 칸은 3열×2행이며, 납품 시트로 정리하면서 한 줄로 재배치했습니다. 생성 원본을 바로 게임에 넣지 않습니다.
- `inputs.json`, `build.ps1`: 원본을 자르고 같은 배율로 축소한 뒤 색상·알파·기준선을 정리하는 제작 자료입니다. 프레임마다 따로 크기를 키우지 않아 점화·확산·소멸의 상대 크기가 유지됩니다.
- `review.ps1`, `verify.ps1`: 내장형 비교 페이지 생성과 규격 확인 자료입니다. PowerShell에서 각각 실행할 수 있으며 Unity는 실행하지 않습니다.

## 기존 효과 조사와 연결 인계

`Characters/Projectiles/`에는 투사체 3종, `BattleArt/Effects/`에는 `arrow_hit`, `fire_field`, `magic_burst`, `torch_flame`, `trap_burst` 5종이 있었습니다. 별도의 `explosion.png`나 `hit_sparks.png`는 없으며, 폭발·불티는 위 파일들로 표현합니다.

전투 코드에서 `BattleArt/Cannon/muzzle_smoke.png`를 포구 연기와 폭발 후 공용 연기에 함께 사용하고 있어 이 시트도 교체 후보에 포함했습니다. 기존 아래 기준점 (128, 240)을 유지했습니다. 불꽃·폭발·불티·횃불의 기존 발광 처리는 Claude가 그대로 유지하고, 연기·먼지는 비발광으로 연결합니다. 별도의 연기 시스템이나 포구 섬광 API를 만들지 않았습니다.

교체 대상의 원래 경로와 SHA-256은 `manifest.json`의 `sourceGamePath`, `sourceGameSha256`에 있습니다. `sheets/`의 파일만 해당 경로로 교체하고 기존 가져오기 설정을 유지하면 됩니다. 새 `dust_puff.png`는 적이 쓰러질 때 한 번 재생하도록 **Claude의 신규 연결이 필요**합니다. 이 카드에서는 게임 경로·코드·씬·가져오기 설정·`.meta`를 수정하지 않았습니다.

효과에는 인물용 발 기준 y=352를 적용하지 않습니다. 효과는 셀 아래 y=256, 포구 연기는 y=240, 투사체는 셀 중심을 기준으로 합니다. 불바다·폭발·먼지의 마지막 불투명 줄은 y=252~255, 포구 연기는 y=236~239입니다. 셀의 기준점은 그 아래 경계입니다.

## 이미지 생성 요청

기본 제공 `image_gen`을 사용했습니다. 생성 요청은 다음과 같습니다. 도구 실행 뒤 셀 재배치·색상 제한·최근접 확대·단독 점 정리만 수행했습니다.

공통: 투명 PNG, 글자·테두리·바닥·격자 없음. 64화소 기준의 큼직한 픽셀 덩어리, 재질별 세 단계 명암, 한 점 두께의 짙은 외곽선. 부드러운 벡터 선·흐림·그라데이션·빛 후광을 배제. 화살과 쇠는 주인공 6판의 어두운 외곽선과 나무·상아색·차가운 회색을 사용. 불꽃은 상아색 중심, 금색 중간, 주황·적갈색 바깥쪽. 연기는 따뜻한 회색·갈색 계열.

| 대상 | 요청 내용 |
|---|---|
| 화살 | 오른쪽을 향하는 나무 화살 한 개, 왼쪽 상아색 깃, 오른쪽 은회색 화살촉, 굵고 읽기 쉬운 실루엣 |
| 총알 궤적 | 왼쪽으로 가늘어지는 꼬리와 오른쪽의 밝은 끝, 상아색 중심·금색 가장자리·어두운 좁은 외곽선 |
| 대포알 | 단단한 둥근 쇳덩이, 왼쪽 위 네모난 밝은 점과 오른쪽 아래 어두운 명암 |
| 타격 불티 | 점화, 짧은 네 갈래 섬광, 넓어진 금색 조각, 분리된 조각, 작은 잔불, 마지막 잔상 |
| 불바다 | 모든 칸에서 불이 유지되는 반복 동작, 좌우로 흔들리고 가운데가 솟는 넓고 낮은 불길 |
| 마법 폭발 | 작은 점화, 상승하는 불, 가장 큰 둥근 화염, 터져 나가는 불덩이와 연기, 잔불과 연기, 마지막 연기 |
| 횃불 | 받침 없는 좁은 불꽃만, 좌우 기울기·솟음·두 갈래를 오가는 반복 동작 |
| 함정 폭발 | 섬광, 상승 불길, 큰 불길과 각진 돌조각, 갈라지는 흙먼지, 작은 잔해, 마지막 잔상 |
| 포구 연기 | 작은 점화 섬광, 작은 연기, 가장 큰 다섯 덩어리 연기, 분리, 작은 조각, 마지막 잔상 |
| 쓰러짐 먼지 | 작은 낮은 충격, 두 덩어리, 넓고 낮은 다섯 덩어리 먼지, 분리, 작은 두 조각, 마지막 한 조각. 불·인물 없음 |

## 확인 결과와 남은 확인

10종 45프레임의 시트 크기, 기존 파일과의 크기·칸 수 일치, 프레임별 가운데 정렬과 아래 기준선, 0/255 알파, 4배 도트 격자, 단독 한 점 부재, 4배 미리보기의 화소 일치를 자동 확인했습니다. 모든 최종 시트의 모양을 이미지로 열어 확인했습니다.

HTML의 내장 PNG 21개를 실제 해독했고, 비교 대상 19개와 참고 이미지 2개가 포함되어 있습니다. 외부 리소스 참조가 없고 JavaScript 구문 검사도 통과했습니다. **연결된 브라우저가 없어 페이지의 실제 렌더링·재생·버튼 동작은 확인하지 못했습니다.** 페이지에는 이미지 로드 수 표시가 있어 사용자가 연 뒤 실패 여부를 확인할 수 있습니다.

Unity는 실행하지 않았습니다. Claude 연결 뒤 발광 증폭·빛번짐·전투 거리의 표시 크기, 반복 불꽃의 연결감, 먼지 재생 시점을 확인해야 합니다. 제공받은 실제 캡처는 현재 게임의 참고 화면이며 새 시안을 적용한 캡처가 아닙니다.
