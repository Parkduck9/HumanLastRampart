# 휴대전화 터치 조작 그림 1판

K-125 · 가로 화면 · K-123과 같은 양피지·나무·닳은 황동 계열입니다. **그림 자료만 제공**하며 게임 연결은 Claude가 맡습니다.

## 구성

- 1x/: 픽셀 원본 80개. 3x/: 가장 가까운 이웃 방식으로 정확히 3배 확대한 게임 그림 80개.
- previews/: 각 원본의 4배 미리보기 80개, 한국어 상태 모음, 실제 화면 3종의 원본·투명 조작층·합성본.
- manifest.json: 모든 그림의 역할, 상태, 크기, 셀, 피벗, 순서, 9분할 경계와 시안 배치 좌표.
- 검토 페이지: _HTML/6_그림_화면/codex_K-125_터치조작_v1.html. 이미지와 동작을 내장하여 서버 없이 엽니다.

| 종류 | 게임 크기 | 제공 상태 |
|---|---:|---|
| 가로 이동 패드 | 312×144 | 중립·왼쪽·오른쪽·안쪽·바깥쪽, 같은 구성의 60% 불투명 버전 |
| 원형 스틱 | 168×168 | 같은 5상태와 60% 불투명 버전 |
| 가로 홈 / 손잡이 | 312×72 / 60×60 | 별도 홈, 보통·눌린 손잡이 |
| 행동 단추 | 96×96 / 72×72 | 보통·눌림·꺼짐·강조, 별도 4칸 강조 테 |
| 행동 기호 | 48×48 | 상호작용 손·지도·도움말·일시정지·배속·등대 명령·계단 아래/위·뒤돌기·북/서/동/남·마법·대포·취소·확인·드래그 선택·명령 표적 |
| 성벽 선택판 | 192×192 | 중앙 등대, 각 방향 보통/눌림 조각, 5칸 비교 시트 |
| 터치 파문 | 셀 96×96 | 중심 고정 4칸, 초당 12칸 권장 |
| 길게 누르기 고리 | 셀 96×96 | 위에서 시계 방향으로 1/8~8/8, 8칸 |

1x/의 단추는 32×32 / 24×24, 기호는 16×16입니다. 파일 이름의 96/72는 **게임 크기**입니다. 시트는 왼쪽부터 진행하며, 피벗은 **각 셀의 중심**입니다. UI 자료에는 인물용 발 기준선이 없습니다.

## 조합과 연결

- 단추 가운데는 기호를 그리지 않은 나무 면입니다. glyph_*를 중심에 별도로 겹칩니다. 도움말 물음표는 요청된 기호이며, 글자·숫자·방위 문자·키 이름은 PNG에 넣지 않았습니다.
- action_*_pulse_sheet는 테만 있는 4칸 시트입니다. 보통 단추 위에 겹치고 초당 8칸으로 순환합니다. 번지는 빛 없이 황동의 3단계 밝기가 바뀝니다.
- 이동 상태 시트는 모양 비교용입니다. 실제 조작은 별도 손잡이를 움직이고 안/밖 표식을 연결합니다. 가로형의 위·아래 표식은 별도 깊이 입력을 보여줍니다.
- compass_base 위에 원하는 compass_방향_pressed를 **같은 원점**으로 겹칩니다. 8개 조각 모두 투명한 64×64 원본 캔버스이므로 자르지 않습니다. 가운데 등대는 유지됩니다.
- 파문은 마지막 칸 뒤 숨깁니다. 길게 누르기 고리는 실제 누른 시간에 맞춰 칸을 선택합니다.
- move_slider_track만 9분할합니다. 경계 순서는 왼쪽/아래/오른쪽/위이며 원본 8/8/8/8, 게임 24/24/24/24입니다. 가로만 늘리고 세로는 고정합니다. 원형 단추·스틱·선택판·고리를 9분할하지 않습니다.
- Point, Clamp, 압축 없음, 밉맵 없음, 색 곱셈 흰색을 사용합니다. 1배 그림을 화면에서 3배로 쓰거나 3배 그림을 그대로 사용하며 중복 확대하지 않습니다.
- 일반 그림 알파는 0/255입니다. _60 패드는 0/153으로 **60% 불투명**입니다. 파문은 칸별 255/220/180/120이며 모든 가장자리는 같은 픽셀 격자를 유지합니다.
- 실제 기기 밀도·안전 영역·입력 영역·드래그/길게 누르기 판정·배속 순환은 이번 그림의 확정 범위가 아닙니다.

## 실제 화면 위 시안

세 장 모두 실제 1920×1080 캡처를 크기 변경·재도색 없이 사용했습니다. previews/source_*와 mockup_*를 비교할 수 있고, overlay_*는 추가된 조작 그림만 담은 투명층입니다.

- 성벽 위 전투: W35의 104_w35_day_f_west_wall_arrived.png. 왼쪽 아래 가로 패드, 오른쪽 아래 상호작용·계단·지도·도움말·정지·배속.
- 등대: 요청된 W35의 103_w35_day_e_at_tower_prompt.png. 왼쪽 아래 원형 패드, 오른쪽 아래 성벽 선택판·빛 명령·뒤돌기·계단·지도·정지.
- 전투 지도: Docs/References/ui_20261023/map_full.png. 왼쪽 아래 선택·명령, 오른쪽 아래 정지·마법·대포·확인·취소. 중앙 전장과 기존 명령판을 보존합니다.

기존 키 안내와 HUD는 원본 그대로입니다. 시안은 모바일 입력이 작동하는 화면이 아닙니다. 주인공·HUD 영역에 투명 조작층이 겹치지 않는지 픽셀 단위로 검사했습니다. 지도에는 주인공이 표시되지 않습니다.
