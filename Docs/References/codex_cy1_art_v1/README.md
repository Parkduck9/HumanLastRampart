# 바퀴1 전투 캐릭터 외형 시안 v1

- 작성자 Codex, T-CX-015 / CY1-X5, 2026-10-13.
- 상태: 사용자 외형 검토 대기. 각 캐릭터 정면 단일포즈 1장, 애니메이션/방향/네이티브 도트 규격 미확정. Game에는 반영하지 않음.
- 생성: imagegen 스킬의 내장 도구로 에셋별 1호출(총6). CLI/API 키 사용 없음. 실제 프롬프트 전체는 prompts.json.
- 파일: ogre.png, ladder_goblin.png, archer.png, gunner.png, cannon_crew.png, wizard.png. 기존 고블린 원본은 변경하지 않음.
- 사다리 고블린: 기존 고블린 시트를 외형 참고/변형 입력으로 사용해 사다리 장비로 변경. 나머지5종은 새 생성.
- 검토: 큰 오우거 실루엣, 사다리 전체/고블린 몸, 활·화살통, 총, 대포 장전 도구, 마법사 지팡이/로브를 육안으로 확인. 몸·장비가 보이는 단일포즈.
- 파일 검증: 원본과 저장본 SHA256 동일. PNG RGBA8, 완전 투명 픽셀 존재. 크기/알파 분포는 png-analysis.json.
- 결과 한계: 고해상도 생성 시안이며 반투명 가장자리·주변 번짐이 남는다. 정식 게임 스프라이트용 도트 크기·색 수·장비 통일·발 기준점·모션 시트는 외형 선택 후 제작/확인해야 한다. 픽셀 완성 에셋으로 승인된 것이 아니다.

미리보기는 preview.html. CSS 표시 크기를 바꾸어도 원본 PNG는 바꾸지 않는다. 밝은/어두운 배경에서 가장자리 확인 가능. 캐릭터의 게임 내 크기 비교가 아니라 외형 검토용 카드다. 이미지의 표시 높이가 같아도 오우거의 실제 게임 크기를 확정하지 않는다.
