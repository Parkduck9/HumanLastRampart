# K-115 · 높은 등대탑 그림 자료

[검토 페이지](../../../_HTML/6_그림_화면/codex_K-115_등대탑_v1.html)는 그림과 재생 기능을 내장해 서버 없이 열 수 있습니다. 낮 226·밤 236 원본과 합성본, 꺼짐·점등 부품, 불꽃 세 밝기, 반복 재질을 비교합니다.

12m 높이의 기존 입체 탑에 붙일 **텍스처와 투명 스프라이트**입니다. 큰 석재, 그을음, 오래된 청동 화로·반사경, 철창, 황실 등불지기 문장을 사용했습니다. 원래 K-102의 어두운 돌과 따뜻한 청동 정체성을 이어갑니다. 인물 방향은 사용자가 고른 주인공 6판 원본을 참고했습니다.

## 재질

| 파일 | 크기 | 반복·물리 범위 |
|---|---|---|
| `textures/tower_wall_albedo.png` | 256×256 | 가로·세로 반복, 한 장 8×8m |
| `textures/tower_trim_albedo.png` | 256×64 | 가로 반복·세로 고정, 한 장 8×2m |
| `textures/tower_roof_albedo.png` | 128×128 | 가로·세로 반복, 한 장 4×4m |
| `textures/lamp_interior_glow.png` | 128×128 | 반복 없음, 등실 내부 전용 반투명 온광 |

기준은 **32픽셀 = 1m**입니다. 석벽·띠·지붕은 포인트 필터, 색 재질만 사용하며 노멀맵은 없습니다. 석벽·지붕의 반대편 경계와 띠의 좌우 경계가 정확히 일치합니다. `previews/*_repeat_2x2.png`에서 이음새를 확인할 수 있습니다. 띠의 세로 반복은 의도하지 않았습니다. 띠 그림을 좁은 면에 붙일 때는 표현된 높이에 맞춰 부분 좌표를 사용합니다.

빛 그림만 부드러운 필터를 권장합니다. 최대 알파는 실제 94/255이며 테두리는 완전히 투명합니다. 등실 면 안쪽으로 제한하고, 밤 전체의 노출이나 주변 안개에 사용하지 않습니다. 실제 주변 조명·회전 빛줄기·그림자는 게임의 기존 조명이 담당합니다.

## 분리 스프라이트

아래 파일은 모두 `native/`와 `game/`에 있습니다. 각각의 4배 확인용 그림은 `previews/`에 있습니다.

| 이름 | 내용 |
|---|---|
| `lamp_window_dead.png`, `lamp_window_lit.png` | 돌 창틀·철창·붙어 있는 깨진 유리, 창 사이 투명 |
| `brazier_lens_dead.png`, `brazier_lens_lit.png` | 청동 화로와 반사경, 불꽃 없이 분리 |
| `door_dead.png`, `door_lit.png` | 철제 띠를 두른 목재문·돌 아치·오른쪽 랜턴 |
| `lantern_dead.png`, `lantern_lit.png` | 별도로 배치할 수 있는 랜턴 몸체 |
| `flame_warming.png` | 약한 불, 왼쪽부터 6장 |
| `flame_lit.png` | 보통 불, 왼쪽부터 6장 |
| `flame_bright.png` | 강한 불, 왼쪽부터 6장 |

원본 칸은 **96×128**, 받침 기준은 위에서 잰 **(48,120)**입니다. 게임용은 정확히 최근접 3배 확대한 **288×384** 칸, 받침 **(144,360)**입니다. 아래가 원점인 Unity 정규화 피벗은 **(0.5,0.0625)**입니다. 원본 스프라이트의 단위당 픽셀 수는 32, 3배 연결용은 96으로 맞추면 같은 월드 크기를 유지합니다. 스프라이트의 압축·밉맵은 사용하지 않고 포인트 필터를 적용합니다.

문짝 폭은 약 38픽셀로 약 1.2m이며, 아치와 옆 랜턴을 포함한 전체 그림은 80×112픽셀입니다. 문에 포함된 랜턴과 별도 랜턴을 같은 위치에 중복 배치하지 않습니다. 꺼짐과 점등 창틀·화로·문은 같은 알파 형태를 사용합니다. 점등 뒤에도 파손된 유리는 남습니다.

기존 게임의 `Beacon/flame_warming.png`, `Beacon/flame_lit.png`는 읽어서 각 6칸임을 확인했습니다. 연결용 결과도 이름·칸 수·왼쪽부터의 순서를 유지합니다. 강한 불 시트는 신규 이름입니다. 실제 기존 파일은 변경하지 않았습니다.

## 등실에 겹치는 순서

원본 96×128 조립 칸을 기준으로 아래 위치에 각 부품의 피벗을 놓습니다. 연결용 좌표는 각각 3배입니다.

| 부품 | 원본 조립 칸 안 위치 |
|---|---|
| 창틀 받침 | (48,120) |
| 화로 받침 | (48,113) |
| 불꽃 바닥 | (48,99) |
| 내부 빛 사각형 | 왼쪽 위 (16,57), 크기 64×56 |

뒤에서부터 어두운 등실 내부 → 제한된 온광 → 청동 화로·반사경 → 불꽃 → 철창·창틀 순서입니다. 불꽃은 초당 8장으로 반복하며 모든 장의 바닥을 같은 곳에 둡니다. 강한 불도 창틀 위로 빠져나가지 않는 높이로 정리했습니다. 원본의 빈 공간까지 포함한 전체 칸을 조립 크기로 사용합니다. `manifest.json`의 피벗과 별도의 장착 좌표를 함께 참고합니다.

`previews/lamp_room_*_4x.png`는 불꽃이 없는 조립 예시입니다. 검토 HTML에서는 실제 분리 부품 위에 불꽃을 반복해 보여 줍니다.

## 실제 화면 합성

`mockup_day.png`와 `mockup_night.png`는 각각 실제 226·236 스크린샷의 탑 주변 지정 영역에 생성 그림을 덧댄 1920×1080 목업입니다. 원본과 같은 시점·탑 규모를 기준으로 제작했습니다. 지정 영역 밖은 원본 픽셀 그대로이며, 밤을 전체적으로 밝히지 않았습니다. 지정 영역 좌표는 자료 목록에 기록했습니다.

이 합성본은 조명과 재질의 방향을 보는 그림입니다. 제공한 텍스처를 실제 입체 탑에 붙여 렌더한 화면은 아닙니다. Claude가 연결한 뒤 실제 면의 반복 간격, 원근, 조명 세기를 확인해야 합니다. 선택 사항인 깃발과 갤러리 사슬은 생략했습니다.

## 제작·검증

내장 이미지 생성 도구로 재질·부품·상태 변형·불꽃·스크린샷 합성 원안을 만들었습니다. 픽셀 크기 정리, 알파 정리, 재질 색 단계 제한, 경계 연결, 기준점 맞춤과 최근접 확대를 거쳤습니다. 정적 부품은 공통 22색, 불꽃은 6색으로 제한했습니다. 실제 생성 요청의 한글 정리는 `prompts.json`에 있습니다.

`verification.json`에는 PNG 48개의 크기, 원본 11개 시트의 모든 장의 바닥선과 알파·연결 성분, 정확한 3배 확대, 반복 경계, 지정 영역 밖 목업 픽셀 보존 결과가 있습니다. 반 픽셀 단위의 외곽 중심 차이는 홀수 폭 모양의 정수 픽셀 배치에 따른 것이며 셀 피벗은 고정입니다. 고립 픽셀은 없고 각 프레임은 하나의 연결된 모양입니다.

`review_validation.json`과 `review_*.png`는 실제 브라우저에서 그림 로딩, 반복 재생, 일시정지·한 장 넘기기, 낮·밤 전환, 확대, 휴대폰 폭 표시를 확인한 기록입니다. Unity는 실행하지 않았으며 실제 게임 적용·플레이 확인은 수행하지 않았습니다.
