## 크기와 파일

카드 제목의 크기 미정 표시는 D-081 확정으로 대체했습니다. 고블린 기본 키 약 56점, 원본 칸 96×128, 몸 중심축 x=48, 발 아래 경계 y=120입니다. 마지막 불투명 행은 119입니다. 공격 중 곤봉은 머리 위로 올라가며, 쓰러짐에서는 같은 선을 지면 접촉선으로 사용합니다. 인물 높이를 프레임마다 56점으로 강제하지 않고 같은 축척을 유지합니다.

## 제작과 비교

내장 imagegen 도구로 동작 원안을 생성했습니다. 참조는 K-070의 56점 종족 고블린, K-066 측면 고블린, 사용자 선택 영웅 `generated.png`입니다. 올리브 피부·노란 눈과 흰 반사점·갈색 머리·가죽 조끼·곤봉을 유지했습니다. 영웅의 파란 눈은 고블린에게 적용하지 않았습니다. `prompts.json`에 생성·수정 프롬프트를 보관합니다.

원안은 알파128 기준 이진화, 일정 축척 최근접 축소, K-066 고블린 14색 팔레트 대응, 중심축과 지면 배치로 정리했습니다. 분리된 잔여 픽셀은 제거하며 각 장의 8방향 연결 덩어리가 하나인지 검사합니다. 부위별 변형이나 프레임별 키 맞추기는 하지 않았습니다. 머리·몸통은 동작에 따라 기울며 모든 윤곽선이 정확히 한 점이라는 뜻은 아닙니다.

페이지의 새 그림은 원본 4배입니다. 기존 게임 그림은 인물 높이가 비슷하게 보이도록 최근접 환산하고 지면을 맞췄습니다. 원본 시트 자체는 변경하지 않았습니다. 토벽 타격의 기존 비교는 현재 사용하는 걷기이며 전용 기존 시트는 없습니다. 토벽 모양은 타격 위치를 설명하는 페이지 목업으로 PNG에 들어가지 않습니다. 쓰러짐은 마지막 장을 잠시 유지합니다. 표시 속도는 검토용 180ms이며 게임 재생 시간의 확정이 아닙니다.

## 확인과 연결

`manifest.json`: 칸·피벗·배열·프레임 순서·프레임별 불투명 영역·분리 픽셀 정리 수. `validation.json`: 크기·알파·발선·연결 덩어리·정수 확대·기존 Game 해시 확인. `source_hashes_before.json`: 시작 당시 Game 파일 해시. `build.py`: 원안부터 PNG와 HTML 재생성. Pillow·NumPy가 필요합니다. `verify_review.cjs`: 로컬 Chrome에서 내장 이미지 디코딩·조작·모바일 넘침 확인. 결과와 캡처는 `review_validation.json`, `review_desktop.png`, `review_mobile.png`입니다.

Claude 연결 대상: 기존 `Goblin/goblin_walk_attack4.png`, `Fall/goblin_fall4.png` 교체와 새 `goblin_wallhit4.png` 연결. 파일 이름·장 수·장 순서를 유지했으며 D-081에 따라 기존 게임 칸 256×384를 288×384로 바꿉니다. 가져오기·분할·노멀맵·피벗·게임 타격 시점 연결은 Claude 작업입니다. 기존 노멀맵을 새 그림에 그대로 사용하면 맞지 않습니다. 이 카드에서는 Game 파일·Unity 설정·노멀맵을 변경하지 않았습니다.

Unity 실행·Play·실제 게임 캡처·Git 쓰기는 수행하지 않았습니다. 최종 게임 크기와 토벽 접촉 위치는 연결 후 사용자의 Play 확인이 남아 있습니다.
