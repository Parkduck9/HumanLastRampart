# 결과 상세 표시 구현

- 작성자: Codex / T-CX-020
- 사용자 승인: 결과 상세 구현을 설명한 뒤 “시작하자”. 성벽 수리·스토리 구현 승인은 포함하지 않는다.

요약에는 전투 번호·처치·획득 골드·병력 손실 합계·성벽 피해 합계가 표시된다. 성벽 피해/병력 손실/영웅 상태 버튼으로 각각 상세 창을 열고, 긴 목록은 휠·드래그로 스크롤한다. 닫으면 원래 버튼으로 포커스가 돌아간다. 상세 창이 열리는 동안 뒤쪽 메뉴 입력은 차단한다.

결과 반영은 기존 BattleResultApplier.TryApply를 진입 때 호출하는 방식 그대로다. 상세는 시작 BattleSetup과 LastBattle을 ID로 대조해 만든 문자열이다. 같은 병종의 여러 분대, 전멸해 현재 Campaign에서 지워진 분대도 별도 표시한다. 손실 결과가 없는 분대와 성벽은 변화0, 미참전 영웅은 시작 상태와 미참전 표기를 쓴다. 화면을 닫거나 다시 표시하는 행위는 골드·병력·성벽·실행ID를 변경하지 않는다.

공용 ScreenView/Core/App/씬 수정 없이 Meta 안에 전용 formatter·스크롤창을 추가했다. 창은 기존 ScreenView의 Canvas 아래에 있어 OnExit 때 함께 입력/구독/오브젝트가 정리된다. 새 EventSystem·카메라는 추가하지 않는다. 현재 임시 한글 글꼴과 UI 색을 재사용한다.

검증: 현재 실제 Core/Meta 데이터와 소스로 결과41+표시8=49/49 통과. 전멸분대·같은병종ID·역순결과·10회상세재열기무변경·미참전사망·한글명/최대HP·시작데이터누락 확인. 실제 Unity6.3 Managed/프로젝트 어셈블리 참조로 Meta 전체 csc 컴파일 종료0. 이 검사는 Unity 임포트/Play/실제4K화면·스크롤 조작 검증을 대신하지 않는다.

Claude QA 요청: 실제승리→3개상세버튼→닫기포커스·뒤입력차단→긴분대목록스크롤→다음정비·재진입보상무변경·한글4K잘림 확인. 화면 종료 중 상세가 열려 있어도 오브젝트/선택 해제 확인.

## T-CX-024 M7 참가 규칙 연결 | 2026-10-14 14:04 KST
