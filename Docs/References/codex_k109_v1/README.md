# K-109 · 루멘 파로스 A안 전체 그림

사용자가 고른 K-107 비교판의 두 번째 인물(A안)과 현재 게임 영웅의 체형을 기준으로 만들었다. 밤색 헝클어진 머리, 남색 사관학교 제복과 금장, 크림색 등불지기 망토, 등대 문양, 작은 허리 등불과 망원경을 사용했다. 정면·측면 얼굴에는 눈과 입을 넣었다.

검토 페이지: [루멘 전체 그림](../../../_HTML/6_그림_화면/codex_K-109_루멘전체그림_v1.html). 필요한 그림을 내장했으므로 서버 없이 직접 연다.

`*_native_4x.png`는 전투 원본의 정확한 4배 미리보기이다. 초상과 튜토리얼의 `*_4x.png`는 납품 크기의 정확한 4배이다. 노멀·스펙 원본도 각각 제공한다.

## 재질과 조명

색 그림은 제한 팔레트와 불투명/투명의 두 알파 값으로 정리했다. 노멀맵은 원본 실루엣 안쪽 경계에서 기울기를 계산한 RGB 방식이며, 바깥은 평평한 (128,128,255) 값이다. 기존 노멀맵과 같이 전체 캔버스는 불투명하고 실제 표시 범위는 색 그림의 알파를 따른다. 가져올 때 선형 데이터로 읽어야 한다. 기존 게임 연결과 셰이더 설정 변경은 Claude가 담당한다.

스펙 마스크의 천은 12/255, 금장과 허리 금속은 주로 220/255이다. 등불의 따뜻한 유리색 일부는 150/255이다. 머리와 부츠 영역을 금속 분류에서 제외했다. 발광맵은 요청 범위에 없으며 별도 발광을 구워 넣지 않았다. 노멀과 마스크의 실제 조명 반응은 Unity에서 확인하지 않았다.

## 검토 화면

배경은 실제 `beacon_game_20261022/05_pf_night_clean.png`를 그대로 사용한다. 현재 영웅과 루멘을 같은 위치·같은 크기로 각각 합성하고 인물 RGB에만 0.65를 곱한다. 사진 속 기존 병력과 영웅을 지우거나 벽 구조를 새로 그리지 않았다. 사진은 이미 조명 처리가 된 캡처이므로 배경에 0.65를 다시 곱하지 않는다. 이것은 게임 장면을 활용한 비교 합성이며 새로운 Unity 실행 캡처가 아니다.

후면 걷기·왼쪽 걷기·정면 걷기는 초당 6칸, 달리기는 8칸이다. 지휘는 초당 6칸으로 진행 후 마지막 칸을 유지하고 검토용으로 2초마다 반복한다. 대기는 요청대로 1칸의 정지 그림이다. 브라우저에서 일시정지·한 칸 이동·인물 확대·발선 표시를 사용할 수 있다.

## 제작과 확인

내장 이미지 생성 도구로 원안을 만들고, 정면 입 보완과 초상 얼굴 보완을 각각 수행했다. 생성 원안은 `walk_generated.png`, `walk_final_source.png`, `command_generated.png`, `portraits_generated.png`, `portraits_final_source.png`에 보관했다. 원안에는 불규칙한 픽셀과 반투명이 있으므로 교체에는 위 표의 정리된 PNG만 사용한다. `prompts.json`은 제작 지시, `placement.json`은 추출 영역, `manifest.json`은 배치와 출처를 기록한다.

`pack_assets.ps1`은 본체 분리·최근접 축소·팔레트 정리·정렬·노멀 및 광택 마스크 생성용이다. `build_review.ps1`은 내장형 검토 HTML을 만든다. `verify_assets.ps1`과 `check_review.cjs`는 실제 수행한 수치·코드 검사를 재현한다. 검사 결과는 `validation.json`, `review_validation.json`에 있다.

20프레임의 크기·발선·몸 중심·이진 알파·연결 성분과 색/노멀/스펙의 정확한 3배 확대를 검사했다. PNG를 디코딩하고, HTML에 내장된 이미지와 여섯 동작·일시정지·프레임 이동 코드를 검사했다. 연결 가능한 브라우저가 없어 실제 브라우저 렌더링은 확인하지 못했다. 확대 PNG는 직접 열어 확인했다.

게임 파일·협업 문서·로그는 변경하지 않았다. Unity 실행·게임 연결·실제 플레이·커밋은 하지 않았다. Claude 연결 후 좌우 반전, 보행 전환, 노멀과 광택 반응을 확인하고 사용자의 최종 시각 검토를 받아야 한다.
