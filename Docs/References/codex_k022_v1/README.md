## 사다리병은 K-017과 동일

`references/k017_carry_run4.png`, `k017_deploy4.png`, `k017_climb4.png`와 정면·측면 사다리 소품은 K-017의 바이트 동일 복사본이다. 새 사다리병 외형이나 새 동작은 만들지 않았다. 인물 256×384/기준점128·352, 소품256×1536/하단128·1472를 그대로 유지한다. K-017 노멀맵 견본은 사다리가 없는 운반 자세에만 대응한다.

긴 사다리와 인물을 분리한다. 기존 제안인 사다리 실체1152px=4.3m, 4m성벽, 가로대·손 접점 미검증 사항도 유지한다. K-017 후면 등반 2번의 손 가림과 정면·측면 소품 간 가로대 정합은 이번 카드에서 고치지 않았다.

## 원안에서 격자 시트까지

`build.ps1`은 알파32 초과 실체 경계를 측정하고, 생성 원안에서 프레임을 잘라 최근접으로 비율 유지 축소한 뒤 투명 칸에 배치한다. 한 시트의 4칸은 같은 축소율이다. 고블린과 오우거 쓰러짐은 인접 인물 사이 빈 구간을 수동 분할해 신체 잘림을 피했다. 원안·완성 사각형과 공통 축소율은 `manifest.json`에 기록했다.

공격은 원안 발 높이676을 공통 지면352에 맞췄다. 3번의 곤봉은 발 아래쪽까지 내려오지만 384px 칸 안에 남는다. 쓰러짐은 최종 실체 바닥을352에 맞췄다. 픽셀 색을 다시 칠하거나 도형으로 캐릭터를 만들지 않았다. 경계 자르기에서 매우 낮은 알파의 바깥 잔광은 제외될 수 있다.

## 노멀맵 처리와 한계

노멀 원안 실체 경계를 각 색 그림의 알파 경계에 맞춘 후 같은 캔버스에 최근접 대응했다. 색 알파32 이하 영역은 정확히 RGB(128,128,255), 실체 영역은 XY세기0.55로 약하게 만들고 3성분을 단위벡터로 재정규화했다. R=오른쪽, G=위쪽, B=정면의 +Y 견본이며 RGB PNG 자체는 불투명하다. 실제 실루엣은 함께 보관한 `references/*_albedo.png`의 원래 알파를 사용한다.

색과 노멀의 외곽·칸 일치는 내부 부위의 정밀 일치를 보장하지 않는다. 눈·코·손·가죽 주름의 대응은 근사이며 3D 모델에서 베이크한 자료가 아니다. 노멀의 실제 조명 방향과 빌보드 접선, 좌우 반전, 색에 이미 그려진 명암과의 중복은 게임 연결 후 확인해야 한다. 이번 카드의 직접 지시대로 적3종 **한 자세씩만** 만들었다. 다른 자세 노멀은 없다.

## 검토 페이지

`_HTML/codex_K-022_적동작_v1.html`과 `preview.html`은 같은 독립 HTML이다. PNG 14종·스타일·스크립트를 내장하며 서버나 외부 라이브러리가 필요 없다.

- 새 동작3종/K-017동작3종 선택, 재생·정지·처음부터·이전/다음·프레임 이동, 4/6/8칸 속도, 배경3종, 발 기준선.
- 전체4칸 나란히 보기, K-017 정면/측면 소품 보기.
- 적3종 색/노멀/조명 비교, 광원 좌우·높이, 평면노멀 비교. CPU Lambert 근사이며 URP와 동일한 출력이 아니다.

재생성 순서: `build.ps1` → `build_viewer.ps1` → `verify.ps1`. Windows PowerShell과 System.Drawing만 사용한다. 원안과 기존 K-017 경로가 함께 있어야 한다. 원안의 구도가 달라지면 분할 좌표도 다시 확인해야 한다. `game_before.json`은 수정 전 Game 파일594개의 비교 기준이다.

## 확인한 것과 남은 것

정적 검사46개 통과(`qa.json`): 시트크기·각칸실체·가장자리여백·4칸차이·투명배경·해시, 노멀크기·빈영역평면색·단위벡터오차0.012이하, K-017복사일치, HTML내장14종과사본일치, Game594개 파일해시·수동 파일수비교. 원안6장과 최종6장도 직접 열어 확인했다. Game에 추가·변경·삭제 없음.

CUA의 브라우저 목록이 비어 있어 **HTML 실제 브라우저 로드·재생·조명 조작·모바일 배치·콘솔 검증은 미수행**이다. HTML 정적 검사와 실제 브라우저 시험을 구분한다. Unity는 열거나 실행하지 않았다. Git 쓰기도 하지 않았다.

사용자 검토가 남았다. 새 고블린 첫 칸 실체높이211px(기존 걷기240px), 오우거 공격 첫 칸201px/들기261px, 쓰러짐 첫 칸187px이다. 기존 오우거 정지 그림173px과 걷기 그림의 크기도 다르다. 눕는 몸의 폭과 들어 올린 곤봉을 같은 칸 안에 넣은 결과이므로, 실제 전환에서의 크기·발 위치·타격점·손잡이 파지·최종 가독성을 확인하고 필요하면 원안을 보완해야 한다. Game 연결은 사용자 확정 뒤 Claude 담당이다.
