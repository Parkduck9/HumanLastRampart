01 / 동작을 비교하세요

새 그림 3장과 K-017의 기존 그림 3장을 같은 256×384 칸으로 확인합니다.

공격·달리기·등반은 반복합니다. 쓰러짐과 세우기는 4번에서 멈춥니다. 쓰러짐은 바닥, 등반은 이동 참조점입니다.

최근접 축소 · 그림 전체 비율 유지 · 같은 시트의 4칸은 공통 축소율 사용

왼쪽부터 1 → 2 → 3 → 4 · 새 시트는 1024×384 RGBA · 기존 시트 덮어쓰기 없음

K-017 사다리 소품과 연결 시 주의

운반·세우기·등반 그림은 K-017 원본과 바이트가 같습니다. 아래 긴 사다리는 별도 소품이며 인물 시트에 합치지 않습니다.

소품 256×1536 / 하단 (128,1472). 실체 1152px=4.3m 제안. 손·가로대 접점과 실제 4m 성벽 걸침은 미검증입니다. 이번 카드에서 새 사다리병 동작은 추가하지 않았습니다.

02 / 표면이 빛을 받는 방향

적마다 한 자세의 견본만 제작했습니다. 아래 조명은 검토용 계산이며 실제 게임 조명과 다릅니다.

노멀 원안의 실체 경계를 색 그림에 맞추고 원래 알파로 제한했습니다. 눈·손·옷 주름의 내부 대응은 근사입니다. 정밀한 3D 베이크가 아니며, 원래 색 그림에 그려진 명암도 남아 있습니다.
