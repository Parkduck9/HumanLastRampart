# K-140 루멘 측면 달리기 시안

왼쪽을 향한 루멘의 측면 달리기 네 자세를 한 줄에 생성한 투명 배경 콘셉트 이미지입니다. 현재 게임 시트와 K-139 시안을 외형 참고로 사용했고, 이전 흰머리 시트는 동작 참고로만 사용했습니다. 게임용 셀에 맞춘 이미지가 아니며 크기 조정과 픽셀 정리, 배치는 후속 작업입니다.

검토할 점: 뒤쪽 부츠의 발끝과 굽이 일부 자세에서 충분히 분명하지 않고 팔의 교차 움직임도 네 자세 사이에서 뚜렷하지 않습니다. 배경 가장자리에 미세한 반투명 픽셀이 있어 정리가 필요합니다. 이 이미지는 완성된 게임용 애니메이션이 아닌 시안입니다.
