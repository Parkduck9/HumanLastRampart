# 빛을 잇는 자들 · Microsoft Store 그림 1.0

[스토어 그림 검토 페이지](../../../_HTML/6_그림_화면/codex_K-130_스토어그림_v1.html)는 그림을 모두 내장하므로 서버 없이 열 수 있습니다. 하단 1/3 가림을 켜고 끌 수 있으며 모든 제출 이미지는 ‘실제 크기 보기’로 픽셀 크기 그대로 확인합니다. 가림 표시는 납품 그림에 포함되지 않습니다.

## 제출 파일

|---|---|---|

| `store/poster_720x1080.png` | 720×1080 | 작은 포스터 |
| `store/box_2160x2160.png` | 2160×2160 | 정사각 대표 표지 |
| `store/box_1080x1080.png` | 1080×1080 | 작은 표지 |
| `store/super_hero_3840x2160.png` | 3840×2160 | 글자 없는 가로 전경 |

제출용 PNG는 총 25개입니다. `targetsize`는 실제 픽셀 크기이므로 `scale`과 같은 파일명에 섞지 않았습니다. 요청한 16·24·32·48·256px와 그 두 배에 해당하는 32·48·64·96·512px를 중복 없이 8개로 제공합니다. 일반 로고 5종은 배율 100%·200%를 모두 포함합니다. 작은 크기는 최근접 방식이며 작은 그림에 새 세부 묘사를 추가하지 않았습니다.

모든 PNG에 sRGB 프로필을 내장했습니다. `store/`는 모두 불투명입니다. 정사각 패키지 로고와 무배경 아이콘은 기존 K-124 전경의 투명도를 유지합니다. 가로 로고와 시작 그림은 어두운 불투명 배경입니다. 운영체제가 붙이는 마스크·테두리는 굽지 않았습니다.

## 그림과 제목

루멘의 은발·큰 머리·검정 생도복·금색 테두리·큰 갈색 장화와 K-124의 철창 등실을 따랐습니다. 실제 메뉴의 네 변 성벽·낮은 붉은 지붕 건물·중앙 봉화를 참고했습니다. 전경의 적은 고블린과 K-128/K-129 성벽손 오우거의 긴 팔·쇠장갑 실루엣을 사용했습니다. 봉화의 따뜻한 빛과 루멘의 작은 등불이 밤의 중심입니다.

포스터와 정사각 표지는 각각 독립 구도로 생성했습니다. 가로 전경은 사방에서 접근하는 적과 요새를 높은 시점에서 보이는 홍보용 그림입니다. 실제 플레이 캡처나 게임 화면 교체물이 아닙니다. 하단 1/3에는 제목·루멘·봉화 등 핵심을 놓지 않았으며 어두운 성벽·안개·종속적인 적 실루엣만 남겼습니다.

제목은 생성 모델에 맡기지 않고 정확한 문자열 **빛을 잇는 자들**을 로컬 맑은 고딕 굵게의 1비트 마스크로 찍은 뒤 최근접 확대했습니다. **빛 · 을 · 잇 · 는 · 자 · 들**을 확대 확인했고, 영문은 **LIGHTBEARERS**입니다. 글꼴 파일은 재배포하지 않습니다. 두 표지의 한글·영문 각 글자 아래 실제 배경 픽셀 전체를 검사한 최소 대비는 **16.5138:1**입니다. 제목은 상단 2/3 안에 있습니다. 가로 전경에는 문자·로고·화면 표시가 없습니다.

논리 원본은 포스터 360×540, 정사각 540×540, 가로 960×540입니다. 큰 제출 그림은 정확한 4배, 작은 제출 그림은 정확한 2배 최근접 확대입니다. `native/`는 논리 원본, `previews/*_4x.png`는 정확한 4배 확인 그림입니다. 인물용 게임 시트를 교체하지 않으므로 96×128 칸·발 기준선·움직임·피벗은 적용하지 않습니다.

## 제작 기록과 검사

- `sources/`: 최종 채택 생성 원안 3개. 제출용이 아닙니다.
- `prompts.json`: 내장 이미지 생성 도구의 실제 요청과 조명 보정 요청.
- `manifest.json`: 모든 납품 파일의 크기·용도, 그림 해시, 투명도, 배율, 제목 정보.
- `verification_assets.json`: 크기·sRGB·불투명·정확한 4배 확대·제목 대비 검사.
- `verification_browser.json`, `previews/review_*.png`: 실제 브라우저에서 검토 페이지 로딩·가림 토글·원본 보기·화면 맞춤·작은 화면 검사.

내장 이미지 생성 도구로 그림을 생성·보정하고, 제목 합성·색 정리·지정 크기 변환은 Pillow로 처리했습니다. 픽셀을 흐리는 보간과 자동 디더링은 사용하지 않았습니다. 제작 전 [픽셀 확대 원칙](https://developer.mozilla.org/en-US/docs/Games/Techniques/Crisp_pixel_art_look)과 [Microsoft Store 그림 안내](https://learn.microsoft.com/en-us/gaming/game-publishing/concepts/store-listing)를 읽고 이번 카드의 금지 항목을 `CARD_RESULT.md` 첫머리에 기록했습니다.

게임 폴더·기존 문서·협업 기록은 수정하지 않았습니다. Unity 실행과 Git 쓰기는 하지 않았습니다. 클로드가 패키지 파일 연결·스토어 슬롯 지정·최종 등록 화면에서의 표시 확인·커밋을 수행해야 합니다.
