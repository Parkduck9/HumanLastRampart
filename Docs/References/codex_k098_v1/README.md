# K-098 · 소품·대포 광택 마스크와 접촉 그림자

43개 현재 게임 시트(62프레임)에 맞는 반사 마스크·노멀 연결표와 접촉 그림자 5종을 제공한다. Game/ 파일과 원색 그림은 수정하지 않았다. Unity 실행과 Git 쓰기도 하지 않았다.

검토 화면: [접촉 그림자·광택](../../../_HTML/6_그림_화면/codex_K-098_접촉그림자광택_v1.html). 이미지 134개를 모두 내장했으므로 서버 없이 직접 연다. 그림 선택, 원본·마스크·노멀·계산 조명의 동시 프레임 재생, 일시 정지·다음 칸·광택 켜기·빛 회전을 제공한다. 실제 Unity 캡처가 아닌 계산 견본이다.

대포 폴더의 모든 색 PNG, 대체 대포 `cannon_aim3`, 횃불대·함정 1/2를 포함한 Props 전체를 검사했다. 바위·참나무·소나무·덤불뿐 아니라 시체 더미, 땅 장식, 방패·무기·표지판도 포함한다. 선택 항목인 벽 albedo는 생략했다.

K-092의 포 반동·운반 병사 마스크 3개는 현재 원본과 해시 또는 알파가 달라 새로 만들었다. 기존 파일은 보존했다. 재사용 파일은 `manifest.json`에 정확한 저장소 상대 경로를 기록했다. 이 폴더만 이동하면 재사용 자산 경로가 끊기므로 Claude는 manifest의 경로를 기준으로 가져와야 한다.

## 채널과 가져오기

- R = 반사 강도, G = 매끄러움, B = 0, A = 원본 알파 바이트 그대로.
- 무광 목재·천·피부·흙·잎: 13/26. 가죽: 77/64. 습기 있는 돌: 105/96. 거친 철: 242/140. 밝은 철: 255/191. 금색 장식: 255/217. 연기·그을음: 0/0.
- 색·재질 분류에 따라 목재와 잎은 낮게, 회색 철 부품은 높게 지정했다. 바위의 녹색 이끼는 낮은 반사값을 유지한다. 돌의 습기는 정적인 재질 견본이며 날씨 상태를 표현하는 추가 채널은 없다.
- 마스크: Default, sRGB 끄기, Point, Clamp, 밉맵 끄기, 압축 없음. Normal map 형식으로 가져오지 않는다.
- 노멀: +X 오른쪽 / +Y 위 / +Z 관찰자, 투명 RGB 128·128·255. 초록 채널 반전 없음. RGB를 직접 해석하는 셰이더는 Default·선형·Point·압축 없음으로 사용한다. Unity Normal map 형식으로 가져오려면 셰이더의 디코딩과 맞춰야 한다.
- 새 노멀은 K-081과 같은 계열의 실루엣 Gaussian 반경 2·5 및 약한 밝기 요철로 계산한 근사값이다. 칸마다 따로 계산해 이웃 프레임의 영향을 막는다. 3D 베이크나 재질별 실제 기하 형상 복원은 수행하지 않았다.

## 크기·격자·부착점

이번 카드의 명시적인 1:1 조건을 적용했다. 소품·대포를 인물용 96×128 / 288×384 셀로 재배치하지 않는다. 새 마스크·노멀의 크기, 프레임 순서, 알파, 프레임별 경계와 바닥선은 현재 원색과 동일하다. 원본의 기존 고립 픽셀은 임의로 지우지 않으며, 새 알파 픽셀은 추가하지 않았다.

정수 최근접 축소가 바이트 단위로 정확할 때만 `native/`에 작은 격자를 제공했다. 그 외 자산의 native는 현재 원본 해상도 그대로다. manifest의 `native_scale`로 원래 게임 크기를 복원한다. `mask`와 `normal`이 게임용 1:1 경로이고, `native_mask`와 `native_normal`이 격자 원본이다. 4배 미리보기는 이 격자 원본의 정확한 최근접 4배다.

운반 병사 현재 PNG는 1728×384, 288×384 셀 6프레임, 발 기준 (144,360)이다. 기존 `CannonArt.cs` 및 K-092의 384px 셀 표기는 구형이다. **Claude는 연결 시 이 불일치를 수정해야 한다.** 이번 카드에서 Game 코드는 수정하지 않았다. 포 반동은 256×256 셀 3칸, 연기는 256×256 셀 6칸, `cannon_aim3`은 512×384 셀 3방향이다. 운반 본체·포가는 768×384 단일 이미지, 바퀴는 101×101이다. 기존 부착점을 manifest에 보존했다. 소품에는 신규 피벗을 임의 지정하지 않았다.

## 그림자 권장 시작값

| 크기 | 기준 해상도 → 납품 2배 | 권장 지면 판 폭 | 권장 깊이 |
|---|---|---:|---:|
| 병사 | 64×32 → 128×64 | 0.38 m | 0.19 m |
| 오우거 | 128×64 → 256×128 | 0.85 m | 0.425 m |
| 대포 | 160×64 → 320×128 | 0.75 m | 0.30 m |
| 사다리 운반 2인 | 192×64 → 384×128 | 1.10 m | 약 0.367 m |
| 작은 소품 | 48×24 → 96×48 | 0.30 m | 0.15 m |

모두 검정 RGB, 타원 내부 알파 `170 × (1 − 반지름²)²`, 바깥 알파 0이다. 중심 알파는 약 170/255, 권장 재질 불투명도는 0.65로 시작한다. K-088과 같은 검정 일반 알파 합성 `SrcAlpha OneMinusSrcAlpha`, Bilinear / Clamp / 압축 없음 / 밉맵 끄기를 권장한다. RGB만 곱하면 검정 사각형이 되므로 알파를 적용한다. 중앙 피벗 (0.5,0.5), 지면 XZ에 놓고 깊이 충돌을 피한다. PNG를 다시 원근 압축하지 않는다. 폭은 시작 제안이며 실제 카메라와 유닛 축척에서 Claude가 확인한다.

## 재현·검사

Node.js 기본 모듈만 사용한다. `node Docs/References/codex_k098_v1/build_assets.cjs`로 재생성하고 `node Docs/References/codex_k098_v1/verify_assets.cjs`로 저장된 PNG를 다시 검사한다.

`manifest.json`은 원본→마스크→노멀 경로·SHA-256·크기·셀·프레임·기존 부착점·각 프레임 알파 경계·바닥선과 검증표를 담는다. `validation.json`에는 크기·알파 완전 일치, B=0, 투명 RGB, 단위 법선, 손실 없는 격자 왕복, 정확한 4배 미리보기, 그림자 대칭·연속성·테두리·단조 감쇠 검사 결과를 담았다.

검토 HTML에 `?verify`를 붙이면 내장 이미지 디코딩, 모든 62프레임 렌더링, 일시 정지·재생·다음 칸을 검사한다. Chrome headless로 실행한 결과는 `browser_validation.json`, 직접 확인한 화면은 `review_desktop.png`다. Unity 실행·실제 재질 조명·좌우 반전·최종 광택·발밑 지면 배치는 검증하지 않았다.
