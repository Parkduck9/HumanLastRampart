## 채택한 방향

주인공 v6의 작은 머리·작은 눈, 또렷한 어깨/몸통/다리, 절제된 금장과 픽셀 명암을 새 외형 기준으로 선택했다. v4/v5와 첫 실패 생성 generated.png가 아니라 **corrected.png 및 hero_idle_56x112.png의 방향**이다. 전후 HTML의 오른쪽 v6를 가리킨다.

같은 방향을 궁수·총병·대포병·마법사 및 적 캐릭터에도 적용한다. 각 병종의 확정된 머리색·복장·무기, 주인공과의 구분은 유지한다. 인간형의 과도한 머리 비중을 줄이는 원칙을 공유하되 고블린/오우거의 종족·체격·게임 내 크기 차이를 없애거나 모두 동일 등신으로 강제하지 않는다.

## Claude에게 요청할 게임 연결

1. 주인공 v6를 기준으로 기존 캐릭터의 새 외형 적용을 진행한다. 우선 실제 카메라/배경에서 크기·가독성·투명 가장자리를 비교한다.
2. 검토 PNG는 56×112/인물96px/발y104이며 기존 게임 계약 256×384/발128,352와 다르다. 소비 코드에 단순 덮어쓰지 말고 기존 칸·피벗/표시 키·재질·노멀 정합성을 유지해 변환한다. 새 계약 변경은 별도 검토한다.
3. 현재 v6는 비스듬한 앞모습 정지 한 장뿐이다. 기존 뒷모습/측면/걷기/달리기/명령/사격/시전/피격·쓰러짐 시트를 같은 방향으로 새로 만들어 일관성을 맞춘다. 정지 한 장을 모든 방향/프레임에 반복해 완료로 기록하지 않는다.
4. 다른 캐릭터는 병종별 새 정지 기준 그림 → 사용자가 확인 가능한 비교 MD/HTML → 해당 동작 시트/노멀 준비 → Claude 게임 연결 → 실제 화면 비교 순서다. 이번 선택은 공통 방향 승인이지 아직 만들지 않은 개별 그림의 자동 품질 승인이나 동작 제작 완료가 아니다.
5. generated/corrected 원안에 남은 미세 광택, 저해상도 변환 때 눈/금장 정보 손실은 연결 전 점검한다. 실게임 비교 전 옥토패스와 동일 품질로 검증됐다고 선언하지 않는다.
