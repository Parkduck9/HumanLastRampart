공식 페이지는 도트 캐릭터에 3DCG 화면 효과를 결합하는 방향을 설명한다. 브라우저로 공식 장면도 열어 확인했지만 작은 썸네일이라 원본 스프라이트 정확한 화소/팔레트/등신 수를 계측할 수 없다. 공식 배경용 field_command 이미지 둘은 흐릿한 장식 그림이라 픽셀 계측 근거로 제외했다. 아래는 육안 비교와 우리 제작 목표이며 원작 수치라고 주장하지 않는다.

## 이전 결과 판정

v4는 긴 일러스트 인체/세부 금장 위주로 게임용 실루엣에서 멀어졌다. v5는 작은 PNG를 제공했지만 고해상도 생성 그림을 최근접 축소한 것으로, 픽셀 격자를 처음부터 설계한 것과 다르다. 48px 시험은 눈이 사라졌고 64px에도 얼굴/금장 표현이 거칠고 몸이 가늘다. 따라서 옥토패스와 동일한 품질/형태로 검증 완료했다고 할 수 없다.

## 새 제작 목표

인물 약3등신의 더 단단한 실루엣, 머리/머리카락 축소, 몸통/종아리 폭 확보, 작은 눈, 절제된 금장, 큰 덩어리의 머리 명암. 백발·검금 장교복·갈색 장화 유지. 원작 캐릭터 자체를 복제하지 않고 독자 주인공을 재설계한다. imagegen으로 새로운 정지1칸을 생성하며 원안/정확프롬프트/규격을 보관한다. Game 적용과 애니메이션은 범위 밖.

## 검증 경계

생성 프롬프트의32×48 격자/24색/3등신은 목표이며 모델 출력에서 자동 달성했다고 기록하지 않는다. 결과를 직접 보고 머리·몸통·다리 실루엣과 작은 표시 가독성을 비교한다. 기술적인 크롭과 확대만 허용하고 단순 축소만으로 게임용 완성도 보장을 선언하지 않는다.
