# K-106 등대 빛줄기

등대가 북·동·남·서 가운데 한 방향을 비추는 기능을 위한 그림 자료입니다. 설계 근거는 `Docs/GDD/Concept_Beacon_v1.md` 9.4장입니다. Game/ 변경과 Unity 실행은 하지 않았습니다. 모든 그림은 신규 에셋이며 기존 게임 시트 대체는 없습니다.

## 구성

- `native/beam_40.png`, `beam_60.png`, `beam_80.png`: 부드러운 경계의 따뜻한 지면 광원, 전체 각도 40·60·80도.
- `native/shimmer_40.png`, `shimmer_60.png`, `shimmer_80.png`: 폭별 먼지·일렁임 6프레임. 왼쪽부터 0~5, 초당 6프레임으로 1초 반복. 먼지 위치는 고정하고 밝기를 주기적으로 바꿔 마지막과 처음을 연결합니다.
- `native/beam_head_north.png`: 회전형 렌즈 광원 한 장. K-102 불꽃과 겹쳐 사용합니다.
- `game/`: 위 원본 시트의 정확한 최근접 3배 확대판.
- `map/`: 반투명 지도용 40·60·80도 부채꼴, 각각 96×96.
- `ui/`: 48·64화소 방위 단추, 나침반, 3폭 표시와 9분할 테두리. 방위 시트는 북·동·남·서 순서입니다. 비활성은 어두운 무광, 선택은 금빛 면, 회전 중은 끊긴 원호입니다. 회전 중 그림은 고정된 상태 표식이며 회전 동작은 연결 코드가 처리합니다.
- `previews/`: 각 원본과 UI·지도 아이콘의 최근접 4배 확대판.
- `mockup_north_high_1920x1080.png`: 북쪽·강 밝기의 야간 합성 목업. 빛 안과 밖의 적을 밝기로 구분하고 K-103 안개 경계를 사용했습니다. 실제 실행 캡처가 아닙니다.
- `manifest.json`: 이미지별 크기, 칸, 회전축, 순서, 합성 방식.
- `sources.json`: 읽어 사용한 기존 그림의 SHA-256. 생성 전후 동일 여부를 검증합니다.

## 지면 빛줄기 연결

| 항목 | 원본 | 게임판 |
|---|---|---|
| 칸 크기 | 384×256 | 1152×768 |
| 탑 중심 회전축 | (192,248) | (576,744) |
| 지면 반경 | 232화소 | 696화소 |
| 반경 기준 거리 | 약 60m | 약 60m |

좌표는 왼쪽 위가 (0,0)입니다. Unity 정규화 회전축은 아래쪽 원점 기준 (0.5, 0.03125)입니다. 전체 사각 평면은 약 **99.31×66.21m**이며, 회전축을 탑의 지면 중심에 맞춥니다. 북쪽은 텍스처 위쪽입니다. 평면을 지면에 눕혀 배치하고 카메라가 투영하도록 합니다. 그림 자체에 원근을 굽혀 넣지 않았습니다. 지면과 같은 깊이로 놓아 깜박이지 않도록 높이는 연결 담당이 정합니다.

세 폭의 크기·거리·회전축은 같습니다. 폭은 전체 각도이며 좌우 각도는 절반입니다. 경계는 각도 안쪽 3도, 반경 안쪽 18화소 구간에서 줄어듭니다. 판정 경계 바깥에는 광원 픽셀이 없습니다. 물리적 판정 경계 자체를 보여 주는 조준선은 아닙니다.

빛줄기·먼지·렌즈는 **직선 알파 RGBA + SrcAlpha / One** 가산 합성을 전제로 합니다. RGB에 알파를 미리 곱하지 않았습니다. 먼지도 같은 평면과 회전축을 쓰며, 현재 밝기에 맞는 폭의 먼지 시트 하나만 겹칩니다. 알파가 0인 픽셀의 RGB는 0입니다. 작은 떨어진 먼지 덩어리는 의도한 입자입니다.

이미지 좌표에서 시계방향 북 0 / 동 90 / 남 180 / 서 270도입니다. Unity XZ 평면 방향과 회전 부호는 프로젝트 축에 맞게 변환해야 합니다. 방향을 고른 뒤 3초 동안 회전시키는 기능과 적 약화 판정은 Claude가 구현합니다. 동시에 두 빛줄기를 켜는 동작은 의도하지 않았습니다.

## 렌즈와 지도

렌즈는 원본 96×128, 회전축 (48,42), 게임판 288×384, 회전축 (144,126)입니다. K-102 화로의 같은 좌표에 맞춥니다. Unity 정규화 축은 (0.5, 0.671875)입니다. 탑 발 기준 (48,120)에 맞추면 렌즈가 어긋납니다. 빌보드의 회전과 지면의 회전은 카메라 투영이 다르므로 연결 시 별도로 맞춰야 합니다. 검토 페이지의 렌즈 회전은 방향 개념을 확인하는 예시입니다.

지도 부채꼴의 축은 (48,90), 반경은 68화소입니다. 범위 60m를 지도 축척에 맞춰 확대하고 탑 아이콘 중심에 맞춥니다. 일반 알파 합성입니다.

## UI

기존 `Art/UI/Resources/HudArt/Map/compass_back.png`의 어두운 바탕과 황동색 테두리를 따랐습니다. 한글 방위를 넣어 글자를 회전시키지 않고 각 단추를 따로 배치할 수 있습니다. 단추 시트 네 칸은 북·동·남·서이며 애니메이션이 아닙니다. 폭 표시 세 칸은 약 40도·보통 60도·강 80도입니다. 나침반은 틀/바늘을 그린 보조 표식이고 방위 선택은 네 단추가 담당합니다.

9분할 틀은 48·64화소 모두 왼쪽·아래·오른쪽·위 경계 8화소이며 중앙은 투명합니다. 최소 24×24 이상에서 사용합니다. UI 크기는 원래 요청대로 48·64화소이고 별도 게임용 3배판은 만들지 않았습니다.

## 검토와 확인 범위

검토 페이지: `_HTML/6_그림_화면/codex_K-106_등대빛줄기_v1.html`. 그림을 모두 내장해 서버 없이 직접 열 수 있습니다. 폭별 먼지 반복, 재생 정지, 방위 선택 시 3초 전환, 폭 선택, 기존 게임 시트와 비교를 제공합니다.

이 카드는 인물을 새로 제작하지 않았습니다. 지면·렌즈·지도·UI에는 인물 발선 검사를 적용하지 않고 고정 회전축과 칸을 검사합니다. 목업의 적은 K-070 승인 고블린 자료를 재사용했습니다. 실제 전투 카메라의 60m 투영, 지면 깊이, 적 실시간 조명, 약화 수치는 Unity 연결 후 확인해야 합니다.

재생성: `node Docs/References/codex_k106_v1/build.cjs` → `node Docs/References/codex_k106_v1/verify.cjs`. 기존 K-102 PNG 유틸리티와 설치된 Playwright를 읽어 사용합니다. 실행 결과는 이 카드 출력 폴더와 지정 검토 HTML에만 기록합니다.

2026-10-22 검사 결과: 명세에 등록된 PNG 60개 크기·RGBA·투명 영역 RGB 0, 원본/게임판의 최근접 3배 일치, 지면 각도·반경과 고정 회전축, 서로 다른 먼지 6프레임, 의도하지 않은 분리 픽셀 없음, 기존 참조 파일 해시 일치를 확인했습니다. 브라우저에서 내장 그림 전체 로드, 먼지 재생·정지, 폭 3개 선택, 회전 중 단추 잠금, 2.7초 시점 회전 유지와 3.1초 시점 완료를 확인했습니다. 1440화소 데스크톱·390화소 모바일 화면을 저장하고 직접 보았으며 가로 넘침과 자바스크립트 오류가 없었습니다. 세부 결과는 `verification.json`, `review_validation.json`에 있습니다.
