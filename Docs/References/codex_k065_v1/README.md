## 추가 직측과 정정 (2026-10-20)

위 초기 측정의 **22.44화소는 키52점에 맞추는 환산 간격**이다. 원본 고유 격자의 점 간격이라는 뜻으로 사용하지 않는다. 원본의 강한 색 경계를 직접 분석하면 머리 부분의 경계 y=240,256,273,289,305,322,339,355,371,387에서 간격은 주로16~17화소다. 원본 전체를 최근접64×96으로 축소한 고유 격자 추정본의 인물 키는 약73점, 머리는 약24점이며 비율은 약33%다. 생성 그림이므로 전 구간에 완벽하게 일정한 격자가 존재한다고 단정하지 않는다.

납품 그림은 카드에서 요청한 **인물 키52점·머리 약17점·외곽선 약1점**으로 통일한다. 즉 원본 고유 격자 추정과 납품 비교 규격을 구분한다. 주인공은 새로 그리지 않고 첫 생성본을 최근접 축소해 비교에만 사용했다. 원본의 알파128 경계499×1167화소와 머리 구간 y≈224~610은 처음 측정과 같다.

검토 페이지는 지정된 `_HTML/4_그림_캐릭터/codex_K-065_아군6판_다시_v1.html`이며 그림과 스타일·스크립트를 모두 내장한다. 1배·4배에서 같은52점 높이·같은 발선을 사용한다. 앞뒤는 각각 생성한 참고 그림이므로 머리 모양과 장비 주름에는 차이가 남을 수 있다. 이 카드는 동작 시트·노멀·게임 연결·Unity 실행·실제 전투 검증을 포함하지 않는다.
