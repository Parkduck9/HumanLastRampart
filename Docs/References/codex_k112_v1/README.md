## 제작 기준

- 05_pf_night_clean.png를 편집 대상으로 삼고 06_pf_night_hud.png, 07_pf_map_full.png로 화면과 요새 방향을 확인했습니다.
- 광선 폭·등불 밝기는 고정하고 출력만 커지는 연출 의도입니다. 감쇠 때문에 보이는 빛길 폭은 달라집니다. 백분율은 게임 조도 측정값이 아닙니다.
- 따뜻한 광원, 어두운 비조명 영역, 빛을 등지는 긴 그림자, 병사와 성벽의 선명한 윤곽을 강조했습니다.
- 전장에 고블린 세 개를 연출용으로 추가하고 기존 왼쪽 화염을 약화했습니다.
- 내장 이미지 생성 도구로 제작했습니다. 생성 크기 1672×941에서 1920×1080으로 최근접 크기 조정했습니다. 색과 조명 표현을 포함한 참고화이며 배포용 픽셀 시트가 아닙니다.
- 외부 조명 사진은 분위기만 참고했고 산출물에 복제·동봉하지 않았습니다.

## 확인 범위와 남은 것

이 북쪽 성벽 카메라에는 마당과 등대 탑이 보이지 않습니다. 따라서 마당 밝기와 탑 꼭대기 뒤 섬광은 직접 검토할 수 없습니다. 100% 아래쪽 광원 유입은 화면 밖 점화의 암시입니다. 해당 연출을 판단하려면 실제 마당·탑이 보이는 같은 게임의 캡처가 필요합니다.

40%의 흔들림은 정지 순간이며 시간에 따른 깜박임을 검증하지 않았습니다. 자동 비교는 세 정지화 교체이며 실제 광선 동작이 아닙니다. 생성 편집 특성상 원본 픽셀이 완전히 동일하지 않습니다.

PNG 크기와 전체 불투명 알파를 검사하고, 각 참고화와 비교 띠를 직접 확인했습니다. 프레임·발 기준·피벗·4배 스프라이트 미리보기는 정지 전투 참고화에 적용하지 않습니다. 유니티 실행, 게임 조명 연결, 플레이 검증은 하지 않았습니다.
