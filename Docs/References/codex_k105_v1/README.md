# 빛을 잇는 자들 · 제목과 이야기 배경

K-105의 가제 제목 로고와 정지 배경입니다. 사용자 카드 지시와 `Concept_Beacon_v1.md` 1·3·5장을 바탕으로 제작했습니다. 주인공 재설계는 이 카드에 포함하지 않습니다.

## 완성 그림

| 파일 | 크기 | 용도 |
|---|---|---|
| `title_logo_1600x560.png` | 1600×560 | 큰 제목 · 투명 RGBA |
| `title_logo_800x280.png` | 800×280 | 작은 제목 · 투명 RGBA |
| `main_menu_dark_1920x1080.png` | 1920×1080 | 검은 안개 바다 위 등불탑 · 왼쪽 메뉴 여백 |
| `story_fog_tide_1920x1080.png` | 1920×1080 | 도시를 삼키는 검은 안개 해일 |
| `story_dead_beacon_1920x1080.png` | 1920×1080 | 해 질 녘 폐허 요새에 도착하는 원정대 |
| `story_relit_beacon_1920x1080.png` | 1920×1080 | 같은 요새의 재점화 · 빛기둥과 갈라지는 안개 |

배경은 모두 불투명 RGBA입니다. 이야기 배경의 하단 1/3(위에서 y=720~1079)은 대사창을 위한 낮은 대비 영역입니다. 초상은 게임에서 앞에 배치하며 그림에는 포함하지 않았습니다. 요새 장면의 사람은 작은 원정대 실루엣뿐이고 얼굴·주인공 복장은 식별할 수 없습니다.

## 검토

저장소의 `_HTML/6_그림_화면/codex_K-105_제목과이야기배경_v1.html`을 직접 여세요. 필요한 그림은 전부 내장되어 서버나 인터넷이 필요 없습니다. 현재 게임의 `ScreenArt/main.png`와 새 배경을 나란히 비교합니다. 현재 인트로 장면도 같은 기존 배경을 참조합니다. 기존 그림에 있는 주인공은 비교 자료이며 새 그림에 사용하지 않았습니다.

‘배치 예시’는 메뉴·초상 자리·대사창을 가리는 영역을 확인하기 위한 검토용 표시입니다. 실제 UI나 Unity 캡처가 아닙니다. ‘점화 전후 자동 비교’는 두 정지 배경을 2초마다 전환합니다. 동작 시트나 게임용 애니메이션은 만들지 않았습니다.

## 제작 자료와 전달

- `sources/`: 내장 imagegen 도구로 생성한 원안 5장. 점화 장면은 폐허 요새 원안을 참조하여 생성했습니다.
- `previews/`: 완성 배경 4종과 작은 로고의 4배 최근접 확대 PNG.
- `prompts.json`: 사용한 최종 프롬프트. `generation.json`: 원안 생성 경로 기록.
- `manifest.json`: 완성 크기·알파·중앙 피벗·정지 프레임 정보. `build.py`: 원안 복사, 최근접 크기 변환, 자료 및 검토 페이지 생성.
- `review_validation.json`, `review_*.png`: 브라우저 확인 결과와 검토 화면.

배경 원안은 1672×941이며 1920×1080으로 최근접 변환했습니다. 제목도 동일한 원안에서 비율을 유지해 두 크기로 내보냈습니다. 4배 미리보기는 완성 그림을 확대하므로 세부 정보가 늘어나는 원화가 아닙니다. 캐릭터용 96×128 셀·발 기준선 계약은 이 정지 배경 카드에 해당하지 않습니다.

Game/에는 복사하거나 수정하지 않았습니다. Claude가 배경을 연결하고 제목을 배치해야 합니다. Unity를 열거나 Play·실제 게임 캡처를 수행하지 않았으며 게임에서의 최종 가독성과 화면 비율 확인은 남아 있습니다. 초상·병사·적·기존 성벽 에셋은 변경하지 않았습니다.
