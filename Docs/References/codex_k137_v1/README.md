# K-137 주인공 다리 검토본 — 미완료

옆 걷기와 옆 달리기 8칸의 접지 밑창 양끝을 한 픽셀 블록씩 안쪽으로 정리하고, 어두운 가죽색 밑창 띠를 넣었다. 기존 발끝과 달리기 자세는 보존했다. 노멀 맵의 바뀐 부분도 갱신했다. 거울 반전한 그림은 없으며, 반전 사용 시 노멀 맵 R 채널을 뒤집어야 한다.

뒤 걷기 0~3, 앞 걷기 0~3은 무릎 굽힘과 앞모습 발끝을 자연스럽게 완성하지 못해 Claude 원본 그대로다. 따라서 이 결과는 카드의 완성본이 아니다. 옆의 띠와 발 모양도 사용자 검토가 필요하다.

- 게임용 시트와 노멀: `hero_walk_run_grid.png`, `hero_walk_run_grid_normal.png`, 1152×1536, 4×4칸, 칸 288×384, 피벗 (144, 360).
- 원본 크기: `hero_walk_run_grid_native.png`, `hero_walk_run_grid_normal_native.png`, 384×512, 칸 96×128. 게임용 그림은 원본 크기에서 최근접 3배와 일치한다.
- `before_after_2x.png`: 돌 회색 바탕, 왼쪽 원본과 오른쪽 수정본 각각 2배. `preview_native_4x.png`: 원본 크기 4배.
- 행 순서: 뒤 걷기, 옆 걷기, 옆 달리기, 앞 걷기. 각 행은 왼쪽부터 0~3번이다.

## 검사

- 16칸 모두 최하단 불투명 행 y=359, 해당 행의 RGB 각 채널 55 미만 비율 100%.
- 알파 실루엣의 좌우 경계를 열별로 검사한 결과 연속 수직선 최대 27픽셀: 31픽셀 이상 없음.
- 뒤·앞 행은 원본과 완전히 같고, 옆 행의 변경은 y=354~359에 한정되어 코트 위 영역은 보존했다.
- 게임용 그림은 원본 크기 시트를 최근접 3배한 결과와 모든 픽셀이 일치한다. 투명 배경이 유지된다. 노멀은 원본과 같이 불투명 중립 배경을 사용한다.
- 픽셀 단위 독립 점 자동 검사는 하지 않았다. Unity 재생과 실제 게임 화면 검증은 하지 않았다.
