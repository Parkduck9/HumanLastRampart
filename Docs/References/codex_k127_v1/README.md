# K-127 · 등대 일꾼 바퀴 밀기

K-119의 A·B 외형을 기준으로 밀기 8칸, 시작 3칸, 손 놓고 이마 닦는 휴식 3칸을 앞·뒤·좌·우로 제작했습니다. 더 깊이 몸을 기울인 강하게 밀기는 좌우 각각 8칸입니다. 막대나 바퀴는 그림에 포함하지 않습니다.

- 원본 `native/`: 칸 96×128, 발 (48,120), 보이는 발바닥 최하단 y=120.
- 게임 `game/`: 최근접 3배, 칸 288×384, 발 (144,360). 발바닥 접촉 행은 360~362입니다.
- 확대본 `previews/`: 원본 최근접 4배, 칸 384×512.
- 막대 중심은 원본 y=85, 게임 y=255이며 발 위 35점 / 105점입니다. 손이 중심선을 감싸는 자세입니다. 실제 막대의 두께·가림은 게임 연결 후 확인해야 합니다.
- 시작은 0→1→2를 한 번 재생한 뒤 밀기로 연결합니다. 휴식은 0→1→2를 한 번 재생하고 마지막 자세를 유지합니다. 이마 닦기를 계속 반복하지 않습니다.
- 밀기 8칸은 왼발 지지부터 반대발 지지까지의 보행 순서입니다. 방향별 같은 프레임 번호가 같은 보행 단계를 뜻합니다. 권장 밀기는 초당 8칸, 강하게 밀기는 초당 10칸입니다.
- 기존 `worker_a_push.png`, `worker_b_push.png` 이름과 8칸 순서를 유지하는 오른쪽 밀기 별칭도 제공합니다. 방향별 새 파일은 `worker_{외형}_{동작}_{방향}.png`입니다. 기존 4칸 휴식 파일은 교체하지 않습니다.
- 왼쪽은 K-119 방식으로 x=48을 기준으로 오른쪽을 반전했습니다. 빛 방향도 반전됩니다.

## 검토

저장소 루트의 `_HTML/6_그림_화면/codex_K-127_일꾼바퀴밀기_v1.html`을 직접 엽니다. 그림은 전부 내장되어 서버 없이 동작합니다. 새 동작 28종을 K-119의 같은 방향 걷기 및 현재 게임의 기존 밀기와 나란히 재생합니다. 일시 정지, 한 프레임 이동, 외형·방향·동작 선택, 속도와 기준선을 제공합니다. 시작·휴식은 검토를 위해 끝 자세 유지 후 다시 재생합니다.

## 제작과 확인 범위

내장 이미지 생성 도구로 외형별 원안과 막대 제거 보정본을 생성했습니다. K-119 걷기의 실제 색만 사용하도록 팔레트를 맞추고, 알파 문턱·가장 큰 연결 영역으로 반투명 가장자리와 고립 점을 정리했습니다. 원안 및 프롬프트는 `source/`, `prompts.json`, 정리 규칙은 `build.cjs`에 있습니다. 시트 규격·순서·재생 설정은 `manifest.json`, 프레임별 경계는 `extraction.json`과 `verification.json`을 확인합니다.

생성 확장본으로 얼굴 픽셀이 K-119와 완전히 같지는 않습니다. 발 기준·알파·팔레트·확대 방식은 파일 검사 대상이며, 실제 회전 속도와 발걸음의 동기화 및 막대와 손의 접촉은 Unity에서 확인해야 합니다. Unity 실행과 Game/ 수정은 하지 않았습니다. 게임 연결은 Claude가 담당합니다.
