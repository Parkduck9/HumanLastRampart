# K-136 주인공 걷기 다리 검토본

이 결과물은 미완성 검토본입니다. 앞·뒷면 여덟 프레임은 기존 온전한 다리의 전체 복제와 코트 아래 연결을 확인하지 못했습니다. 원본의 다리가 셀 중심선을 가로지르는데 중심선으로 잘라 반전했으며 y=333부터만 바꾸어, 위쪽 바지와 발 전체가 같은 변환을 받지 않았습니다. 사용자 승인이나 게임 반영 대상으로 사용하지 마세요.

셀 288×384, 4×4, 피벗 (144, 360). 네이티브 셀 96×128, 피벗 (48, 120). 원본과 수정본은 왼쪽부터 프레임 0~3이며 행은 뒤 걷기, 옆 걷기, 옆 달리기, 앞 걷기입니다. 바닥 기준은 y=359입니다.

변경 픽셀 수는 원본 색상 시트와 RGBA 값이 다른 실제 픽셀 수입니다. 밑줄 검정 비율은 y=359의 불투명 픽셀 중 RGB가 모두 55 미만인 비율입니다. 수직 외곽선은 좌우 이웃이 투명한 불투명 픽셀의 최장 연속 길이입니다. 위쪽 차이는 y=0~332의 변경 수이며 코트 끝을 포함한 상체가 그대로임을 보수적으로 확인합니다.
