## 레퍼런스와 수정

석재는 기존 성벽 시안 A의 따뜻한 회색 돌 계열, 지붕은 어두운 청회색, 들판·언덕은 올리브색으로 생성. 각 재질별로 위쪽 색/아래쪽 노멀 원안을 imagegen으로 만들었다. generation.json에 전체 프롬프트/경로, *_source.png에 선택 원안 보관. 난간 초안에 전체 건축 형태가 들어가 바닥·난간3종을 표면 전용으로 재생성했고 corrections.json에 기록했다. 초기3원안은 *_source_initial.png로 구별한다.

## 반복 이음새와 도트 출력

AI 원안의 한 색/노멀 대응 타일을 뽑아 최근접 축소한 뒤 **미러 반복 타일로 규격 출력**했다. 좌우/상하 반사에서 노멀 XY 방향을 같이 뒤집고 반사축의 접선 기울기를0으로 맞춘다. 최종 색/노멀 모두 첫·마지막 행과 열이 정확히 같고, 노멀 단위벡터도 확인했다.

이는 원안 그대로가 손으로 완성한 무작위 무이음 타일이라는 뜻이 아니다. 미러 반복 특유의 대칭 무늬가 생길 수 있어 HTML의 2×2/3×3 반복에서 사용자가 판단한다. 특히 석재 규칙성·풀의 대칭이 눈에 띄면 후속 비대칭 주기 원안으로 교체한다. 노멀맵은 AI 근사 표면이며 3D 베이크가 아니다. 실제 모형 경계·UV 회전/축척·마테리얼 경계 이음새는 Claude 연결 후 별도 검증해야 한다.

## 검토 및 임포트

- `_HTML/codex_배경도트질감_노멀맵_v1.html`: 9종 선택, 색/노멀/조명, 광원 방향/높이·평면 비교, 1·2·3배 반복. 모든 이미지 내장.
- 제안 임포트: 색 sRGB, 노멀 Normal map/Linear·Y+, Point·Repeat·NPOT None·초기 압축 없음. 탑벽128×192가 자동 POT 변환되지 않게 한다. 원거리 밉맵/점 필터 지글거림은 실제 카메라에서 Claude가 검토한다.
- Unity 모형 UV는 타일1개당 위 표의 m범위. 예: 성벽40m×4m에 바깥면 타일을10×1 반복. 모서리탑4m×6m 각 면은 탑벽1×1. 모형 크기와 관계 없이 텍스처를 늘려 붙이면32px/m가 깨진다.
- 노멀은 패킹/UnpackNormal·TBN 및 UV 반사 방향을 함께 맞춘다. HTML의 CPU Lambert 결과는 Unity 렌더 검증을 대신하지 않는다.
