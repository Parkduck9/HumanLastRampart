## 구성과 동작 범위

- 왼쪽: 전체·북쪽·동쪽·남쪽·서쪽, 실제 코드와 같은 우선순위 명령 6개, ▲/▼ 접기. 명령 문구는 `BattleSim.Commands.cs`의 `PriorityNames`를 읽어 사용했다.
- 오른쪽: 대포가 있는 성벽, 1~4번 대포 선택, 지도 클릭으로 조준 위치 표시, 선택한 대포 조준 해제, ▲/▼ 접기.
- 오른쪽 아래: 네 성벽의 현재 명령 요약. 병사 창을 접어도 적용 상태를 살필 수 있게 남기는 **새 배치 제안**이다.
- 아래 가운데: Q=폭발, W=불바다. 버튼·키보드로 고르며 같은 항목을 다시 누르면 해제한다. 대포와 마법 선택은 서로 풀린다.
- 위: 준비 중 시간 정지 안내와 황동 [전투 시작]. 실제 전투·화면 전환은 연결하지 않았다.
- 검토 도구: 두 창 접기·펼치기, 전투 중 안내 비교, 시안 초기화.
- 전체 명령은 개별 명령을 덮어쓰고, 성벽 하나를 고르면 그 성벽만 바뀐다. 전투 중 비교 상태는 전령 도착을 계산하지 않고 안내 문구만 바꾼다.
- 대포 조준은 대포마다 따로 보관한다. 마법은 위치 표식만 보여준다. 사거리·피해·자원·재사용 대기·발사·저장·병력 이동은 계산하지 않는다.
- Tab·M·Esc로 지도 닫기와 전투 시작을 연결하지 않았다. Esc는 선택만 취소한다. 실제 지도 닫기도 전투를 시작하는 D-071 동작은 Claude 연결 영역이다.

병력 300명·궁수/총병 10명 깃발·성·언덕·거리 원은 가림과 배치를 살피기 위한 예시다. 지형·병력 수·좌표 축척·명령 규칙을 새로 확정하는 자료가 아니다. K-020 표식 확정 전이므로 임시 도형을 사용했다.

## 실제 수행한 확인

1. PowerShell 5.1에서 두 생성 스크립트 실행 성공. 한글 경로·문구가 깨지지 않도록 PowerShell 원본만 UTF-8 BOM으로 보관했다.
2. 실제 HTML 스크립트를 Node VM과 최소 DOM 모형으로 실행해 **29/29 통과**. 상태 변경·선택·접기·조준·키 처리·초기화·축소 계산·중복 ID·내장 리소스·보관본 동일성을 확인했다.
3. 정지 목업 PNG를 직접 열어 전체 배치·한글·네 방향·패널 가림을 육안 확인했다. 남쪽 글자를 가리던 안내문을 위로 이동하고 PNG를 재생성·재확인했다.
4. 대표 HTML과 보관 HTML이 같은 내용인지 검사했다. SVG XML 파싱 및 PNG 크기를 확인했다. 기존 참조 그림 크기를 실제 파일에서 읽었다.

**검증 제한:** 연결 브라우저 목록이 비어 있었고 Chrome/Edge 헤드리스 렌더는 이미지 생성을 완료하지 못했다. 실제 브라우저 렌더·콘솔·포커스 이동·글꼴별 줄바꿈·CSS 클릭 가림은 확인하지 못했다. DOM 모형 검사는 해당 검증을 대신하지 않는다. Unity·실제 전투·실제 캡처는 수행하지 않았다.

## 남은 검토·질문

- 병사 창을 접어도 별도로 남는 ‘성벽별 현재 명령’ 작은 창을 유지할지 사용자 검토가 필요하다.
- 준비 중 마법을 실제 발동할 수 있는지, 선택만 허용할지 이 카드에서 정하지 않았다. 최종 동작을 확인한 뒤 Claude가 연결한다.
- K-020 표식 확정 뒤 지도에 맞춘 가독성과 가림을 다시 비교한다.
- Claude 연결 뒤 1920×1080·1280×720에서 글자 크기, 명령 창/대포 창 접기, 네 방향과 병력 표식·조준점 가림, Q/W 키 충돌, 실제 사거리 원을 검토한다.

## 재생성

카드 루트 PowerShell에서 아래를 실행한다. Unity나 Git을 사용하지 않는다.

```powershell
& Docs/References/codex_k021_v1/build.ps1
& Docs/References/codex_k021_v1/draw_mockup.ps1
```

`verify.mjs`는 `verify(fs, vm, 자료폴더_절대경로)`를 내보낸다. Node의 `node:fs/promises`·`node:vm`을 전달하면 `qa_results.json`을 다시 만든다. 검토 HTML을 바꾸면 보관본도 `build.ps1`로 갱신하고 검사를 다시 실행한다. 정지 목업은 별도 그리기 원본이므로 배치 변경 때 `draw_mockup.ps1`도 함께 맞춘다.
