## 기준과 문구

- 영웅은 `Docs/References/codex_hero_octopath_review_v6/generated.png`를 참고했습니다. 보정본은 사용하지 않았습니다.
- 큰 머리, 흰 머리카락, 파란 눈, 검정 장교복과 황동 장식, 갈색 장화를 유지하는 키 아트입니다. 게임 스프라이트를 픽셀 단위로 복사한 자산은 아닙니다.
- DECISIONS.md에서 게임 표시 제목 확정 항목을 찾지 못했습니다. 카드의 지시대로 **Human Last Rampart**를 임시 사용했습니다. `MainMenuEntry.cs`에는 “인류의 마지막 성벽”이 있지만 제목 확정 근거로 간주하지 않았습니다.
- 로고와 문구 없는 배경을 분리했습니다. 제목 확정 뒤 로고 문구를 새로 제작할 수 있습니다. 편집 가능한 글꼴·글리프 원본은 제공하지 않습니다.
- 최신 인물 설명은 D-080 정정의 약 52점입니다. 이후 52점/73점 결정은 문서에서 찾지 못했습니다. 이 카드는 크기 결정 대기 표시가 없으며 전투 동작 시트를 만들지 않습니다.

## 제작·내보내기

내장 image_gen으로 배경, 두 줄 로고, 가로 로고, 표지를 생성했습니다. 정확한 요청문은 `prompts.json`에 보관했습니다. 표지는 생성 도구로 합성한 변형이므로 배경 원본과 픽셀 단위 동일성을 보장하지 않습니다.

생성 배경·표지 원본은 1672×941입니다. `export.ps1`로 최근접 보간해 1920×1080으로 내보냈습니다. 화면비 보정은 약 0.05%이며 네이티브 1920 생성으로 표기하지 않습니다. 로고는 생성 원본 크기와 투명 알파를 보존했습니다. 내보내기 스크립트의 생성 원본 경로는 이 세션 PC의 경로입니다. 완성 PNG와 검토 페이지는 그 경로 없이 사용할 수 있습니다.

메뉴 도식은 `MainMenuEntry.cs`와 `ScreenView.DockLeft`의 1920×1080 기준 x=128, 중앙 정렬, 폭 624, 높이 최대 512를 참고했습니다. Unity 캡처나 최종 UI 제안이 아닙니다.

## 검증과 남은 사항

- 배경·표지의 1920×1080 크기와 960×540 축소본 크기 확인.
- 로고의 알파 범위 0~255, 네 외곽 테두리 완전 투명 확인. 바둑판 위에서 배경이 실제 투명함을 확인.
- 육안상 독립된 밝은 잔여 점은 보이지 않지만, 글자 바깥의 알파 1~16인 매우 희미한 생성 잔여 픽셀이 있습니다. **엄격한 무잔여 픽셀 조건은 충족으로 기록하지 않습니다.** 원본 알파 보존을 위해 임의 임계값 제거는 하지 않았습니다.
- 정지 배경·로고이므로 시트 셀·프레임 순서·발선 검사는 적용 대상이 아닙니다.
- Chrome 헤드리스에서 내장 이미지 10개 로드, 자바스크립트 오류 없음, 메뉴 전환과 960px 보기 작동, 390px 모바일 가로 넘침 없음 확인. `review_validation.json`과 검토 캡처 참고.
- 실제 Unity 표시·패널 겹침·색감·임포트 설정은 미검증입니다. Claude 연결 후 사용자 확인이 필요합니다.
- 표시 제목 확정, 저알파 잔여 픽셀 제거 여부가 남았습니다. 게임 연결·Git 커밋은 Claude 담당입니다.

`manifest.json`은 크기·알파·구도 정보를, `build_review.py`는 검토 페이지 생성 절차를 담습니다.
