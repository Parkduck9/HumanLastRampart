대포병은 원래 크기로, 대포는 별도로

병사 키 약 210px와 발 기준을 유지했습니다. 앞 병사·뒤 운반 보조·대포를 각각 합성하며, 불붙이기는 별도 6칸입니다. 아래 그림은 게임 연결 전 검토용입니다.

그림 준비 중

① 앞·뒤 두 명과 별도 대포

· 병사 6칸/초 · 본체 정지 1칸 + 같은 그림의 바퀴 부분만 회전

앞 병사는 손을 뒤로 뻗어 당기고, 뒤 병사는 손을 앞으로 뻗어 운반을 돕습니다. 두 병사의 발은 같은 접지선에 놓입니다. 손과 포가 사이 연결끈은 배치 설명용 선입니다.

뒤쪽의 앞손 운반 자세와 손잡이 연결 방식, 6→1 걸음 연결은 외형 검토 대상입니다. 바퀴 회전은 본체 PNG의 원형 영역을 잘라 돌리는 검토용 합성입니다.

② 막대 들기 → 도화선 점화 → 1초 → 발사

0.00초 막대 들기 → 0.50초 도화선 접촉·점화 → 1.50초 발사. 0.50~1.50초가 정확히 1초입니다. 발사 때 K-016의 기존 포구 연기 6칸을 재사용합니다. 3.20초마다 처음부터 반복합니다.

점화 접점은 도화선의 아래쪽 굽은 부분입니다. 점화 불씨와 포구 연기 방향·반동은 HTML 합성 시안이며 실제 발사 판정이나 게임 지연을 구현한 것이 아닙니다.

③ 기존 병사와 같은 높이로 비교

왼쪽: 기존 달리기 / 가운데: 앞 끌기 / 오른쪽: 불붙이기. 모두 256×384 칸, 발 (128,352). 무기·불씨를 제외한 인물 실체는 약 210px입니다.

④ 대포 기준점·발 위치

왼쪽 대포: 384×384 칸, 배치 기준점 (192,352). 노란 점은 바퀴 중심, 청록 십자는 접지 기준, 주황 점은 도화선 접점입니다. 오른쪽 병사: 발 (128,352). 기준 표시는 PNG에 굽지 않고 합성합니다.
