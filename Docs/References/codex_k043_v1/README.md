## 합성과 재생

운반은 앞·뒤 병사 각각 6칸/초, 고정 대포 본체에 회전 바퀴를 합성한다. 뒤 병사는 앞손 운반 보조로 그렸다. 손과 대포 사이의 끈은 배치 설명용 HTML 선이며 PNG의 일부가 아니다. 같은 접지선에 앞 병사·대포·뒤 병사를 놓고 발 위치를 표시한다. 위치 이동·바퀴 회전을 각각 끄고 볼 수 있다.

점화는 0.00초 시작, 0.50초 4번째 칸에서 도화선 아래쪽 굽은 부분에 접촉, 1.50초 발사다. 점화에서 발사까지 1초다. 1.50~2.10초 기존 포구 연기 6칸을 10칸/초로 재생한다. 병사는 불붙인 뒤 막대를 거둔다. 3.20초마다 반복하며 시간 슬라이더·멈춤·처음부터를 제공한다. 발사 때의 7px 반동·연기의 옆방향 회전은 검토용이다.

## 제작과 재현

내장 imagegen으로 앞 끌기·뒤 보조·점화·대포 원안을 제작했다. `generation.json`에 사용한 정확한 프롬프트 5개를 보관한다. `prompts.json`은 첫 3회 생성의 프롬프트 기록이다. 참조는 `Game/Assets/_Project/Art/Characters/Run/cannon_crew_run.png`, K-038 `cannon_pull_source.png`다. 남색·아이보리 테두리·갈색 장갑/부츠·검은 머리 방향을 유지했으며 기존 도트와 동일 픽셀 그림은 아니다.

`crew_ignite_source.png`는 긴 막대 때문에 미채택한 첫 원안이다. 최종은 `crew_ignite_short_source.png`다. 나머지 원안은 `crew_pull_source.png`, `crew_rear_source.png`, `cannon_source.png`다. 생성 위치의 원본을 삭제하지 않고 카드 폴더로 복사했다.

`build.py`는 3열×2행 원안을 분리하고 알파128 초과 경계를 잡아 최근접 배율 정리·발 정렬·가로 시트 포장을 수행한다. 병사별 시트 안에서는 공통 배율을 쓴다. 원안 알파는 잘라낸 영역 안에서 보존한다. 별도 도트 덧칠·관절 보간·프레임 복제는 하지 않았다. 희미한 외곽 잔여 알파는 경계 바깥에서 잘릴 수 있다. `manifest.json`에 원안 분리 좌표·배율·발 앵커·합성 좌표를 기록했다.

재현: Pillow가 있는 Python으로 `build.py` → `compose_review.py`, Node로 `verify_html.cjs` 실행. 제작 스크립트는 카드 결과 폴더와 지정된 신규 HTML에만 쓴다. `inspect.py`는 원안 알파 경계 점검용이다. Unity에 넣지 않은 시안이므로 `.meta`는 만들지 않았다.

- PNG 6종(신규 4종+참조 사본 2종)의 크기·각 칸 네 모서리 알파0·SHA256 검사 통과: `qa_assets.json`.
- 최종 세 병사 시트·대포 PNG를 직접 열어 옷·방향·전체 막대·발·여백을 확인했다.
- `haul_review.png`, `ignite_contact_review.png`, `fire_review.png`, `scale_review.png`, 이를 모은 `contact_review.png`를 HTML과 같은 좌표로 정적 합성했다. 모아보기 이미지를 직접 열어 앞뒤 배치·점화 접점·발사 연기·동일 배율을 확인했다. 브라우저 캡처가 아니다.
- JavaScript 구문과 Node DOM·캔버스 모형 15개 검사 통과: 읽기, 초기 그리기, 0.499/0.500/1.499/1.500초 경계, 연기 6칸·종료, 반복, 멈춤, 이전/다음 순환, 시간 이동, 자동 진행, 배경/기준/이동/회전 조작, 외부 리소스 없음: `qa_html.json`.
- 실제 브라우저는 도구의 `Browser is not available: iab` 응답으로 열지 못했다. CSS 배치·사용자 조작·화면별 넘침·실시간 재생의 육안 검증은 미수행이다.
