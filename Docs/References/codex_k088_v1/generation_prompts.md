# 이미지 생성 요청 기록

방식: 이미지 생성 스킬의 기본 내장 도구 `image_gen`. 두 이미지 모두 투명 배경을 요청했다. 외부 API·명령행 생성은 사용하지 않았다.

## 효과 아틀라스

73픽셀 크기 머스킷 병사를 위한 작은 픽셀 효과 아틀라스. 글자·총·사람·그림자·격자 없이 투명 배경. 충분히 떨어진 세 줄 구성. 첫 줄은 오른쪽 총구 불꽃 3프레임: 작은 아이보리 발화, 조금 더 큰 짧은 노랑·주황 화염, 사라지는 작은 퍼프. 두 번째 줄은 카메라 반대쪽을 향하는 같은 효과 3프레임: 아래쪽 밝은 코어, 위로 짧고 압축된 화염, 사라지는 퍼프. 세 번째 줄은 위·오른쪽으로 조금씩 흐르고 커지며 사라지는 작은 회갈색 화약 연기 4프레임. 굵은 정수 픽셀 덩어리와 재질별 약 3단계 명암. 번짐·후광·분리된 불똥·배경·글자 금지. 실제 사용 시 10~20 px 안팎의 작은 효과로 읽히게 요청. 불꽃은 #fff5c0 / #ffc35a / #ef842e, 연기는 차분한 회갈색. 가로형 구성.

저장: `source/vfx_generated.png`.

## 토벽 흙자락

기존 전장 흙 데칼과 어울리는 토벽 아래의 긴 흙 얼룩 한 덩어리. 가로가 세로의 약 5배인 직접 위에서 보는 지면 텍스처. 부드럽게 불규칙한 외곽, 연결된 작은 흙 덩이, 가운데는 어둡게 다져진 새 흙, 양 가장자리는 성긴 황갈색 흙 부스러기. 세워진 벽·풀·큰 돌·투영 그림자·배경·글자·테두리 금지. 정사각 픽셀 덩어리와 단순한 약 3단계 명암. #51452b / #75613c / #a58e5c / #c0aa77 계열, 흐림과 연속 그라데이션 없음. 충분한 투명 여백이 있는 가로형 구성.

저장: `source/dirt_generated.png`. 최종 자산은 앞의 3색으로 정리했다.
