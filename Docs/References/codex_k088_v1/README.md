## 프레임과 부착점

효과 셀은 원본 96×128, 게임용 288×384이며 프레임은 왼쪽부터 재생한다. 사람 약 73 px를 기준으로 최대 화염은 오른쪽 17×11 px, 반대쪽 11×16 px다. 셀 전체 크기와 실제 불꽃 크기를 혼동하지 않는다.

원본 총구 앵커는 **왼쪽 위 기준 (48,80)**, 게임용은 **(144,240)**이다. Unity의 왼쪽 아래 정규화 피벗은 **(0.5,0.375)**다. 불꽃 1·2프레임의 방출 시작점을 고정했고, 마지막 퍼프와 연기는 의도적으로 총구에서 떨어진다. 연기는 위쪽으로 2/6/11/17 px 이동하고 알파가 155/125/80/32로 감소한다.

인물 격자의 중심 x=48, 발 기준 y=120, 게임용 발 피벗 (144,360)은 참조 정보다. 이 자산에는 인물이나 발이 없으므로 발 정렬 검사는 해당하지 않는다. **총구 부착에는 발 피벗 대신 효과 앵커를 사용한다.**

불꽃 재생 시간은 35/45/40 ms, 합계 120 ms다. 연기는 발사 80 ms 뒤에 시작해 70/90/110/130 ms, 합계 400 ms 재생한 뒤 숨긴다. 두 효과 모두 반복하지 않는다. 검토 화면만 비교를 위해 1.2초마다 반복한다.

## 합성과 지면 배치

- 불꽃: 투명 바탕, 직선 알파, `Blend SrcAlpha One`. 검정 바탕 시트가 아니다. 마지막 퍼프의 알파도 곱해야 한다. Point / Clamp / 압축 없음 권장.
- 연기·흙자락: `Blend SrcAlpha OneMinusSrcAlpha`, Point / Clamp / 압축 없음 권장.
- 그림자: 검정 RGB, 연속 알파, Bilinear / Clamp / 압축 없음 권장. 알파 가중 곱셈은 `땅색 × (1 - 텍스처 알파 × 불투명도)`다. 검정 RGB만 곱하는 재질에 그대로 넣으면 사각형이 검게 된다. 검정 일반 알파 합성도 같은 식의 감쇠를 낸다.
- 그림자와 흙은 지면 XZ에 놓는다. PNG를 다시 원근 압축하지 않는다. 지면과 아주 조금 띄워 깊이 충돌을 피하고, 흙자락을 먼저 그린 뒤 토벽을 표시한다. 피벗은 중앙 (0.5,0.5).
- 그림자 권장 시작 불투명도는 0.65, 흙자락은 0.8이다. 미터 단위 판 크기는 manifest에 있다. 실제 카메라·낮밤·대포 확대에 맞춘 최종 값은 게임에서 확인한다.

## 현재 사수와의 비교 및 연결할 때 남은 일

읽은 현재 사수는 `Game/Assets/_Project/Art/Characters/Fire/gunner_fire.png`이며 1728×384, 288×384 셀 6프레임이다. **0 시작 2번 프레임에는 기존 불꽃이 이미 포함된다.** 원본은 수정하지 않았다. 검토 화면의 새 효과는 같은 시트의 불꽃 없는 1번 겨누기 프레임 총구 (원본 축소 기준 약 87,59)에 합성했다. Claude는 실제 연결 시 기존 불꽃과의 중복, 총구 소켓·방향·가림 순서·발사 타이밍을 처리해야 한다.

현재 사수 그림은 뒤·오른쪽 사선 시점 하나다. 반대쪽 불꽃도 같은 총구에 붙인 방향 견본으로 보여 준다. 정후면 사수 그림이나 신규 사수 동작은 이번 산출물에 포함하지 않는다.

접지 비교는 원본 사수·기존 토벽을 이용한 도식 합성이다. 실제 게임 캡처가 아니며 Unity의 재질·조명·깊이·축척 검증은 하지 않았다. 그림자 생성 수식의 알파 곱셈과 게임 재질의 실제 결과를 구분한다.

## 제작·확인

이미지 생성 스킬의 기본 내장 `image_gen` 도구를 사용했다. 프롬프트 기록은 `generation_prompts.md`에 있다. 생성 이미지에서 주 덩어리를 추출하고 최근접 축소·3색 정리·알파 및 프레임 배치를 적용했다. 그림자는 부드러운 타원 감쇠 수식으로 생성했다. 기존 K-068 흙·토벽을 시각 참조했다.

`build_assets.py`로 재구성하며 `verify_assets.py`는 크기·알파·테두리·고립 픽셀·3배 확대·부착점·연기 이동·그림자 감쇠·참조 무변경을 확인한다. `verify_review.cjs`는 브라우저에서 이미지 디코딩·애니메이션·조작·모바일 배치를 확인한다. 실제 검사 결과는 `verification.json`, `review_validation.json`에 기록한다.
