# 성벽손 오우거 — 게임용 동작 시트 v1

사용자가 선택한 K-128 B안을 바탕으로 만든 우두머리 전용 그림입니다. 기존 일반 오우거를 교체하지 않습니다. 게임 연결과 Unity 실행은 하지 않았습니다.

검토판: [동작·노멀·성벽 크기 비교](../../../_HTML/6_그림_화면/codex_K-129_우두머리동작_v1.html). 이미지와 스크립트를 모두 내장하여 서버 없이 직접 열 수 있습니다. 각 동작을 현재 일반 오우거의 걷기 또는 공격과 나란히 보여 줍니다. 실제 전투 장면이 아니며 성벽은 높이 비교용 도식입니다.

## 규격

| 항목 | 원본 | 게임용 |
|---|---|---|
| 칸 크기 | 256×288 | 768×864 |
| 지면 피벗 | (128,280) | (384,840) |
| 기립 키 | 약144점 = 4.5m | 정확히3배 확대 |
| 성벽 눈금 | 128점 = 4m | 동일 월드 눈금 |
| 등반 매달림 기준 | (128,16) | (384,48) |
| 추락 몸 중심 기준 | (128,152) | (384,456) |

좌표는 좌상단 원점, 오른쪽·아래쪽이 양수입니다. 지면 y280은 마지막 불투명 행279 바로 아래의 경계입니다. 서 있을 때 발바닥, 누웠을 때 몸의 최하 접점을 맞췄습니다. 발을 드는 자세에서는 떠 있는 발을 억지로 지면에 내리지 않았습니다. Unity의 좌하단 정규화 피벗은 지면 기준 `(0.5, 0.0277777778)`입니다.

우두머리의 긴 팔을 머리 위로 뻗는 자세와 누운 자세를 담기 위해 일반 인물96×128보다 큰 칸을 사용했습니다. 모든 동작의 칸 규격은 같습니다. 10칸 게임 시트의 가로는7680이므로 최대 텍스처 크기를8192 이상으로 유지해야 합니다. 기존 일반 오우거의256×384 규격과 혼용하지 마세요.

프레임은 **모두 가로 한 줄, 왼쪽부터0번**입니다. 노멀맵도 같은 칸과 프레임 순서입니다. 각 프레임의 바운드·단계·기준점·게임 좌표는 `manifest.json`에 있습니다. 원안의 연결된 인물 윤곽을 각각 분리했으므로 머리 위 주먹이 이웃 행으로 튀어나온 원안도 격자 경계에서 잘리지 않습니다. 원안 칸의 중앙축을 고정해, 앞으로 뻗은 주먹 때문에 몸 전체가 뒤로 밀리도록 바운드 중앙을 재정렬하지 않았습니다.

- `preview_4x/`: 원본 색 시트와 지도·초상의 정확한4배 확대19개.

- 위 두 그림의 `_normal.png`: 아이콘·초상용 대응 노멀.
- `manifest.json`: 파일 경로·칸·피벗·프레임 순서·기준점·팔레트·가져오기 권고.

- `validate.py`, `validation.json`: 크기·알파·연결 윤곽·기준선·배율·단위 노멀·입력 해시 검사와 결과.

## 색과 노멀

선택된 B안의 올리브 회색 피부·갈색 가죽·무광 쇠 팔레트를 사용하고, 눈에 필요한 짙은 파랑 두 색만 추가했습니다. 원안의 반투명 가장자리와 작은 분리 조각을 제거하고 단일 원본 격자·제한된 팔레트로 맞췄습니다. 명확한 외곽선과 왼쪽 위에서 오는 빛을 유지했습니다. 실제 게임 일반 오우거의 색·노멀과 가져오기 설정을 읽기 전용으로 확인했습니다.

노멀은 **동일한 색 윤곽의 얕은 부조와 약한 명도 굴곡에서 계산한 근사**입니다. 이미지 생성 도구로 원안을 만든 뒤 기술 데이터로 인코딩했습니다. 입체 모델에서 구운 노멀이 아니며, 근육·쇠장갑 면의 실제 방향을 모두 복원하지 않습니다. `R=오른쪽`, `G=위쪽`, `B=앞쪽`인 탄젠트 공간 +Y이고 빈 곳은RGB(128,128,255)입니다. 노멀은 불투명RGB이므로 실루엣에는 색 시트의 알파를 사용합니다.

가져오기 권고는 Point·Clamp·밉맵 끔·압축 없음, 색은sRGB, 노멀은선형·NormalMap 타입·초록 뒤집기 끔입니다. 이는 기존 오우거의 Point·선형 노멀·초록 뒤집기 끔 설정을 참고한 값입니다. 실제 임포터나 셰이더 설정을 이번 카드에서 수정하지 않았습니다.
