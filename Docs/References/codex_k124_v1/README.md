# K-124 · 등실 아이콘 조명 수정

[검토 페이지](../../../_HTML/6_그림_화면/codex_K-124_아이콘수정_v1.html)에서 기존 K-121과 수정본을 1024·512·256·192·128·48px별로 비교할 수 있습니다. 밝고 어두운 바탕, 48px 실제 크기와 4배 확대, 투명 전경, 적응형 원형·둥근 사각형 예시를 제공합니다. 이미지가 모두 내장되어 서버 없이 열립니다. 큰 아이콘은 화면에서 축소 표시하며 ‘원본 보기’로 실제 크기를 확인합니다.

## 수정 내용

철창 등실, 오른쪽 위로 나가는 따뜻한 빛, 슬레이트 지붕과 돌 회랑 구도를 유지하고 조명을 다시 그렸습니다. 지붕과 돌이 중앙에서 파랑·회색으로 나뉘던 경계를 없앴습니다. 양쪽 면에 같은 회색 재질을 적용하고, 왼쪽 위 달빛은 얇고 채도 낮은 윤곽으로, 내부 등불은 창살·처마 아래·가까운 돌 윗면의 따뜻한 조명으로 표현했습니다. 돌은 무광이며 지붕 윗면에 등불의 강한 금색 테두리를 두르지 않았습니다.

내장 이미지 생성 도구로 조명 편집을 두 차례 수행했습니다. 첫 보정에 남은 왼쪽 면의 푸른 채색을 두 번째 보정에서 제거했습니다. 최종 생성본을 128×128 논리 전경으로 정리하고, 모든 납품 크기를 최근접 방식으로 변환했습니다. 원본 K-121 파일은 수정하지 않았습니다.

K-121과 파일명·출력 크기·배치를 맞췄습니다. 정사각형 아이콘과 적응형 배경은 기존과 같은 남색 `(11,21,40)`이며 알파는 전부 255입니다. 적응형 전경은 432px 캔버스의 `(120,120)`에 192×192px로 놓았습니다. 안전 원은 중심 `(216,216)`, 반지름 132px이고 실제 전경의 최대 반지름은 약 105.423px입니다. 검토용 모서리 마스크와 안전 원은 에셋에 굽지 않았습니다. 단색 테마 레이어는 K-121과 마찬가지로 포함하지 않습니다.

정지 아이콘이므로 인물 셀·발 기준선·애니메이션 계약은 적용하지 않습니다. 프레임은 하나, 피벗은 중앙입니다. 1024px 출력은 128px 논리 그림의 8배이며 별도의 고해상도 세부 묘사가 추가된 그림은 아닙니다.

## 확인

아이콘 PNG 9개 크기·알파가 명세와 일치합니다. 128px 정사각형에서 나머지 크기 5개로의 최근접 변환, 4배 확인 그림 2개의 픽셀 일치를 검사했습니다. 투명 전경에서 알파 32 미만을 정리하고 3논리 픽셀 미만의 고립 성분을 검사했으며 제거할 고립 성분은 없었습니다. 중앙 색 분할 제거, 48px 지붕·철창·등불·돌 받침 판독, 투명 경계는 그림과 브라우저 캡처를 직접 살펴봤습니다.

헤드리스 Edge에서 내장 이미지 40개가 모두 로드됐습니다. 1440px와 390px 화면의 가로 넘침이 없고 원본 보기 창에서 1024px 원본이 열리는 것도 확인했습니다. 실제 기기의 작은 아이콘 표시와 운영체제 마스크는 연결 후 확인이 필요합니다.

제작 전 도트의 픽셀 덩어리·색 단계·띠 모양 음영을 다룬 [픽셀 아트 자료](https://pixeljoint.com/forum/forum_posts.asp?TID=11299)를 검색해 카드별 금지 사항을 먼저 기록했습니다. 추가로 [생성 그림에서 생기는 조명·재질 불일치 설명](https://geekchamp.com/how-to-tell-ai-generated-game-art-from-human-made-art-without-guessing/)과 [옥토패스 개발진의 HD-2D 설명](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style)을 확인했습니다.

Game/·기존 에셋·협업 기록은 수정하지 않았습니다. Unity 실행과 Git 쓰기는 수행하지 않았습니다. 실제 게임 연결·플랫폼 슬롯 지정·실기기 검증·커밋은 클로드에게 인계합니다.
