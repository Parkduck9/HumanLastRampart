# 궁수·총병·대포병 후면 데모 v1

- 작성자: Codex / T-CX-025
- 사용자 요청: 기존 캐릭터 설정을 유지한 후면 데모 에셋 3종.
- 기준: codex_character_pixel_v2 정면 PNG를 각 생성의 직접 참조로 사용. 약2.2등신·큰 사각 픽셀·남색 제복과 크림/금색 장식·갈색 가죽 장비 유지.
- 궁수: 갈색 머리, 활, 등 뒤 화살통과 흰 깃털 화살.
- 총병: 짙은 갈색 머리, 한쪽 금속 견갑, 목재 총과 가죽 멜빵.
- 대포병: 검은 머리, 작업 앞치마의 등끈/허리끈, 장갑, 장전봉. 앞치마 앞판을 등으로 옮기지 않음.
- 정적 후면 중립 포즈·투명 PNG 원본. 애니메이션이나 실제 Game 반영은 하지 않음. 기존 정면 PNG도 보존.
- preview.html에서 기존 정면/신규 후면, 후면32·48·64px 표시와 격자/밝음/어두움 배경 비교. 투명 여백은 표시용 canvas에서만 제외하며 PNG 원본은 가공하지 않음.
- 생성 확대 원본은 정확한 네이티브 픽셀 격자를 확정한 파일이 아님. 게임 픽셀 크기/임포트 설정과 실제 카메라에서 판독성은 후속 Unity 확인 필요.

## 결과 확인

후면 PNG3종 보관, 원본 전체 몸·장비·후면 방향 육안 확인. PNG3개 투명 배경과 불투명 몸/장비 영역에 여백 확인(png_analysis.json). 생성본의 매우 낮은 알파 흔적은 원본 그대로 보존하고, 미리보기에서는 알파32 이상 영역을 표시 기준으로 사용한다.

실제 브라우저 정면/후면6개 로드 완료, 비교/소형표시 canvas15개, 304px 좁은 화면 가로 넘침 없음, 밝은 배경 전환 확인. 32px에서도 장비 실루엣 확인용이며 실제 Unity 카메라에서의 판독성은 미검증. 프롬프트는 prompts.json에 보관.
