# K-107 — 루멘 파로스 새 디자인 시안

사관학교를 갓 졸업한 스무 살 남자, 황실 등불지기 가문의 마지막 혈통이라는 새 설정을 바탕으로 만든 **선택용 시안**이다. 귀향 장교의 검정·금색 외투와 견장은 쓰지 않았다. 게임 파일 교체와 전체 동작 제작은 하지 않았다.

검토 페이지: [`루멘 파로스 시안`](../../../_HTML/6_그림_화면/codex_K-107_주인공새디자인_시안_v1.html). 이미지가 내장되어 서버 없이 직접 열린다.

| 안 | 머리 | 생도복 | 등불지기 망토 | 비교할 점 |
|---|---|---|---|---|
| A | 밤색 비대칭 앞머리 | 짙은 청록 | 아이보리 어깨 망토 | 후면에서 밝은 망토와 등대 문양이 잘 읽힘 |
| B | 짙은 남색 가르마 | 아이보리 | 청록 비대칭 망토 | 정면에서 밝은 상의와 등불이 잘 읽힘 |
| C | 이마를 드러낸 금발 | 차분한 자주 | 회청색 어깨 망토 | 머리색과 망토 테두리로 구분 |

모든 안에 작은 허리 등불과 접이식 황동 망원경이 있다. 작은 원본 크기에서는 망원경이 막대처럼 보일 수 있어 확대 그림도 함께 확인한다. 초상은 무표정이며 같은 안의 복색과 머리색을 따른다.

## 파일과 크기

- `variant_[a/b/c]_turnaround_native.png`: 정면 → 왼쪽 측면 → 후면 → 후면 오른팔 지휘 포즈, 4칸. 각 칸 96×128, 전체 384×128.
- `variant_[a/b/c]_[front/side/back/command]_native.png`: 위 네 포즈의 개별 칸.
- `variant_[a/b/c]_turnaround_game.png`: 위 시트를 최근접 3배로 확대한 1152×384. 각 칸 288×384이며 기존 영웅과 같은 칸 크기다.
- `*_turnaround_native_4x.png`: 원본의 정확한 4배, 1536×512. `*_turnaround_game_4x.png`: 게임 크기의 정확한 4배, 4608×1536.
- `variant_[a/b/c]_portrait.png`: 기존 스토리 초상과 같은 256×384 투명 캔버스. `*_portrait_4x.png`: 정확한 4배. `*_portrait_generated.png`: 생성 원안.
- `comparison_[front/back/command]_night065_game.png`: 기존 / A / B / C 순서, 같은 성벽과 같은 발선. 실제 288×384 칸을 1:1로 놓은 1152×512 합성판. 각 비교판의 원본 배율과 게임 크기 4배 그림도 제공한다.
- `old_hero_turnaround_[native/game].png`: 읽기 전용 게임 그림에서 추출한 비교 자료. 정면은 걷기 시트의 4행 1열, 측면은 2행 2열, 후면은 대기, 지휘는 3번째 칸이다. 정면·측면은 기존 걷기 프레임이므로 새 시안의 정지 포즈와 자세가 완전히 같지는 않다.
- `variant_[a/b/c]_generated.png`: 내장 이미지 생성 도구의 네 포즈 원안. `prompts.json`은 전체 제작 지시, `placement.json`은 추출·배치 수치, `manifest.json`은 규격·출처, `validation.json`은 실제 수행한 검증 결과다.

## 기준과 처리

기준은 사용자 선택 `codex_hero_octopath_review_v6/generated.png`, 그 선택본에서 만든 K-070 영웅, 현재 게임 영웅의 칸 크기·기본 자세다. 수정본·과거 미리보기는 방향 기준으로 사용하지 않았다. 생성 원안에서 각 포즈를 분리하고 알파 128 기준으로 투명 경계를 정리한 뒤, 종횡비를 유지한 최근접 축소와 발선 배치를 적용했다. 축소 후 떨어진 1~3점 성분은 제거했다. 생성 원안은 균일한 도트 격자가 아니므로 최종 작은 그림에서 확인해야 한다.

새 포즈는 모두 인물 높이 73px, 발 아래 경계 y=120(마지막 불투명 행 119), 몸 축 x=48이다. 게임 크기는 발 피벗 (144,360), 마지막 불투명 행 359다. 팔을 드는 지휘 포즈도 몸 축과 발선을 유지한다. 의복·머리 실루엣의 차이는 디자인 비교 대상이다. **현재 동작 리그에 연결하거나 걷기 중 흔들림을 시험한 결과는 아니다.** 선택 후 K-108에서 기존 동작별 관절 위치를 대조하며 전체 프레임을 제작한다.

밤 비교판은 저장소의 `wall_a.png`와 영웅들을 합성하고 전체 RGB에 0.65를 곱했다. 임의의 등불 발광 보정은 넣지 않았다. 실제 Unity 조명·카메라·후처리를 재현한 캡처가 아니다. 비교판에는 위치를 일정하게 둔 정면·후면·지휘 포즈를 모두 제공한다.

기존 스토리 초상은 같은 256×384 크기의 전신 구도다. 이번 요청의 **흉상**을 우선하여 새 초상은 머리와 가슴까지 확대했다. 캔버스와 중앙 정렬은 유지하지만 얼굴 배율은 기존 전신 초상과 다르다. 최종 선택 시 흉상 구도를 유지할지 함께 결정하면 된다.

검토 페이지의 자동 전환은 네 **정적 포즈를 차례로 보여 주는 기능**이다. 새 걷기·달리기·지휘 애니메이션이 아니다. 배율 단추는 원본 1배 / 게임 크기 / 원본 4배를 구분한다.

## 다음 단계

최종 그림은 재질별 약 3단계 색을 담은 안별 제한 팔레트로 정리했다. `palette.json`에 실제 색을 기록했다. 초상도 기존 초상의 큰 도트에 맞춰 64×96 작업 격자에서 정리한 뒤 최근접 4배로 256×384를 만들었다. 생성 원안은 처리 전 자료이므로 최종 그림보다 색 수가 많고 반투명 가장자리가 남아 있다.

A/B/C 중 하나를 고른 뒤 K-108에서 걷기·달리기·대기·지휘 전체 그림과 필요한 표정을 제작한다. 아직 게임 연결, Unity 실행, 실제 플레이 캡처, 커밋은 하지 않았다.
