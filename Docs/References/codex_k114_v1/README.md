# K-114 · 탑과 일꾼 참고 그림

1920×1080 정지 콘셉트 3장입니다. 실제 정비 마당의 왼쪽 파손 성벽, 병영 아치, 중앙 공방, 오른쪽 초록 차양 상점과 계단을 바탕으로 만들었습니다. 야간 전투 화면의 성벽과 병사 색을 함께 참고했습니다.

- `night_courtyard_1920x1080.png`: 계단을 내려오는 루멘, 점화된 등대와 북쪽 빛줄기.
- `night_capstan_1920x1080.png`: 탑 하부를 열어 보여 주는 근접 장면. 루멘의 명령, 일꾼 셋의 수평 손잡이와 수직 축·상부 회전판.
- `day_prep_1920x1080.png`: 같은 마당에서 꺼진 등대를 비계로 수리하는 낮 장면.
- `*_generated.png`: 내장 이미지 생성 도구의 원본 1672×941.
- `*_detail_4x.png`: 납품본의 480×270 부분을 최근접 4배 확대한 세부 보기. 전체 장면 4배판은 아닙니다. 자른 위치는 manifest.json에 있습니다.
- `prompts.json`: 내장 image_gen 도구에 보낸 생성 지시 원문.
- `verification.json`: 파일 크기·알파·검토 페이지 내장 이미지 검사 기록.

검토 페이지: `../../../_HTML/6_그림_화면/codex_K-114_탑과일꾼_참고_v1.html`

## 읽는 법

검토 페이지는 외부 리소스 없이 직접 열 수 있습니다. 그림과 실제 게임 자료를 나란히 배치했습니다. 세부 보기와 원본 자료도 내장했습니다. 정지 콘셉트 카드이므로 동작 시트나 프레임 애니메이션은 만들지 않았으며, 빛 회전은 그림 속 궤적으로만 표현합니다.

## 확인과 남은 검토

세 납품본은 1920×1080이며 최근접 보간으로 정규화했습니다. 알파는 모두 255인 불투명 배경 그림입니다. 투명 스프라이트가 아니므로 발 피벗·프레임 기준선·투명 영역의 떠돌이 픽셀 검사는 해당하지 않습니다. 이미지 내용은 직접 열어 확인했습니다. 브라우저 연결이 없어 페이지의 실제 렌더링·모바일 화면 검사는 수행하지 못했습니다. 내장 PNG는 별도로 디코딩했습니다.

- 참고용 콘셉트이며 실제 게임 캡처나 배치 확정안이 아닙니다.
- 일꾼을 보여 주기 위해 K-102의 탑 하부를 넓혔습니다. 최종 크기와 절개 구조는 게임 적용 시 검토가 필요합니다.
- 근접 장면은 구조 설명용 확대이며 전경과 벽면·장치 세부가 완전히 일치하지 않습니다.
- 캐릭터는 그림 안의 참고 표현이며 73점 스프라이트 납품물이 아닙니다.
- 정지 그림이므로 발 기준선·프레임 흔들림 검사는 해당하지 않습니다.

Game/, 협업 로그와 Git 이력은 수정하지 않았으며 Unity도 실행하지 않았습니다.
