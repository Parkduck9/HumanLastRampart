## 초상·배경 제안 이름

요청 문서가 인물·배경 파일명을 지정하지 않아 다음 이름을 제안한다.

| 파일 | 규격 | 내용 |
|---|---|---|
| story_portrait_hero.png | 1024×384 | 주인공 장교 4표정 |
| story_portrait_wizard.png | 1024×384 | 마법사 4표정 |
| story_portrait_archer.png | 1024×384 | 궁수 전령 4표정 |
| story_bg_rampart_dusk.png | 640×360 | 해 질 녘 성벽 |
| story_bg_rampart_night.png | 640×360 | 같은 성벽의 밤 |

- 시트는 가로 4칸, 각 칸 256×384. **왼쪽부터 보통·웃음·놀람·결의**다.
- 각 칸의 흉상 내용 영역은 **왼쪽 위 기준 x=64, y=160, 폭=128, 높이=192**. 얼굴·가슴 위 흉상을 크게 확대하더라도 대사창 위에 들어가도록 투명 여백을 남겼다. 미리보기는 이 내용 영역의 정확히 3배다.
- 검토 장면은 640×360 논리 격자에 초상 칸을 원래 크기로 놓고 전체 그림을 3배로 출력한다. 초상 그림 자체를 임의의 소수 배율로 줄이지 않는다. 글자는 1920×1080 출력 위에 별도로 얹는다.
- 현재 게임의 기존 초상 배치에 그대로 복사했을 때의 흉상 위치·크기는 확인하지 않았다. Claude가 여백을 고려해 연결해야 하며, 이 배치 시안을 인터페이스 확정으로 쓰면 안 된다.
- 주인공은 흰 머리·검정과 금 장교복, 마법사는 밤색 머리·보라색 로브·금 장식을 참고했다. 궁수 기존 그림은 뒷모습뿐이므로 **얼굴은 새 시안**이다. 얼굴이 같은 사람으로 읽히는지는 사용자 검토가 필요하다.
- 배경은 인물 없이 제작해 전신 비율을 확정하지 않았다. 배경 장면은 이야기 문서의 특정 사건을 새로 정하는 자료가 아니다.

## 제작 자료

- `build_ui.ps1`: 코드로 관리하는 정수 화소 UI 도형·재질 원본. `-Story`를 주면 스토리 부품도 만든다. 모든 주석은 한글이다.
- `source_hero.png`, `source_wizard.png`, `source_archer.png`, `source_bg_dusk.png`, `source_bg_night.png`: 내장 imagegen 원안 5장.
- `source_hero_clean_attempt.png`, `source_wizard_clean_attempt.png`: 광륜 제거 편집 재시도 2장, **미채택**.
- `prompts.json`: 실제 생성·편집 프롬프트 원문과 채택 관계. 프롬프트 원문은 재현 자료라 영문 그대로 보존했다. UI 설명·주석·검토 페이지는 한글이다.
- `prepare_story.ps1`: 원안을 최근접 표본으로 규격에 맞추고 투명 칸에 배치한다. 색·알파 의미를 바꾸거나 자동으로 배경을 제거하지 않는다.
- `review_template.html`, `build_review.ps1`: 납품 PNG 51종을 내장한 독립 HTML 제작 자료.
- `verify_assets.ps1`, `qa_assets.json`: 파일 규격·RGBA·팔레트·알파·경계 검사와 결과.
- `qa_review_logic.json`: JavaScript 구문과 가상 DOM·Canvas에서의 경계·상태 연산 확인. **실제 브라우저 시험 아님**.
- `proof_ui_3x.png`: UI 3배 확대 도판. **브라우저/유니티 캡처 아님**.

Windows PowerShell에서 이 폴더의 `build_ui.ps1 -Story` → `prepare_story.ps1` → `build_review.ps1` → `verify_assets.ps1` 순서로 재생성한다. 외부 패키지 설치는 필요 없다.
