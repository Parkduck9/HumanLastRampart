# K-120 정비 마당 배경

기존 3840×1080 가로 파노라마를 새 안뜰 배치로 다시 그렸습니다. 중앙 사각 등대, 북쪽 계단에서 등대 둘레 광장으로 이어지는 포장길과 가로등, 성벽 주변의 낮은 건물 열 채가 기준입니다. 실제 안뜰 캡처는 배치 참고로, 기존 정비 배경은 정면 구도와 바닥 원근 참고로 사용했습니다.

## 배치와 구분

- 서쪽: 성벽 수리소(망치·돌), 굴뚝이 있는 대장간.
- 동쪽: 병영(교차 창), 울타리와 건초가 있는 마구간.
- 북쪽: 작은 종탑의 예배당, 곡물창고, 작은 창고. 가운데 계단과 길을 비웠습니다.
- 남쪽: 함정 공방(덫), 상점(동전 주머니·올리브색 차양), 작은 집. 우물은 남서쪽 가장자리에 두었습니다.
- 중앙: 12m 사각 등대 디자인과 원형 석재 광장. 낮에도 등실 안의 작은 불이 보입니다.

## 연결 시 주의

Game 파일은 변경하지 않았습니다. 이 그림은 등대까지 포함하므로 현재 `AddBeaconTower`가 덧그리는 탑·불꽃을 그대로 겹치면 탑이 두 개로 보입니다. Claude가 연결 시 중복과 가림 순서를 조정해야 합니다.

현재 `BuildScene`은 `PrepYard/prep_yard`를 한 번 로드하고 봉화 상태에 따라 배경을 바꾸지 않습니다. 따라서 카드의 조건부 소등 배경은 만들지 않았습니다. 향후 배경 자체를 상태에 따라 교체한다면 등실 부분만 바꾸는 변형이 별도로 필요합니다.

경계 사각형은 위쪽 왼편을 원점으로 하는 `[x,y,너비,높이]`이며 오른쪽·아래쪽 경계는 포함하지 않습니다. 건물 본체·간판·붙어 있는 소품을 포함한 수작업 측정 범위입니다. 문 바닥 좌표와 문 앞 접근 영역은 별도로 있습니다. **건물 경계 전체를 이동 트리거로 쓰지 마세요.** 접근 영역은 연결 검토용 제안이며 기존 보행 마스크에서 도달 가능한지 확인하지 않았습니다.

그림 크기와 가로 스크롤 방식은 기존과 같습니다. 정면 시점과 바닥 원근을 따라 그렸지만 실제 입체 메시를 기존 카메라로 재투영한 그림은 아닙니다. 등대의 미터 단위 투영, 기존 `layout.json`·`walkable_mask`·가림 그림·충돌체와의 일치는 보장하지 않습니다. Claude가 새 경계에 맞춰 다시 연결하고 실제 게임에서 확인해야 합니다.

게임용은 원본의 정확한 최근접 3배이고 미리보기는 정확한 4배입니다. 포인트 필터, 압축 없음, 밉맵 없음, 원본 크기 유지가 기준입니다. 전체가 불투명한 배경이므로 캐릭터의 발 밑선·투명 외곽 고립 픽셀 검사는 해당하지 않습니다. 문 바닥은 장소마다 기록했습니다.

## 제작과 검증

내장 이미지 생성 도구로 구도와 그림을 제작한 뒤, 생성 패딩을 제거하고 최근접 방식으로 픽셀 격자를 맞췄습니다. 조사 후 정리한 카드별 금지 사항은 루트 `CARD_RESULT.md` 맨 위에 있습니다. 흐린 픽셀·과한 빛 번짐·네온색·무의미한 장식을 피하고 석재·목재·기와의 명암과 기능 간판을 우선했습니다.

픽셀 크기·불투명 알파·패딩색 제거·정확한 3배/4배 일치는 `pixel_verification.json`에 있습니다. 실제 브라우저의 이미지 로딩·경계 전환·좌우 보기 결과는 `review_verification.json`에 기록합니다. Unity 실행, 게임 적용, 플레이·충돌·이동 검증은 수행하지 않았습니다.
