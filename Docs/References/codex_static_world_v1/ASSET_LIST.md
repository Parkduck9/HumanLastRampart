## 사용·교체 방법

_HTML/codex_전투정적에셋목록_v1.html을 더블클릭한다. 카드에서 원본/포장 PNG와 규격 JSON을 내려받을 수 있고, 파일 선택으로 임시 대체 그림을 넣어 비교할 수 있다. 임시 비교는 브라우저 안에서만 바뀌며 프로젝트 파일을 덮어쓰지 않는다. 교체할 때 에셋 ID와 바꾸고 싶은 부분을 알려주면 해당 시안만 v2로 만든다.

원본은 source.png, 검토 포장은 static_grid.png, 규격은 asset.json으로 각 ID 폴더에 보관한다. 생성은 imagegen 스킬의 내장 도구로 에셋별 호출했다. 총탄·함정은 첫 결과의 실사 질감을 제외하기 위해 도트 시안으로 재생성했다. 프롬프트와 원본 경로는 generation.json 및 corrections.json. 포장은 그림 재색칠 없이 최근접 축척/배치만 한다.

PNG/알파/칸 경계/내장 자료·JS 구문 검사 및 실제 브라우저 확인 결과는 qa.json에 기록한다. Unity Play·게임 연결·완전 타일 접합·최종 카메라 비율은 별도 검토 대상이다.

### 제작 후 확인

8개 정적 PNG의 RGBA·1칸 규격·배치 경계·저장 픽셀 일치, 사물 투명 배경과 바닥 불투명, HTML 내장 PNG/원본/JSON의 파일 바이트 일치, JS 구문과 HTML 두 사본 일치를 확인했다. 실제 브라우저에서 카드 8개와 이미지 11개(반복 성벽 3개 포함) 로드, 투사체 분류 3종, 배경·작은 크기, 대포 원본 파일을 선택한 임시 비교·원본 복원을 확인했다. 검사 콘솔 오류 0, 기본 창 가로 넘침 없음. browser_review.png에 전체 화면을 보관했다. file: 직접 실행은 검사하지 않았으며 외부 자료 요청이 없는 단일 HTML로 제공한다.
