# K-078 사다리 고블린 동작 1판

주인공 v6의 **처음 생성본** `codex_hero_octopath_review_v6/generated.png`와 K-066 사다리 고블린 통일판(K-069 수정), K-070의 고블린 약 56점 비율을 기준으로 제작했습니다. 검은 뾰족머리, 황록 피부, 황색 홍채와 흰 반사점, 갈색 스카프·가죽옷, 손목 붕대, 큰 갈색 장화를 유지했습니다. 적의 눈 색은 K-066의 종족 색을 따릅니다.

## 납품 파일

각 파일의 `_native.png`는 원본, `_4x.png`는 원본의 최근접 4배 미리보기입니다. 접미어 없는 PNG가 연결용입니다. 모든 프레임은 왼쪽부터 읽습니다. 기존 파일명·칸 수·동작 단계 순서를 유지하며, 캐릭터 칸 크기만 D-081에 따라 바뀝니다. 기존 `Walk`는 사다리 포함, `carry_run4`는 인물만이므로 그 구성을 그대로 따랐습니다. 운반 달리기는 생성 원안의 칸을 2→1→4→3 순으로 배치해 기존 지지발 순서에 맞췄습니다.

## 크기와 연결 기준

- 카드 제목의 크기 미정 표시는 D-081의 확정값으로 해소했습니다. 고블린 몸은 약 56점이며, 작은 사다리나 높이 든 팔까지 포함한 범위는 더 큽니다.
- 캐릭터 원본 발 기준은 (48,120), 게임용은 (144,360)입니다. 마지막 불투명 행은 원본 y=119, 게임용 y=359입니다. 좌표는 이미지 왼쪽 위에서 잽니다.
- 몸통은 허리띠 버클의 중심을 x=48±0.5점에 정렬했습니다. 발선은 모든 칸에서 같습니다. 사다리나 팔이 한쪽으로 뻗어도 전체 그림의 경계 상자를 억지로 가운데에 맞추지 않았습니다.
- Unity의 아래쪽 원점 기준 정규화 피벗은 캐릭터 (0.5,0.0625)입니다. `manifest.json`에 출력 크기·각 프레임 경계·몸통 기준점·프레임 순서·연결 대상 경로를 적었습니다.
- 별도 사다리는 예외입니다. 기존 256×1536, 바닥 (128,1472)을 유지했습니다. 원본 64×384를 4배 확대하며, 원본 바닥은 (32,368), 마지막 불투명 행은 367입니다. 정면·측면 모두 위쪽 y=320부터 바닥 y=1472까지 1152점의 그림 범위를 유지합니다. 게임 높이 4.3m 연결은 Claude가 담당합니다.
- 등반은 요청한 정면 아래 시점으로 바뀌었습니다. 화면 오른쪽 손·무릎 올림 → 왼쪽 손으로 옮겨 잡기 → 왼쪽 손·무릎 올림 → 오른쪽으로 다시 잡기 순서입니다. 실제 사다리와 손·발의 접촉 위치는 게임 연결 후 확인해야 합니다.

## 제작과 재현

내장 image_gen으로 동작별 원안을 생성하고 서기·등반을 추가 수정했습니다. `source_*.png`에 원안을 보관하고 `prompts.json`에 사용한 프롬프트를 기록했습니다. 등반 2칸은 `source_climb_corrected.png`의 두 번째 칸, 3칸은 `source_climb_left.png`를 사용합니다. 나머지 출처는 manifest에 있습니다.

`build.py`는 투명도 128 기준 이진화, 프레임 분리, 최근접 축소, K-066 색상 중심의 제한 팔레트 적용, 고립된 4점 이하 잔여 조각 제거, 버클 중심·발선 배치, 게임용 확대와 검토 HTML 생성을 수행합니다. 새 동작을 코드로 그리지 않고 생성 원안을 시트 규격에 맞게 정리합니다. `sources.json`은 출력 높이와 초기 정렬값입니다.

## 검증

- 캐릭터 총 17칸: 원본·게임 크기, 알파 0/255, 모든 발선, 몸통 중심 x=48±0.5, 각 칸 하나의 연결된 실루엣, 동작별 프레임 고유성, 3배 최근접 픽셀 일치를 검사했습니다.
- 사다리 2장: 원본·게임 크기, 알파, 마지막 불투명 행, 단일 실루엣, 4배 최근접 픽셀 일치를 검사했습니다. 상세 결과는 `validation.json`입니다.
- 한국어 검토 HTML은 이미지와 코드를 모두 내장하여 서버 없이 직접 엽니다. 현재 게임 원화와 새 원본을 같은 칸 높이로 비교하며, 금색 선은 각 시트의 발선입니다. 실제 플레이 화면이 아닙니다.
- `verify_review.cjs`로 Chrome에서 이미지 21개(캔버스용 14개, 전체 시트 7개)의 디코딩, 재생·정지·한 칸 이동, 스크립트 오류, 390점 화면의 페이지 가로 넘침을 검사했습니다. `review_validation.json`, `review_desktop.png`, `review_mobile.png`를 참고하세요.
- `game_hashes_before.json`과 최종 해시를 비교하여 Game/ 1065개 파일의 무변경을 확인합니다. 최종 결과는 `scope_validation.json`에 기록합니다.

Unity 실행·Play·게임 연결은 수행하지 않았습니다. 최종 게임 표시 크기, 설치 완료 시점, 사다리와 등반 손·발의 접촉은 Claude의 연결과 사용자 플레이 확인이 남아 있습니다.
