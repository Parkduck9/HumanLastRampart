# 마법사 밤색 머리 구분 시안 v1 (T-CX-038)

- 상태: 색상 후보 시안, 사용자 검토 대기. 확정 디자인/게임 연결 승인 아님.
- 사용자 문서 방향으로 사진 다시 생성 요청. 우선 직전 제작 대상인 마법사 후면을 변경한다.
- 근거 D-055: 플레이어 이외 인물은 머리·의상·장비·실루엣으로 구분한다. 구체 색은 미정이므로 이번 밤색은 Codex 제안이다.

## 시안

백발 플레이어와 구분되는 따뜻한 밤색/적갈색 머리. 기존의 보라색 금테 의상, 갈색 벨트·부츠, 파란 수정 지팡이, 약2.2등신의 후면 서 있기 포즈를 유지한다. 머리색 이외 요소는 유지하도록 imagegen 편집을 요청했고 전체 모습을 육안 확인했다. 픽셀 단위 완전 동일성은 보장하지 않는다.

원본 백발 v1은 덮어쓰지 않는다. 정면 마법사는 아직 백발이며 이번 시안에서 수정하지 않았다. 색상 방향을 사용자가 결정하면 정면·후면·이후 프레임을 함께 맞춘다. 다른 병사·인물의 새 색/디자인도 별도 시안과 검토가 필요하다.

## 파일과 규격

wizard_back_chestnut_source.png: 생성 원본.
wizard_back_chestnut_grid.png/json: 투명RGBA256×384, 1열1행, frame0/FPS0, 발(128,352), Unity pivot(.5,32/384), aspect2/3. 격자 파일은 최근접 축척·배치만 한다.
build_sheet.py, generation.json, qa.json, README.md, preview.html도 보관한다.
사용자 HTML: _HTML/codex_마법사머리색시안_v1.html.

규격·알파·잘림·색 추가 없는 최근접 포장·저장 픽셀 일치 검사를 통과했다. HTML 그림8개 및 PNG/JSON/MD다운로드를 내장하여 서버 없이 비교 가능하다. 실제 브라우저 시각 검사/Unity 실행/게임 연결은 수행하지 않았다. 기존 PNG와 게임 데이터는 유지한다.
