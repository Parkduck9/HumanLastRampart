# K-094 · 함정 자유 설치 그림

폭발 함정 1종의 지도용 표식, 범위 원, 매설 먼지와 자유 배치 견본입니다. 현재 `TrapCatalog.asset`에 등록된 `trap_bomb`를 기준으로 제작했습니다. 기존 전투 그림 `trap_1.png`와 `trap_2.png`를 서로 다른 종류로 늘리지 않았습니다.

검토 페이지: [`함정 자유 설치`](../../../_HTML/6_그림_화면/codex_K-094_함정자유설치_v1.html). 모든 그림을 내장하여 서버 없이 직접 열립니다. 현재 게임 그림과 비교, 포인터·방향키 자유 이동, 반경 변경, 불가 상태, 매설 먼지 재생을 확인할 수 있습니다. 이 페이지의 배치는 견본이며 실제 구매·저장·게임 지형 판정과 연결되지 않습니다.

## 크기와 기준점

- 지도 배율은 5m당 32화소, 즉 1m당 6.4화소입니다. 지도 아이콘은 24×24화소이며 중심은 왼쪽 위 기준 (12, 12)입니다. 흙·마개 본체는 약 22화소 안에 들어가며 선택 모서리는 24화소 외곽을 씁니다.
- 지도 상태 시트는 120×24화소입니다. 왼쪽부터 `buried`, `armed`, `selected`, `ghost`, `ghost_invalid` 순서입니다. 상태 시트는 애니메이션이 아니며 상태별로 한 장씩 고릅니다. 무장은 작은 붉은 심지 표시이고 실제 점화·폭발 연출은 포함하지 않습니다.
- 매설 먼지는 32×32화소 네 장, 매설 기준점 (16, 26), 초당 10장, 한 번 재생으로 0.4초입니다. 프레임 순서는 `dig_0` → `dig_1` → `dig_2` → `dig_3`입니다. 상승량 0·1·3·5화소와 투명도 감소는 의도된 동작입니다. 완료 후 효과를 제거합니다.
- 공통 시트는 96×128 원본과 정확한 최근접 3배인 288×384를 함께 제공합니다. 함정 5장, 먼지 4장입니다. 매설 기준점은 (48, 120) / (144, 360)이며 사람의 발을 그린 것은 아닙니다. 지도에는 작은 전용 그림과 중심 피벗을 사용합니다. 지도 원본의 함정 중심은 공통 납품 시트의 매설 기준점과 다르므로 두 피벗을 혼용하지 않습니다.
- Unity 정규화 피벗은 지도 아이콘 (0.5, 0.5), 지도 먼지 (0.5, 0.1875), 공통 시트 (0.5, 0.0625)입니다. 점 필터·압축 없음·투명도 사용을 권장합니다. Unity 임포트 설정은 변경하지 않았습니다.

## 범위 원 사용

기본 피해 반경은 현재 `TrapDef.cs`의 10m입니다. 지도 원본에서는 반경 64화소, 원 그림은 133×133화소, 중심 (66, 66)입니다. 반경별 캔버스 크기는 `2 × 반경 + 5`, 중심은 `반경 + 2`이며 바깥 투명 여백을 둡니다. 5·10·15·20m에 해당하는 반경 32·64·96·128화소를 제공합니다.

원은 한 화소 정수 점선이며 약 4화소 선과 4화소 공백을 반복합니다. 내부 채움은 중심 알파 8에서 가장자리 약 30까지 옅게 증가합니다. 선과 채움을 독립 파일로 제공하므로 채움 → 선 → 아이콘 순서로 겹칠 수 있습니다. 허용은 황동 또는 초록, 불가는 빨강이며 검토 페이지에서는 ×도 함께 보여 줍니다.

PNG 자체를 늘리면 선도 굵어집니다. 임의 배율에서는 최종 화면 반경으로 원을 다시 그리거나 `vector-effect="non-scaling-stroke"`가 지정된 SVG를 사용해야 합니다. 검토 페이지는 확대된 지도에서도 점선을 화면 한 화소로 다시 그립니다. Unity에서 SVG를 직접 읽는 데 필요한 패키지나 렌더러는 설치하지 않았으며, Claude가 현재 사용 중인 방식에 맞춰 연결해야 합니다. 재생성 알고리즘은 `build_assets.ps1`과 검토 페이지 안에 보존했습니다.

## 제작과 검증

내장 이미지 생성 도구로 함정·먼지 원안을 만든 뒤, 각 영역을 분리하여 작은 화소 격자로 최근접 샘플링하고 제한 팔레트와 외곽선을 적용했습니다. 바깥 분리 화소를 제거하고 동일 원안에서 상태와 먼지 네 단계를 파생했습니다. 범위 원은 크기·한 화소 선을 통제하는 정수 원 알고리즘으로 제작했습니다.

- PNG 64장의 크기·알파·해시를 기록했습니다. 기본·무장·미리보기 아이콘과 먼지 프레임은 각각 연결된 한 덩어리입니다. 선택 모서리와 점선 조각은 의도된 분리 요소입니다.
- 지도·공통 시트의 순서와 매설 기준점, 3배 및 4배 그림의 모든 화소 일치를 검사했습니다. 투명 픽셀의 보이지 않는 RGB 차이는 프레임 비교에서 제외합니다.
- Chrome 헤드리스 브라우저 검사 13항목을 통과했습니다. 내장 그림 12종 로드, 오류 없음, 소수 자유 좌표 유지, 허용 위치 클릭, 불가 위치 배치 차단, 2배 반경 재생성, 방향키·엔터, 먼지 정지·재생을 확인했습니다.
- 전체 페이지와 2배 불가 상태의 브라우저 화면을 확인했습니다. 화면 이미지들은 Unity 캡처가 아닙니다.

재생성은 이 폴더의 `build_assets.ps1` → `build_review.ps1` 순서입니다. 파일 검사는 `verify_assets.ps1`, 브라우저 검사는 `verify_browser.cjs`입니다. 스크립트는 외부 패키지 없이 Windows의 System.Drawing과 로컬 Node.js·Chrome을 사용합니다. 브라우저 경로는 현재 PC 기준이므로 다른 환경에서는 조정해야 합니다.

## 남은 연결 작업

Claude가 실제 지도의 자유 좌표 입력·설치 판정·함정 상태·반경 데이터·매설 효과를 연결해야 합니다. 범위 원의 겹침 자체를 설치 금지 규칙으로 추가하지 않았습니다. 지도 바탕은 현재 타일로 재조합한 미술 견본이며 실제 맵 데이터의 재현이 아닙니다. 게임 연결·Unity Play·실제 게임 캡처·사용자 외형 확정은 수행하지 않았습니다. 기존 Game 파일과 기존 검토 페이지·목록·협업 기록을 변경하지 않았습니다.

검증 후 임시 Chrome 프로필 `qa/browser-profile/`의 삭제가 자동 승인 검토에서 정책 차단되었습니다. 상세 사유는 반환되지 않았습니다. 그림 자료가 아니므로 Claude가 커밋 대상에서 제외하고 정리해야 합니다. `qa/browser_dom.txt`는 사용하지 않은 빈 파일이며, `qa/review_browser.png`는 초기 추가 화면입니다. 최종 검토 증거는 `qa/review_browser_full.png`와 `qa/radius_invalid_zoom2.png`입니다.
