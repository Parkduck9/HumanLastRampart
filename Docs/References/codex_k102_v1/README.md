# K-102 중앙 등불탑

[검토 페이지](../../../_HTML/6_그림_화면/codex_K-102_등불탑_v1.html)는 서버 없이 직접 열 수 있습니다. 모든 그림과 재생 코드를 내장했습니다. 꺼짐·예열·완전 점화, 불꽃 반복, 기존 게임 에셋 비교, 밤 전투와 낮 정비 목업을 확인할 수 있습니다.

이 카드는 등불탑 컨셉 에셋만 제작합니다. 제안 문서의 게임 규칙이나 카메라 설정을 확정하지 않으며, Game 폴더를 수정하지 않았습니다.

## 크기와 연결

탑 기준 셀은 96×128, 게임 셀은 288×384입니다. 세 상태 모두 실루엣 74×98화소이며 x=11~84, y=23~120에 들어갑니다. 73화소 인간보다 조금 높은 중앙 시설입니다. 탑의 지면 기준점은 기준판 (48,120), 게임판 (144,360)입니다. 좌표는 왼쪽 위가 원점입니다. Unity의 정규화 피벗으로 옮기면 탑은 (0.5,0.0625)입니다.

불꽃은 투명 배경의 독립 시트입니다. 탑과 같은 크기의 셀을 사용하므로 같은 캔버스 위치에 겹칩니다. 화로 기준점은 (48,42), 게임판은 (144,126)입니다. 모든 프레임의 불꽃 하단은 기준판 y=41에 고정하고 윗부분의 높이와 좌우 흔들림만 바꿨습니다. 왼쪽부터 0~5, 초당 8프레임으로 반복합니다. 분리 불꽃에는 발 픽셀이 없습니다.

빛기둥은 길이가 필요해 별도 셀 96×256, 게임판 288×768을 사용합니다. 기준점은 (48,248), 게임판 (144,744)이며 화로 기준점에 맞춥니다. 따라서 탑 캔버스 왼쪽 위 기준 오프셋은 (0,-206), 게임판은 (0,-618)입니다. 기둥을 탑·불꽃 뒤에 두고 `SrcAlpha One` 가산 합성을 사용합니다. PNG는 미리 알파를 곱하지 않은 RGBA입니다. `One One` 재질에 그대로 넣으면 투명 가장자리 RGB까지 더해질 수 있으므로 합성 계수를 맞춰야 합니다. 실제 조명, 블룸, 안개 제거는 포함하지 않습니다.

일반 탑과 불꽃은 이진 알파, 빛기둥은 반투명 알파입니다. 텍스처는 Point 필터, 압축 없음, 밉맵 없음이 기준입니다. 실제 연결과 렌더 순서는 Claude가 적용합니다. 기존 게임에 동일한 등불탑이 없어 교체하는 파일이나 유지할 기존 프레임 순서는 없습니다.

## 제작과 목업 범위

내장 `image_gen` 도구로 투명 원안을 1회 생성했습니다. 현재 `wall_a.png`와 승인된 정비 마당을 시점·재질 참조로 사용했습니다. 원안은 투명도 정리, 작은 색상 단계 정리, 최근접 축소, 외딴 픽셀 제거 후 같은 지면 기준선으로 정렬했습니다. 불꽃 원안을 행 단위로 흔들고 높이를 바꾸어 6프레임으로 구성했습니다. 탑 상태는 폐허 화로가 점화 과정에서 복원되는 표현입니다. 빛기둥 주변의 분리된 불티는 의도한 효과입니다.

전투 목업은 `codex_k085_v1/battle_before.png` 기존 캡처를 1920×1080으로 맞추고 배경 RGB 전체에 0.65를 곱한 뒤 탑과 가산 빛기둥을 얹었습니다. 기존 화면에 있던 UI도 함께 어두워진 합성 예시이며 실제 야간 셰이더 결과는 아닙니다. 탑 지면 기준점은 (960,1030)입니다.

정비 목업은 `codex_k089_v1/prep_yard.png`의 중앙 (960,0)부터 1920×1080 영역을 잘라 기존 픽셀 비율을 유지했습니다. 탑 지면 기준점은 (960,915)입니다. 영웅은 `codex_k070_v1/hero_native_96x128.png`를 사용했습니다. 영웅 디자인을 새로 생성하거나 수정하지 않았습니다.

## 확인

`node Docs/References/codex_k102_v1/assemble.cjs`로 에셋과 HTML을 다시 만듭니다. 이어서 `verify.cjs`로 크기, RGBA 알파, 탑 기준선과 중심, 각 불꽃의 고정 하단, 분리된 픽셀, 정확한 3배 복제를 검사합니다. `verify_review.cjs`는 설치된 Playwright와 Edge를 이용해 로컬 HTML의 이미지 디코딩, 두 불꽃의 프레임 진행, 일시정지, 모바일 가로 넘침과 자바스크립트 오류를 검사합니다.

Unity 실행·Play·실제 게임 연결 검증은 수행하지 않았습니다. 탑의 월드 위치, 실제 카메라 가림 관계, 가산 재질·광원 강도는 연결 후 확인이 남습니다.
