# K-074 총병 동작 1판

검토 페이지: [총병 동작 비교](../../../_HTML/4_그림_캐릭터/codex_K-074_총병동작_v1.html). 그림·스타일·스크립트를 내장했으므로 서버 없이 직접 열 수 있다. 현재 게임 시트와 나란히 재생하며 정지, 한 칸 이동, 좌우 뒤집기, 속도 변경을 제공한다.

## 제작 기준

카드 제목의 크기 미정 표시는 본문의 확정 규칙 D-081을 적용했다. 원본 칸은 96×128, 서 있는 인물은 약 73픽셀, 머리는 약 24픽셀이다. 처음 생성한 주인공 6판 `codex_hero_octopath_review_v6/generated.png`를 스타일 기준으로 사용했다. 정정본·기존 56×112 주인공·미리보기는 기준으로 사용하지 않았다.

K-065 총병 앞·뒤의 갈색 머리, 남색·크림색 군복, 가죽 띠와 큰 갈색 장화를 유지했다. K-070 궁수는 체형 참고만 했다. 총은 긴 금속 총열과 나무 개머리판이 있는 머스킷으로 제작했다. 얼굴이 보이는 달리기·피격 프레임에는 파란 눈과 밝은 눈 강조가 있다.

기본 이미지 생성 도구로 4종 원안을 만든 뒤 연결된 인물 영역을 추출하고 최근접 축소, 32색 양자화, 이진 알파, 발선 배치를 수행했다. 원안은 `*_generated.png`, 전체 프롬프트는 `prompts.json`, 재현 스크립트는 `build.py`다. 생성 원안은 완벽하게 균일한 격자가 아니므로 모든 국소 외곽선이 정확히 한 점 두께라고 보장하지는 않는다.

## 전달 규격

| 동작 | 게임용 파일명 | 칸 수 | 왼쪽부터 순서 |
|---|---|---:|---|
| 후면 대기 | `gunner_static.png` | 1 | 대기 |
| 측면 달리기 | `gunner_run.png` | 4 | 오른발 전진 → 교차 → 왼발 전진 → 교차 |
| 후면 사격 | `gunner_fire.png` | 6 | 견착 → 조준 → 발사·총구 화염 → 반동 → 총 내리기 → 재장전 암시 |
| 쓰러지기 | `gunner_fall.png` | 4 | 피격 → 무릎 꺾임 → 옆으로 넘어짐 → 쓰러짐 |

각 동작의 `*_native.png`는 원본, 접미사 없는 파일은 정확한 최근접 3배 게임용, `*_4x.png`는 원본의 정수 4배 확대다. `contact_sheet_4x.png`로 전체 15칸을 볼 수 있다.

- 원본 칸 96×128, 발 기준 (48,120), 마지막 불투명 행 y=119.
- 게임용 칸 288×384, 발 기준 (144,360), 아래 투명 여백 24픽셀.
- Unity 왼쪽 아래 기준 정규화 피벗은 (0.5, 0.0625). 위 좌표는 왼쪽 위 기준이다.
- 몸을 기준으로 정렬하므로 총구 화염 때문에 인물이 옆으로 밀리지 않는다. 달리기는 오른쪽을 보며 반대 방향은 좌우 반전한다.
- 쓰러질 때 키가 낮아지고 폭이 넓어진다. 마지막 프레임은 누운 몸의 접촉선을 발선에 맞췄다.

기존 게임 시트의 파일명·1/4/6/4칸 구성을 유지했다. D-081에 따라 칸 크기만 기존 256×384에서 288×384로 바뀐다. 비교 화면은 기존 시트를 확대하지 않고 기존 발 기준 (128,352)을 새 발선에 맞춰 (16,8)만큼 옮겨 표시한다. 검토용 재생 속도는 게임 재생 시간의 확정값이 아니다.

## 확인 결과와 인계

15칸 모두 RGBA, 알파 0/255, 바닥 마지막 행 y=119, 칸 경계 잘림 없음, 1~2픽셀 고립점 없음과 정확한 최근접 3배 확대를 확인했다. 프레임별 영역·연결 영역 크기는 `validation.json`, 칸 순서·크기·피벗은 `manifest.json`에 있다.

Chrome에서 내장 이미지 12개와 애니메이션 화면 8개의 로딩, 재생·정지·한 칸 이동·뒤집기·속도 변경을 확인했다. 스크립트 오류 0건, 너비 390픽셀에서 가로 넘침 없음. `review_validation.json`, `review_desktop.png`, `review_mobile.png`에 결과를 보관했다. 생성 원안·전체 칸·브라우저 캡처도 직접 확인했다.

읽기 전용 입력 `Game/Assets/_Project` 1,020개 파일의 시작·종료 SHA-256이 일치했다. Unity 실행·Play·실제 게임 캡처·게임 연결·Git 쓰기는 수행하지 않았다. 사용자 외형 검토 후 Claude가 Game의 시트 교체와 칸 크기·피벗·재생 설정을 연결한다. 노멀맵은 지정 산출물에 포함하지 않았다.
