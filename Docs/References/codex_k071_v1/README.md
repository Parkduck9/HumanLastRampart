# K-071 이야기 초상 6판

처음 생성한 주인공 6판 `codex_hero_octopath_review_v6/generated.png`와 K-065 아군의 머리색·복장·장비를 참고한 이야기 전용 전신 초상입니다. 보정본은 방향 기준으로 사용하지 않았습니다. 그림과 표정은 내장 이미지 생성 도구로 제작했으며, 파이썬은 최근접 규격 변환·알파 정리·시트 조립·검사·검토 페이지 제작에 사용했습니다. 정확한 프롬프트는 `generation_manifest.json`에 보관합니다.

## 현재 화자와 원본 규격

`story_intro.asset`와 `story_defeat.asset`를 읽었습니다. 이름 있는 화자는 장교·궁수·마법사입니다. 빈 화자는 내레이션이며 그림이 없습니다. 총병·대포병은 현재 이야기에서 말하지 않습니다.

| 화자 | 현재 파일 | 전체 크기·형식 | 이야기에서 읽는 칸 |
|---|---|---|---|
| 장교 | `Art/Characters/Hero/hero_walk_run_grid.png` | 1024×1536 RGBA PNG · 4열×4행 | 12번 · 맨 아래 행 첫 칸 |
| 궁수 | `Art/Characters/Static/archer_static.png` | 256×384 RGBA PNG | 0번 |
| 마법사 | `Story/Resources/StoryArt/wizard_front_chestnut.png` | 256×384 RGBA PNG | 0번 |

위 경로는 `Game/Assets/_Project/` 아래이며 읽기만 했습니다. StoryArt 폴더에는 현재 마법사 PNG만 있습니다. 다른 두 화자는 전투 그림을 재사용합니다. 원본 해시 목록은 `source_hashes_before.json`입니다.

`StoryCells`의 칸은 256×384이며 왼쪽 위부터 가로로 번호를 붙입니다. `StoryPlayer`의 화면 표시 크기는 512×768, RectTransform 피벗은 (0.5,0), 좌우 앵커는 (0.25,0)/(0.75,0), 기본 세로 위치는 140입니다. 말할 때 코드가 8만큼 올립니다. PNG 내부 발바닥 아래 경계 y=352와 몸의 중심축 x=128을 유지하므로 이 화면 배치 코드를 바꿀 필요가 없습니다. PNG 자체에는 Unity 앵커 정보가 없으며 `manifest.json`에 명시했습니다.

## 새 그림과 연결 방법

- `hero_neutral.png`, `hero_determined.png`, `hero_surprised.png`, `hero_tired.png`: 장교 기본·결의·놀람·피로.
- `wizard_neutral.png`, `wizard_determined.png`, `wizard_surprised.png`, `wizard_tired.png`: 마법사 기본·결의·놀람·피로.
- `archer_neutral.png`, `archer_alarmed.png`: 궁수 기본·경계.
- 위 10장은 모두 256×384 RGBA, 새로 연결할 때 칸 번호는 0입니다. 표정의 접미어가 파일명에 들어 있습니다.
- `*_64x96.png`는 각 그림의 기본 격자, `*_4x.png`는 납품 PNG의 최근접 4배(1024×1536) 확대본입니다.
- `hero_expressions.png`, `wizard_expressions.png`, `archer_expressions.png`는 표정을 왼쪽부터 나열한 시트입니다. 순서는 위 목록과 같습니다. 해당 `_4x`는 시트 자체의 최근접 4배 확대본입니다.
- `wizard_front_chestnut.png`, `archer_static.png`는 기존과 같은 파일명·크기·칸 수의 기본 표정 복사본입니다.
- `hero_walk_run_grid.png`는 기존과 같은 1024×1536·16칸 배열이며 **12번 칸만 새 기본 표정으로 바꾼 이야기 전용 복사본**입니다. 나머지 15칸은 원본 그대로입니다. 전투 공유 시트에 덮어쓰지 말고 이야기용 경로에 복사한 뒤 스토리의 그림 참조만 바꾸세요. 또는 `hero_neutral.png`를 사용하고 이야기 칸 번호를 0으로 바꾸세요. 이 카드에서는 게임 파일·참조를 바꾸지 않았습니다.
- `current_*.png`는 현재 게임에서 실제로 읽는 칸을 추출한 비교 자료입니다. `all_portraits.png`는 장교·마법사·궁수 순서의 전체 비교판입니다.
- `*_generated.png`는 각 표정의 생성 원안입니다. 생성 도구의 기본 저장 위치에 의존하지 않도록 폴더 안에 보관했습니다.

신규 게임 에셋의 `.meta` 생성과 기존 GUID 보존은 Claude가 실제로 연결할 때 처리합니다. 이 폴더는 Game 밖의 제작 자료이며 Unity를 실행하지 않았습니다.

## 격자와 검토

현재 초상 칸의 인물 높이에 맞춰 장교 76점·궁수 75점·마법사 74점으로 배치했습니다. 이는 이야기 초상용 배치이며 전투 인물의 52점/약73점 결정을 대신하지 않습니다. 모든 표정은 발바닥 아래 경계 88점(납품 352화소)에 놓이고, 장화 구간의 중심을 중심축 32점에 가장 가까운 정수 격자로 맞췄습니다. 좌우 비대칭 장비를 포함한 전체 알파 경계의 중심과 몸 중심축은 다릅니다.

`build_review.py`를 실행하면 PNG와 이미지 내장 HTML을 재구성하고 크기·이진 알파·발선·고립 픽셀·최근접 배율·게임 원본 해시·장교의 보존된 15칸을 검사합니다. `validation.json`에 실제 수행한 검사 결과를 기록합니다. 생성 원안의 미세 색상까지 재질별 정확히 3색으로 강제하거나 모든 외곽선 구간이 정확히 한 점임을 전수 보장하지는 않습니다. 생성 표정 사이 옷 주름과 국소 윤곽에는 약간의 차이가 남을 수 있습니다.

검토 페이지: `_HTML/4_그림_캐릭터/codex_K-071_스토리초상6판_v1.html`. 이미지·스타일·스크립트를 내장하여 서버와 외부 자료 없이 열립니다. 현재 게임 칸과 새 그림을 같은 크기로 나란히 표시하고, 1.2초 자동 표정 전환·수동 표정 선택·전체 표정 펼치기를 제공합니다. 움직임 시트가 아닌 표정 전환입니다.

내장 PNG 26개의 디코딩은 검사했습니다. 브라우저 연결 도구에서 인앱 브라우저를 사용할 수 없고 사용 가능한 브라우저 목록도 비어 있어 실제 HTML 렌더링과 단추 동작은 확인하지 못했습니다. Game 연결·Unity 실행·실제 화면 캡처는 수행하지 않았습니다. 최종 외형 채택과 Claude의 연결 뒤 게임 화면 확인이 남아 있습니다.
