# K-121 · 메인 화면과 등실 아이콘

[검토 페이지](../../../_HTML/6_그림_화면/codex_K-121_메인화면_아이콘_v1.html)는 새 메뉴·현재 게임 배경 비교, 시차 이동의 재생·정지, 제목·단추 표시 전환, 아이콘의 밝고 어두운 바탕 비교와 적응형 마스크 예시를 제공합니다. 그림과 함렛 Black 글꼴을 내장해 서버 없이 열립니다. 그림에는 글자를 그리지 않았습니다.

각 레이어는 640×360 논리 원본, 정확한 최근접 3배인 1920×1080, 4배인 2560×1440을 함께 제공합니다. 2560판은 새 세부 묘사를 추가한 그림이 아닙니다. 모든 레이어의 캔버스와 중앙 피벗은 같습니다. 정지 배경·아이콘이므로 인물용 96×128 셀·발 기준선·동작 프레임 규칙은 적용하지 않습니다.

## 배치와 연결

뒤에서부터 하늘 → 들판 → 요새와 등대 → 전경 순서입니다. 1920판을 그대로 겹치면 완성 배경과 픽셀이 일치합니다. 시차 이동에는 전체를 같은 중심에서 1.035배 확대해 화면 가장자리에 여유를 둡니다. 1920판 기준 좌우 이동 한도는 각각 2·4·6·10px, 위아래는 3px입니다. 강한 카메라 이동이나 회전용 배경은 아닙니다. 빛줄기는 요새에 붙은 정지 그림이며, 독립적인 회전 광원이나 빛줄기 애니메이션은 제공하지 않습니다.

현재 `MainMenuEntry.cs`와 `ScreenView.DockLeft`의 왼쪽 128px·폭 624px 배치를 읽고 왼쪽 공간을 비웠습니다. 검토 화면의 제목·단추는 배치 예시이며 실제 유니티 화면을 캡처한 것이 아닙니다. 제목은 요청된 ‘빛을 잇는 자들’을 함렛 Black으로 표시했고 기존 게임 제목 코드는 수정하지 않았습니다.

배경은 K-117의 평지 사각 요새와 K-115의 12m 등대·큰 돌·철창 등실·기와지붕·아치문을 참고했습니다. 실제 `courtyard_20261023/01_bldg_day_0_overview.png`도 확인했습니다. 해안 절벽이나 일반 판타지 성 대신 게임의 평지와 붉은 지붕·등대 광장 관계를 따랐습니다. 정확한 게임 렌더를 복사한 그림은 아닙니다.

아이콘은 등실·따뜻한 불빛·철창·지붕을 크게 잡았습니다. 정사각형 버전은 모서리 마스크를 포함하지 않습니다. 적응형 전경 전체는 가운데 (216,216), 반지름 132px 안전 원 안에 놓고 배경은 캔버스 전체를 채웠습니다. 원형·둥근 사각형 검토 마스크와 점선은 PNG에 포함되지 않습니다. [안드로이드 공식 적응형 아이콘 지침](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)을 참고했습니다. 단색 테마 레이어는 이번 납품 범위에 포함되지 않습니다.

## 제작과 확인

내장 이미지 생성 도구로 배경·아이콘을 만들고 하늘·들판·요새·전경을 분리했습니다. 분리는 생성 편집이므로 원안과 픽셀이 완전히 같지는 않습니다. 최종 배경은 납품 레이어를 다시 합성했습니다. 논리 픽셀 크기를 통일하고 알파 32 미만과 3픽셀 미만의 고립 성분을 제거했습니다. 요새 가장자리 보정 시도도 원자료에 남겼지만 최종은 첫 분리본을 사용했습니다. 아이콘과 레이어의 확대·축소는 최근접 방식입니다.

제작 전 [생성 그림의 시각적 이상 징후 자료](https://geekchamp.com/how-to-tell-ai-generated-game-art-from-human-made-art-without-guessing/)와 [옥토패스 트래블러 개발진의 픽셀·조명 설명](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style)을 읽었습니다. 회색 안개로 화면 덮기, 혼합 픽셀 밀도, 광택 돌, 네온색, 장식 글자, 작은 풍경형 아이콘을 피하는 항목을 CARD_RESULT.md에 먼저 기록했습니다.

Game/·협업 기록·기존 산출물은 수정하지 않았습니다. 유니티 실행·임포트·플레이·깃 쓰기는 수행하지 않았습니다. 실제 게임 연결, 최종 메뉴 제목 적용, 플랫폼 아이콘 슬롯 지정과 기기 확인은 클로드 담당입니다. 이 작업 폴더의 ProjectSettings에서 연결된 앱 아이콘 텍스처는 발견하지 못했습니다.

실제 검사 결과: 납품 PNG 23개 크기·알파, 레이어 최근접 확대 8개, 합성 일치, 4배 확인 그림 6개를 검사했습니다. 적응형 전경의 최대 반지름은 116.9124px로 132px 안전 원 안입니다. 헤드리스 엣지에서 내장 이미지 30개·함렛 글꼴·움직임·정지·표시 전환이 정상이며, 오류와 390px 화면 가로 넘침이 없었습니다. `review_desktop.png`, `review_menu.png`, `review_mobile.png`를 직접 살펴봤습니다. 읽기 전용으로 확인한 게임 배경·메뉴 코드·설정 파일의 해시도 유지됐습니다.
