# K-079 오우거 동작 제작본

사용자가 선택한 주인공 6판의 첫 생성본(`codex_hero_octopath_review_v6/generated.png`)과 K-066 오우거의 올리브색 피부·가죽 장비·철퇴를 기준으로 제작했다. 큰 머리, 짧고 튼튼한 몸, 큰 장화, 어두운 픽셀 윤곽과 제한된 명암을 적용했다. 보정된 주인공 그림은 사용하지 않았다.

## 검토 페이지

[`오우거 동작 비교`](../../../_HTML/4_그림_캐릭터/codex_K-079_오우거동작_v1.html)를 파일로 직접 연다. 이미지와 동작 재생 코드가 내장되어 서버가 필요 없다. 현재 게임 시트와 제작본을 같은 크기로 비교하고, 일시 정지·한 칸씩 보기·속도·발선·밝은 배경을 선택할 수 있다. 전체 프레임과 원본 4배 확대는 각 동작 아래에서 펼친다.

## 크기 적용

기존 오우거는 게임 칸 256×384 안에 일반 적보다 큰 체형을 사용한다. 따라서 카드의 **기존 크기 유지** 조건을 적용했다. 이번 원본은 오우거 예외 칸인 **128×192**, 게임용은 **정확한 최근접 2배인 256×384**다. 일반 인물의 96×128 원본·3배 확대와 구분해야 한다.

- 원본 몸 중심 x=64, 지면선 y=176. 장화의 마지막 픽셀 행은 y=175.
- 게임 피벗은 왼쪽 위 기준 (128,352). Unity의 왼쪽 아래 정규화 좌표는 (0.5, 0.0833333333).
- 서 있는 키는 원본 약 120점, 게임 약 240px로 일반 인물의 게임 키 약 219px보다 크다.
- 공격 3번 칸은 장화를 지면선에 고정하고 철퇴 끝만 원본 y=185 경계까지 내려간다. 그림 전체의 맨 아래를 발 위치로 사용하면 안 된다.
- 쓰러짐은 같은 지면선·피벗에서 몸이 회전한다. 넘어진 발을 서 있는 발 위치로 끌어오지 않는다.
- 서 있기와 걷기의 몸 크기를 맞췄다. 기존 서 있기 그림보다 커진 모습은 비교 페이지에서 확인할 수 있다.

## 전달 시트

| 게임용 파일 | 원본 파일 | 칸 수 | 왼쪽부터 순서 | Claude 연결 대상 |
|---|---|---:|---|---|
| `ogre_static.png` | `ogre_static_native.png` | 1 | 가만히 서기 | `Art/Characters/Static/ogre_static.png` |
| `ogre_walk.png` | `ogre_walk_native.png` | 4 | 왼발 전진 → 중간 디딤 → 오른발 전진 → 반대쪽 중간 디딤 | `Art/Characters/Walk/ogre_walk.png` |
| `ogre_attack4.png` | `ogre_attack4_native.png` | 4 | 준비 → 머리 위로 들기 → 성벽 내려치기 → 복귀 | `Art/Characters/Walk/ogre_attack4.png` |
| `ogre_fall4.png` | `ogre_fall4_native.png` | 4 | 뒤로 휘청임 → 무릎 꺾임 → 옆으로 넘어짐 → 바닥 정지 | `Art/Characters/Fall/ogre_fall4.png` |

게임용 서기 시트는 256×384, 나머지는 1024×384다. 원본 서기는 128×192, 나머지는 512×192다. 각 `_native_4x.png`는 원본의 정확한 최근접 4배 확대다. 서기는 걷기 두 번째 칸을 재사용한다. 게임에서는 쓰러짐을 한 번 재생하고 마지막 칸을 유지한다. 검토 페이지는 마지막 칸을 잠시 유지한 뒤 반복한다.

`Game/` 파일과 `.meta`는 수정하지 않았다. Claude가 위 네 파일을 연결한다. `ogre_static_normal.png`는 이번 카드 범위에 포함되지 않아 제작·교체하지 않았다.

## 제작 자료와 검증

기본 제공 이미지 생성 도구로 걷기·공격·쓰러짐을 각각 생성했다. 원본 생성 그림은 `_generated.png`, 사용한 프롬프트는 `prompts.json`에 보관했다. 생성 알파를 128 기준으로 이진화한 뒤 프레임을 추출하고, 도트 격자·몸 중심·지면선을 정리했다. 작은 고립 조각을 제거하고 피부·가죽·철·송곳니의 제한 팔레트와 파란 홍채를 정리했다. 반투명 후광은 전달 시트에 포함하지 않았다.

`manifest.json`에 크기·피벗·프레임 순서·원본 추출 범위·기존 게임 그림 SHA-256을 기록했다. `validation.json`에는 픽셀 검사, `review_validation.json`에는 브라우저 검사 결과를 기록했다.

확인한 항목: 13칸 전체의 이진 알파, 투명한 칸 경계, 프레임별 연결 도형 1개, 지면 접촉 행, 게임용의 정확한 2배 확대, 미리보기의 정확한 4배 확대, 기존 게임 그림 네 파일의 해시 유지. 세 동작의 4배 시트를 육안으로 확인했다. Chrome에서 파일로 직접 열어 이미지 12개 로딩과 프레임 진행을 확인했으며, 데스크톱과 500px 폭에서 가로 페이지 넘침이 없었다. `review_desktop.png`, `review_mobile.png`는 브라우저 확인 캡처다.

Unity 실행·실제 게임 연결·게임 화면 캡처는 하지 않았다. 390px 폭은 Chrome 창의 최소 폭 제약 때문에 별도로 검증하지 않았다.
