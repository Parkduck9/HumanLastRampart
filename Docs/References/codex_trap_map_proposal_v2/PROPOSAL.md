# 정비 함정 지도 시안 v2 — T-CX-046

작성 Codex / 2026-10-15 / 사용자 검토 전. M-CL-065·D-061에 따른 화면 시안이며 Game 구현·계약 변경이 아니다.

## 방향을 먼저 이해하기

전체 지도는 **북쪽이 항상 위**다. 가운데 성, 네 성벽, 지형에 기록된 언덕을 그린다. 북쪽에 `북·정면 / 주 공격 방향`과 굵은 붉은 화살표를 표시한다. 대부분 북쪽에서 오지만 전략적인 적이 다른 면으로 우회할 수 있다는 안내를 붙인다. 예고하지 않은 적의 실제 위치·확정 이동 경로를 공개하는 기능이 아니다.

성벽 선택은 북·동·남·서 네 버튼으로 직접 고른다. 전체 지도에서는 선택 성벽을 붉은 선, 그 앞 설치 영역을 황동색으로 표시한다. 오른쪽 제목·하단 성벽 표기·성벽 버튼의 선택 상태를 같이 바꾼다. 색만으로 구분하지 않는다.

## 8열 확인과 좌표

- 현재 terrain_1~4의 castleHalfSize=20: 한 면 40m. TrapCellSize 기본값 5m이므로 `floor(40/5)=8열`.
- TrapNear=10, TrapFar=80 기본값: `floor((80−10)/5)=14행`.
- 기존 TrapPreparationPanel은 TrapGrid.Columns/Rows로 동적 생성하고 고정 열 수를 24로 박아두지 않았음. 8열 계산 경로는 정적 확인. 실제 Unity 화면 잘림·클릭은 미검증.
- 시안은 실제 지형 YAML을 읽고, 누락된 칸 크기/거리 필드는 TerrainDef 기본값으로 보완한다. 읽은 값은 terrain_snapshot.json에 보관. 아직 커밋 전인 Claude 작업 폴더의 40m 지형을 기준으로 함.
- 격자는 **선택 성벽에서 바깥을 바라본 방향**이다. 먼 행은 위, 가까운 행은 아래. 북: 좌서/우동, 동: 좌북/우남, 남: 좌동/우서, 서: 좌남/우북을 글자로 표시한다.
- 칸 좌표는 Core.Traps.TrapGrid.Center 식을 따른다. 외향 o, 우향=(o.z,-o.x), along=-half+(col+0.5)×cell, away=half+near+(row+0.5)×cell, center=o×away+right×along. 지도 좌표는 X오른쪽/Z위쪽.
- 언덕의 `(x,z)` 중심과 `y` 반경을 반영한다. 칸 중심이 반경 안이면 기존 규칙대로 ×/비활성. 지형이 바뀌면 다시 계산.
- 선택 칸을 전체 지도에 파란 사각형으로 같이 표시하고, X·Z·거리·행열을 텍스트로 보여 준다. 전체 지도는 영역 이해, 오른쪽 격자는 정확한 선택을 담당한다.

## 행동 흐름

성벽 → 칸 → 비용 확인 → 설치. 성벽/지형/칸 변경 시 이전 견적 폐기. 언덕·설치된 칸은 선택 불가. 환불·판매 버튼 없음.

검토 HTML의 250 G·함정25 G·설치 표시는 체험용 메모리 상태이며 캠페인 데이터에 쓰지 않는다. 시안 초기화는 체험 상태만 초기화한다. 비용·구매·재고·보관품·지도 표시·중복 설치·정비 세션 검증은 승인 후 기존 거래 로직을 그대로 연결한다. 시안은 회수나 신규 환불 기능을 제안하지 않는다.

Codex 소유 TrapPreparationPanel의 표시·선택 UI를 수정하고, 기존 session.TryQuote/TryCommit을 유지한다. 새 지형 계약/API는 필요하지 않은 방향. 4면 방향 매핑과 주 공격 안내 근거는 Claude와 확인한다.
