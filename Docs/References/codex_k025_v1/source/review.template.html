D-064 시안 / 게임 미연결

그림을 읽고 있습니다
설명용 합성 그림입니다. 기존 들판 질감에 새 소품을 얹었습니다. 원경의 반사 반복·소품의 밤 명암은 HTML 비교용 표현이며, 실제 카메라·조명·충돌·크기를 검증한 게임 캡처가 아닙니다.

01 / 같은 소품의 경사 시점과 윗면

윗줄은 세운 판 후보, 아랫줄은 수직으로 내려다볼 때 눕힐 윗면 판 후보입니다. 점 필터로 확대하고, 밝은 배경에서도 경계를 확인할 수 있습니다.

02 / 성 둘레를 두르는 원경 띠

낮·밤 산과 숲은 한 장씩의 투명 PNG입니다. 아래 경계선은 두 띠가 만나는 곳입니다. 직접 반복의 이음새와 반사 반복의 대칭을 비교합니다.

직접 반복은 좌우 능선 높이가 정확히 맞지 않습니다. 반사 반복은 위치를 맞추지만 봉우리 패턴이 대칭으로 반복됩니다. 승인 후 별도의 연결 전용 구간을 만들거나 최종 원형 배경을 검토해야 합니다. 무봉제 타일 완료로 판정하지 않았습니다.

03 / 하늘 그라데이션 두 안

낮 · 푸른 회색에서 옅은 모래빛으로

위 #607f8c → 65% #a8b5ad → 아래 #dbceb0

밤 · 남색에서 먼 안개빛으로

위 #101a31 → 65% #29364f → 아래 #566273

32×256 불투명 PNG. 구름·해·달을 굽지 않아 날씨와 시간 연출을 별도로 올릴 수 있는 색안입니다.

04 / 두 시점에서 보이게 하는 배치 제안

경사 시점 그림에 수관·바위 윗면과 옆면을 함께 담았습니다. 수직 탑뷰용으로는 별도 윗면 그림을 제공합니다.

세운 판만 수직 카메라에서 보면 얇아집니다. 윗면 판을 함께 두거나, 카메라 각도에 따라 그림을 전환하는 방식이 필요합니다. 이는 연결 제안이며 새 게임 구조를 확정한 것이 아닙니다.

윗면과 경사 그림은 별도로 생성한 시안입니다. 수관 외곽·바위 균열의 정밀 정합과 두 판이 겹치는 경계는 미검증입니다. 실제 두 시점의 가림·전환 검토가 남아 있습니다.

05 / 크기와 가져오기 기준

기존 World/README.md의 32화소/m와 점 필터 기준을 참조했습니다. 아래 새 소품 크기·피벗은 제안입니다. 피벗은 그림 왼쪽 위 기준 화소 좌표입니다.

그림경사 칸피벗실체 높이 / 32윗면 칸

소품은 투명 RGBA, 가장자리 고정·점 필터·무압축을 검토합니다. 월드 질감의 반복 설정을 소품에 그대로 적용하지 않습니다. 원경은 투명 띠이며 원근상 거리에 따라 보이는 크기를 정해야 하므로 32화소/m를 강제로 적용하지 않습니다.

나무가 적 진입로·함정 표시를 가리지 않도록 가장자리 배치를 우선 제안합니다. 바위·풀숲도 전투 구역 가독성 확인 후 수량과 위치를 정합니다. 배치·장애물 판정·노멀맵·그림자 연결은 이번 카드에 없습니다.
