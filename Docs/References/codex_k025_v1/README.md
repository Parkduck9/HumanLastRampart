## 기존 그림에서 읽어 맞춘 기준

`Game/Assets/_Project/Art/Battle/Resources/BattleArt/World/README.md`의 **32화소/m·점 필터**를 참조했다. 같은 폴더의 `field_grass_albedo.png`(256×256)를 직접 보고 올리브 풀·회갈색 흙과 조화되도록 색을 잡았다. 해당 `.meta`의 필터 0, 밉맵 켬, 반복 설정을 읽었다. 기존 질감은 검토 HTML 안에 읽어 내장했으며 Game 파일을 수정하거나 새 임포트 파일을 만들지 않았다.

참고 `_HTML/15_옥토패스식그래픽설계.html`의 원칙: 도트 판을 3D 공간에 두고, 가까운 사물과 먼 원경을 분리하며, 전투 중심부 가독성을 유지한다. 원경 대비를 낮추고 산과 숲에 거리별 색 차이를 두었다. 이번 HTML은 실제 URP 조명·피사계 흐림·그림자를 구현하거나 검증한 화면이 아니다.

## 새 규격은 모두 제안

| 소품 | 경사 칸 | 피벗, 왼쪽 위 기준 | 실체 최대 높이 | 윗면 칸 |
|---|---|---|---|---|
| 넓은잎나무 | 128×160 | 64,152 | 144px, 최대 4.5m | 128×128 |
| 침엽수 | 128×224 | 64,216 | 208px, 최대 6.5m | 128×128 |
| 낮은 바위 | 96×80 | 48,72 | 64px, 최대 2m | 96×96 |
| 갈라진 바위 | 64×112 | 32,104 | 96px, 최대 3m | 64×64 |
| 풀숲 | 64×48 | 32,40 | 32px, 최대 1m | 64×64 |

실체는 종횡비를 보존해 칸 안에 들어가므로 표의 최대 높이보다 작아질 수 있다. 실제 축소 높이는 manifest의 `cropAndPlacement[7]`과 HTML 표에 기록한다. 바닥 기준점은 뿌리·바위 아래쪽을 맞추는 제안이며 정밀 접지점은 미확정이다. 윗면 피벗은 가운데다. 윗면과 경사 그림의 실제 크기를 일치시키는 3D 배치 스케일은 아직 정하지 않았다.

소품은 RGBA 투명, 점 필터·가장자리 고정·무압축을 제안한다. 원경은 1024×352 RGBA, 원근 거리에 맞춰 크기를 따로 정한다. 원경에 환경 질감의 32화소/m를 기계적으로 적용하지 않는다. 기존 World 질감의 Repeat 설정을 소품·윗면 그림에 그대로 옮기지 않는다. 새 `.meta`는 만들지 않았으며 사용자 확정 뒤 Claude가 실제 임포트를 담당한다.

## 위·옆 시점 판의 의미

경사 그림은 윗면과 옆면이 함께 보이는 약 35도 내려다보기 시안이다. 수직 탑뷰용 윗면 그림도 별도로 제공한다. 두 그림은 같은 소품을 참조하여 생성했지만 정확한 3D 투영쌍은 아니다. 나무의 가지·수관 외곽과 바위 균열 위치가 완전히 일치하지 않을 수 있다.

제안은 세운 판에 경사 그림, 수평 판에 윗면 그림을 두거나 시점에 따라 전환하는 것이다. HTML 도식은 설명용이고 실제 메시·셰이더·빌보드·전환 코드를 만들지 않았다. 두 판을 동시에 그렸을 때 중복 수관이 보이거나 윗면 판이 떠 보이는지, 정면·지도에서 실루엣과 깊이가 맞는지는 연결 후 확인해야 한다.

## 원경 반복·낮밤의 한계

산과 숲은 한 장에 합쳐진 원경 판이며 분리된 시차 레이어가 아니다. 낮 원안을 보정하고 이를 밤색으로 편집했다. 밤이 생성 편집이므로 낮밤 픽셀 형태가 완전히 같다는 보장은 없다. 두 파일의 알파·실루엣 차이를 검사 결과에 기록한다. 페이지는 낮과 밤을 즉시 전환하며 보간 전환의 정합을 검증하지 않았다.

좌우 끝 높이가 정확히 맞지 않아 **직접 반복 무봉제 완료가 아니다.** 검토 페이지는 반사 반복 제안과 직접 반복 비교를 제공한다. 반사 반복은 이음 위치를 맞추지만 능선이 대칭으로 되풀이된다. 최종 원형 띠를 만들려면 연결 전용 그림이나 전체 둘레 방향 검토가 필요하다. 실제 반경·높이·폭·컬링·수직 탑뷰에서 원경 숨김 여부는 미정이다. 먼 적·성벽과 겹치지 않도록 160m 전투 구역 바깥 배치가 필요하다는 제안만 남긴다.

## 하늘 색 원본

하늘은 그림 생성 대신 단순 수직 색 수식으로 만든 PNG다. 위→65%→아래를 선형 보간한다.

- 낮: `#607f8c` → `#a8b5ad` → `#dbceb0`.
- 밤: `#101a31` → `#29364f` → `#566273`.

해·달·구름은 굽지 않았다. 하늘 색은 시안이며 현재 게임 시간·날씨 정의를 수정하지 않았다.

## 제작·확인 범위

생성 도구로 원안과 투명 배경 보정, 밤색 편집, 윗면 시안을 만들었다. 원안이 크게 보이는 것은 생성 해상도이며 게임에서 쓸 크기는 별도 축소본이다. 프로그램 처리는 알파 경계 영역 자르기·최근접 축소·투명 여백 배치에 한정한다. RGB를 덧칠하거나 배경색을 추출 제거하지 않았다. 일부 투명 픽셀에 RGB 색이 남을 수 있다. 뷰어가 알파를 무시하면 색 번짐이 보이므로 검토 HTML의 밝은·어두운 배경 합성을 기준으로 본다. 반투명 테두리가 배경에 잘 섞이는지는 사용자 검토 사항이다.

실제 수행한 파일·알파·원안·HTML 내장 검사 48건은 `qa/verification.json`, 스크립트 문법·최소 DOM 모형에서의 동작 검사 10건은 `qa/script_model_verification.json`을 따른다. 연결 가능한 브라우저가 없어 실제 브라우저 렌더링·반응형·콘솔을 검사하지 않았다. 알파 합성 확인 이미지는 `qa/alpha_contact_sheet.png`이며 게임 캡처가 아니다. Unity·게임 Play·게임 성능 검증도 하지 않았다. 사용자는 나무 두 종의 외형·바위 차이·풀 크기·낮밤 색·원경 반복을 먼저 검토하고, 확정 후 Claude가 연결한다.

측정한 미해결 사항: 낮밤 원경에서 알파값이 다른 화소 31,954개, 알파 128 기준 실루엣이 다른 화소 5,495개(전체 360,448화소), 낮 띠 좌우 열의 값이 다른 행 99개다. 따라서 낮밤 그림의 정확한 겹침이나 직접 반복 이음새를 통과로 기록하지 않았다. 바위 윗면 그림에는 경사 면 표현이 일부 남아 있어 완전한 수직 지도에서의 인상을 검토해야 한다.
