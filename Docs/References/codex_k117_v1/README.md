# K-117 · 이야기 배경의 높은 등대탑

[전후 비교 검토 페이지](../../../_HTML/6_그림_화면/codex_K-117_이야기배경_등대탑_v1.html)에서 K-111 원본과 수정본을 나란히 볼 수 있습니다. 대사창 겹쳐 보기와 큰 그림 펼치기를 지원하며, 모든 그림을 내장해 서버 없이 직접 열립니다.

## 반영한 기준

K-111의 평지 위 사각 네 성벽, 요새 전체가 보이는 먼 사선 시점과 하단 대사 영역을 유지했습니다. 작은 받침 화로를 성벽 높이의 약 세 배인 12m 등대탑으로 바꿨습니다. K-115 목업의 큰 석재·띠 장식·철창 등실·청회색 기와지붕·아치문을 따라 그렸습니다.

실제 `courtyard_20261023/259_w27_day_2_courtyard_overview.png`, `01_bldg_day_0_overview.png`, `279_w27_night_1_wall_top_tower_north.png`를 확인했습니다. 북쪽 성벽 안 계단에서 등대의 원형 광장으로 이어지는 길, 길가 가로등과 성벽 가까운 낮은 건물을 반영했습니다. 길은 탑 뒤에서 왼쪽으로 보이도록 배치했고 원형 광장을 돌아 앞쪽 문으로 접근합니다. 멀리 있는 작은 인물은 얼굴을 묘사하지 않았습니다.

야간에는 등실과 가로등의 따뜻한 빛, 차가운 푸른 바닥과 성벽을 구분했습니다. 전체를 회색 안개나 광택으로 덮지 않고, 빛이 닿은 바닥과 탑 반대편 그림자가 보이게 했습니다. 이야기용으로 다시 그린 배경이며 실제 게임 렌더를 그대로 합성한 화면은 아닙니다.

## 제작과 인계

내장 이미지 생성 도구로 제작하고 수정했습니다. 생성본은 `sources/`에 보관했습니다. 생성 크기를 1920×1080으로 최근접 정리했으며, 4배 확인용 그림도 최근접 확대했습니다. `prompts.json`은 제작 요청의 한글 정리입니다. `manifest.json`에는 파일명·크기·대사 영역·대체 원본을 기록합니다.

`verification.json`은 실제 수행한 규격·알파·4배 확대·하단 명암 측정과 브라우저 검사의 기록입니다. `review_desktop.png`, `review_mobile.png`는 검토 페이지 확인 화면입니다. 불투명 배경에는 투명 잔점이 없으며, 화면 속 작은 돌·별·흙 표현은 그림의 일부입니다.

기존 K-111·K-115 자료와 Game/은 수정하지 않았습니다. Unity 실행·임포트·플레이 확인·Git 쓰기는 수행하지 않았습니다. 게임 연결·실제 대사창과의 최종 확인·커밋은 Claude 담당입니다.
