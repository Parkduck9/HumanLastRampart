# K-080 주인공 동작 시트

검토 페이지: [`codex_K-080_주인공동작_v1.html`](../../../_HTML/4_그림_캐릭터/codex_K-080_주인공동작_v1.html). 그림·스타일·동작 재생 코드를 내장해 서버 없이 직접 엽니다.

사용자가 선택한 6판 **generated.png**의 흰 뾰족머리, 파란 눈, 짙은 장교복, 금색 견장과 테두리, 갈색 장화를 기준으로 제작했습니다. D-081에서 크기가 확정되었으므로 카드 제목의 크기 결정 대기는 해소된 것으로 처리했습니다. 보정본은 사용하지 않았습니다.

## 제공 파일

| 게임용 이름 | 원본 크기 | 게임용 크기 | 프레임 순서 |
|---|---|---|---|
| `hero_back_idle.png` | 96×128 | 288×384 | 후면 대기 1장 |
| `hero_walk_run_grid.png` | 384×512 | 1152×1536 | 4열×4행, 후면 걷기 / 왼쪽 걷기 / 왼쪽 달리기 / 정면 걷기 |
| `hero_command.png` | 288×128 | 864×384 | 후면 대기 → 손 올리기 → 팔 뻗어 지휘 |

각 이름의 `_native.png`는 원본 시트, `_4x.png`는 원본을 정수 4배 확대한 미리보기입니다. 게임용 파일은 원본을 정확히 정수 3배 최근접 확대한 것입니다. 모든 원본 프레임의 불투명 인물 키는 73px입니다. 머리는 약 24px를 목표로 생성했으며, 머리카락 끝을 포함하는 육안 경계는 자세마다 조금 다릅니다.

원본 칸은 96×128, 발바닥 아래 경계는 y=120(마지막 불투명 행 119), 몸 중심 기준은 x=48입니다. 게임용 발 기준은 (144,360), Unity 아래쪽 원점 기준 정규화 피벗은 (0.5,0.0625)입니다. 팔을 뻗는 지휘 동작은 전체 그림의 가로 중앙 대신 머리 외곽 중간을 몸 중심축으로 삼았습니다. 정수 좌표 때문에 머리 중간은 47.5~48.5 범위이며, 프레임별 실제 경계는 `manifest.json`과 `validation.json`에 적었습니다.

후면 대기는 지휘 첫 프레임과 같은 그림으로, 지휘 시작 때 별도의 인물 크기 변경이 없습니다. 좌우 반전·방향 전환·재생 속도·걷기와 달리기의 전환 처리는 Claude가 연결합니다. 여기에 적힌 프레임 순서는 현재 게임 시트를 직접 읽어 확인했습니다. 새 동작은 같은 순서의 접지/통과 자세로 제작했습니다.

## 제작 자료

- `hero_walk_run_grid_generated.png`, `hero_command_generated.png`: 내장 이미지 생성 도구의 생성 원안입니다. 게임용으로 직접 사용하지 않습니다.
- `prompts.json`: 사용한 전체 프롬프트와 참조 역할입니다. CLI/API 생성은 사용하지 않았습니다.
- `build.cjs`: 알파 128 이진화, 가장 큰 연결 본체 유지, 인물 키 73px 최근접 축소, 27색 공통 팔레트 정리, 중심·발선 정렬, 시트 및 검토 페이지 제작을 재현합니다. 재질별 주요 명암은 약 3단계이며 머리와 피부에는 경계색이 추가됩니다.
- `manifest.json`: 칸·피벗·배열·프레임별 경계·기존 파일 해시입니다.
- `verify.cjs`, `validation.json`: 시트와 검토 페이지의 검사 코드 및 결과입니다.
- `review_desktop.png`, `review_mobile.png`: 로컬 검토 HTML의 브라우저 확인 화면입니다. 게임 캡처가 아닙니다.

## 확인과 연결 시 주의

20프레임 모두 크기, 인물 키 73px, 발 아래 경계 120, 머리 중심축, 이진 알파, 투명 영역 RGB=0, 칸 내부 여백, 본체 연결 성분 1개를 자동 검사했습니다. 게임용 3배 및 미리보기 4배의 모든 화소가 최근접 확대와 정확히 일치합니다. 분리된 잔점은 없습니다. 최종 전체 시트와 데스크톱 검토 화면을 육안으로 확인했습니다. 생성 원안의 모든 국소 선 두께가 정확히 1px라고 보증하는 검사는 수행하지 않았습니다.

검토 HTML의 모든 이미지 디코딩, 동작 재생, 일시 정지, 한 장씩 보기, 모바일 가로 넘침 없음, 페이지 오류 없음을 실제 Chrome으로 검사했습니다. 현재 게임 그림은 원래 칸 크기를 유지해서 표시하고, 새 그림은 3배로 표시해 발선을 맞췄습니다. 따라서 왼쪽과 오른쪽 인물의 화면 키는 다릅니다.

**Game/ 파일은 변경하지 않았습니다.** 기존 3개 PNG의 SHA-256이 작업 전과 같은 것을 확인했습니다. 기존 파일명과 프레임 수·행 순서는 유지하되, 기존 256×384칸을 유지한다는 카드 문구는 상위 공통 지시와 D-081의 288×384칸으로 대체했습니다. Claude는 이 폴더의 게임용 3개 PNG를 기존 경로에 연결하고 칸 크기·피벗을 조정해야 합니다. 기존 `hero_walk_run_grid_normal.png`는 새 시트에 대응하지 않으므로 노멀맵 재사용 여부도 연결 때 확인해야 합니다. 이 카드에서는 노멀맵을 제작하거나 변경하지 않았습니다.

Unity 실행, Play, 실제 게임 캡처, 실제 화면에서의 크기·가독성·전환 검증은 수행하지 않았습니다. 사용자 외형 검토와 Claude 연결이 남아 있습니다. Git 쓰기는 수행하지 않았습니다.
