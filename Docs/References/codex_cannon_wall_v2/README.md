# 대포 3방향과 큰 도트 성벽 3안 (T-CX-042)

사용자 요청: 대포를 좌·중앙·우로 돌려 쏘도록 방향 에셋 3개 제작, 성벽은 더 크고 도트가 뚜렷한 여러 시안 제작. 기존 정적 v1은 보관한다.

## 대포

- cannon_left / cannon_center / cannon_right: 동일 대포의 후면 좌측 사선·후면 중앙·후면 우측 사선 조준. 화면 위쪽 들판을 향한다.
- 각각 512×384 RGBA, 1칸 정적, 공통 바닥 기준점 (256,352). 파일의 제안 규격이며 Unity 최종 크기 확정은 아니다.
- 설치 위치와 조준 방향은 별개다. HTML에서 좌·중앙·우 설치 위치 중 하나를 고르고 세 조준 에셋을 교체할 수 있다. 설치 위치가 조준을 강제하지 않는다.
- HTML 발사 확인은 기존 포탄 그림을 날려 방향을 보는 데모다. 조준 전환은 3방향 정적 그림 교체이고 연속 회전 애니메이션·탄도·피해·발사 속도·Game 연결은 별도다. 자동 방향 전환은 화면 검토용이다.

## 성벽

| ID | 시안 | 비교 포인트 |
|---|---|---|
| wall_a | A 큰 사각석 | 규칙적인 큰 돌·기본 회색 성벽 |
| wall_b | B 거친 거석 | 거대한 거친 돌·짙은 색·무게감 |
| wall_c | C 두꺼운 요새벽 | 밝은 큰 돌·두꺼운 지지대·넓은 통로 |

성벽은 사물보다 크게 보는 1024×512 검토 포장이다. 작은 벽돌 대신 큰 돌 면과 굵은 도트 덩어리를 생성하도록 요청했다. 사진·작은 원본을 임의의 필터로 픽셀화한 것이 아니다. 통로 폭, 반복 경계, 낮은 카메라와 캐릭터/대포 비율은 비교 후 조정한다. 무봉제 타일 접합은 확정하지 않는다.

## 파일과 검토

_HTML/codex_대포3방향_성벽3안_v2.html을 더블클릭하면 설치·조준·발사 데모와 세 성벽을 확인할 수 있다. 그림/스크립트/문서 내장, 서버 불필요. 각 시안 원본 source.png, 포장 static_grid.png, asset.json. 대포 3칸 방향 시트 cannon_aim3_grid.png는 모션 프레임이 아닌 방향 목록이다. 별도 JSON에 순서·기준점·데모용 포구 위치를 기록한다.

imagegen 스킬 내장 도구로 생성, 프롬프트·원본 경로 generation.json 보관. 전체 그림 최근접 축척/배치만 사용한다. 게임 Art·Combat 코드와 이전 원본은 변경하지 않는다. Game 연결 요청은 Claude outbox로 남긴다. Unity Play는 수행하지 않는다.

## 제작 후 확인

6개 원본 보존·PNG/규격·공통 기준점·격자 3칸 바이트·내장 자료·JS 구문·HTML 사본을 확인했다. 실제 브라우저에서 설치 3곳×조준 3방향의 9개 조합을 바꿔 9회 발사, 포탄 종료·자동 조준 전환·성벽 배경 전환·초기화와 카드 6개 이미지 로드를 확인했다. 콘솔 오류 0, 기본 창 가로 넘침 없음. 포구 점은 육안으로 둔 데모 좌표이며 실제 게임의 정확한 회전축/발사점 계약은 미확정이다. file: 주소 직접 실행은 검사하지 않았고 자료를 내장한 HTML로 제공한다.
