사격 시트는 기존 **4열×3행 원본을 덮지 않는 별도 파일 제안**이다. 실제 엔진 필드나 병종·공격속도·재장전시간·대미지·사거리 계약을 바꾸지 않는다. 8fps는 보기 위한 속도이며 전투 공격 주기와 동일하다고 확정하지 않는다. 궁수·총병은 기존의 갈색 머리·남색/아이보리 복장·가죽 장비를 유지하고 주인공 백발/검정금색 장교복과 구별한다. 총병의 오른쪽 금속 어깨 보호대도 기준이다.

## 대포 방향과 배치

대포는 뒤에서 보며 **그림 위쪽이 성 바깥 들판 방향**이다. 앞쪽 큰 검은 원을 카메라로 향한 정면 포구로 해석하지 않는다. 카메라 가까운 쪽은 후미 고리다. 바퀴와 포가를 접지 기준으로 잡고 포신만 뒤로 밀렸다가 돌아오는 모습을 제안한다. 실제 사격구 폭1.12m에서의 월드 크기와 가림은 Claude 연결 후 확인해야 한다.

연기는 별도 시트여서 포구 위치에 독립 배치한다. 포구 좌표·방출 방향·좌우 조준시 그림 선택/회전·순서·반동량(m)은 아직 미확정이다. 이 검토는 색 그림이고 노멀맵·실시간 발광·연기3D·물리반동·게임 연결을 포함하지 않는다.

## 제작과 보관

built-in imagegen으로 서로 다른 그림마다 별도 원안을 생성했다. 참조 원본3개를 직접 보고 참고 사본을 보관했다. 원안 `_source.png`, 전체 프롬프트 jobs.json, 실제 이미지 크기·SHA256·프레임 크롭·공통 배율·피벗은 각 JSON/manifest.json에 있다. 원안의 투명 공백으로 동작을 분리하고 같은 시트는 공통 배율·세로범위를 적용해 최근접 정렬했다. 병사 발/대포 바퀴 기준으로 고정해 팔·포신 움직임 때문에 전체 몸체가 옆으로 미끄러지는 현상을 줄였다. 픽셀 덧칠·그림의 코드 대체·중복 칸 복제는 하지 않았다.

총병 첫 원안은 옆 프레임의 총과 가로 범위가 겹쳐 사용하지 않고, 간격을 넓힌 새 원안으로 교체했다. 폐기한 그림은 기본 생성 위치에 남기며 최종 시트/HTML에는 포함하지 않는다.

## 확인 방법

_HTML/codex_K016_무기와사격_v1.html 또는 preview.html을 서버 없이 직접 연다. 모든 PNG/문서를 내장했다. 재생/정지·이전/다음·한번재생·8/10/12fps·1배/2배·밝은/어두운 배경, 투사체 표시 회전을 비교한다. 정적 투사체는 애니메이션하지 않는다. 회전 미리보기만320×320 투명 여백 캔버스에 중앙 배치해 대각선/수직 회전 시 잘리지 않게 했다. 원본 칸256×128과 중심피벗128·64는 유지한다. PNG 저장은 최종 제안 시트를 저장한다.

build.py는 Pillow·NumPy·Node로 격자/메타/HTML/정적 QA와 플레이어 DOM모형 검사를 재현한다. DOM모형은 실제 브라우저 렌더링과 다르다.

## 미확정·한계

AI 그림이라 세부 도트·팔/무기 파지·재장전 동작·미세한 반투명 외곽이 달라질 수 있다. 후면에서 무기가 읽히도록 약간 비튼 시안이며 실제 전투 각도/방향/머리 흔들림/작은 크기의 구분은 사용자 판단이 필요하다. 원안의 팔·장비 세부가 모든 프레임에 픽셀 단위로 같다고 보장하지 않는다.

대포는 3D 모형이 아닌 제안 스프라이트다. 사격구와 실제 카메라에 맞는지, 포구 연기 결합과 발사 타이밍이 자연스러운지, 투사체의 실제 화면 크기와 회전은 게임 연결 후 실제 캡처로 검토한다. Unity 실행·실제 캐릭터 발사·사격구 가림·광원·게임 프레임률/성능은 수행하지 않았다.
