- 작성자: Codex. 근거: 사용자 병렬 지시, M-CL-070, D-067, RULES 8.1/10.6.
- 코드·게임 연결은 Claude 담당. 이 폴더는 M070에서 지정한 References/_HTML 범위의 검토 자료 보관본이다. M-CL-071에서 카드 worktree가 생성되었고 K004/K006 카드 커밋을 만들었으나, 메인 폴더의 선행 검토 사본과 경로가 겹쳐 합치기가 중단되었다. M-CL-072에 따라 최신 K004 문서/메타를 선택해 메인 폴더 합본으로 G-CX-038 보관한다. 카드 가지는 Claude가 별도로 닫으며 카드 병합 완료로 기록하지 않는다.
- 기존 포탑 투시 PNG를 게임에 붙이는 방향에서, **실제 3D 성벽/포탑 + 2D 도트 캐릭터**를 같은 카메라로 보는 방향으로 정리했다. 새 구조와 치수의 최종 확정은 사용자 검토 후다.

## K-004 카메라 장면

`K-004/actual_capture.png`는 기존 게임 캡처 Game/playprobe/93_weather_Clear_Day.png 사본이다. `reference.png`는 그 구도를 참고해 imagegen으로 새로 생성한 목표 장면이다. 두 그림을 실제 구현 전후 사진으로 혼동하지 않는다.

긴 수평 난간, 병사 후면 한 줄, 하단 중앙 백발 주인공, 같은 공간에 연결된 우측 포탑을 보여 준다. 병사는 통로에 서고 대포는 사격구를 향한다. 생성 장면의 하늘/수평선과 배경 세부는 실제 캡처보다 많이 나타난다. 정확한 카메라 투영·32px/m·병력 수·대포 수를 보장하는 그림이 아니다.

읽기 확인한 현행 BattleCameraRig는 원근 FOV40°, A Back1.05/Up0.75/Pitch17°, B1.6/1.05/19°, C3.2/2.75/28°다. 이 값은 기존 코드 근거이며 생성 그림에서 수학적으로 재현됐다는 뜻이 아니다. 실제 적용 값은 Claude K-001 이후 캡처와 다시 비교한다.

## K-005 3D 모형용 표면 8종

성벽 바깥면, 통로, 난간 윗면/옆면, 포탑 벽/옥상 바닥, 들판 풀/흙의 알베도·탄젠트 노멀 8쌍. 포탑은 평지붕 포대이므로 roof는 빨간 기와가 아닌 석재 옥상 바닥이다.

32px/m 규격: 벽·통로·포탑 벽·옥상 128×128=4×4m, 난간 윗면/옆면128×64=4×2m, 풀·흙256×256=8×8m. 포탑 폭이5m로 확정되어도 재질은 4m 타일을 UV로1.25번 반복하는 방식이 가능하며 타일 하나를5m에 늘이지 않는다.

imagegen이 같은 시트 좌/우에 색/노멀을 그렸다. 출력은 좌/우 절반 분리, 최근접 축소, 노멀 벡터 정규화만 수행한다. 미러 복제·타일 경계 덧칠·알베도 명도를 높이로 바꾸는 처리는 없다. source.png와 generation.json에 원안/프롬프트를 남긴다.

**타일 후보이며 최종 무봉제 인증은 아니다.** 3×3 반복 보기와 경계 차이 측정은 검토 자료다. AI 색/노멀 세부 형상의 완전 일치와 Unity의 실제 Y방향/광원 반응은 별도 검증해야 한다. 자동 규격 검사를 통과해도 조명/타일 외형 합격으로 해석하지 않는다. 필요하면 경계나 노멀을 재제작한 뒤 연결한다.

첫 반복 검사에서 성벽·난간 윗면/옆면의 세로 경계 차이가 상대적으로 컸다. 세 후보를 imagegen으로 한 번 더 수정 요청했고 난간 두 개는 수치가 낮아진 후보를 선택, 성벽은 개선되지 않아 초기안을 유지했다(correction_review.json). **이 세 표면의 경계 보완은 남아 있으며 게임용 무봉제 완성 상태로 넘기지 않는다.** 다른 5종도 숫자만으로 무봉제 최종 승인을 선언하지 않는다. 뷰어는 이 미완료 점을 직접 비교하기 위한 것이다.

권장 가져오기: Albedo sRGB, Normal은 Normal map/Linear, Filter Point, Wrap Repeat, 압축 없는 비교부터. 밉맵은 거리별 번짐/떨림을 실제 장면으로 보고 Claude가 정한다. HTML 조명은 단순 노멀 내적 예시이며 URP 렌더 결과가 아니다.

## K-006 온전한 포탑 형태

`K-006/orthographic_reference.png`: 정면·우측면·상면, 온전한 한 종류. 기존 회색 PNG의 석재/형태를 참고하되 투시를 제거한 모델링 개념도다. 높이/너비 비율은 별도 벡터 도식으로 표시한다.

제안값: 외곽5×5m, 난간 포함 총7m, 옥상 통로 약6m, 성벽 연결 통로4m, 통로 폭2m. 연결 성벽 한 면40m는 기존 기준. 포탑5×5×7m는 K-001 사용자 검토 전 미확정이다. 두 인접면과 L자로 연결하고 성벽 통로 높이에서 출입, 내부 계단으로 옥상 접근하는 형상 제안이다.

생성 3뷰는 CAD 도면이 아니다. 상면 표시배율, 석재/난간 세부 개수는 입면과 정확히 일치하지 않아 픽셀로 치수를 재면 안 된다. HTML의 비율 도식이 제안 치수 관계를 나타낸다. 파손/붕괴·새 게임 규칙·3D 메시·충돌체는 만들지 않았다.
