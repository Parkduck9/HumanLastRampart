# K-006 모서리 포탑 형태 참고

- 상태: 검토 자료 완료 / 정식 카드 worktree 이관·사용자 검토 대기.
- 목적: 고정된 투시 PNG를 최종 건물처럼 쓰지 않고, 실제 3D 모형 제작에 참고할 정면·우측면·상면을 제공한다.
- 제작: built-in imagegen. 기존 회색 포탑 원본을 재료·형태 참고로 사용했다. 정확한 입력 프롬프트와 원본 경로는 `generation.json`에 보존했다.
- 결과: `orthographic_reference.png` 한 장. 낡은 중성 회색 석재, 평평한 포대 바닥, 난간·사격구·대포, 지붕 계단구, 낮은 성벽 연결을 표현한다.
- 범위: 온전한 모서리 포탑 한 종류. 파손·붕괴·게임 코드·실제 3D 모형은 포함하지 않는다.

## 크기 해석

탑 폭 5m × 깊이 5m × 높이 7m는 **제안값**이다. 연결 성벽의 한 면 40m·높이 4m·통로 폭 2m 기준과 구분한다. 그림의 픽셀에서 실치수를 측정하지 않는다. 부모 비교 HTML의 정확한 비율 도해를 함께 확인한다.

## 시각 검토 결과와 한계

정면과 우측면은 지면 기준선과 탑 높이가 맞고 낮은 성벽이 구분된다. 상면에서 포대·대포·계단구를 확인할 수 있다. 다만 생성 이미지는 CAD 도면이 아니어서 상면 표시 배율과 세 뷰의 난간·돌 세부가 완전히 일치하지 않는다. 두 성벽의 직각 연결은 각 입면에 짧은 벽으로 암시되며 별도 평면 도해로 보완한다. 조명·색은 참고 표현이며 실제 재질의 알베도나 노멀맵으로 사용하지 않는다.

## 보관·검증

기본 생성 위치 원본을 삭제하지 않고 바이트 그대로 복사했다. 실제 PNG 크기·색 모드·SHA-256과 복사 일치는 `generation.json`에 기록했다. 직접 이미지를 열어 위 내용을 검토했다. Unity Play·실제 게임 캡처·3D 접합 시험은 수행하지 않았다.

본 폴더는 부모가 허가 범위를 확인한 References 검토용 staging bundle이다. 정식 카드 worktree 작성·커밋·develop 합치기는 수행하지 않았으며, 조정 담당의 카드 폴더 준비와 사용자 방향 검토 후 진행한다.
