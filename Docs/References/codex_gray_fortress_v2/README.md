# 낡은 회색 성벽 · 숲 · 포탑 외형 비교 v2

- 작성: Codex / T-CX-051. 사용자 요청에 따른 새 레퍼런스이며 최종 게임 연결 승인이 아니다.
- 추천: 낡은 중성 회색 돌벽과 같은 석재 통로, 채도가 낮은 올리브 풀. 넓은 수관 나무와 침엽수로 높이 차이를 주고 포탑은 사각 탑과 낮은 포대를 구분한다.
- 옥토패스 비교는 사용자가 제공한 마을 화면과 기존 v1 질감, 새 v2를 나란히 보는 외형 검토다. 원작의 조명·카메라·후처리를 재현하거나 같은 결과를 검증한 것은 아니다. 공식 설명: https://www.jp.square-enix.com/octopathtraveler/about/

PNG 컷아웃 8종과 질감 3종이다. 각 폴더 source.png는 생성 원본이다. 프롬프트와 출처는 *_generation.json, 실제 배율·접지·해시는 manifest.json에 보관한다. 질감은 원본 전체를 최근접 축소하며 미러 복제나 경계 픽셀 덧칠을 하지 않았다. 포탑 상태는 각각 원형을 참조해 생성한 정적 그림이다. 자동 상태 보간이나 파괴 애니메이션이 아니다.

## 검토할 점

1. 새 회색 벽/통로가 기존 갈색 계열보다 의도에 가까운지, 작은 캐릭터가 바닥에 묻히지 않는지.
2. 3×3 반복에서 줄눈·풀 덩어리의 연결과 반복 무늬가 눈에 띄는지. 경계 오차 수치는 보조 자료이며 완전한 무봉제 인증이 아니다.
3. 나무가 축소되어도 두 실루엣으로 구분되는지, 포탑 3상태가 같은 구조물로 읽히는지.
4. 돌·잎의 세부가 여전히 촘촘한 부분은 다음 수정 후보다. 원본에는 명암이 있으므로 최종 3D 모델의 평면 알베도로 바로 붙이는 자료가 아니다.

포탑/나무는 모델링 레퍼런스 또는 임시 2D 정적 에셋이다. 3D 메시·충돌체·체력·파괴 동작은 포함하지 않는다. 컷아웃은 접지와 비교를 위한 표시 격자이고 전체 물체에 32px/m를 보장하지 않는다. 질감 3종에만 명시한 미터 규격을 적용한다.

사용자 제공 user_octopath_reference.png는 비교 화면으로만 보관하며 새 에셋 ZIP에 포함하지 않는다. HTML은 이미지 내장이라 오프라인 열람 가능하도록 구성한다. 실제 file:// 열람과 Unity Play는 별도 확인 사항이다.
