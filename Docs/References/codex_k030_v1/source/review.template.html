04. 규격과 남은 검토

그림시점크기기준점 · 왼쪽 위 원점

지도 모서리 토벽은 짓는 중과 완성의 L 방향이 달라, 접속용 최종 타일로 쓰기 전 방향을 맞춰야 합니다. 토벽 끝과 모서리는 자동 접속 타일이 아닙니다. 회전·연속 배치 시 틈과 겹침은 추가 검토가 필요합니다. 지도용은 윤곽을 정리했지만 일부 면의 명암에 경사 표현이 남을 수 있습니다.

궁수·총병 복장의 색과 특징은 기존 그림을 참조했으나 프레임별 옷자락·어깨판·끈 위치가 완전히 같지는 않습니다. 생성 시트의 인체·도구 접점과 걸음의 부드러움은 사용자 검토가 필요합니다. 발 기준점은 그림 칸의 제안이며 엄밀한 발 접촉점 보장은 아닙니다.

그림의 크기·높이·피벗·재생 속도는 전부 제안입니다. Unity 실행, 실제 전투 화면, 조명·가림·노멀맵·지도 연동은 검증하지 않았습니다.
