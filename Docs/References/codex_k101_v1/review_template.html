HUMAN LAST RAMPART · K-101

현재 그림에 맞춘 반사 마스크

주인공·마법사·대포병 점화 시트 7장의 재질 정보를 다시 만들었습니다. 원본과 마스크는 같은 칸을 동시에 재생합니다. 오른쪽 재질 구분 그림으로 금장·보석·발광 효과가 어디에 지정됐는지 확인할 수 있습니다.

점화는 432×384칸 × 6프레임입니다. 나머지는 288×384칸입니다. 그림과 마스크의 크기·알파·발 위치는 완전히 같습니다. 게임 연결 전 자료이며 실제 조명 화면은 Unity에서 확인해야 합니다.

이미지 준비 중

무광: 천·피부·머리·나무가죽금장·금속 장식지팡이 보석발광 효과: 반사 제외

R은 반사 강도, G는 매끄러움입니다. 금장 R/G = 255/217, 보석 = 255/230, 가죽 = 77/64, 천·피부·머리 = 13/26, 발광 효과 = 0/0. B는 0, A는 원본 알파입니다. 값은 선형 데이터이며 색 공간 보정을 적용하지 않습니다.

밝은 머리·눈·피부·흰 천을 금속으로 취급하지 않습니다. 시전 보석 본체와 주변 마법 효과를 구분했습니다. 점화 원본의 희미한 잔여 알파를 포함해 기존 픽셀을 그대로 보존했습니다.
가져오기 권장: sRGB 끄기 · Point · 밉맵 끄기 · 압축 없음 · Clamp · 일반 데이터 텍스처. 초록 선은 피벗 y=360이며 원본 발 모양을 이동시키지 않았습니다.
외부 리소스와 서버 없이 이 파일만 열면 검토할 수 있습니다.
