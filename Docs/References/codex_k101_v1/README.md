# K-101 반사 마스크 재제작

현재 게임 원본 7장을 기준으로 반사 마스크를 새로 만들었다. 기존 K-092 마스크를 확대하지 않고 현재 픽셀을 재분류했다. Game/ 파일은 수정하지 않았다.

게임 원본은 `Game/Assets/_Project/Art/Characters/`의 Hero·Static·Fire 하위 파일이다. 정확한 경로와 SHA-256은 manifest.json에 기록했다. 프레임은 행 우선이며 각 행 왼쪽부터 읽는다. 주인공 이동 4행은 후면 걷기 / 왼쪽 걷기 / 왼쪽 달리기 / 정면 걷기 순서다.

기본 피벗은 위쪽 기준 (144,360), 원본은 (48,120)이다. **점화는 K-086 v5의 144×128 원본 칸·피벗 (96,120), 게임 칸 432×384·피벗 (288,360)을 보존했다.** 전체 폭 2592를 288폭 9칸으로 나누지 않는다. 이는 기존 시트의 격자를 보존하는 작업이다.

## 채널과 재질

RGBA8 PNG이며 R은 반사 강도, G는 매끄러움, B는 0, A는 원본 알파 바이트 그대로다. 수치는 선형 데이터다.

| 재질 | R | G |
|---|---:|---:|
| 천·피부·머리·나무·외곽선 | 13 | 26 |
| 가죽 | 77 | 64 |
| 거친 철 | 242 | 140 |
| 밝은 철 | 255 | 191 |
| 황동 단추·견장·금장 | 255 | 217 |
| 지팡이 보석 본체 | 255 | 230 |
| 불꽃·보석 주변 마법 효과 | 0 | 0 |

K-092의 기본값과 분류 함수를 재사용했다. 현재 팔레트의 금장·가죽을 구분하고, 머리색·피부색·파란 눈은 낮은 반사를 유지한다. 시전 중 보석과 주변 효과는 같은 색이 사용되므로 본체 영역을 프레임별로 지정했다. 점화의 견장 단추는 위치와 색으로 제한하고 흰 옷단은 무광으로 유지했다. 투명 픽셀의 RGB는 모두 0이다.

## 산출물과 재생성

- 폴더 루트 `*_spec.png`: Claude가 연결할 게임 크기 마스크 7장.
- `native/`: 손실 없는 3배 최근접 격자를 복원한 원본 마스크 7장.
- `previews/`: 원본 마스크의 4배 최근접 미리보기 7장.
- `materials/`: 재질 분류 검토용 색상 그림 7장. 게임용 마스크가 아니다.
- `material_contact.png` 등 접촉표: 현재 원본과 분류를 확인하는 보조 그림.
- `manifest.json`: 크기·격자·피벗·프레임 경계·원본 해시·파일별 검증 결과.
- `build_masks.py`, `review_template.html`: 재생성 도구. Python·Pillow·NumPy와 저장소의 K-092 제작 함수·K-086 v5 명세를 사용한다.

저장소 루트에서 `python Docs/References/codex_k101_v1/build_masks.py`로 재생성한다. 새로 만든 파일은 이 폴더와 지정된 검토 HTML에만 저장한다.

검토 페이지는 `_HTML/6_그림_화면/codex_K-101_반사가면재제작_v1.html`이다. 이미지가 내장되어 서버 없이 직접 열 수 있다. 원본 / 마스크 / 재질 구분을 동시에 재생하고, 이동 시트는 행마다 별도 표시한다. 재생·정지·한 칸 이동·R/G 채널 보기와 발 기준선을 지원한다.

## 검증 및 연결 시 주의

7개 시트·32개 프레임의 크기와 알파가 현재 게임 원본에 정확히 일치한다. B=0, 투명 RGB=0, 원본↔게임용 3배 최근접 왕복, 4배 미리보기 크기, 프레임별 알파 경계·발 아래 경계 보존을 검사했다. 새 알파 픽셀은 없다. 기준 피벗 y=360이며 모든 프레임의 불투명 경계도 y=360이다. 점화 원본에 존재하는 희미한 잔여 알파는 지우지 않았다.

검토 HTML에 내장된 이미지 21장의 디코딩·크기와 스크립트 문법 검사를 통과했다. 별도 스크립트 실행 검사에서 동작 카드 10개 생성, 21장 초기화, 재생·정지·한 칸 이동, 채널 전환, 발 기준선 전환을 확인했다. 이 검사는 브라우저의 실제 화면·렌더링을 검증하지 않는다. 현재 세션에는 연결된 브라우저가 없어 실제 브라우저 화면 검토는 수행하지 못했다. Unity 실행·Play·게임 안 조명 비교도 수행하지 않았다.

`python Docs/References/codex_k101_v1/verify.py`로 검증을 다시 실행한다. 스크립트 문법·동작 검사는 Node.js를 사용하며 결과는 `validation.json`에 저장된다.

Claude 연결 권장값: 일반 데이터 텍스처, **sRGB 끄기**, Point, 밉맵 끄기, 압축 없음, Clamp. 원본과 같은 격자·프레임 순서로 사용한다. 이 폴더는 Unity Assets 밖의 제작 자료이므로 .meta를 만들지 않았다. Game/에 복사하고 Unity 가져오기를 할 때 해당 에셋의 .meta를 함께 관리한다.
