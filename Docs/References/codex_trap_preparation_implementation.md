# 정비 함정 구매·설치 구현 (T-CX-036)

- 상태: 구현·직접 소스 검사 완료, Claude Unity 화면/연동 QA 및 커밋 허가 대기.
- 담당 Codex. 승인 설계 PrepTrapsProposal·D-050/051·C-008 r6/C-004 v1.3.

## 구현 범위

정비에 ‘함정 구매·설치’ 버튼을 추가한다. 다음 전투 지형은 CampaignStartDef의 전투 번호 매핑으로 고른다. 북/동/남/서 성벽을 바꿔 공용 TrapGrid의 24열×14행(현재 지형값)에서 빈 칸을 선택한다. 성벽에 가까운 줄은 아래에 표시한다. 언덕 칸·이미 점유한 원래 설치 칸은 비활성화한다.

함정 종류·상점 재고·보관 재고, 구매/보관 재설치, 지도 표시(기본 켜짐)를 선택한 뒤 견적→확정한다. 구매는 정의 가격(현재25골드)과 상점1개 차감, 보관품은 골드 없이 보관1개 사용. 성공 때만 새TrapId와 칸 가운데 좌표를 기록한다. 미표시 함정은 지도 점화가 불가능함을 안내한다. 환불·판매·회수 실행은 제공하지 않는다.

정비 재입장 때 같은 전투 번호에는 상점 보충을 반복하지 않는다. 모든 종류의 재고를 검사한 뒤 다음 목록과 보충 번호를 함께 반영한다. 상점/보관 목록 오류·재고 부족·골드 부족·언덕/점유/범위 밖·ID 범위 초과·만료 견적·정의/상태 변경은 구매 상태를 변경하지 않는다. 닫기·정비 화면 종료로 견적을 무효화한다. 다른 지형 설치물과 모집/수리·보상 상태는 보존한다.

재고 수치는 코드에 고정하지 않고 TrapDef.ShopStockStart/PerPrep/Max를 사용한다. 작업 중 Claude가 TrapDef 기본값을12/+6/24로 바꾼 것을 읽었다(기존 D-050은6/+3/12). Codex는 그 값을 수정하거나 새로운 밸런스로 확정하지 않았으며, Claude에게 최신 승인/기록 확인을 요청한다. 두 데이터값 모두 거래 시험으로 확인했다.
