# 강화·훈련·용병 아이콘 1판

정비 화면의 상점과 병영에서 사용할 검토용 그림 26종입니다. 게임 파일은 변경하지 않았습니다.

- 원본: 이 폴더의 품목별 PNG, 각 32×32px·RGBA·투명 배경.
- 확대본: `preview_2x/`의 64×64px, `preview_4x/`의 128×128px. 최근접 이웃 방식으로 원본 점과 정확히 대응합니다.
- 전체 비교표: `contact_sheet.png`. 한국어 품목명과 연결용 파일명을 표시하고, 두 배경에서 4배로 비교합니다.
- 검토 페이지: 저장소 루트의 `_HTML/6_그림_화면/codex_K-067_강화아이콘_v1.html`. 이미지와 기존 판 질감을 모두 내장해 서버·인터넷 없이 직접 열 수 있습니다.
- 품목 대응: `manifest.json`. 기존 데이터에서 한국어 이름·설명·가격·고용비·급료를 읽었습니다.

## 그림 기준

기존 UI 키트의 좌표 기반 제작 방식을 이어 사용했습니다. 별도의 이미지 생성 서비스는 사용하지 않았습니다. K-059의 양피지·나무 판과 게임에 있는 기존 금화·대포 아이콘을 참고했습니다. 이 작업 폴더에는 `codex_k033*` 폴더가 없어 기존 UI 아이콘 실물을 기준으로 삼았습니다.

외곽선은 가장 바깥 한 점을 짙게 둘렀으며, 사방 가장자리에는 최소 1px 투명 여백이 있습니다. 색은 UI 색상 기준에 있는 11색으로 제한했습니다. 기본 황동·잉크·양피지에 위험색과 불·폭발색을 더했습니다. 안티앨리어싱과 반투명 점은 사용하지 않았습니다.

훈련은 활·머스킷·대포의 병종별 문양을 유지하고 아래에 계급점 1·2·3개를 놓았습니다. 용병은 같은 활·머스킷 문양에 계약 동전을 붙였습니다.

공용 표시는 다음과 같습니다.

| 파일 | 뜻 | 배치 예 |
|---|---|---|
| `mark_gold_coin.png` | 골드 | 가격 옆 |
| `mark_wage.png` | 돌아오는 화살표가 있는 동전, 반복 급료 | 용병의 전투당 급료 옆 |
| `badge_one_battle.png` | 검과 숫자 1, 한 전투만 사용 | 불화살 꾸러미·화약 통 옆 |
| `badge_per_wall.png` | 단일 성벽, 성벽별 구매 | 방패 난간 옆 |

공용 표시는 품목 그림에 합쳐 넣지 않았습니다. 군의관 천막은 현재 데이터에서 성벽별 구매가 아니므로 해당 표시를 붙이지 않습니다.

## 다시 만들기와 확인

Windows PowerShell과 기본 `System.Drawing`을 사용합니다. Unity 실행이나 패키지 설치는 필요하지 않습니다. 다음 파일을 순서대로 실행합니다.

1. `build_icons.ps1`: 원본·확대본·비교표·품목 대응표 생성.
2. `build_review.ps1`: 한국어 검토 페이지 생성.
3. `verify_assets.ps1`: 크기·투명도·11색 팔레트·여백·중앙 배치·확대 점 대응·훈련 문양 동일성·데이터 목록·중복 그림 검사.
4. `verify_review.ps1`: 설치된 Chrome을 숨김 상태로 실행해 로컬 페이지·이미지·필터·1440px 및 390px 배치를 확인하고 종료.

검사 결과는 `qa_assets.json`, `qa_review.json`에 저장했습니다. 검토 페이지를 실제 브라우저로 연 `review_desktop.png`, `review_mobile.png`, `review_training.png`도 함께 보관했습니다. 전체 비교표와 세 화면 이미지를 직접 열어 확인했습니다.

게임 연결과 Unity 실행 화면 비교는 이번 카드에서 수행하지 않았습니다. 연결 시 원본 PNG를 사용하고 필터는 Point, 압축은 없음, 밉맵은 끄는 설정을 권장합니다. 확대 PNG는 검토용입니다.
