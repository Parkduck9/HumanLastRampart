# K-096 생성 지시와 추출 기록

내장 imagegen을 1회 사용했습니다. CLI/API 우회는 사용하지 않았습니다. 아래는 실제 생성 지시의 한국어 재기록입니다. 생성 원안은 `source/generated_ui_atlas.png`에 보관했습니다.

## 생성 지시

용도: UI 시안용 스프라이트 원안 아틀라스. 어두운 중세풍 픽셀 아트 성벽 방어 게임의 수리 UI. 투명 배경, 1024×1024 정사각형을 요청한다.

위쪽에 가로 직사각형 버튼 배경 4개를 둔다. 요청 범위는 x=64..960, 각 y=64..191 / 256..383 / 448..575 / 640..767이다. 작게 계단지거나 잘린 모서리, 어두운 청록·목탄색 내부, 황동·금색 테두리, 굵고 어두운 픽셀 윤곽선, 재질당 약 3단계 명암, 모서리 리벳을 사용한다. 중앙 3분의 1은 가로 9-slice 확대를 위한 평평하고 단순한 면으로 둔다. 중앙에 그라데이션이나 질감을 넣지 않는다.

위부터 기본은 오래된 황동, 가리킴은 밝은 금빛 황동, 누름은 어둡고 안으로 눌린 황동, 비활성은 채도를 낮춘 목탄·회색 황동으로 구분한다. 글자는 전혀 넣지 않는다.

아래쪽에는 동전과 수리 망치를 한 개씩 둔다. 동전의 요청 범위는 x=160..287, y=832..959이며 중앙에 마름모를 새긴 둥근 금화다. 망치는 x=448..575, y=832..959이며 단단한 나무 손잡이와 강철 머리를 가진 대각선 도구다. 아이콘은 크고 뭉툭한 픽셀, 선명한 실루엣, 굵은 어두운 윤곽선, 3단계 명암을 사용한다. 나머지 영역은 완전히 투명하다. 정사영 2D 부품만 만들며 원근·라벨·목업 장면은 넣지 않는다.

## 실제 원안과 정규화

도구의 실제 출력은 1254×1254였습니다. 생성 위치·크기는 요청과 달라 실제 알파 범위를 읽고 각 행의 부품을 추출했습니다. 버튼 행은 대략 y=87..261 / 299..473 / 509..684 / 717..892였습니다.

버튼별 주 연결 성분만 추출해 바깥의 생성 흔적을 제외하고, 328×48로 최근접 정규화한 뒤 336×56 캔버스에 4px 여백으로 배치했습니다. 좌우 모서리 영역 28px, 위아래 16px을 유지한 9-slice로 160·240px 너비도 만들었습니다. 동전과 망치는 각각 주 연결 성분을 추출하고 24·32px에 1px 이상의 여백을 두어 최근접 축소했습니다. 원안은 수정하지 않았습니다.

## 좌표가 고정된 UI 제작

성벽 테두리는 K-091 v2의 네 방향 정상 패치에서 알파 실루엣을 추출하고, 내부 구멍을 메운 뒤 바깥쪽 거리 1·2px를 실선, 3·5px까지를 황동 발광으로 만들었습니다. 캔버스와 피벗은 그대로 유지했습니다.

체력 막대는 9-slice 경계와 채움 여백을 정확히 맞출 수 있는 사각 UI 도형으로 제작했습니다. 전체 목업은 기존 성벽 패치, 납품 버튼·막대·아이콘과 한국어 텍스트를 조합했습니다. 새로운 게임 코드나 Unity 설정은 작성하지 않았습니다.
