## 성벽 합성

- 모든 외곽선은 **256×256, 피벗 (128,128)** 입니다. K-091 v2 패치와 동일한 위치·배율로 놓습니다. 시트 전체에 중심 피벗을 잡지 말고 개별 256×256 셀을 먼저 분리합니다.
- 북·동·남·서 교체 사각형은 각각 `(52,8,152,52)`, `(196,52,52,152)`, `(52,196,152,52)`, `(8,52,52,152)` 입니다. 좌상단 기준 x,y,너비,높이입니다.
- 바탕 성벽 → 해당 교체 사각형을 알파 0으로 지우기 → 손상 패치 → 선택 외곽선 순서로 합성합니다. 외곽선을 올릴 때는 교체 사각형을 지우지 않습니다.
- 외곽선은 정상 성벽의 알파 128 이상 실루엣에서 내부 구멍을 메운 뒤 바깥쪽으로 추출했습니다. 가리킴은 불투명 1px / 발광 반경 3px, 선택은 불투명 2px / 발광 반경 5px입니다. 포탑은 제외합니다. 손상·붕괴 때도 정상 벽의 선택 영역을 유지합니다.
- 카드 worktree에 K-091 v2 폴더가 없어 원본 프로젝트에서 읽기 전용으로 참조했습니다. 비교에 필요한 파일만 이 폴더에 복사했습니다. 바탕 PNG는 현재 게임 성벽과 디코딩된 모든 픽셀이 같습니다. PNG 압축 방식 차이로 파일 해시는 다를 수 있습니다.

## 9-slice와 체력 표시

경계 순서는 Unity의 **좌·아래·우·위** 입니다. 모든 UI 부품은 중심 피벗이며, 방향별 테두리는 크기 조절 없이 한 장으로 사용합니다.

| 부품 | 9-slice 경계 | 사용 기준 |
|---|---|---|
| 버튼 3종 × 4상태 | `28,16,28,16` | 높이 56 권장, 최소 80×40. 글자·비용 아이콘은 별도 배치 |
| 체력 프레임·채움 4종 | `8,8,8,8` | 높이 28 권장. 채움의 원본 내부 영역은 x=6..313, y=6..21 |

체력 프레임을 전체 너비 W로 배치하고, 회복 후 예상 채움 → 현재 체력 채움 순서로 올립니다. 두 채움은 프레임과 같은 왼쪽에 정렬합니다. 비율 p가 0보다 크면 채움 캔버스 너비는 `max(16, round((W-12)×p)+12)`로 9-slice 합니다. p=0이면 채움을 숨깁니다. 원본 좌우 투명 여백 6px을 보존합니다. 극소량에서는 최소 채움 4px이 나타나므로 정확한 체력 수치는 텍스트로 함께 표시합니다.

연한 황동색 예상 채움의 알파는 155/255입니다. 현재 채움을 그 위에 올려 회복될 구간만 보이게 합니다. 막대 프레임·세 채움 색은 불투명이고 주변은 투명합니다.

검토 화면의 색 구간은 초록 67% 이상, 노랑 34~66%, 빨강 33% 이하의 예시입니다. 목업은 북 420, 동 920, 남 180, 서 0 / 최대 1,000, 북쪽 +100 수리를 선택했습니다. 비용 40 / 232 / 992는 체력당 0.4금화를 가정한 예시이며 게임의 가격 확정이 아닙니다. 목업의 돌벽 체력 색은 원래 알파를 유지하고 RGB에 상태 색을 30% 혼합한 표시입니다. 원본 손상 패치는 변경하지 않았습니다.

## 가져오기 권장값과 검증

투명 RGBA, Point 필터, 압축 없음, Clamp를 권장합니다. 개별 PNG를 사용하거나 manifest의 셀 단위로 시트를 분리합니다. 시트의 오른쪽·아래쪽 인접 셀이 섞이지 않도록 필터와 아틀라스 여백은 통합 단계에서 확인합니다.

29개 개별 PNG 모두 규격·투명 배경·캔버스 가장자리 여백을 검사했습니다. 8방향 연결 성분이 각각 1개로 고립된 알파 픽셀이 없으며, 외곽선은 원본 정상 성벽의 불투명 실루엣과 겹치지 않습니다. 7개 4배 확대본은 원본 픽셀의 정확한 4×4 복제임을 전수 비교했습니다. 목업은 1920×1080입니다.

Chromium에서 내장 이미지 49개 읽기, 네 방향 선택, 가리킴 모드, 자동 순환, 체력 0과 회복 상한, 비활성 버튼 3종, 160px·700px 버튼 늘리기를 확인했습니다. 브라우저 캡처도 직접 열어 확인했습니다.

캐릭터의 96×128 셀·발 기준선·3배 게임 시트 규격은 이 UI 키트에 해당하지 않습니다. Unity 가져오기·게임 연결·실제 플레이 확인·사용자 최종 외형 승인은 남아 있습니다.
