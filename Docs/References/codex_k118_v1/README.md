# K-118 안마당 건물 에셋 1안

낮은 건물 열 채에 씌울 반복 재질, 기능 건물 앞면과 작은 구조물입니다. 정비 마당의 석재·오래된 목재·붉은 기와·올리브색 상점 차양을 따랐습니다. 등대의 12m 높이와 기존 빈 중앙 공간이 기준입니다.

## 구성

- `textures/`: 256×256px 반복 재질 7종. 회벽·목골, 거친 석조 기단, 판벽, 점토 기와, 나무 너와, 슬레이트, 이엉.
- `decals/`: 기능 건물 4종의 낮·밤 앞면 8장과 창문 발광 마스크 4장. 각 144×64px, 투명 배경.
- `props/`: 연기 없는 굴뚝, 작은 종탑, 울타리, 건초, 장작, 우물 정면, 마구간 물통, 등불 교단 깃발 8종.
- `game/`: 앞면·소품 원본을 최근접 3배로 확대한 16장. 크기를 올려도 세계에서 차지하는 크기는 같습니다.
- `previews/`: 최근접 4배 이미지, 3×3 반복 확인 이미지, 목업 보호 영역 마스크.
- `mockup_day.png`, `mockup_night.png`: 실제 캡처 위의 방향 검토용 합성. 납품 재질을 메시로 렌더링한 결과가 아닙니다.
- `manifest.json`: 파일 크기, 미터 환산, 피벗, 반복 여부, 건물·면별 대응. `generation.json`에는 내장 이미지 생성 도구의 최종 프롬프트와 생성 원본 위치를 기록했습니다. 원본은 `sources/`에도 보관했습니다.

검토 페이지: [`codex_K-118_안마당건물_v1.html`](../../../_HTML/6_그림_화면/codex_K-118_안마당건물_v1.html). 이미지·스크립트를 내장했으므로 파일을 직접 열 수 있습니다. 앞면의 낮·밤 자동 전환과 수동 선택, 현재 화면과 목업 비교, 반복 경계 확인을 제공합니다. 정적 건물 카드이므로 캐릭터 동작 시트는 교체하지 않습니다.

## 크기와 연결

원본은 **32px=1m**, 게임용 3배 이미지는 **96px=1m**입니다. 모든 이미지는 Point 필터, 재질은 Repeat, 앞면·소품은 Clamp를 사용합니다. 256px 재질 한 장은 8×8m입니다. 벽이나 지붕 전체에 한 장을 늘리지 말고 미터 기준 UV를 사용합니다. 재질 내부의 반복 단위는 목골·석조·판벽·기와·이엉 4m, 슬레이트 2m, 너와 8m입니다. 지붕 타일이 건물보다 커 보이지 않도록 밀도를 조정했습니다.

현재 `BattleCourtyardBuildings.cs`의 메시 UV는 0입니다. Claude가 면별 UV와 데칼 부착을 연결해야 합니다. 석재와 지붕은 무광 알베도이며 노멀맵은 없습니다. 낮·밤 앞면의 차이는 창문 영역에 한정했습니다. `_window_emission.png`의 흰 픽셀만 발광 마스크로 사용할 수 있으며, 넓은 빛 번짐은 구워 넣지 않았습니다.

앞면은 마당을 바라보는 면 `-Out(side)`에 붙입니다. 폭 4.5m, 높이 2m 캔버스이며 문 중심 피벗은 위에서 `(64,61)`입니다. 작은 창문의 유리만 밤에 따뜻한 황갈색으로 바뀝니다. 간판은 망치와 돌 / 교차 창 / 가시 덫 / 동전 주머니로 구분하며 글자는 넣지 않았습니다. 앞면 셀의 좌우 투명 여백도 크기 계산에 포함합니다.

밑선은 **마지막 불투명 행 바로 아래의 픽셀 경계**입니다. 앞면의 마지막 불투명 행은 60, 밑선은 y=61입니다. 소품도 높이에서 3을 뺀 위치가 밑선이며 아래 세 행을 비웠습니다. 게임용 피벗과 밑선은 각각 3배입니다. 캐릭터용 96×128 셀·y=120 규약은 이 정적 건물 카드에 적용하지 않았습니다.

건물 폭·깊이·기존 높이는 명세의 `buildings`에 그대로 기록했습니다. 건물은 지붕 포함 최대 2.5m이며 굴뚝·종탑을 포함한 최고점은 3m 이내로 유지합니다. 굴뚝·종탑은 기존 부속 상자를 대체하고 중복해 쌓지 않습니다. 울타리는 기존 선분 길이에 맞춰 이어 쓰며, 소품은 정면 이미지이므로 측면까지 묘사하는 3D 구조물이 아닙니다. 너와·이엉은 선택 재질이며 기존 건물의 지붕 종류를 바꾸는 결정은 포함하지 않았습니다.

## 목업의 범위

낮 목업은 `01_bldg_day_0_overview.png`, 밤 목업은 `279_w27_night_1_wall_top_tower_north.png`가 원본입니다. 합성 마스크 밖의 픽셀은 원본과 완전히 같습니다. 낮은 기존 상자 외곽 안에서 재질 방향을 보여 줍니다. 일부 부속의 실루엣은 상자 외곽에 맞춰 잘렸으므로 실제 부속 모양은 별도 소품 PNG를 기준으로 합니다.

279번은 건물 추가 전의 캡처입니다. 밤 목업의 먼 성벽 건물은 예상 배치이며 실제 게임 투영을 검증한 자료가 아닙니다. 등대·하늘·전경·화면 표시는 보존했습니다. 모든 목업은 배치와 분위기 검토용이며 실제 납품 텍스처의 적용 결과는 아닙니다.

## 검사와 남은 확인

`verification.json`: 원본 23장의 크기·알파·밑선·가장자리 여백·3픽셀 미만 고립 성분, 7개 재질의 대응 경계, 게임용 16장의 정확한 최근접 3배, 목업 보호 영역 변경 0픽셀을 확인했습니다. `review_verification.json`은 내장 PNG 압축 데이터 해독, 명세 크기, 외부 리소스 없음, 낮·밤·정지·재개 스크립트 검사를 기록합니다.

이 세션에는 연결된 브라우저가 없어 브라우저 렌더링과 실제 클릭은 확인하지 못했습니다. JavaScript 검사는 최소 DOM 대역을 사용한 정적 검사입니다. Unity는 열거나 실행하지 않았습니다. 실제 배치·광원·가림·원근·축소된 간판 가독성은 Claude 연결 후 사용자 캡처로 확인해야 합니다. `Game/`, 협업 문서·로그, Git은 수정하지 않았습니다.

재생성 순서는 PowerShell의 `package.ps1`, `verify.ps1 -Normalize -Density`, Node의 `build_review.js`, `review_check.js`입니다. `-Normalize`와 `-Density`는 최초 포장 직후 한 번만 적용하며 일반 재검사는 인자 없이 `verify.ps1`을 실행합니다. 생성 원본은 `sources/`를 사용합니다.
