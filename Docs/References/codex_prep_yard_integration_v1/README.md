# 정비 마당 2.5D 연결·함정 구덩이 보정

2026-10-21, T-CX-096·097. 사용자 승인으로 K-089 고정 배경·통행 마스크·가림 레이어·장소 좌표를 실제 게임에 연결했다. 원본 그림을 다시 생성하거나 고치지 않았다.

## 실제 구현

- Meta/PrepYard: X/Z 8m 깊이 이동, 3D 바닥 BoxCollider, 인물 CapsuleCollider, 기둥·나무통 MeshCollider, 5개 장소 Trigger. 반경을 포함한 통행 마스크와 작은 이동 간격으로 관통을 막는다. 장소 활성화는 원본 화면 좌표의 접근 사각형을 따른다.
- K-089 고정 투영과 실제 3D 카메라 투영의 화소 좌표 일치를 검사했다. 배경은 한 장, 캐릭터·바닥 투영 그림자는 별도 투명 렌더 텍스처, 앞 소품 가림은 원본 레이어로 합성한다. WASD/방향키, 가까이에서 E/스페이스. 다섯 장소 모두 가로 경유→깊이 접근 이동 검사.
- 배경 그림과 카메라를 함께 회전하는 방식은 아니다. 건물의 고정 그림자는 배경에 포함되며, 동적 그림자는 인물 실루엣을 바닥 평면에 투영한 근사다. 실시간 건물 조명/그림자 복원을 완료했다고 주장하지 않는다.
- 창/출정 확인/화면 열림 중 이동 중단. 다음 화면에서 독립 3D 공간·카메라·렌더 텍스처와 생성 자원을 해제한다. 최신 주인공 288칸·발360을 사용한다.
- 함정: 폭발 효과는 기존 0.6초 수명대로 삭제됨을 확인했다. 지속 구덩이 trap_2가 세로 빌보드로 남는 것이 공중 잔상의 원인이었다. 구덩이만 GroundPlane=1, 중앙 피벗, 지면+0.025m로 바꿨다. 전투 계산·자동 폭발 확률은 유지했다.
