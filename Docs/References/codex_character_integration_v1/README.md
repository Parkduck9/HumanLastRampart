# 최신 캐릭터 전체 적용·감사 최종 결과

2026-10-21 / T-CX-098. 사용자 지시대로 누락을 먼저 기록한 뒤 최신 색 시트·짝 노멀·동작 소비 경로를 확인하고 연결했다. 처음 주인공도 최신이라는 구두 설명은 잘못이었다. 실제 256칸 구형을 발견하고 승인된 288칸 최신본으로 교체했다.

## 적용 범위

- 색 시트35개·135프레임, 짝 노멀35개. 최신 원본/Game 파일 해시·전체 RGBA·알파·크기 검사35/35. 기존 에셋 GUID 유지, 새 노멀/동작의 .meta 동봉.
- 주인공 3종, 궁수·총병·대포병, 마법사 4종, 고블린·사다리 고블린·오우거를 새 그림으로 맞췄다. 오우거의 의도된256×384 예외는 유지했다.
- 점화병은 K081 구형1728폭으로 되돌리지 않고 최신 v5 2592폭/432칸·발288,360을 유지했다. 동일한 K081 수학 계산으로 확장 점화 노멀을 별도 생성·30검사하고 색/알파 불변을 확인했다. 근사 법선이며 3D 베이크가 아니다.
- UnitDef/EnemyDef poseNormals에 색/노멀 쌍을 저장하고 크기가 다른 구형 법선을 거부한다. 병사 사격·쓰러짐·점화, 적 공격·쓰러짐·사다리 세우기·오르기, 영웅 정지·손짓, 마법사 정면/걷기/시전, 사다리·견인병까지 실제 렌더 경로에 붙였다. Campaign 저장 구조는 바꾸지 않았다.
- 마법사 이동에 옆걷기4칸과 실제 이동 방향 반전을 적용했다. 사다리 운반 동작을 이동에 선택하고 사다리 정면/측면은 시야 각도로 나눠 그린다. 고블린 전용 공격 연결, 대포 견인 체형219점·걸음36화소 보정, 결과 화면 최신288칸 비율/발선을 보정했다.

## 사용과 보관 구분

실행 경로가 있는 시트32개. `ladder_goblin_static.png`, `ogre_static.png`는 별도 서기 상태가 없는 적의 예비 그림이며, `ladder_goblin_walk.png`는 사다리 운반 그림을 우선하는 이전 걷기 대안이다. 세 파일도 최신본과 노멀을 보관했지만 전투에서 모두 재생된 것으로 기록하지 않는다. 모든 포즈의 자연스러움·접촉·타격 시점이 최종 승인됐다는 의미도 아니다.
