# 확장 점화 v5 법선 (기술 계산)

2026-10-21. T-CX-094에서 적용한 색 PNG는 변경하지 않고 K081의 결정적 법선 계산을 최신 여백 포함 144×128 칸에 적용했다.

- 원색: `Game/Assets/_Project/Art/Characters/Fire/cannon_crew_ignite6.png`, 2592×384.
- 정확한 3배 최근접 격자가 일치하는지 확인하고 864×128 native를 저장했다. 6칸을 개별 계산해 옆 프레임의 블러가 섞이지 않는다.
- 계산식은 `codex_k081_v1/resume_wizard_normals.py`와 같다. 높이 = `3.8*smooth(mask,2)+1.8*smooth(mask,5)+.45*smooth(luminance*mask,.8)`. 기울기의 법선 `(-dx,+dy,1)`을 정규화하고 RGB는 `round(128+127*n)`으로 저장한다.
- 알파는 같은 좌표의 색 PNG에서 그대로 유지했다. 투명 RGB는 128,128,255. native 법선을 3배 최근접 확대해 Game에 동일 바이트로 복사했다.
- 6프레임×5항목(크기, 알파, 투명 RGB, 벡터 길이 0.99~1.01, 양의 Z)의 30검사 통과. 게임 크기 알파·정확한 3배 격자·복사 해시·원색 해시 불변도 확인했다.
- 근사 기술 법선이며 3D 베이크가 아니다. 색 생성·편집이나 동작 변경은 하지 않았다. 실제 조명 모습·정의 참조·Unity 그리기 시험은 부모 작업에서 진행한다.

상세 결과는 `validation.json`, 재현은 `build_normal.py`다. Game 복사가 포함되므로 Unity 시험 중에는 실행하지 않는다.
