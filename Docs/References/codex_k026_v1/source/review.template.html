상태판 배치 예시

수치와 날씨는 배치 검토용 가상 값입니다. 실제 게임 화면 캡처가 아닙니다.

검토할 점

  • 24px에서 활·총·대포와 여섯 명령의 형태를 빠르게 구분할 수 있는지 확인해 주세요. 실사용 시 명령 이름을 함께 표시하는 안입니다.
  • 비는 성긴 빗줄기, 소나기는 굵고 촘촘한 빗줄기로 구분했습니다. 번개는 추가하지 않았습니다.
  • 맑음은 사방으로 빛나는 해, 낮은 지평선 위의 해입니다. 날씨와 시간은 별도 표식입니다.
  • 주인공은 장교 제복과 훈장, 특수 적은 뿔 달린 큰 적으로 표현했습니다. 이 두 상징의 적합성은 사용자 확인이 필요합니다.
  • 기준 도트는 24px입니다. 48px는 정확한 2배이며, 32px는 색 번짐 없는 최근접 좌표 변환입니다. 32px의 도트 폭은 1~2px로 달라질 수 있습니다.
  • 게임 연결·Unity 가져오기·실제 HUD 가독성은 미검증입니다. 방향 확정 후 연결하고 실제 화면과 비교합니다.
