K-024 성벽 손상·전장 흔적

회색 석재의 멀쩡 / 금감 / 부서짐, 시체 더미 높이 3단계, 묻힌 함정과 터진 구덩이를 비교합니다. 멀쩡 단계는 현재 게임 그림의 동일 사본입니다. 모든 그림과 원안이 이 파일에 들어 있어 서버 없이 열 수 있습니다.

그림 불러오는 중

32px/m는 질감의 밀도 기준입니다. 성벽 128×128 = 4×4m, 난간 128×64 = 4×2m의 반복 범위이며, 난간 모형 높이를 2m로 바꾸자는 뜻은 아닙니다. D-068 난간 벽 0.105m는 약 3.36화소라 작은 금은 실제 화면에서 잘 안 보일 수 있습니다.

배치 전 확인할 점

손상 2단계는 어두운 속돌과 패인 면의 그림입니다. 실제 성벽 윤곽·구멍·충돌은 바꾸지 않습니다. 난간 윗면은 같은 석재 원안에서 얻은 견본이며 옆면과 모서리가 맞물리는지는 모형에서 확인해야 합니다.

시체는 고블린 계열 견본입니다. 세 단계 모두 64×64 캔버스, 아래 접점 (32,56), 몸체 폭 48화소를 사용합니다. 같은 폭에서 높이만 증가하며 시체 수·등장 조건·높이의 최종 수치는 미확정입니다. 함정은 폭 56화소의 땅 표면 그림으로, 구덩이의 입체 깊이나 통행 판정은 포함하지 않습니다.

기존 노멀맵을 손상 질감에 그대로 붙이면 균열과 조명이 어긋납니다. 이번 시안에는 손상 노멀맵이 없으므로 색만 비교하고, 채택 뒤 별도 제작·실제 조명 검토가 필요합니다.
