- 대상: 고블린, 사다리 고블린, 사다리 운반 달리기, 오우거.
- `*_half.png`: 원본 순서·행·프레임 수 유지. 고블린 걷기 4 + 공격 4, 나머지 걷기 4.

## 좌표와 연결

| 대상 | 절반 칸 | 절반 발 | 1/4 칸 | 1/4 발 |

| 오우거 | 128×192 | (64,176) | 64×96 | (32,88) |

PNG 왼쪽 위 기준이며 발 좌표는 마지막 불투명 행 다음 픽셀 경계입니다. 모든 프레임 발끝이 이 경계에 닿습니다. 중심을 다시 맞추지 않고 원본의 위치·비대칭 무기 자세를 보존했습니다.

K-099의 현재 칸 기준 정확한 절반·1/4 규격이 공통 신규 인물 96×128·3배 규격보다 우선합니다. 근접 시트 교체용이 아니며 다시 288×384로 확대하지 않습니다.

점 필터·밉맵 끄기를 전제로 합니다. 각 칸 UV 안에서 샘플링해야 합니다. 아틀라스 바깥 감싸기만으로 내부 칸 샘플 유출이 막히지 않습니다. 절반은 면적 축소 후 색상 선명화, 1/4은 초록 피부·갈색 장비의 명암을 단순화했습니다. 알파는 0 또는 255이며 1~2픽셀 고립 조각을 제거했습니다.

절반 약 60~110m·1/4 110m 초과를 연결 후보로 기록했으며 실제 전환값은 Claude 측정 후 확인해야 합니다. 비교의 24·14·9픽셀은 같은 칸 높이를 적용한 모의 표시입니다. 야간 참고 이미지의 들판 조각을 사용했으며 게임 셰이더 조명은 재현하지 않았습니다.
