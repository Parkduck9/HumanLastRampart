# 곤봉 고블린 에셋 시안 v1

- 작성자: Codex
- 날짜: 2026-10-13
- 상태: 사용자 외형·동작 검토 대기
- 사용자 선택: 정면 걷기와 정면 공격만, 짧은 나무 곤봉, 두 동작 모두 4프레임.

## 외형과 동작

작은 초록 고블린에 큰 뾰족 귀, 짧은 검은 머리, 호박색 눈, 작은 송곳니, 낡은 갈색 가죽 장비와 짧은 나무 곤봉을 적용했다. 주인공 참고 이미지는 도트 표현 기준으로만 사용했고 고블린은 새 캐릭터로 생성했다.

Imagegen으로 정면 걷기·공격 6장씩의 작업 원본을 만든 뒤, 공격 타격 포즈에서 사라진 곤봉을 실제 원본 이미지 편집으로 복원했다. 사용자가 두 캐릭터 모두 4프레임으로 줄이도록 지시해 최종 걷기 4장·공격 4장으로 선택했다.

걷기는 두 접지와 두 통과 자세를 반복한다. 공격은 준비 → 곤봉 들어 올리기 → 내려치기 → 자세 회복. 3번째 공격 프레임을 타격 표시 시점으로 JSON에 기록했지만 실제 피해 판정은 구현하지 않았다.

## 보관 파일

- `codex_goblin_walk_attack4_v1.png`: 1024×768 투명 PNG, 4열×2행, 걷기와 공격 각 4장.
- `codex_goblin_walk_attack4_v1.json`: 실제 프레임 좌표·발 기준점·공격 표시 시점·재생 길이.
- `codex_goblin_preview_v1.html`: PNG·JSON 내장 미리보기. 단독 오프라인 실행·PNG/JSON 저장 가능.

시트 셀은 256×384, 발 기준점은 셀 내 (128,352). 렌더링 해상도 차이는 이미지 전체 최근접 크기 조절로 정리했다. 실제 게임용 픽셀 크기·히트박스·공격 거리·피해량·머티리얼은 별도 확정 대상이다.

## 미리보기

걷기 반복, 공격 1회, 공격 반복, 한 프레임 이동, 표시 크기·속도, 다가오는 이동 비교를 제공한다. 공격 1회는 회복 프레임에서 멈춘다. PNG 자체의 팔/다리 동작을 재생하며 분절 회전은 사용하지 않는다.

Game 반영·Unity Play·Git 쓰기는 이 에셋 작업에서 하지 않았다. 고블린 외형과 공격 가독성은 사용자 검토 대상이다.

사용자의 정리 지시에 따라 미선택 프레임이 포함된 생성 작업 원본과 배치 스크립트는 삭제했다. 현재 선택한 4+4프레임 PNG·JSON·HTML을 보관한다.
