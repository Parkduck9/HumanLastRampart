# K-081 최신 결과 — 기술 법선 재개 완료 / 게임 외형 검토 대기

2026-10-20, Codex. 마법사 최신 K076 원본 4시트(10프레임)에 기존 실루엣 높이장 법선 계산을 적용했다. 그림을 새로 그리거나 색 원본을 수정하지 않았다. 수정본은 `native/resume_v2/`, `game/resume_v2/`, `previews/resume_v2/`에 별도로 저장하여 기존 31시트와 구형 마법사 PNG를 모두 보존했다.

- **최신 진입점:** `manifest_current.json`, `resume_validation_current.json`.
- **35시트·135프레임, 210/210 기술 검사 통과.** 각 시트마다 native 크기/알파, game 크기/알파, manifest 정수배 최근접 확대, 게임 색 원본 SHA-256의 6개 항목을 확인했다.
- 마법사 4개는 native 96×128 칸, game 288×384 칸, 발 기준 48·120 → 144·360으로 정확히 3배다. 사다리 2개는 기존 4배, 오우거 4개는 기존 2배 규격을 유지한다. 과거 검사 `exact3x` 표시는 시트별 정수배 확대라는 뜻으로 쓰여 오해가 있었으며 최신 검사는 `exact_manifest_scale`로 바로잡았다.
- 원본 `manifest.json` 및 최초 `resume_validation.json`은 이력으로 보존했다. 한국어가 손실된 옛 메타정보를 추측 복원하지 않았으며 새 사용 경로는 `manifest_current.json`이다.
- `resume_wizard_normals.py`에 재현 가능한 계산/검사를 보관했다. 투명 RGB는 128·128·255, +X 오른쪽/+Y 위/+Z 관찰자이며 원색 알파를 그대로 사용한다. 노멀은 실루엣 블러와 약한 밝기 요철의 **근사값**이며 3D 베이크 결과가 아니다.
- 두 방향 조명 미리보기를 최신 4시트에 다시 계산하고 HTML 내장 이미지도 갱신했다. 정적 마법사 왼쪽 위 조명 PNG를 직접 열어 확인했다. 해당 제작 시점에는 브라우저/Unity 검증 전이었다. 이후 부모가 최신 마법사4종 선택·재생/정지·프레임 전환을 확인하고 resume_v2_browser.png에 보관했다. Unity/URP 조명·좌우 반전·최종 외형 승인은 별도다.
- 직접 열기: `_HTML/codex_K081_노멀맵재개검토_v1.html`. 원본 폴더의 `resume_preview.html`도 같은 내용을 담는다.
- Game 연결과 Git 작업은 하지 않았다. 기술 검사 통과와 사용자의 외형 승인은 구분한다.

## 최초 재개 검사 기록 — 당시 일부 보류 (아래 내용은 최신 결과가 대체)
