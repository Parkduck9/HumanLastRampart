# K-013 스토리 화면 2판 구현

- 근거: D-066 공통 스타일 승인, M-CL-074 스토리 카드, 작업 T-CX-056.
- 작업 폴더: C:/Unity/1/HLR-cards/K-013 / card/K-013.
- 상태: 코드 및 별도 컴파일 확인 완료 / 실제 Unity 화면 확인 대기.

기존 5번 화면의 중앙 메뉴형 배치를 배경 공간 + 밤색 앞모습 마법사 + 화면 아래 대사창으로 바꿨다. 하단 창은 화자·대사·다음 행동을 분리하고 공통 짙은 녹색·황동 테두리를 쓴다. 승인 시안의 공간 구분을 단순 색면으로 표현했으며 새 배경 그림을 생성하지 않았다.

## 구현과 경계

- `Story/StoryEntry.cs`: 밤색 마법사를 읽고 스토리 전용 ScreenView 생성 경로를 사용한다.
- `UI/ScreenView.cs`: 기존 3인자 생성자는 원래 중앙 패널 경로로 위임한다. 추가된 5인자 생성자만 스토리 배치를 사용한다. 기존 입력 차단·포커스·해제·Dispose 경로를 함께 사용한다.
- `Story/Resources/StoryArt/wizard_front_chestnut.png`: 원본 `Art/Characters/Static/wizard_static.png`의 바이트 동일 사본이다. 원본 Art 수정 없이 씬·App 변경도 필요 없는 Resources 경로로 연결했다. 새 GUID의 meta와 폴더 meta를 포함한다. 렌더링 비율을 보존하고 원본 Point 필터를 유지한다.

일반 스토리의 기존 대사 `성벽을 지키기 위한 여정이 시작됩니다.`와 버튼 `다음`, 패배 엔딩의 기존 대사 `성벽의 방어가 끝났습니다.`와 버튼 `메인으로`를 유지했다. 완료 신호는 둘 다 기존 `Complete(ScreenOutcome.Done)`이다. 화면 전환·중복 완료 차단·진행·저장은 기존 계약과 ScreenEntryBase/App이 맡는다. 제안 상태 C-009의 그래프 API나 선택지·건너뛰기·대사 기록을 새로 사용하지 않는다.

## 설명 화면

- `preview.html` 및 `_HTML/codex_K013_스토리화면_v2.html`: 같은 내용의 서버 불필요 단독 HTML. 마법사 PNG를 내장했다.
- HTML은 **구현 배치를 설명하는 목업이며 실제 Unity 캡처가 아니다**. 일반/패배 전환과 버튼 안내만 동작한다.
- `build.py`: 내장 PNG와 HTML을 다시 만든다.
- `verify.py --compile --unity-project C:/Unity/1/HumanLastRampart/Game`: 정적 자료 검사와 별도 Roslyn 컴파일을 수행한다. 기존 메인 작업 폴더의 Unity Library 참조 rsp를 읽기만 하며 카드 소스와 임시 출력 폴더를 사용한다. Unity 실행·Play 시험은 하지 않는다. 이 PC의 Unity 6000.3.25f1 경로가 필요하다.

## 검증 결과와 남은 일

`qa.json`의 자료·계약 보존 정적 검사 및 컴파일 결과 18/18 통과. UI와 Story 두 어셈블리 컴파일 종료코드 0, 오류·경고 출력 없음. 이 숫자는 Unity 기능 시험 건수가 아니다. 원본/사본 PNG SHA-256이 같고, HTML 두 사본과 내장 PNG도 일치한다.

합친 뒤 조정 담당/사용자가 실제 Unity에서 아래를 확인한다.

1. 일반 스토리에서 인물·화자·대사·다음이 표시되고 다음 한 번에 기존 다음 화면으로 진행한다.
2. 패배 엔딩에서 메인으로 버튼이 표시되고 기존 메인 복귀 동작을 유지한다.
3. 연속 클릭·키보드 포커스·화면 나간 뒤 UI 정리가 기존처럼 작동한다.
4. 16:9, 넓은 화면, 작은 창에서 대사창·인물 비율과 가림을 확인한다. 긴 대사 처리 확장은 별도 스토리 데이터 작업이다.
5. 기존 메인·결과·정비 화면의 중앙 패널·버튼 배치가 바뀌지 않았는지 확인한다.

이 카드에서는 실제 Unity 실행·기능 시험·브라우저 검증을 하지 않았다. 새 배경 최종 아트·스토리 데이터 형식·Core/App/Combat·원본 Art·씬·공용 문서는 변경하지 않았다. 카드 루트 CARD_RESULT.md는 보고용이며 커밋하지 않는다.
