# 점화의 밤 — 우두머리 네 시안

선택용 정지 컨셉입니다. 외형·크기·대응 아이디어는 사용자 선택 전 제안이며, 확정 규칙이나 게임용 동작 시트가 아닙니다.

검토 페이지: [`우두머리 네 시안`](../../../_HTML/6_그림_화면/codex_K-128_우두머리시안_v1.html). 이미지·스타일·동작을 모두 내장하여 서버 없이 직접 열 수 있습니다. 네 시안을 나란히 보고 기본 색 / 검은 실루엣 / 밤의 광선, 원본 점 1·2·4배를 바꿀 수 있습니다. 선택 표시는 페이지 안에서만 유지됩니다.

## 파일

- `A_ram_concept.png`, `B_climber_concept.png`, `C_caller_concept.png`, `D_shield_concept.png`: 각 1600×1160. 정면 4배 확대, 정면·측면 원본 크기, 고블린·오우거·4m 성벽, 축소 실루엣, 야간 색 대비, 한글 설명을 한 장에 넣었습니다.
- `lineup.png`: 1600×800. 네 정면을 같은 단위의 2배로 비교합니다.
- `*_study.png`: 각 448×192 투명 PNG. 정면 → 측면의 두 정지 연구 그림입니다. 각 칸 224×192, 중심 x112, 발바닥 아래 경계 y184입니다. 마지막 불투명 행은183입니다. 시간 순서의 애니메이션 프레임이 아닙니다.
- `manifest.json`: 생성 프롬프트, 출처, 팔레트, 크기·피벗·보기 순서, 비교판 좌표, 검증 결과입니다.
- `review_desktop.png`, `review_mobile.png`: 로컬 HTML을 실제 Chrome으로 연 확인 자료입니다.

컨셉 전용 넓은 칸입니다. 96×128 원본 / 288×384 게임 시트로 가져오지 마세요. 게임용 시트와 애니메이션은 아직 만들지 않았습니다. 선택 후 최종 크기와 칸 규격을 정해 Claude가 연결할 별도 제작 카드로 넘겨야 합니다.

## 크기와 화풍

32점 = 1m, 성벽 4m = 128점입니다. 공성추104점(3.25m), 등반 오우거144점(4.50m), 북지기106점(3.31m, 지팡이 포함·몸 약2.7m), 방패지기112점(3.50m)으로 제안했습니다. 두 방향은 같은 높이와 발선으로 정렬했습니다.

고블린은 승인된 K-070 종족 비율판56점입니다. 성벽 비교에 넣은 오우거는 현재 게임의 정지 그림을96점으로 환산한 것으로, 이 카드에서 확정한 세계관 수치가 아닙니다. HTML에는 현재 게임의 고블린 걷기·공격 전체 시트와 오우거 걷기 전체 시트도 내장했습니다. 첫 칸은 각각288×384, 256×384로 읽어 비교 높이에 맞췄습니다.

내장 이미지 생성 도구로 각 시안의 정면·측면을 생성했습니다. 참고는 선택 영웅 원본 `codex_hero_octopath_review_v6/generated.png`, K-066 적 비교판, K-070 고블린입니다. 기존 게임의 오우거·고블린도 읽기 전용으로 확인했습니다. 영웅의 수정본이나 미리보기는 방향 기준으로 쓰지 않았습니다.

생성 원안의 서로 다른 격자와 반투명 가장자리를 그대로 게임 자산으로 취급하지 않았습니다. 원안 알파200 기준 → 각 방향 비율 유지 최근접 축소 → 28색 고정 팔레트 대응 → 발선 배치로 정규화했습니다. 정면 확대는 이 정규화된 그림을 정확히4배 최근접 확대한 것입니다. 올리브 피부·갈색 가죽·목재·어두운 쇠를 중심으로 눈과 입을 남겼습니다. 기존 적과 모든 국소 외곽선·재질의 단계 수가 완전히 같다는 뜻은 아닙니다.

## 읽는 법과 한계

성벽은 높이를 비교하는 눈금용 도식입니다. 실제 전투나 마당을 새로 그린 화면이 아닙니다. 지도0.5배는 가독성을 보기 위한 축소 가정이며 현재 카메라의 실제 배율은 측정하지 않았습니다. 밤의 광선은 어두운 바탕과 따뜻한 색면에 놓은 대비 예시입니다. 실제 광선·안개·그림자·함정 효과를 구현하거나 검증한 것이 아닙니다.

큰 방패는 몸의 일부와 한쪽 발을 가립니다. 북지기는 지팡이·북 때문에 전투 실루엣이 커 보입니다. 이 특성을 선택 시 함께 검토해 주세요. 등반·북 연주·차축 노출 같은 동작은 현재 그림에 애니메이션으로 들어 있지 않습니다.

생성 전 [생성형 픽셀 그림의 격자·색·가장자리 문제](https://www.rangy.ai/blog/ai-pixel-art/)와 [옥토패스 제작진의 픽셀 인물·낮밤 조명 설명](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style)을 읽고, 이번 카드의 금지사항5개를 루트 `CARD_RESULT.md` 첫머리에 작성했습니다.

## 확인

- 네 연구 그림의 칸·높이·중심·발선, 이진 알파, 투명 영역의 불필요한 색 데이터 없음 확인.
- 정면·측면 각각 불투명 영역이8방향 기준 한 연결 덩어리이며, 따로 떠 있는 픽셀 덩어리 없음 확인.
- 네 상세판의 확대 그림이 원본 정면의 정확한 최근접4배인지 화소 비교.
- HTML 내장 PNG 디코딩, 네 상세 시트 열기, 선택 표시, 배율·표시 전환, 스크립트 오류0 확인.
- Chrome 1600×1100에서 네 카드가 한 줄에 표시되고, 390×844에서 페이지 전체 가로 넘침 없음 확인. 그림 상자 안의 가로 이동은 의도한 동작입니다.
- 기존 참조 파일 해시 유지와 추적 파일 변경 없음 확인. Unity 실행·Play·새 게임 캡처·Game 수정·Git 쓰기는 하지 않았습니다.

사용자 선택, 실제 전투 거리에서의 판독성, 최종 크기·규칙·동작·게임 연결은 남아 있습니다.
