# K-134 주인공 걷기 발 수정

옆 걷기 1행의 1번과 3번 프레임에서 화면 오른쪽 장화 끝과 윤곽, 밑창을 3×3 격자로 둥글게 보완했다. 노멀 맵도 같은 위치에서 윤곽을 이동했다. 행과 프레임 번호는 0부터 센다. 원본 게임 파일은 수정하지 않았다.

- 크기: 1152×1536, 4×4 셀, 셀 288×384, 피벗 (144, 360). 모든 프레임의 마지막 불투명 행은 y=359다.
- `walk_r1_f1_before_4x.png` 등은 셀 전체의 4배 최근접 확대 비교 이미지다.

## 셀별 변경 픽셀 수

RGBA 값이 하나라도 달라진 픽셀 수. 행별 값은 프레임 0, 1, 2, 3 순서다. 나머지 셀은 모두 0이며 2행 1·2번의 K-133 수정도 그대로다.

| 시트 | 0행 | 1행 | 2행 | 3행 |
|---|---|---|---|---|
| 색상 | 0, 0, 0, 0 | 0, 405, 0, 405 | 0, 0, 0, 0 | 0, 0, 0, 0 |
| 노멀 | 0, 0, 0, 0 | 0, 504, 0, 459 | 0, 0, 0, 0 | 0, 0, 0, 0 |

## 30px 이상 직선 윤곽 검사

세 색상 원본의 모든 셀을 투명/불투명 경계로 검사했다. 지면 y=359의 평평한 밑창은 제외했다. 좌표는 셀 내부 기준이다.

- 걷기 시트 1행 1번: 오른쪽 x=176, y=315–356, 42px. 잘린 장화, 수정.
- 걷기 시트 1행 3번: 오른쪽 x=173, y=318–350, 33px. 잘린 장화, 수정.
- 걷기 시트 2행 2번: 윗쪽 y=153, x=123–152, 30px; 아래쪽 y=338, x=186–215, 30px. 기존 머리와 기울어진 발의 형태에 속하며 잘린 끝으로 보이지 않아 유지.
- 뒤 대기(1셀)와 명령(3셀): 해당 조건의 추가 경계 없음.

변경 영역은 기존 장화에 연결되며, 새로 떨어진 픽셀은 없다. Unity 실행 및 실제 게임 확인은 하지 않았다.
