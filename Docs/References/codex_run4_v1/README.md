# 아군 달리기 4프레임 재제작 (T-CX-040)

궁수·총병·대포병·마법사를 좌우 달리기 4프레임으로 다시 제작했다. 무릎 들기, 뒤꿈치 접기, 넓은 보폭, 몸의 전경사와 공중 단계를 사용한다. 장비를 든 손은 운반 자세를 유지하고 빈 팔은 흔든다. 오른쪽은 왼쪽 시트 반전이므로 장비 손잡이도 뒤집힌다.

각 시트 RGBA 1024×384, 4열 1행, 칸 256×384, 기준점 (128,352), 1→2→3→4 반복, 기본 8FPS. 전체 포즈에 동일 최근접 축척만 적용한다. 모든 프레임의 원본 지면을 공유해 공중 자세의 발을 바닥으로 억지로 내리지 않는다. 머리만 고정하거나 팔다리를 겹쳐 합성하지 않는다. 마법사 밤색 머리는 D-057 확정 방향을 따른다.

오우거·사다리 고블린은 기존 codex_walk6_v1의 정면 걷기 PNG/JSON/4개 프레임을 그대로 사용하고 기본 6FPS도 유지한다. 기존 걷기 초안은 보관한다.

통합 HTML: _HTML/codex_아군달리기_적걷기4프레임_v2.html. 아군 4종의 개별 달리기 HTML도 같은 폴더에 보관한다. 모든 그림·규격·스크립트를 내장해 더블클릭으로 확인할 수 있다. 전체 재생/정지, 프레임 선택, 속도, 좌우 방향, 이동/제자리, 작은 크기, 배경과 기준점 비교를 지원한다.

사용자 검토용 초안이며 실제 게임 연결과 Unity Play 검증은 수행하지 않았다. 무기 사용·공격·시전 모션은 포함하지 않는다. 포장 검증은 qa.json, 브라우저 검증은 완료 후 아래 추가 기록을 따른다.
