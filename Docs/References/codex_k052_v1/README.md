## 길이·방향·크기

K-048의 포구 중심 (151,170)~포미 (333,205)는 약185px. 새 그림의 포미 (254,215)~포구 중심 (713,158)는 약463px로 약2.50배다. 끝점은 외형에서 수작업으로 판독했다. 생성 원안을 포신·포가로 분리해 포신만 길이를 맞추고, 앞바퀴는 별도로 정규화했다. 기울어진 원통의 시각적 끝점에는 수px 오차가 있을 수 있다.

기존 정지 대포병 높이300px를 K-048의210px에 맞춘 환산은0.7배다. 정면 설치 대포는345×320px→241.5×224px. 정면 왼쪽 바퀴의 가려지지 않은 구간 (610,190,42,162)에서 알파128 초과 경계 높이를 재면144px이며, 환산100.8px를101px로 반올림했다. `reference_wheel_roi.png`는 이 측정 구간이다. 포가 옆모습의 긴 꼬리는 정면 폭과 직접 등치하지 않았다. 포가 폭·무게감·원근의 최종 일치는 검토가 남는다.

견인 방향은 왼쪽, 포가 꼬리는 왼쪽, 포구는 오른쪽이다. [미국 국립공원청 설명](https://home.nps.gov/fosc/learn/education/artcannon.htm)의 운반 시 포가 꼬리와 전차 연결을 근거로 방향을 정했다. 이 시안의 두 병사 인력 운반과 구체적인 손잡이는 게임용 표현이다. 뒤 병사는 바퀴 옆의 화면 앞쪽에서 미는 배치라 포신과 겹친다. 포구 앞을 가로막는 배치는 피했지만 겹침의 가독성은 사용자 확인 대상이다.

## 팔레트와 외곽선

원본은 `cannon_aim3.png`, `Cannon/cannon_recoil.png`, 대포병 정지·달리기·점화 시트다. `wall_cannon_bay.png`, 총병·궁수 정지 시트도 직접 열어 주변 아트와 비교했다.

`palette.json`: 알파250 이상 픽셀에서 RGB를 합쳐 센 전체 상위64색과 빈도. 원본에는 비슷하지만 서로 다른 RGB가 많아 전체 상위색만으로는 피부·흰 테두리·목재가 빠진다. `selected_palette.json`은 재질별 목표색에 가장 가까우면서8회 이상 등장한 **실제 원본 RGB**를 골랐다. 불씨는 출현 횟수 제한 없이 기존 점화 시트에서 골랐다. 임의의 새 RGB를 추가하지 않았다. `used_palette.json`은 저장된 최종 PNG의 실제 사용 색이다.

- 대포9색: #0C0A10, #2B2A35, #3F3F4B, #595660, #8F827D, #4E3627, #754F38, #936341, #B78154.
- 병사14색: #0A0809, #161B2E, #1E2444, #483F46, #2D2124, #562E19, #663921, #804728, #9A5031, #FBBD95, #F7DCB2, #F9B180, #3A3038, #4D424A.
- 불씨3색: #FFFA90, #FBB02A, #E75501. 주황색은 불씨에만 쓰며 대포 팔레트에는 없다.

외곽 깊이 지표는 실루엣 각 수평선 좌우에서 어두운 픽셀(RGB 최댓값48 이하)이 연속되는 길이이다. 폭25px 이하 줄, 0px·15px 이상은 제외했다. 중앙값은 원본 설치 대포4px, 반동3px, 정지·달리기 병사4px, 점화5px. 새 대포2px, 새 병사 세 종류3px다. 정지 원본4px는0.7배에서2.8px이므로 새 병사3px로 정리했다. 대포는 원본0.7배의2.8px보다 약간 가늘게 남았다. 이 지표는 외곽선과 내부 그림자를 구분하지 못하며 두께의 완전한 일치를 뜻하지 않는다. 상세 표본수·사분위는 `outline_measurements.json`.

남색 코트·갈색 멜빵·크림색 테두리·어두운 머리색을 유지하고 큰 세로 눈을 작은 선으로 줄였다. 색상 일치는 픽셀 검사로 확인했지만 머리 비율·얼굴·명암 감성이 같은 사람으로 읽히는지는 사용자 외형 검토가 남는다. 생성 원안은 최종 제한 팔레트를 적용하기 전의 자료이므로 색 검사 대상은 최종 PNG다.

## 보행·점화

원안 열을1,2,6,4,5,3 순서로 포장했다. 발밑 두 줄의 실제 불투명 픽셀 중앙값을 재서 x=128,160,192 / 128,160,192에 정렬했다. y=352 고정, 한 칸당 왼쪽32px 이동이므로 주기 내 접지 세계x는128,128,128 / 32,32,32다. `walk_measurements.json`에 실제 좌표·파지점·외곽을 보관했다. 바퀴 회전각은 −이동거리/50.5라디안이다. HTML과 정적6칸 이미지가 이 회전량을 사용한다. 재생은 연속 보간 없이 이동과 칸을 함께 갱신한다. 고정 시점은 세 주기 후 화면 위치를 초기화한다. 실제 게임의 연속 이동 접지 처리는 구현하지 않았다.

점화 네 번째 칸 불씨 중심(132,132), 병사 배치x=420+269−132=557에서 새 도화선(689,132)에 닿는다. 대포 로컬 접점은(269,132)이며 새 포미에 맞춰 도화선을 연장했다. 0.50초 접촉→1.50초 발사, 접촉 뒤1초 대기. 6칸의 하체 y285~383은 첫 칸과 같은 픽셀로 고정해 발을 옮기지 않는다. 발사 섬광은 검토 페이지의 표시이며 신규 효과 에셋이 아니다.
