K-052 · 사용자 확정 전 시안 · 2026.10.16

대포 끌기, 길이와 재질을 다시 맞추다

포신을 약 2.5배로 늘리고, 기존 대포·대포병에서 직접 추출한 색만 사용했습니다. 앞 병사는 포가 꼬리를 당기고 뒤 병사는 바퀴 옆에서 밉니다. 게임 연결 전 외형·동작 검토 자료입니다.

기존 그림과 비교걷기 6칸불붙이기 6칸팔레트·외곽선K-048 전후규격·남은 확인

01 · 기존 설치 대포·대포병과 나란히

환산 비교: 기존 병사·설치 대포를 함께 0.7배, 새 그림은 1배. 원본 비교: 양쪽 모두 같은 1배. 각 캔버스 안의 배율은 동일하며 페이지 폭에 맞춰 함께 축소됩니다. 실제 Unity 표시 크기를 측정한 결과는 아닙니다.

정면 왼쪽 바퀴의 가려지지 않은 구간 (610,190,42,162)에서 높이 144px → 0.7배에서 101px. 새 앞바퀴도 지름 101px입니다. 포가의 옆모습 꼬리는 투영이 달라 정면 폭과 직접 등치하지 않았습니다.

얼굴·옷·도트 비교: 아래 세 인물은 모두 원본 1배, 같은 발높이입니다. 기존 달리기 시트는 정지 시트와 원본 크기가 다릅니다.

02 · 앞에서 당기고, 뒤에서 밀기

왼쪽으로 견인 ← / 포구는 오른쪽 →. 미국 국립공원청의 포가 꼬리와 전차 연결 설명을 근거로 꼬리를 진행 방향에 두었습니다. 이 시안은 전차·말 대신 인력이 움직이는 게임 표현입니다. 뒤 병사는 포신의 화면 앞쪽, 바퀴 옆에 서서 밀며 포신과 겹쳐 보일 수 있습니다.

한 칸당 왼쪽 32px, 주기당 192px. 같은 발 디딤 3칸의 세계 좌표가 일정하도록 PNG 발밑 픽셀을 정렬했습니다. 바퀴 회전각은 −이동거리 ÷ 50.5. 이동과 그림은 같은 칸 경계에서 갱신하며 연속 보간하지 않습니다. 고정 시점은 세 주기 후 화면 위치를 되돌립니다.

03 · 도화선 접촉 0.50초 → 발사 1.50초

새 도화선 접점은 대포 칸 기준 (269,132). 네 번째 칸의 불씨 중심과 같은 좌표로 맞췄습니다. 0.50초에 접촉, 1초 후인 1.50초에 발사 표시가 켜집니다. 점화 후 병사는 막대를 거두고 발은 352px 선을 유지합니다. 발사 섬광은 검토용 표시이며 게임 효과 에셋이 아닙니다.

04 · 원본 픽셀 팔레트와 외곽선

원본의 알파 250 이상 픽셀에서 RGB 빈도를 집계했습니다. 전체 상위 64색은 제작 자료에 보관하고, 재질별 목표색에 가까우면서 8회 이상 나온 실제 RGB를 최종 팔레트로 골랐습니다. 불씨는 작은 영역이므로 출현 횟수 제한 없이 원본 점화 시트에서 뽑았습니다. 새 PNG의 불투명 픽셀은 해당 팔레트에만 속합니다.

측정법: 알파 128 초과 실루엣의 각 수평선 좌우 끝에서, RGB 최댓값 48 이하인 연속 픽셀 깊이. 폭 25px 이하 줄·0px·15px 이상은 제외. 외곽과 내부 그림자가 섞이는 대용 지표입니다. 원본은 0.7배 표시 시 두께도 0.7배가 되므로 수치 일치만으로 감성이 같다고 판정하지 않습니다.

05 · K-048 전후 비교

두 시안의 병사 높이를 모두 210px로 두었습니다. K-048 포구 중심 (151,170)~포미 (333,205)의 중심선 약 185px → 새 포미 (254,215)~포구 중심 (713,158)의 약 463px, 약 2.50배. 끝점은 외형에서 수작업으로 판독한 좌표입니다. 포신을 길게 만들기 위해 바퀴·병사를 함께 확대하지 않았습니다.

06 · 규격과 사용자 검토 항목

항목시안 규격
대포768×384, 기준점 (336,352), 앞바퀴 중심 (336.5,301.5), 지름 101px. 포신 중심선 약 463px.
병사 3종각 2304×384, 6칸, 한 칸 384×384. 배치 기준점 (192,352). 인물 높이 210px, 점화 불씨는 별도 높이.
보행 발 위치디딤 x: 128→160→192 / 128→160→192. 발밑 y=352. 주기 내 세계 x: 128,128,128 / 32,32,32.
설치 크기 기준기존 정지 병사 300px·정면 대포 345×320px, 환산 0.7배. 정면과 옆모습의 포가 폭·높이는 투영 차이가 있으므로 별도 검토.

확정이 필요한 부분: 기존 그림과 같은 사람·재질로 읽히는지, 긴 포신의 무게감과 포가 꼬리 비례, 바퀴 옆에서 미는 배치의 겹침, 6→1 보행 연결과 손 파지. 외곽선 측정값을 제공했지만 화면상 두께·얼굴·명암 감성의 최종 일치는 사용자 검토가 남아 있습니다.
