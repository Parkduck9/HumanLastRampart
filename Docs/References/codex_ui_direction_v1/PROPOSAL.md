# 성벽의 밤 — 공통 UI 및 4화면 시안 v1 / T-CX-047

작성 Codex / 2026-10-15 / **공통 스타일 사용자 검토 전, Game 구현 전**. 사용자 요청·M-CL-065·D-061에 따른 제안. 게임 진행·경제·카메라를 이 문서로 다시 확정하지 않는다.

## 참고를 우리 게임에 적용하는 방향

[Kingdom Two Crowns 공식 소개](https://kingdomthegame.com/kingdom-two-crowns/)의 간결한 전략·자원 운용과 현대적인 도트 표현을 참고한다. [Octopath Traveler 공식 소개](https://www.square-enix.com/asia/newsportal/en/th/octopath/)의 도트 캐릭터와 입체 공간 표현을 참고한다. 아래 UI 구성은 Codex의 해석·제안이며 원작 화면 복제가 아니다. 이동·카메라는 D-061을 구현하는 Claude 담당이다.

## 공통 스타일 뒤에 검토할 네 화면

1. **메인(0):** 도트 전장 배경과 제목. 새 게임/설정/종료 세 행동, 저장 이어하기 등 미확정 기능 추가 없음. 시안 배경은 코드로 만든 배치 도형이며 최종 게임 배경 아트가 아님.
2. **스토리(5):** 세계가 보이는 배경, 화면 아래 어두운 대사 창. 화자·대사·다음 행동 구분. 기록/건너뛰기는 예시 UI이며 기존 스토리 규칙 확인 후 연결. 부관·대사는 레이아웃용 예시, 신규 인물 설정 확정 아님. 마법사 이미지는 배치용 기존 에셋이다.
3. **결과(4):** 승패와 보상·손실·성벽 상태를 먼저, 상세는 펼침. 정비 진입을 주된 행동으로. 수치는 레이아웃 예시이며 보상 재지급/밸런스 변경 없음.
4. **정비(3):** 골드와 필요한 수리/모집/함정을 세 영역으로. 비용 확인 뒤 확정. 다음 전투는 별도 하단 행동. 함정은 별도 지도 시안으로 연결. 실제 거래·오류·정원·재고·세션 수명 규칙 유지.

공통 스타일 승인 전에 Game UI를 일괄 교체하지 않는다. 승인 후 Codex가 0·3·4·5를 순서대로 적용하고 Claude에게 같은 색·글자·버튼·창 기준을 전달해 전투 HUD를 맞춘다. 이동·카메라·전투 시뮬레이션은 수정하지 않는다.

## 검토 페이지와 검증 범위

`_HTML/codex_공통UI_화면시안_v1.html`은 공통 스타일 탭부터 열린다. 메인·스토리·결과·정비를 탭으로 확인하고 결과 상세/대사 넘기기/정비 이동/함정 링크를 체험한다. 버튼 동작은 시안 안내에 한정, 실제 게임 저장·종료·전투를 실행하지 않는다.

독립 HTML에 그림을 내장. 서버 없는 더블클릭 사용 가능하도록 상대 링크는 _HTML의 형제 함정 지도 파일을 가리킨다. 브라우저 검증 결과는 qa.json에 별도 기록한다. Unity Play·실제 4K 화면·입력장치 검증은 승인 후 수행해야 한다.
