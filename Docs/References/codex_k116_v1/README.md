# K-116 안마당 바닥·소품·계단

실제 62번·57번 캡처를 바탕으로 만든 에셋과 배치 목업입니다. 게임 연결은 Claude가 진행합니다. 바닥은 기존 성벽의 회갈색에 맞추고, 긴 벽돌 줄과 거울 이음새 대신 불규칙한 둥근 돌을 사용했습니다.

## 구성

- `courtyard_cobble_512.png`: 512×512, 양방향 반복. 32픽셀=1m에서 한 장은 16×16m입니다. 36m 마당에는 가로·세로 각각 2.25회 반복합니다. `courtyard_repeat_36m.png`는 이 범위의 평면 점검용입니다.
- `decal_dirt`, `decal_puddle`, `decal_straw`, `decal_cracked`: 흙·물웅덩이·짚·깨진 돌 투명 그림입니다. 중앙을 기준으로 바닥에 놓습니다. 길에는 흙·짚을 듬성듬성 놓고, 물웅덩이는 가장자리의 낮은 곳에 소량 배치합니다. 같은 간격으로 격자 배치하지 않습니다.
- `props_box_atlas_native.png`: 128×128. 상자 6면, 통 윗면·아랫면·옆면을 분리했습니다. 상자는 1m 정육면체입니다. 상자와 통은 입체 메시의 각 면에 대응하는 영역을 사용합니다.
- `barrel_side_100x32.png`: 통 옆면 전용 가로 반복 띠. 지름 약 1m·높이 1m 원통 한 바퀴에 대응합니다. 윗면은 별도 원판에 연결합니다.
- `weapon_rack`, `cart`, `arrow_bundles`: 무기 거치대 정면·수레·화살 묶음의 투명 소품입니다. 각각 원본·정확히 3배 확대한 게임용·4배 검토용을 제공합니다.
- `stair_tread_64x10.png`, `stair_riser_64x6.png`: 계단 윗면·앞면. 가로로만 반복합니다. `stair_step_atlas_64x16.png`에는 두 영역을 세로로 붙였습니다.
- `stair_flank_128x64.png`: 계단 옆 돌벽. 가로로 반복하며 경사진 옆면 메시로 자릅니다. 위쪽 덮개 돌은 좁은 별도 윗면이 필요합니다.
- `mockup_62.png`, `mockup_57.png`: 실제 캡처 위에 바닥·소품·직선 계단을 그린 1920×1080 배치 목업입니다. 납품 텍스처를 Unity에서 렌더한 결과는 아닙니다.

## 면 좌표

좌표 원점은 이미지 왼쪽 위이며 표기는 `x, y, 너비, 높이`입니다. 게임용 아틀라스 좌표는 모두 3배입니다.

| 면 | 원본 좌표 | 실제 크기 |
|---|---|---|
| 상자 앞 | 0, 0, 32, 32 | 1×1m |
| 상자 오른쪽 | 32, 0, 32, 32 | 1×1m |
| 상자 뒤 | 64, 0, 32, 32 | 1×1m |
| 상자 왼쪽 | 96, 0, 32, 32 | 1×1m |
| 상자 위 | 0, 32, 32, 32 | 1×1m |
| 상자 아래 | 32, 32, 32, 32 | 1×1m |
| 통 위 | 64, 32, 32, 32 | 지름 약 1m 원판 |
| 통 아래 | 96, 32, 32, 32 | 지름 약 1m 원판 |
| 통 옆 | 0, 64, 100, 32 | 둘레 약 3.14m×높이 1m |

통 뚜껑의 네 모서리 갈색은 원판 메시 바깥이라 표시하지 않습니다. 통 옆면의 100픽셀은 실제 원둘레를 정수로 반올림한 값으로 오차는 약 0.53%입니다. 아틀라스의 남는 부분은 투명입니다.

## 연결 기준

필터는 Point, 밉맵은 끄고 압축은 사용하지 않는 것을 권장합니다. 바닥과 개별 반복 텍스처는 지정 축만 반복합니다. 전체 아틀라스에는 Clamp를 사용하고 면마다 정확한 UV 영역을 지정합니다. 아틀라스에는 여백이 없으므로 선형 필터·밉맵을 켜면 면 경계가 섞입니다.

원본 그림은 32픽셀/m, 3배 게임용 그림은 96픽셀/m로 연결하면 같은 크기입니다. 바닥·계단의 원본 텍스처에는 캐릭터용 셀 크기를 적용하지 않습니다. 서 있는 소품의 접지선은 원본 높이−2이고, 마지막 불투명 행은 높이−3입니다. 데칼은 바닥 평면용 중앙 피벗입니다. 정확한 크기·영역·피벗은 `manifest.json`에 있습니다.

계단 배치 참고치는 높이 4m, 폭 1.5m, 20단, 단높이 0.2m, 디딤 깊이 0.3m, 총 길이 6m입니다. 옆 난간은 각 디딤면보다 약 0.6m 높게 따라갑니다. 텍스처의 10픽셀·6픽셀은 표현을 위한 정수 규격이며 메시 치수는 위 수치를 사용합니다. 충돌·동선·조명·깊이 정렬은 이 카드에서 구현하지 않았습니다.

## 검토와 확인

한국어 검토 페이지: `_HTML/6_그림_화면/codex_K-116_안마당_v1.html`. 모든 이미지를 내장했으며 서버 없이 열 수 있습니다. 두 실제 캡처의 전후 비교, 36m 반복, 상자 면 회전, 소품 확대, 계단 치수를 제공합니다.

이미지는 내장 생성 도구로 제작한 뒤 크기 정규화, 최소 오차 경계 연결, 32색 팔레트 정리, 투명 테두리 정리를 했습니다. 좌우 반전으로 타일을 만들지 않았습니다. 각 원본의 3배·4배 그림은 최근접 방식으로 확대했습니다. 검사 수치는 `verification.json`, 제작 출처는 `generation.json`에 기록했습니다.

Unity는 실행하지 않았으며 Game 파일도 수정하지 않았습니다. 실제 게임에서의 36m 반복감, 계단 높이와 경로 연결, 낮·밤 조명은 Claude 연결 후 사용자 확인이 필요합니다. 배치 목업의 돌 크기·음영은 실제 납품 텍스처를 정확하게 투영한 값이 아닙니다.
