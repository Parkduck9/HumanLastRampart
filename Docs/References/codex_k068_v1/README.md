# 전장 들판 꾸미기 · 1판

카드 K-068의 그림 납품본입니다. 게임 연결은 Claude가 담당합니다. 기존 Game 파일과 지면 알베도·노멀 맵은 변경하지 않습니다.

- 검토: 저장소 루트의 `_HTML/5_그림_전장/codex_K-068_들판꾸미기_v1.html`. 서버 없이 직접 열 수 있으며 모든 그림이 내장되어 있습니다.
- 자산: `sprites/`의 투명 PNG 31개와 종류별 시트 3개. 개별 그림과 시트 그림은 같은 화소입니다.
- 배치 정보: `manifest.json`. `pixel_rect`, `sheet_rect`는 왼쪽 아래 원점의 화소 단위, `pivot`은 왼쪽 아래 원점의 0~1 정규화 좌표입니다.
- 크기: `size_m`은 폭·깊이·높이의 미터 단위 제안값입니다. 한 지면 칸은 5m입니다. 빌보드는 여백을 포함한 사각형 크기 `billboard_size_m`도 제공합니다.
- 출처: `source/`의 생성 원본, `generation.json`의 공통 지시문·개별 지시문과 원본 경로. 내장 이미지 생성 도구로 각 자산을 별도로 만들었습니다.
- 검증: `verification.json`, `readability.json`. `review/`에는 실제 캡처 기반 합성 목업·식별 비교·길 연결·전체 자산 그림이 있습니다.

## 배치 방법

바닥 데칼은 수평 XZ 지면에 붙입니다. 생성 원본의 낮은 시점 비율을 지면용 비율로 복원했으므로, 가져온 그림을 다시 납작하게 만들지 않습니다. 검토 목업에서는 깊이에 sin(25°)를 한 번 적용합니다. 지면과 아주 조금 띄워 겹침 깜빡임을 피하고, 적보다 먼저 그립니다. 기본 투명도 제안은 0.62입니다.

덤불·풀·무기·방패·표지판과 지형은 화면을 향해 세우며 밑변 중앙이 기준점입니다. 기본 투명도 제안은 0.85입니다. 실제 조명에서 너무 흐리거나 진하면 조절합니다. 키 큰 풀과 덤불은 적 몸통과 겹칠 수 있으므로 주요 접근로 바깥으로 제한합니다. 성벽 병사 화면 폭 약 0.35m 기준과 실제 카메라를 함께 보고 최종 크기를 조절해야 합니다.

길 조각은 5m 정사각형입니다. 직선은 북쪽·남쪽, 곡선은 북쪽·동쪽 연결이며 연결부 4화소를 공유합니다. 90° 단위로 지면 사각형을 회전하여 이어 붙입니다. 포인트 필터·클램프를 권장합니다. 원거리 축소·밉맵·텍스처 압축은 연결 후 실제 카메라에서 확인해야 합니다.

토벽 세 단계와 토벽 잔해는 모두 같은 256×128 캔버스와 5.6×2.8m 빌보드, 밑변 중앙 기준점입니다. 교체 시 같은 위치·스케일을 유지합니다. 토벽의 실제 충돌·엄폐·파괴 상태는 기존 지형 시스템을 따릅니다. 쓰러진 나무와 토벽 잔해는 통과 가능한 시각적 흔적이며 새 장애물 판정을 추가하지 않습니다.

그을음·구덩이는 화재·폭발 위치에서 생성할 그림입니다. 일반 풀밭에 상시 흩뿌리지 않습니다. 기존 지면 질감은 이번 납품에서 교체하지 않아 알베도·노멀 쌍이 유지됩니다.

## 확인 범위와 남은 확인

파일 차원의 투명도·시트 좌표·길 연결 일치와 실제 고블린 프레임을 얹은 정지 합성 비교를 수행합니다. 밝기 차이 지표는 윤곽선의 보조 진단이며 게임 플레이 식별률이 아닙니다. 목업은 캡처의 전경과 적 위치를 고정하고 빈 지면에 새 그림을 합성한 것입니다. 시점별 원근·광원·깊이 정렬·움직이는 고블린의 식별·원거리 흐림은 게임 연결 후 사용자의 실행으로 확인해야 합니다.

재생성 후 정리와 페이지 제작은 `build_review.py`를 실행합니다. 생성 원본과 `generation.json`이 필요하며, Pillow와 Windows 맑은 고딕 글꼴을 사용합니다. Unity는 실행하지 않습니다.
