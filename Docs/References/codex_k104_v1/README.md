# K-104 · 빛의 봉화선 지도

안개로 뒤덮인 대륙 지도와 요새 상태·수비대·빛 경로·빈 UI 프레임을 납품합니다. 게임 연결은 Claude 담당이며 Game/은 수정하지 않았습니다.

- 전체 목업: `beacon_route_mockup_1920x1080.png` — 점화 2곳, 현재 위치인 꺼진 요새 1곳, 미발견 1곳. 수비대 120·86은 표시 예시입니다.
- 배경: `beacon_map_1920x1080.png` — 글자·요새·경로 없는 독립 배경으로 4~6곳 배치 가능.
- 요새: `fortress_{fogged,dead,lit}_{64,96}.png`, `fortress_states_{64,96}_sheet.png`. 시트 순서는 미발견 → 발견·꺼짐 → 점화.
- 수비대: `garrison_shield_32.png`와 `garrison_count_frame_112x40.png`. 배지의 숫자 안전 영역은 좌상단 기준 `(42,8,62,24)`입니다. 실제 숫자는 별도로 표시합니다.
- 경로: `light_route_dim_96x24.png`, `light_route_lit_96x24.png`, `light_travels_6f_96x24_sheet.png`. 이동 시트는 576×24, 96×24 셀 6개, 왼쪽부터 120밀리초 간격으로 반복합니다. 먼저 프레임을 자르고 가로 반복하며 진행 방향에 맞게 회전합니다. 점 간격 16픽셀, 타일 길이 96픽셀입니다.
- 추가 표시: `current_fortress_ring_128.png`, `route_arrow_32x24.png`.
- UI: `beacon_title_frame_640x96.png`, `beacon_button_frame_340x52.png`. 글자 없는 프레임이며 9분할 테두리는 Unity 좌·하·우·상 순서로 모두 16픽셀입니다. 제목 안전 영역 `(32,20,576,56)`, 버튼 안전 영역 `(24,12,292,28)`. 프레임의 중앙 채움도 함께 늘립니다.
- `previews/`: 소형 에셋 17종의 최근접 4배 확대본. 배경과 전체 목업은 원본 크기로 검토합니다.

## 기준과 사용 방법

K-096 수리 화면의 어두운 청록·황동·양피지 색감을 따릅니다. 버튼과 제목은 기존 K-096 기본 원본을 9분할하여 각각 340×52·640×96으로 조정했습니다. K-091-v2는 K-096에 보존된 자료를 참고했으며, 현행 게임의 `TrapMap/castle_perimeter.png`를 읽기 전용 비교 자료로 검토 페이지에 표시했습니다. 봉화선 전용 기존 게임 시트는 없습니다.

픽셀 좌표는 좌상단 원점입니다. 요새 셀의 공통 바닥 경계는 64픽셀 셀에서 y=58, 96픽셀 셀에서 y=90이며, 마지막 불투명 픽셀은 각각 y=57·89입니다. 셀 중심 x=32·48을 유지합니다. 요새 피벗은 좌상단 좌표 `(32,58)`·`(48,90)`, Unity 하단 원점 정규화 값은 `(0.5,6/64)`·`(0.5,6/96)`입니다. 나머지는 중앙 피벗을 사용합니다. 상세 크기·순서·9분할 값은 `manifest.json`을 따릅니다.

인물이 없는 지도 UI이므로 D-081의 인물 셀 96×128, 발 y=120, 3배 게임 시트 규칙은 적용하지 않습니다. 64·96픽셀 마커는 각각 사용할 수 있는 UI 납품 크기이며, 확대본은 검토용입니다. 소형 PNG는 Point/무압축, 지도 배경은 Bilinear를 권장합니다. 정적 경로는 가로 Repeat·세로 Clamp, 나머지는 Clamp입니다. 애니메이션 아틀라스 전체를 바로 Repeat하지 않습니다.

생성 도구는 내장 image_gen입니다. 원안과 프롬프트는 `source/`, `PROMPTS.md`에 보관했습니다. 마커는 동일 폭으로 분할한 뒤 최근접 축소하고, 알파 40 미만과 주 연결 성분 밖의 고립 픽셀을 제거했습니다. 바닥을 고정한 후 64·96픽셀 시트로 묶었습니다. 경로·방패·고리는 단순 픽셀 도형이며, 목업은 납품 에셋과 한국어 문구를 합성했습니다. 배경 생성 원안 1672×941은 1920×1080으로 리샘플했습니다.

## 검토 페이지와 검증

`../../../_HTML/6_그림_화면/codex_K-104_봉화선지도_v1.html`을 직접 엽니다. 모든 이미지를 내장했으며 서버가 필요 없습니다. 6프레임 재생·일시 정지·프레임 선택과 현재 게임 지도 아트·K-096 시안의 나란한 비교가 있습니다. 동작 줄이기 설정에서는 자동 재생을 멈춥니다.

크기·RGBA·마커 기준선·고립 픽셀·경로 타일 간격·프레임 차이·4배 확대본을 검사하며 결과는 `validation.json`에 기록합니다. 브라우저 로드 및 재생 확인은 `browser_verification.json`에 따로 기록합니다. Game/ 변경, Unity 임포트·Play, 실제 게임 캡처는 수행하지 않았습니다.

실제 화면 전환, 수비대 숫자, 텍스트, 버튼 상태, 경로 회전·반복, 현재 위치 고리는 Claude의 연결 작업이 남아 있습니다. 기획의 지원금·수비대 비율 같은 제안 수치는 이 에셋 카드에서 확정하지 않습니다.
