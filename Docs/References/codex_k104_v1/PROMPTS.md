# K-104 이미지 생성 프롬프트

내장 image_gen을 사용했습니다. 아래는 제출한 영문 프롬프트의 한국어 기록입니다. 원안은 `source/`에 보존했습니다. UI 프레임은 기존 K-096 에셋을 재사용했고 단순 도형은 픽셀 좌표로 제작했습니다.

## 지도 배경

넓은 16:9 게임 배경 한 장, 목표 1920×1080. 중세 방어 게임의 어두운 안개 대륙을 낡은 양피지와 잉크 지도로 표현. 검은 청록 바다, 흐린 올리브 회색 육지, 드문 산맥과 작은 숲, 가는 낡은 황동 테두리. 의도적인 굵은 픽셀 묶음과 절제된 음영. 대륙은 왼쪽 아래에서 오른쪽 위로 이어지며 중앙에 요새 4~6곳을 나중에 얹을 넓은 공간 확보. 정규화 위치 (0.19,0.65), (0.40,0.46), (0.62,0.60), (0.82,0.34) 부근은 조용하게 유지. 가장자리, 특히 오른쪽 위에서 안개가 밀려듦. 위 18%, 아래 16%는 UI를 위한 어두운 여백. 글자·숫자·요새·경로·빛·패널·버튼·범례 없음.

## 요새 상태 시트

투명 배경, 같은 크기의 정사각 셀 세 개를 가로 한 줄에 배치한 단일 스프라이트 시트. 같은 작은 중세 봉화 요새의 세 상태. 왼쪽은 짙은 푸른 회색 안개에 덮인 미발견 실루엣, 가운데는 발견했으나 꺼진 회색 석조 요새와 비어 있는 봉화대, 오른쪽은 동일한 요새에 황금빛 불꽃·따뜻한 창문·작은 후광. 셀마다 같은 바닥과 같은 크기, 여유 있는 투명 여백. 64픽셀로 축소해도 읽히는 굵은 픽셀 아트, 짙은 외곽선, 간단한 3단계 돌 음영, 황동과 검은 청록 팔레트. 글자·숫자·셀 테두리 없음. 요새끼리 연결하지 않음. 실제 알파 투명도 사용.
