# 하겐 부관 초상 · K-108

루멘을 보좌하는 45~50세 노련한 군인입니다. 짧은 회색 머리, 흰 수염, 눈가 주름과 흉터, 낡은 청회색 야전 장비와 작은 등불 배지로 젊은 동료들과 구분했습니다.

- 주 전달 파일: `portrait_hagen_neutral.png`, `portrait_hagen_determined.png`, `portrait_hagen_alarmed.png`, `portrait_hagen_tired.png`.
- 기존 스토리 초상과 같은 **256×384**, 투명 배경, 4배 도트, 발끝 마지막 행 **y=351**, 발 피벗 **(128,352)**입니다. 기존 게임 파일은 수정하지 않았습니다.
- 표정 순서: 평상 → 결의 → 경계 → 피로. 스토리 시트는 `hagen_expressions_story_256x384.png`입니다.
- 공통 규칙 보조 시트: `hagen_expressions_native_96x128.png`는 96×128 칸 4개, 피벗 (48,120). `hagen_expressions_game_288x384.png`는 이를 최근접 3배 확대, 피벗 (144,360)입니다. 스토리 연결에는 위의 개별 256×384 파일을 사용합니다.
- 도트 인물 키는 원본에서 74점으로 약 73점 기준에 맞췄습니다. 별도 4배 미리보기는 파일명 끝 `_4x.png`로 구분합니다.
- `comparison_hagen_wizard_archer.png`: 하겐 → 기존 마법사 → 기존 궁수, 각각 동일한 256×384 칸에 원래 배치 그대로 나란히 놓았습니다.
- 검토 페이지: 저장소 루트 `_HTML/6_그림_화면/codex_K-108_부관하겐초상_v1.html`. 그림을 모두 내장하여 서버 없이 열립니다. 표정 자동 전환과 밝은/어두운 배경 비교를 제공합니다.

제작에는 기본 이미지 생성 도구를 사용했습니다. 생성 원본의 알파는 `sources/`에 그대로 보관했습니다. 전달 파일은 최근접 샘플링, 알파 128 기준 이진화, 중심과 발 정렬을 거쳤습니다. 표정별 옷과 손의 세부 도트는 완전히 동일하지 않으므로 전환 모습도 검토해야 합니다. `generation.json`에 생성 지시를, `build.ps1`과 `review.cjs`에 재현 절차를 보관했습니다.

`validation.json`에는 실제 PNG의 크기, 불투명 경계, 부분 알파 수, 연결 성분을 기록했습니다. Unity 실행·Play·게임 내 캡처 확인은 수행하지 않았습니다. 연결과 사용자 외형 승인은 후속 작업입니다.
