# K-138 앞뒤 걷기 다리 검토

**미완료:** 새 다리 그림은 채택하지 않았습니다. 생성 시안이 상체와 옆걸음까지 변경하여 원본 보존 조건을 충족하지 못했습니다. 앞·뒤 걷기의 8칸 모두 기존 대기 자세 다리를 그대로 둔 대체본입니다. 두 PNG는 게임 원본과 바이트 단위로 동일하며 노멀맵도 변경하지 않았습니다.

`comparison.png`는 위가 뒷모습, 아래가 앞모습이며 왼쪽부터 흰머리 참고 / 현재 / 대체본입니다. 각 칸을 2배로 표시합니다. 대체본은 현재와 같습니다.
