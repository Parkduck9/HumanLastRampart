# K-090 · 분대 명령 원형 UI

어두운 목재와 황동 테두리로 만든 원형 명령 바퀴입니다. 기존 명령 메뉴의 목재 띠, 숫자 배지와 금색 붓선을 기준으로 제작했습니다. 게임 파일은 수정하지 않았습니다.

## 검토

- `../../../_HTML/6_그림_화면/codex_K-090_분대명령원형_v1.html`을 브라우저로 직접 엽니다. 이미지와 코드를 모두 내장했습니다.
- 방향과 병력 바퀴가 기본·강조 상태를 자동으로 순환합니다. 포인터를 올리거나 사용 불가 비교를 켤 수 있습니다.
- 지도에서 Shift + 왼쪽 끌기 → 놓기 또는 왼쪽 누르기로 두 흐름을 시험합니다. 이 데모에서는 실제 성벽 판정·병력 계산·명령 전송을 하지 않습니다.
- 전체 합성본 6장: 지도와 밤 화면 각각 상자 선택 → 방향, 병력 선택, 이어서 방향 선택입니다. 모두 1920 × 1080입니다.

## 연결 기준

- 이미지 좌표는 왼쪽 위 기준입니다. Unity 정규화 피벗은 모두 `(0.5, 0.5)`입니다. 방향 바퀴 중심 `(111,111)`, 병력 바퀴 중심 `(180,180)`에 맞춰 각 조각을 겹칩니다.
- 인원 중심 영역은 빈 허브입니다. `40명`은 합성 예시이며, 실제 값은 런타임 글자로 표시합니다. 허브 안 안전 영역은 `(79,96,64,30)`입니다.
- 병력 문구는 `1분대 보내기`, `1/2 보내기`, `전체 보내기`입니다. 24점 굵은 한글로 표시했습니다. 실제 글꼴은 게임에서 확정된 글꼴을 사용합니다. 숫자 배지와 금색 밑줄은 기존 `HudArt/Command/command_number_1..3`, `command_underline`을 재사용합니다.
- 방향 영역은 위 북, 오른쪽 동, 아래 남, 왼쪽 서입니다. 중앙과 조각 사이 틈에는 명령을 연결하지 않습니다. 픽셀 알파 또는 manifest의 각도·반지름으로 판정할 수 있습니다.
- 사용 불가 조각에는 낮춘 채도와 짧은 빗금이 들어 있습니다. 해당 방향의 화살표를 숨기고 글자를 어둡게 표시하며 입력도 막습니다. 빈 선택·인원 부족 등 적용 조건은 게임에서 처리합니다.
- 병력 선택 후 같은 커서 기준점에서 병력 바퀴를 내리고 방향 바퀴를 띄웁니다. 가장자리에서는 화면 안쪽으로 옮깁니다. 선택 결과 유지·닫기 입력 등 최종 동작은 Claude 연결 범위입니다.
- 9분할 테두리는 전부 0입니다. 원형 조각과 모서리를 늘이지 않습니다. 선택 상자는 고정 모서리 4개와 가로·세로 점선 반복으로 조립합니다. 점선은 황동 15점 + 빈칸 9점의 주기입니다.
- 선택 고리 중심을 깃대 접지점에 맞춥니다. 예시 `icon_one`의 접지 좌표는 `(12,42)`이며, 고리의 왼쪽 위는 깃발 왼쪽 위 기준 `(-24,27)`입니다.
- Unity 가져오기 권장값: Sprite / Point / 압축 없음 / 밉맵 없음 / 알파 투명 / Full Rect / PPU 100. 새 게임 에셋과 `.meta` 생성은 Claude가 담당합니다.

## 제작과 출처

`wood_source.png`는 내장 이미지 생성 도구로 만든 평면 목재 재질입니다. 생성 지시: 거의 검은 따뜻한 목재, 절제된 가로 나뭇결, 큼직한 픽셀, 세 단계 명암, 테두리·글자·장식 없음. 이후 원형 마스크, 세 단계 팔레트, 황동 테두리와 상태를 규칙적으로 가공했습니다. 한글은 Windows 맑은 고딕 굵게를 비트맵으로 만들었으며 글꼴 파일은 포함하지 않았습니다.

지도 합성의 배경은 `Docs/References/codex_k020_v1/reference_map.png`에 보관된 **예전 게임 지도 캡처**입니다. 최신 화면으로 표시하지 않았습니다. 밤 합성은 지정된 `Docs/References/night_levels_20261020.png`의 오른쪽 위 0.35 비교 화면입니다. 새 분대 깃발과 메뉴는 합성한 예시이며, 실제 게임 캡처가 아닙니다.

`build.ps1`로 그림을, `package.ps1`로 manifest와 내장형 HTML을 다시 만듭니다. 원본 폴더 구조와 `wood_source.png`가 필요합니다. `verify.ps1`은 크기·알파·3배 확대·상태 마스크·연결 영역과 HTML 내장 그림을 검사합니다.

## 검증 범위

검사 결과와 제한은 `verification.json` 및 루트 `CARD_RESULT.md`에 기록했습니다. Unity를 열거나 실행하지 않았습니다. 게임에서의 입력·가림·실제 인원 표시·기능 연결은 아직 확인하지 않았습니다.
