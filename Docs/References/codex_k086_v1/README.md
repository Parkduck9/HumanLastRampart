# K-086 대포 점화 후면 원안 · 규격 확인 대기

**완료된 교체 시트가 아니다.** 내장 이미지 생성 도구로 K-075와 같은 대포병의 후면 6프레임 원안을 만들었다. 남색 코트·크림색 테두리·갈색 교차 멜빵·큰 장화를 유지하고, 오른쪽 병사가 왼쪽으로 횃불을 내리는 동작을 만들었다. 생성 원안은 `source/ignite_back_generated.png`이다. 생성 프롬프트는 후면 고정, 여섯 칸 가로 배치, 대기 → 왼쪽 접근 → 내리기 → 왼쪽 접촉 → 거두기 → 대기, 투명 배경, K-075 정체성과 선택된 주인공 첫 생성본의 도트 방향을 지정했다. 생성 도구 1회, 외부 API·Python 이미지 편집 없음.

[한국어 검토 페이지](../../../_HTML/4_그림_캐릭터/codex_K-086_대포불붙이기다시_v1.html)는 이미지와 재생 코드를 내장했다. 현재 게임 시트와 후면 원안, 설치 대포 합성의 여섯 칸을 재생·정지·앞뒤 전환할 수 있다. 붉은 사각형은 기존 96×128 칸, 금색 십자는 미확정 접점 후보다. 서버가 필요 없다.

## 먼저 해결할 규격 충돌

인물 73px를 0.35m로 환산하면 208.5714px/m이다. 점화병이 대포 중심 오른쪽 0.30m에 있을 때 간격은 62.5714px이다. 대포 중앙의 포신 상단에 불을 붙이려면 기존 칸 좌표에서 횃불 끝은 **x=48−62.5714=−14.5714px**가 된다. 게임 시트에서는 −43.7143px이다. 96px 칸·중심 x=48·같은 인물 크기·0.30m 간격·중앙 도화선 접촉을 동시에 지킬 수 없다. 단순히 불씨를 왼쪽 가장자리로 옮겨도 14.6px가 모자란다.

검토 제안은 왼쪽에 48px 여백을 추가한 144×128 칸, 발 피벗 (96,120)이다. 3배 게임 규격은 432×384, 발 피벗 (288,360)이다. 인물 크기와 세계 좌표의 발 위치는 유지한다. **사용자 승인 전이므로 native/·game/ 최종 교체 시트를 만들지 않았다.** 기존 96/288 규격에 맞는 것처럼 잘라서 인계하지 않는다.

## 산출물과 합성 좌표

- `previews/ignite_back_proof.png`: 144×128 검토 칸 여섯 개, 전체 864×128. 4배 확대는 `_4x.png`이다. 최종 교체용이 아니다.
- `previews/composite6.png`: 설치형 대포 첫 칸과 점화병 여섯 칸 합성, 한 칸 288×160, 전체 1728×160. 4배 확대는 `_4x.png`이다.
- `source/cannon_reference_4x.png`: 설치 대포 첫 칸의 확대 참고본. 원본 수정 없음.
- `manifest.json`: 칸별 횃불 끝의 실수 좌표, 기존 칸 환산 좌표, 필요한 게임 좌표, 규격 충돌과 미확정 항목.
- `validation.json`·`review_validation.json`: 수행한 검사와 한계.
- `build.ps1`·`build_review.ps1`·`verify_review.cjs`: 원안 정리·페이지 생성·페이지 모형 검사. 빌드는 K-075의 읽기 전용 PixelTools.cs를 사용한다.

대포 원본은 `Game/Assets/_Project/Art/Battle/Resources/BattleArt/Cannon/cannon_recoil.png`의 첫 256×256 칸이다. 원본 기준점은 (128,240), 보이는 폭 234px이다. 합성에서 이 폭을 0.40m = 83.4286px로 축소하고, 대포 기준점을 (128,120)에 두었다. 점화병 발은 실수 좌표 x=190.5714를 정수 x=191로 반올림했다. 약 0.43px 차이다. 보조병은 합성에 넣지 않았다.

**원본에서 별도의 도화선·구멍을 확정할 수 없었다.** 검토본은 포신 후방 상단 중앙에 불씨를 겹친다. manifest의 `fuse_candidate_source` 약 (128,100.43)은 네 번째 칸의 불씨 높이를 대포 원본 좌표로 역산한 **검토 후보**이다. 실제 도화선 위치를 독립적으로 측정한 값이 아니다. 접촉 확정이나 실제 게임 검증으로 사용하면 안 된다. 대포에 가짜 도화선을 추가하지 않았다.

현재 작업 폴더의 `BattlePropView.CannonScale=1.5`, `BattleSim.CannonShooterOffset=0.4`, `CannonCrewOffset=0.55`는 브리프의 폭 0.40m·오른쪽 0.30m·왼쪽 0.45m와 다르다. 이번 합성은 브리프 수치를 따른다. Claude가 연결할 때 수치를 확인해야 한다.

## 수행한 확인과 남은 작업

PNG를 실제 디코딩해 크기, 여섯 칸, 이진 알파, 모든 칸 밑면의 배타 경계 y=120, 3px 미만 고립 성분이 없음을 확인했다. 최종 원안과 합성 확대본을 직접 열어 후면·왼쪽 횃불 방향을 확인했다. 검토 페이지 내장 PNG의 원본 바이트·스크립트 문법·여섯 칸 이동·순환·재생·정지·속도·안내선 전환은 Node VM 모형으로 확인했다. 실제 브라우저 배치·실시간 재생, Unity·Play·게임 캡처는 수행하지 않았다.

승인 후 남은 작업은 최종 칸 규격 확정, 실제 도화선 확정에 따른 끝점 보정, 접촉 칸의 작은 불꽃 강조, 인물 중심과 보폭 및 6→1 연결 정리, 원본·정확한 3배 게임 시트 제작과 픽셀 일치 검사다. 규격 변경을 승인하지 않는다면 병사 간격이나 도화선 위치를 함께 조정해야 한다. Game/·기존 문서·live 기록·기존 HTML·목록·Git은 수정하지 않았다.
