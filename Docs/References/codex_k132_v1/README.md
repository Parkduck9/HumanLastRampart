# K-132 · 스토어 그림 제목 변경

[변경 전후 검토 페이지](../../../_HTML/6_그림_화면/codex_K-132_스토어그림_제목변경_v1.html)는 그림을 내장하므로 서버 없이 열 수 있습니다. 포스터·표지·가로 타일·시작 그림과 변경 없는 가로 전경·앱 타일을 비교합니다.

한글 제목을 **빛을 잇는 자**로 바꿨습니다. 다섯 음절 **빛 · 을 · 잇 · 는 · 자**와 영문 **LIGHTBEARERS**를 확인했습니다. 기존 글자 픽셀의 모양·크기·색을 그대로 사용하고 마지막 음절을 빼서 가운데로 옮겼습니다. 지운 글자 아래 배경은 같은 행의 가까운 배경 픽셀로 복원했습니다. 따라서 제목 사각형 안에서는 배경 픽셀도 일부 바뀝니다.

`store/`는 K-131의 일곱 파일, `msix/`는 K-130의 18개 파일과 이름·크기가 같습니다. 가로 타일과 시작 그림 두 배율만 한글 제목이 있어 수정했습니다. 다른 패키지 로고는 등실 그림이며 글자가 없어 원본 그대로입니다. 가로 전경 두 크기와 앱 타일도 원본 파일과 바이트 단위로 같습니다. `previews/`에는 포스터·표지의 논리 원본 기준 4배와 가로 타일·시작 그림의 4배를 담았습니다.

## 픽셀 검사

아래의 변경 픽셀 수는 각 원본과 비교한 RGBA 픽셀 수입니다. 제목 영역은 기존 제목을 둘러싼 사각형이며 좌상단 포함, 우하단 제외입니다. 모든 수정 파일의 제목 영역 밖 차이는 **0픽셀**, 알파 차이도 **0픽셀**입니다. 수정하지 않은 17개 파일은 원본과 SHA-256이 같습니다.

25개 파일의 크기와 알파를 원본과 비교했고 원본의 색상 프로필 관련 PNG 정보를 보존했습니다. 제목은 모두 상단 2/3 안에 있습니다. 제목색과 제목 사각형의 모든 비제목 픽셀을 비교한 보수적 최소 명도 대비는 포스터 **16.52:1**, 표지 **14.51:1**, 가로 타일과 시작 그림 **15.84:1**로 4.5:1 이상입니다. 상세 크기·영역·차이·대비는 `manifest.json`에 있습니다.

검토 페이지에 내장된 12개 PNG를 디코딩해 확인했습니다. 브라우저에서 실제 화면을 열어 보는 검사는 수행하지 못했습니다. 정지 이미지이므로 움직임 프레임과 발 기준선은 해당하지 않습니다. Unity 실행, 게임 연결, 스토어 등록과 Git 쓰기는 하지 않았습니다.
