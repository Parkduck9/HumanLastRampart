# K-111 · 사용자 의견 수정

하겐의 입, 밤 화로·검은 안개, 이야기 배경 두 장을 수정했습니다. 기존 K-103·K-105·K-108 원본은 보존하고 이 폴더에 수정본만 납품합니다. 게임 연결·커밋은 Claude 담당입니다.

검토 화면: `_HTML/6_그림_화면/codex_K-111_사용자의견수정_v1.html`. 그림을 내장하여 서버 없이 직접 열 수 있습니다. 기존 카드 그림, 현재 게임 그림, 실제 게임 캡처는 구분해서 표시합니다.

## 하겐

- 평상·결의·경계·피로 순서로 닫힌 입, 굳게 다문 입, 벌어진 입, 처진 입을 넣었습니다. 생성 원안의 입 화소만 옮겨 원본의 머리·눈·장비·자세·투명 영역을 보존했습니다.
- `portrait_hagen_*.png`: 기존과 같은 256×384, 발 피벗 (128,352). `hagen_expressions_story_256x384.png`: 4칸 가로 시트입니다.
- `hagen_expressions_native_96x128.png`: 96×128 셀 4칸, 발 피벗 (48,120). `hagen_expressions_game_288x384.png`: 정확한 최근접 3배, 발 피벗 (144,360). 발의 마지막 불투명 행은 각각 y=119 / y=359입니다.
- 초상은 기존 스토리 규격을 그대로 사용하며, 전투용 동작을 새로 만들지 않았습니다. 검토 화면의 표정 자동 전환은 네 정지 표정 비교입니다.

## 화로와 검은 안개

- `native/glow_low.png`, `glow_normal.png`, `glow_high.png`: 192×192 정지 광원. 중심 (96,96), 반경 36 / 46 / 56화소, 최대 알파 40 / 64 / 88. 4단계 감쇠와 완전 투명 외곽으로 넓은 번짐을 줄였습니다. `game/`은 최근접 3배 576×576입니다.
- 기존 K-103의 화로 본체와 불꽃 6프레임은 변경하지 않았습니다. 광원만 교체합니다. 화로의 원본 (48,72), 게임판 (144,216)에 광원 중심을 맞추고 `SrcAlpha One`으로 합성합니다. 밝은 바닥·벽 면과 가려지는 그림자는 별도 조명/가림 처리가 필요합니다. 광원 그림 자체가 실시간 그림자를 만들지는 않습니다.
- `native/fog_band.png`: 512×128, 어두운 띠는 y=36~63 안에만 존재하며 나머지는 투명합니다. 가로 양 끝 화소를 맞췄습니다. `game/fog_band.png`: 1536×384. 일반 알파 합성, 가로 반복·세로 고정입니다.
- **기존 넓은 안개·코너·잔안개를 함께 쌓지 마세요.** 이번 얇은 띠만 먼 전장 경계에 놓습니다. 45m 안쪽에 띠나 감쇠 영역이 들어오지 않도록 Claude가 배치해야 합니다. 이 카드에는 새 코너·잔안개가 없습니다.
- `mockup_north_wall_high_1920x1080.png`: 지정된 실제 캡처 `beacon_game_20261022/05_pf_night_clean.png`를 그대로 바탕으로 색을 조정했습니다. 병사·성벽·평지 구도를 유지하고 화로 두 개와 바닥 그림자를 합성했습니다. 원래 캡처의 원거리 폭발·횃불은 남아 있습니다. 검은 안개는 화면 맨 위 먼 경계의 얇은 띠뿐입니다. 게임 실행 결과가 아닌 합성 목업입니다.

## 이야기 배경

- `story_dead_beacon_1920x1080.png`: 해 질 녘, 꺼진 등불. `story_relit_beacon_1920x1080.png`: 같은 요새의 야간 점화.
- 실제 전투 캡처의 회청색 석재·낮은 사각 여장과 실제 지도 화면의 네 성벽·넓은 안마당을 참고해 다시 그렸습니다. 절벽 위 성채와 높은 성탑을 없애고 평지의 사각 요새로 바꿨습니다. 지도 화면은 배치 참고이며, 이야기 그림은 요새 전체가 보이도록 뒤로 물러선 시점입니다.
- 사람은 멀리 있는 실루엣뿐입니다. 얼굴과 주인공 복장을 묘사하지 않았습니다. 아래 1/3, y=720~1079는 낮은 대비의 어두운 바닥으로 비워 대사창을 배치할 수 있습니다.
- 두 배경은 불투명 RGBA 정지 그림입니다. 캐릭터 발 기준선은 적용하지 않습니다. 점화 전후 자동 비교는 게임 동작 시트가 아닙니다.

## 제작·검증·인계

내장 이미지 생성 도구를 사용했습니다. 전체 프롬프트는 `prompts.json`, 생성 원본은 `sources/`에 있습니다. `build.ps1`은 생성 원안에서 입 화소 추출·광원 알파 정리·안개 정리·합성·최근접 확대를 수행하는 제작 보조 파일입니다. `previews/`는 납품 이미지의 정확한 최근접 4배 미리보기입니다.

`manifest.json`에 파일별 크기·프레임·피벗·합성 조건과 대체 원본을 기록합니다. `validation.json`과 `review_validation.json`에는 실제 수행한 검사 결과만 남깁니다. Unity 임포트·Play·실시간 그림자·45m 배치·실제 게임에서의 가독성 검증은 수행하지 않았습니다.

최종 이미지 검사 **96/96항목 통과**: 입 바깥 화소·알파·발 위치 보존, 정확한 최근접 3배·4배, 투명 영역, 잔점, 안개 이음새, 배경 불투명도와 대사 영역 명암을 확인했습니다. 실제 Edge에서 파일로 직접 열어 내장 그림 25개·CSS 배경 16개 로드, 반복 미리보기 5개, 점화 전후 전환·정지·대사 영역 표시, 390화소 작은 화면 가로 넘침 없음, 자바스크립트 오류 없음을 확인했습니다. 검토 화면 캡처는 `review_desktop.png`, `review_mobile.png`, `review_night.png`입니다.

Game/, 협업 문서·로그, 기존 HTML은 수정하지 않습니다. 기존 안개를 끄고 새 띠를 배치하는 작업, 광원 연결과 실제 화면 확인은 Claude 인계 항목입니다.
