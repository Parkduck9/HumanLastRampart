# 캐릭터 6종 도트 외형 v2

- 작성자: Codex
- 상태: 6종 생성·HTML 확인 완료, 사용자 외형 검토 대기
- 사용자 요청: 6종 외형 제작, 도트 느낌, HTML 비교, 애니메이션 제외.
- 대상: 오우거·사다리 고블린·궁수·총병·대포병·마법사.
- 제작 기준: 정면 단일 포즈, 승인 플레이어처럼 약 2.2등신(머리45%·몸/다리55%), 작은 논리 픽셀 격자를 확대한 느낌, 선명한 계단형 외곽선, 제한된 색과 단계 명암. 부드러운 번짐·광채·회전 방향·동작 프레임은 넣지 않는다.
- PNG 생성 원본을 보관한다. HTML 확대 배율은 표시 설정이며 실제 게임 내 크기나 네이티브 픽셀 규격을 확정하지 않는다.
- 기존 승인 플레이어·곤봉 고블린과 이전 외형 시안은 수정하지 않는다.
- Game 반영·애니메이션 제작은 이 작업에 포함하지 않는다.

## 사용자 추가 방향

전투 캐릭터의 기준 레퍼런스는 승인된 플레이어 도트 스프라이트다. 사용자 “2.2등신 주인공처럼 … 전투에서는 그렇게” 지시로 6종도 머리가 크고 몸·팔다리가 짧은 약2.2등신으로 맞춘다. 오우거는 등신 비율을 맞추되 몸 폭과 전투 크기는 별도다. 이전 길쭉한 생성본은 이번 HTML에 쓰지 않는다.

## 결과와 확인

오우거·사다리 고블린·궁수·총병·대포병·마법사 투명 PNG 각1장과 preview.html을 보관했다. 승인 주인공을 참조해 도트 경계가 뚜렷한 짧은 머리/몸 비율로 생성했다. 이미지 전체몸·장비와 픽셀 표현 육안확인, PNG6개 투명도/내용/경계검사 통과. 실제 생성파일 크기와 해시는 png_analysis.json, 프롬프트는 prompts.json이다. 고해상도 확대 원본이며 정확한 네이티브 픽셀 격자를 확정한 파일은 아니다.

브라우저 이미지6/6 로드, 주인공참조표시, 밝은배경/작은크기 선택, 오류로그0 확인. 좁은304px 창의 가로넘침을 수정하고 document scrollWidth=clientWidth=304 확인. 정적화면이며 타이머/애니메이션루프 없음. 기존시안과현재Game에적용된그림은미변경.
