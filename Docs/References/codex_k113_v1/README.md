## 기준과 제작 방식

- 전투 구도: `../beacon_game_20261022/05_pf_night_clean.png`
- 지도 구도: `../beacon_game_20261022/07_pf_map_full.png`
- 분위기만 참고: 원본 작업 폴더의 `beacon_refs/alanwake_3.jpg`, `alanwake_7.jpg`, `octopath_5.jpg`
- 설계: `../../GDD/Concept_Beacon_v1.md`의 빛 세기 3요소
- 내장 이미지 생성 도구로 실제 화면을 바탕으로 덧그렸습니다. 넓게 시안은 중앙 조명을 낮추고 변색을 유지하도록 한 차례 추가 보정했습니다. 최종 크기 정리와 4배 확대에는 최근접 보간을 사용했습니다. 생성 지시문은 `manifest.json`에 기록했습니다.

전체를 회색 안개로 덮지 않고 어두운 바깥과 따뜻한 빛을 구분했습니다. 지도는 얇은 금색 경계와 부채꼴 채움으로 읽도록 했습니다. 번짐·광택·장식 광선과 흐린 얼굴을 피했습니다.

## 해석할 때 주의할 점

이 자료는 게임에 연결된 결과가 아닌 **조명 연출 참고 그림**입니다. 원본 구도를 따르지만 생성 과정에서 일부 병사·지도 표식·기존 글자와 위치가 다시 그려졌습니다. 지도 UI를 구현 자료나 정확한 좌표 원본으로 사용하지 않습니다.

30°·60°·90°와 2배·1배·0.67배는 설계값입니다. 그림의 밝기는 물리 조도 계측값이 아니며 전투 화면은 원근이 있습니다. 밝기 비교의 약한 쪽은 감쇠 때문에 보이는 밝은 면적도 작지만, 의도한 모으기는 양쪽 모두 60°입니다. 변색 해제의 실제 임계값은 게임 연결 단계에서 조정해야 합니다.

`Game/` 수정, Unity 실행, Git 쓰기를 수행하지 않았습니다. 정적 파일·그림 검증 결과는 `validation.json`, 검토 페이지 확인 결과는 `review_validation.json`을 참고합니다.
