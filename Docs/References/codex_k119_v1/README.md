# K-119 · 등대 일꾼 걷기와 계단

K-110의 A(갈색 앞치마·검은 콧수염), B(올리브색 앞치마·회색 수염) 외형을 기준으로 제작한 에셋입니다. 현재 게임의 작업자 세 명은 A·B·B 배정이므로 별도 C 외형은 만들지 않았습니다.

- 걷기: 8프레임, 앞·뒤·왼쪽·오른쪽.
- 계단 오르기와 내려오기: 각각 6프레임, 뒤·왼쪽·오른쪽.
- 화로 관리: 6프레임, 앞·왼쪽·오른쪽. 작은 철제 기름통을 들고 기울였다가 내립니다.
- 기름통 운반: 8프레임, 앞·뒤·왼쪽·오른쪽.

총 34개 시트, 원본 236프레임입니다. 각 시트는 원본·게임용·4배 미리보기로 제공합니다. 좌향 시트는 우향을 x=48 기준으로 반전해 별도로 저장했으며, 빛 방향도 함께 반전됩니다.

원본 칸은 96×128, 발 피벗은 (48,120)입니다. 게임용은 정확히 3배 최근접 확대하여 칸 288×384, 피벗 (144,360)입니다. 정규 피벗은 (0.5,0.0625)입니다. 마지막 발 픽셀은 원본 y=120, 게임용 y=360~362이며, 기존 K-110의 기준과 같습니다. 몸통의 허리 부근 중앙을 x=48에 맞췄습니다. 동작에 필요한 무릎·어깨·머리 변화는 남겼습니다.

모든 시트는 한 줄에 왼쪽부터 재생합니다. 세부 순서·속도·피벗·반전 원본은 `manifest.json`을 읽습니다. 걷기·계단·운반은 초당 8장, 화로 관리는 초당 6장입니다. 화로 관리 한 사이클은 기름통 잡기 → 들어 올리기 → 기울이기 → 붓기 → 세우기 → 내리기입니다. 계단에서 실제 위치와 높이 변화는 게임이 처리합니다.

`native/`는 원본, `game/`은 연결용, `previews/`는 4배 확대입니다. `source/`는 내장 이미지 생성 도구의 원안이며 최종 시트로 사용하지 않습니다. `prompts.json`에 생성 지시문을 보관했습니다. `build.cjs`는 원안 행 추출·알파 정리·K-110 팔레트 대응·정렬·시트 생성을, `build_review.cjs`는 그림을 내장한 검토 HTML 생성을 담당합니다. 게임 코드는 포함하지 않습니다.

검토 페이지는 저장소의 `_HTML/6_그림_화면/codex_K-119_일꾼걷기_v1.html`입니다. 서버 없이 직접 열 수 있고, 새 동작마다 현재 게임의 밀기 시트를 나란히 보여 줍니다. 모든 방향의 재생·정지·한 프레임 이동·외형/동작 선택을 지원합니다. 실제 등대 캡처는 참고용 원본이며 새 시트를 합성한 화면은 아닙니다.

원안의 알파 200 미만 가장자리를 지우고, 각 프레임의 가장 큰 연결 덩어리만 남겼습니다. 원본은 0/255 알파이며 색은 각 K-110 밀기 시트에 실제 존재하는 색으로 대응했습니다. `extraction.json`에는 원안 행과 배율을, `verification.json`에는 프레임별 범위·발 기준선·연결 덩어리·중복 여부를 기록합니다.

얼굴·의상은 원본을 참고한 새 방향 그림입니다. 원본 얼굴 픽셀을 그대로 보존한 그림은 아니므로 최종 외형과 동작 연결은 사용자 검토가 필요합니다. 유니티 열기·임포트·플레이·실제 화면 검증은 수행하지 않았습니다. 기존 게임 에셋은 수정하지 않았습니다.
