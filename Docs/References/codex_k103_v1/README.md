# K-103 · 성벽 화로와 검은 안개

성벽 위에 놓는 낮고 넓은 화로, 밝기 약·보통·강의 불꽃, 외곽 안개, 등불 밝기 HUD를 제작했습니다. **에셋과 합성 목업만 전달하며 게임 연결은 Claude 담당입니다.**

검토 화면은 저장소 루트의 `_HTML/6_그림_화면/codex_K-103_성벽화로와안개_v1.html`입니다. 서버 없이 직접 열 수 있으며 필요한 그림을 모두 내장했습니다. 불꽃과 잔안개 반복, 재생·정지, 밤 배경, HUD 선택 상태를 확인할 수 있습니다. 기존 게임 횃불 받침·불꽃을 신규 화로 옆에 표시했습니다. 외곽 안개와 밝기 조절기는 신규 요소이므로 같은 기능의 기존 교체 시트는 없습니다.

## 화로와 불꽃 연결

- 원본 셀 **96×128**, 게임 셀 **288×384**입니다. 모든 프레임은 왼쪽부터 읽습니다. 밝기별 6프레임, 초당 8프레임으로 반복합니다.
- 받침의 바닥 화소는 원본 **y=120**, 중심 **x=48**입니다. 게임판 기준점은 **(144,360)**입니다. 명세의 좌표는 이미지 왼쪽 위 원점이며 Unity의 정규화 피벗은 **(0.5, 0.0625)**입니다.
- 꺼진 받침의 폭은 48화소, 높이는 44화소입니다. 강 불꽃을 포함하면 약 80화소입니다. 사람 73화소 기준으로 받침은 낮고 불꽃은 머리 위로 올라오는 크기이며, 실제 카메라 배치는 연결 후 확인합니다.
- 완성된 `brazier_*` 반복 시트를 사용하거나, 꺼진 화로에 `flame_*`를 같은 셀 위치로 겹칩니다. **완성 화로와 분리 불꽃을 동시에 겹치면 불꽃이 중복됩니다.** 받침은 한 원본으로 고정하여 프레임마다 위치와 형태가 흔들리지 않습니다.
- 광원 원본은 192×192, 게임판은 576×576입니다. 광원 중심을 화로 원본 **(48,72)**, 게임판 **(144,216)**에 맞춥니다. `SrcAlpha One` 가산 합성용이며 알파를 밝기로 사용합니다. 주변 불빛을 표현하는 별도 스프라이트이므로 화로 시트에는 부드러운 후광을 넣지 않았습니다.
- 화로·아이콘은 점 필터를 사용하고, 광원은 부드러운 필터를 사용할 수 있습니다. 3배 게임판 파일의 화소 확대는 모두 최근접입니다.

## 외곽 안개 연결

- 환경용 안개 띠는 **512×128 → 1536×384**, 코너는 **128×128 → 384×384**입니다. 캐릭터용 셀과 구분하는 별도 환경 규격이며 명세에 기록했습니다.
- 띠 위쪽은 어두운 전장 밖, 아래쪽은 투명한 전장 안쪽입니다. 좌우 끝 화소가 정확히 같아 가로로 이어 붙일 수 있습니다. 가로만 반복하고 세로는 고정합니다. 밉맵을 끄거나 아틀라스 바깥 화소를 확장하여 이음새 유입을 막습니다.
- 북서 코너의 오른쪽 경계는 띠의 시작 경계와 같고, 아래 경계는 같은 띠를 회전한 경계와 같습니다. 북동·남동·남서는 각각 시계 방향 90·180·270도 회전으로 연결합니다.
- 잔안개는 원본 셀 **96×128**, 게임 셀 **288×384**, 4프레임, 초당 2프레임입니다. 피벗은 원본 (48,64), 게임판 (144,192)입니다. 띠 위에 일반 알파로 겹치며 느리게 이동시키는 용도입니다.
- **안개 띠의 투명해지는 구간과 잔안개 전체까지 성벽에서 45m 바깥에 배치해야 합니다.** 이 에셋은 거리 마스크나 가림 로직을 구현하지 않습니다. 내부 45m에는 안개 도형을 놓지 않는 조건을 Claude가 월드 좌표로 적용해야 합니다.
- 밤 밝기 0.65를 적용한 목업에서 자흑색 경계를 확인했습니다. 내부 적 보존 그림은 배치 원리 예시이며, 그 그림의 픽셀 거리가 실제 45m를 뜻하지는 않습니다. 실제 노출·정렬 순서·거리 조건은 Unity 연결 뒤 확인해야 합니다.

## HUD 연결

- 기존 HUD 체력 테두리의 황동·먹색 팔레트를 재사용했습니다. 등불은 작은 불꽃·중간 불꽃·큰 불꽃과 1·2·3개 표식으로 구분합니다. 작은 표식은 48화소 아이콘에서 더 잘 보입니다.
- `lamp_frame_9slice.png`는 **32×32**, 9분할 경계는 **좌·하·우·상 각각 8화소**입니다. 테두리를 통째로 늘리지 말고 9분할로 배치합니다.
- `lamp_toggle_low/normal/high.png`는 각각 **288×80**이며 선택된 단계만 밝은 황동 테두리로 표시합니다. 세 파일은 시각 상태이며 입력·전투 규칙 코드는 포함하지 않습니다.
- 게임에서 사용할 글자는 `약 / 보통 / 강`입니다. 사거리·적 수·보상 수치는 기획 확정과 측정 범위이므로 이미지에 고정하지 않았습니다.

## 제작 및 확인

기본 제공 이미지 생성 도구로 화로·안개·등불 원화를 만들었습니다. `prompts.json`에 전체 프롬프트를 보관했습니다. 원화에서 불필요한 후광과 작은 점을 정리하고, 고정 받침 합성·프레임 정렬·최근접 확대·안개 주기 경계 보정을 적용했습니다. `build.py`는 포함된 `sources/`를 읽어 납품 이미지를 다시 구성하는 제작 보조 파일이며 게임 코드가 아닙니다.

이미지 검사 220항목이 통과했습니다. RGBA 크기, 투명 영역, 정확한 최근접 3배 확대, 화로 전체 프레임의 바닥·중심·받침 고정, 한 화소짜리 잔점 부재, 잘린 경계 부재, 광원의 부드러운 알파와 투명 가장자리, 안개 가로 이음새·코너 연결·내부 투명 영역을 검사했습니다. 원본 4배 화로와 HUD 및 목업을 눈으로 확인했습니다.

실제 브라우저에서 서버 없이 파일을 열어 내장 이미지와 배경 이미지 로드, 모든 반복 애니메이션, 정지, HUD 3단계 선택을 확인했습니다. 1440화소 데스크톱과 390화소 작은 화면을 캡처했으며 작은 화면 가로 넘침과 자바스크립트 오류가 없었습니다.

**Unity 실행·임포트·Play·실제 캡처·45m 거리 적용 검증은 수행하지 않았습니다.** `Game/`, 공용 문서, 협업 기록, 기존 HTML은 수정하지 않았고 Git 쓰기도 하지 않았습니다. 연결과 커밋은 Claude에게 인계합니다.
