# T-CX-095 설치 에셋 CLI 재검증

2026-10-21. 현재 사용 가능한 Unity MCP 도구와 프로젝트 MCP 패키지가 없어 Unity 6000.3.25f1 CLI로 실행했다. 실제 Editor 프로세스가 없고 Hub만 실행 중임을 확인했다.

- ExpandedIgnitePlacementTests: 6/6 통과. 확장·구형·없는 시트, 생성·이동 및 4면 배치 검사.
- PlayProbe.InstalledIgniteContactSixFrames: 1/1 통과. 검토용 메모리 텍스처 교체 없이 실제 UnitDef 점화 시트와 대포 그리기 텍스처를 그대로 검사한다.
- Boot → 메인 → 쉬움 → 스토리 → 전투 준비를 실제 실행하고, 점화 6칸을 강제로 선택해 촬영했다. A/B/C에서 불꽃 범위가 도화선 고리·심지 끝을 포함하는지 검사했다. 사진 8장을 저장하고 A/B/C 4번 접촉 사진에서 불꽃이 표시되는 것을 직접 확인했다.
- 게임 PNG 두 개는 검토본과 SHA256 동일. 기존 GUID 유지.
- 두 실행 종료 코드 0. 로그 시작 단계에 라이선스 토큰 갱신 경고가 있으나 시험 실행 및 XML 저장은 정상 완료됐다.

이번은 배치·설치·촬영 대상 시험이며 전체 기능 시험, 자연스러운 실시간 자동 사격 주기, 대규모 성능 시험을 다시 완료했다는 뜻은 아니다. 대규모 성능 시험 정원 초과 한계는 이전 기록 그대로다. 게임 동작 코드는 이번에 바꾸지 않았고 검증용 PlayProbe만 확장했다. Git 쓰기 없음.
