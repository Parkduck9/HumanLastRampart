## 노멀맵 견본

`normals/gunner_normal.png`, `cannon_crew_normal.png`, `wizard_normal.png` **각 1장만** 제작했다. 기존 총병·대포병·밤색 마법사 후면 **정적** 색 그림에 대응하며 새 동작 19칸의 노멀맵은 아니다. 같은 폴더의 `*_albedo.png`는 기존 색 그림의 바이트 동일 복사본이다.

- 모두 256×384, RGB 탄젠트 공간 +Y, 초록 = 위. 원안의 배경 XY 중간값을 중심으로 맞추고 세기 0.45로 약하게 정규화했다. B는 양의 반구로 복원한다.
- 색 그림 alpha≤32 영역 RGB는 정확히 (128,128,255). 노멀 PNG는 불투명 RGB이며 실루엣은 색 그림 알파를 사용한다.
- 원안 캔버스 전체를 최근접으로 맞추고 원래 색 마스크로 제한했다. **내부 머리·주름·손·장비 표면 대응은 근사**다. 3D 모델 베이크가 아니다.
- HTML의 방향·높이·평면 비교는 CPU 램버트 근사다. URP·횃불·좌우 반전·모서리 카메라의 실제 조명 검증은 남아 있다.

이번 카드의 사용자 지시로 견본 3장만 예외 제작했다. 기존 주인공·궁수 노멀 견본의 확정 여부를 추정하지 않았고 다른 방향·동작·병종으로 확대하지 않았다.

## 원본·재포장

내장 `image_gen.imagegen`으로 8종 원안을 생성하고 주인공 손짓만 1회 보완했다. 정확한 프롬프트는 `generation.json`, 도구가 저장한 PNG 원본은 `source/`에 보존했다. 선택한 주인공은 `source/hero_command.png`이며 `hero_command_initial.png`는 팔이 수평으로 길게 펼쳐져 기준점이 흔들리는 **미채택 초안**이다. `references/`는 읽기 전용 원래 그림의 복사본이다. `manifest.json`은 원본 경로·SHA256·축척·칸별 원본/포장 영역을 기록한다.

`build.py`와 `components.py`는 그림을 다시 그리지 않고 원안에서 분리된 연결 실루엣을 추출해 각 칸에 넣는다. 분할선을 따라 옆 포즈의 조각이 섞이던 포장 문제를 연결 영역 분리로 해결했다. 원안의 반투명 광채·가장자리(alpha≤128)를 비우고 남은 알파는 255로 정리했다. 전체 포즈에 같은 축척과 최근접 보간만 사용하며 머리·팔·다리를 따로 움직이거나 합성하지 않는다.

최하단을 y352에 맞춘다. 시전·명령은 아래 12화소의 발 중심을 x128에 맞추고, 쓰러짐은 포즈 가로 중심으로 맞춘다. 쓰러진 몸과 장비를 256폭에 넣기 위해 첫 포즈 높이가 궁수 254px·총병 222px·대포병 261px로 기존 정적 그림보다 작아졌다. **칸 규격 일치와 체격·도트 밀도 일치는 별도 확인 대상**이다. 사용자가 체격 유지를 우선하면 무릎을 더 접은 쓰러짐 원안 또는 넓은 사망 전용 칸을 검토해야 한다. 넓은 칸·새 인터페이스를 이번 카드에서 확정하지 않았다.

마법사는 들어 올린 지팡이까지 칸에 담기 위해 상단 여백을 사용한다. 동작 전체의 축척은 일정하다. 주인공 보완본은 두 발과 몸을 유지하고 오른팔을 머리 옆에서 위로 펼친다.

재포장 환경: Python + Pillow + NumPy, 모아보기 글꼴은 Windows 맑은 고딕을 로컬에서 읽는다(글꼴 파일 배포 없음).

```powershell
python Docs/References/codex_k023_v1/build.py
python Docs/References/codex_k023_v1/verify.py
node Docs/References/codex_k023_v1/verify_runtime.js
```

실제 이번 실행에는 Codex 런타임의 Python·Node 절대 경로를 사용했다. build는 기존 원안에서 재포장하며 이미지 생성 API를 다시 호출하지 않는다.

## 검토 방법과 검증 범위

HTML에서 동작 선택 → 처음부터 재생 → 마지막 칸 유지, 이전·다음·칸 직접 선택, 초당 4/6/8/10칸, 절반·원래·2배, 밝은/어두운 배경, 기준점 표시를 비교한다. 노멀 3종은 원본 색·방향색·간이 조명을 나란히 표시한다. 기본 6칸/초는 검토용 제안이다.

- `qa.json`: 파일·RGBA·시트 복원·고유 포즈·바닥·잘림·원본 해시·노멀 단위벡터·빈 영역 평면·내장 이미지 해독 등 **94개 통과**.
- `qa_runtime.json`: Node VM과 DOM 모형에서 선택 5종·수동 칸·끝 정지·재시작·배율·배경·노멀 비교 실행 등 **51개 통과**. 실제 브라우저 시험과 구분한다.
- 생성 원안 8종·보완 주인공·최종 모아보기·노멀 출력은 도구로 열어 육안 검토했다. 최종 모아보기에서 포즈 조각 혼입 제거와 후면 지팡이 상승·명령 손짓을 확인했다.
- 실제 브라우저는 cua 목록이 앱·브라우저 모두 빈 결과여서 **미검증**. file 주소 직접 실행·실제 화면 넘침·브라우저 콘솔을 확인했다고 기록하지 않는다.
- Unity 열기·실행·임포트·게임 연결·실제 성벽 크기/가림 캡처는 **미수행**. Git 쓰기·협업 live·기존 HTML 목록 수정 없음.
