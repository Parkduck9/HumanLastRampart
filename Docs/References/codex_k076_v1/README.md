# K-076 마법사 동작 1판

사용자가 고른 주인공 6판 첫 생성본과 K-065 마법사의 정체성을 기준으로 제작했다. 크기는 D-081 확정값을 따른다. 밤색 머리, 파란 눈과 흰 반사점, 보라색 금테 로브, 갈색 큰 장화, 푸른 보석 지팡이를 유지했다.

## 납품 파일

| 파일 | 프레임 | 왼쪽부터 순서 |
|---|---:|---|
| `wizard_static.png` | 1 | 정면 대기 |
| `wizard_back_static.png` | 1 | 후면 대기 |
| `wizard_cast.png` | 4 | 지팡이 들기 → 빛 모으기 → 방출 → 정리 |
| `wizard_walk.png` | 4 | 오른발 착지 → 왼발 통과 → 왼발 착지 → 오른발 통과 |

이 폴더 바로 아래의 네 시트는 게임용이다. 대기는 288×384, 시전·걷기는 1152×384이며 칸은 모두 288×384다. `native/`에는 동일 파일명의 원본 시트가 있다. 원본 대기는 96×128, 시전·걷기는 384×128이다. `*_4x.png`는 원본 시트의 최근접 4배 확대다.

원본 인물 키는 약 73점이며 머리 외곽선까지 포함하면 약간의 차이가 있다. 기준 중심 x=48, 발바닥 아래 경계 y=120이다. 불투명한 최하단 행은 119다. 게임용은 정확한 최근접 3배이며 피벗은 좌상단 기준 (144,360), Unity 정규화 피벗은 (0.5,0.0625)다. 이동은 오른쪽 방향이며 프레임 자체에 가로 이동을 넣지 않았다.

검토 페이지: [`마법사 동작 검토`](../../../_HTML/4_그림_캐릭터/codex_K-076_마법사동작_v1.html). 서버 없이 직접 열 수 있으며 이미지·스크립트·스타일을 모두 내장했다. 기존 게임 시트와 같은 발선에서 비교하고 재생·정지·프레임 이동·속도 조절을 할 수 있다. 기존 걷기 시트는 없어서 해당 비교 칸에 이를 표시했다.

## 제작 방식과 생성 지시

내장 image_gen 도구를 사용했다. 첫 생성은 5열×2행의 투명 동작 원안을 요청했고, 두 번째 생성은 후면 시전 정리 자세의 지팡이를 오른쪽으로 되돌리고 걷기 반대 착지의 다리 겹침을 바꾸도록 수정했다. 최종 생성 원안은 `master_generated.png`다.

생성 지시의 주요 내용: K-065 마법사 앞뒤 그림으로 인물 정체성을 유지하고, K-070 궁수의 약73점 비율과 주인공 `generated.png`의 큰 머리·또렷한 파란 눈·굵은 외곽선·짧고 튼튼한 몸·재질별 약3단 명암을 적용한다. 모자 없이 밤색 머리, 보라색 금테 짧은 로브, 갈색 장화, 푸른 보석 지팡이를 그린다. 정면·후면 대기 각1장, 후면 시전4장, 오른쪽 옆 걷기4장을 같은 인물 크기와 발선으로 배치한다. 투명 배경에 글자·격자·바닥 그림자·번짐 없이 도트로 표현한다. 시전 순서는 들기·모으기·방출·정리다. 걷기는 착지·통과·반대 착지·통과이며 서로 다른 다리 겹침을 보인다.

`build.ps1`은 생성 원안의 최근접 표본화, 27색 팔레트 대응, 알파 0/255 정리, 연결되지 않은 잔점 제거, 발선 정렬과 확대·검토 페이지 생성을 수행한다. 머리 중심을 기준으로 위치를 맞추며 자세 자체의 팔·로브·다리 변화는 유지한다. 형태 제작과 수정은 이미지 도구로 수행했다.

## 확인 결과와 연결 시 남은 일

- 10프레임 모두 발바닥 아래 경계 y=120, 투명 여백, 이진 알파, 프레임별 연결 영역1개를 검사했다.
- 게임용 PNG가 원본의 정확한 최근접3배인지 모든 픽셀을 대조했다.
- 검토 HTML 내장 PNG 11개를 디코딩했다. 모의 DOM에서 동작 이미지7개 읽기와 프레임 범위·재생·정지·단계 이동을 검사했다.
- 최종 4배 시트는 직접 열어 육안으로 확인했다. 연결 가능한 브라우저가 없어 실제 브라우저 렌더링 검증은 수행하지 않았다.
- 기존 게임 PNG3장의 SHA-256이 보존됐음을 확인했다. `Game/` 수정, Unity 실행, Git 쓰기는 하지 않았다.

Claude가 게임용 PNG를 `Art/Characters/Static/`에 연결하고 칸 크기를288×384로 읽도록 조정해야 한다. 기존 노멀맵의 새 실루엣 대응, 실제 시전 타이밍·걷기 방향 반전·전투 화면 크기·Unity Play 확인은 연결 담당의 후속 작업이다. 새 노멀맵과 Unity 메타 파일은 이 카드에 포함하지 않는다. `validation.json`, `review_validation.json`, `measurements.json`, `manifest.json`에 수치와 검사 범위를 기록했다.
