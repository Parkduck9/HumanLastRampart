## 설계 반영

- 메인: 5장에 따라 크림 판을 제거했습니다. K-083 `main_menu_keyart.png`를 재사용합니다. K-083 로고는 영문이므로 한글 표시 지시를 우선해 현재 캡처의 “인류의 마지막 성벽”을 황동 양각 글자로 조판했습니다. **K-083 로고 그림을 사용한 완성안은 아닙니다.**
- 스토리: 4.2·4.3·4.4와 5장에 따라 두 재질을 비교합니다. 고정 3점 테두리와 모서리, 24×24점 반복 중심 무늬를 사용하며 늘이지 않습니다. K-071 `archer_neutral_64x96.png`를 1:1로 합성합니다. 배경 인물과 겹치지 않게 왼쪽으로 옮겼습니다. 대사는 현재 캡처의 두 문장을 그대로 사용합니다.
- 결과: 보고서 면적은 61.87%입니다. 승리 봉랍 지름은 192px로 현재 캡처를 1080p로 환산한 약 90px의 두 배 수준입니다. “잃은 병사 −1”을 옆에 크게 배치했습니다. 네 면은 방향·색·숫자로 구분하고 병종 아이콘과 잔여 막대를 유지했습니다. K-071 주인공·마법사의 상반신을 원본 크기로 잘라 표시합니다.
- 결과 수치는 현재 캡처의 대포 운용병 31/32, 궁수 160, 총병 60, 처치 120, 골드 +60, 주인공 100/100, 마법사 60/60을 따릅니다. 성벽 최대 체력 1000과 북쪽 950은 캡처의 북 −50을 수치로 설명하기 위한 **예시**입니다.

## 점 격자와 글꼴

전체 화면을 640×360에서 합성한 다음 최근접 3배로 출력합니다. 배경은 최근접 축소 → 중앙값 분할 256색 이하 변환 → 정수 확대 순서입니다. K-083 배경과 기존 `ScreenArt/main.png`, `victory.png`를 읽기만 했습니다. 새 생성 도구 호출은 없으며 기존 그림과 절차적 재질을 합성했습니다.

오프라인 저장소와 Windows 글꼴에서 갈무리·Neo둥근모·둥근모를 찾지 못했습니다. **맑은 고딕 Bold**를 원본 격자에 이진 렌더링했습니다. 글꼴 파일은 배포하지 않습니다. 원본 22 / 15 / 11px 세 단계가 화면 66 / 45 / 33px가 됩니다. 스토리 본문 33px, 이름표 45px, 줄 간격 51px입니다. 1.5배인 49.5px를 3px 격자에 맞춰 약 1.55배로 반올림했습니다.

이 처리로 모든 출력 점은 3×3px이지만, 생성 그림 내부의 묘사 밀도와 수작업 도트의 일관성까지 보장하지는 않습니다.

## 대비 측정과 확인

`contrast.tsv`는 각 글자를 찍기 직전 실제 바탕 픽셀과 글자색의 sRGB 상대 휘도를 계산한 최소값입니다. 식은 `(밝은 휘도 + 0.05) / (어두운 휘도 + 0.05)`입니다. 제목의 어두운 외곽선은 글자 바탕에 포함했습니다.

| 글자 종류 | 측정 최소 대비 |
|---|---:|
| 종이 대사·보고 수치 | 6.409:1 |
| 나무 위 밝은 글 | 10.321:1 |
| 황동 출정 단추 | 7.070:1 |
| 제목 양각 글 | 7.940:1 |
| 승리 도장 | 8.736:1 |
| 메인 보조 메뉴 | 15.717:1 |

4.5:1 기준을 넘습니다. 이는 목업 글자의 측정이며 실제 게임 연결 후의 대비 측정을 대체하지 않습니다. 현재 캡처와 비교 이미지의 설명 띠는 목업 격자 검사 대상에서 제외합니다.

`image_validation.json`은 기대 화면 4장의 크기·알파·3px 격자·최소 대비 결과입니다. `review_validation.json`은 Chrome 헤드리스에서 내장 이미지 로드, 펼치기, 원래 크기 보기, 390px 화면의 가로 넘침과 자바스크립트 오류를 확인한 결과입니다. `review_desktop.png`, `review_mobile.png`는 검토 페이지 캡처입니다.

## 아쉬운 점과 남은 선택

- 스토리 재질은 종이 / 나무 중 사용자가 선택해야 합니다.
- 전용 한글 도트 글꼴과 한글 제목 그림이 미확정입니다. 양각 조판은 전용 로고 아트보다 개성이 부족합니다.
- K-071 초상은 같은 점 배율을 지키면서 기존 화면보다 작아졌습니다. 큰 인물이 필요하면 원본 자체가 더 큰 새 초상이 필요합니다.
- 재질은 검토용 절차적 무늬입니다. 실제 9칸 분할 에셋과 Unity 연결은 포함하지 않습니다.
- 승리 상태만 제작했습니다. 패배·입력·전환·해상도 대응은 미검증입니다.
- 정지 목업에는 동작 프레임·발선·피벗이 적용되지 않습니다. 전체 합성 알파는 255이며 인물 에셋의 발선 검증을 수행했다고 기록하지 않습니다. 육안으로 고립된 합성 잔여 점은 보이지 않으나 생성 배경의 모든 작은 점을 잡티로 자동 분류하지는 않았습니다.
- Unity 실행·Play·게임 코드 변경·Git 쓰기는 하지 않았습니다. 게임 연결과 커밋은 Claude 담당입니다.
