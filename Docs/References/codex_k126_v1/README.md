# K-126 성벽 부서짐 에셋 · 1판

원본 성벽의 따뜻한 회색 석재를 기준으로 정상 → 균열 → 반파 → 파공을 구분하는 에셋입니다. 게임 코드·기존 재질·씬은 수정하지 않았습니다.

- `native/`: 원본 PNG 35개. 여장 4종과 묶음 시트, 외벽 데칼·파공 마스크·테두리·경계 띠 5종, 외부/보행로 각각 소·중·대 × 3변형 잔해 18종, 먼지·불꽃·연기 각 6프레임, 외벽 4단계 합성 예시.
- `game/`: 원본을 최근접 3배 확대한 PNG 35개.
- `previews/`: 원본을 최근접 4배 확대한 PNG 35개.
- `mockups/`: 실제 야간 성벽 위·안뜰 내려다보기 캡처에 얹은 단계별 시안과 네 단계 가로 비교판.
- `manifest.json`: 셀 크기, 피벗, 프레임 순서·속도, 단계, 배치 위치, 실제 참조 경로.
- `generated_atlas.png`: 생성 원본 제작 자료. 게임 연결에는 정리된 PNG를 사용합니다.
- `build_assets.ps1`, `build_review.ps1`, `build_page.cjs`: 제작·합성·검토 페이지 재현 스크립트. 실행 순서는 기재된 순서이며 마지막은 Node로 실행합니다.
- `verify_assets.ps1`, `verification.txt`: 크기·알파·배율·접지·고립 픽셀·반복 경계 검증과 결과.

검토 페이지는 저장소 루트의 `_HTML/6_그림_화면/codex_K-126_성벽부서짐_v1.html`입니다. 이미지와 애니메이션을 모두 내장해 서버 없이 직접 열 수 있습니다.

## 크기와 접지

소품 원본 셀은 96×128, 접지 경계는 y=120, 몸 중심은 x=48입니다. 정적 여장·잔해와 불꽃·연기의 마지막 불투명 행은 119입니다. 먼지는 전환 후 의도적으로 상승·확산합니다. 게임판 셀은 288×384, 피벗은 (144,360)입니다. 좌표는 좌상단 기준이며 Unity 정규화 피벗은 (0.5, 0.0625)입니다.

외벽 데칼·마스크는 원본 128×128 = 4×4m, 게임판 384×384입니다. 경계 띠는 32×128 = 1×4m, 게임판 96×384입니다. 인물 셀 규약은 높이 4m인 외벽 데칼에는 적용하지 않습니다. 원본은 32 PPU, 게임판은 96 PPU를 써야 월드 크기가 같습니다.

## 파공과 반복

`wall_stage1_cracks`와 `wall_stage2_gouges`는 좌우 경계가 완전 투명해 가로 반복할 수 있습니다. 석재 결은 기존 벽 재질이 담당하며 데칼은 손상 정보만 겹칩니다. 1단계의 작은 돌 균열은 아래 잔해와 함께 사용합니다.

`wall_stage3_cut_mask`는 흰색·불투명 영역이 제거 영역입니다. 이 마스크로 기존 벽의 가시 영역을 실제로 제거한 뒤 같은 원점에 `wall_stage3_breach_rim`을 놓습니다. 투명 그림만 기존 3D 박스 위에 붙이면 구멍 뒤에 벽이 남습니다. `wall_stage3_edge_strip`은 별도 깨진 경계 조각입니다. 파공은 단일 손상 구간용이며 가로로 반복하지 않습니다. 파공 안쪽 바닥과 옆면·충돌 변경은 Claude의 연결 작업입니다.

## 효과와 단계 연결

먼지는 좌→우 6프레임, 10fps 1회 재생입니다. 불꽃·연기는 각각 6프레임, 8fps 반복입니다. 불꽃 중심과 연기 밑동은 같은 피벗을 유지하고 윗부분만 변형됩니다. 블룸·후광 없이 작은 불씨와 좁은 연기 실루엣으로 제한했습니다.

기존 HP 66%·33% 경계는 그대로 두었습니다. 제4 파공 상태의 발동 기준은 이 카드에서 새로 결정하지 않았습니다. `manifest.json`의 단계 번호는 에셋 분류이며 전투 규칙 API가 아닙니다.

가져오기는 Point, 압축 없음, 밉맵 없음, 알파 보존을 기준으로 합니다. 이미 색이 들어 있으므로 색 곱셈은 실제 장면 조명에 맞추는 범위에서만 사용합니다. 새 normal map은 제작하지 않았습니다. 외벽의 기존 normal을 그대로 둘 경우 빠진 돌의 깊이가 광원에 따라 어긋날 수 있어 연결 후 확인해야 합니다.

## 실제 화면과 지도 대조

야간 성벽 위는 `tower_20261023/238_tower_tall_night_4_beam_field_from_wall.png`, 안뜰은 `courtyard_20261023/02_bldg_day_1_topdown.png`를 사용했습니다. W35 안뜰 교차로 캡처도 읽어 색과 카메라 맥락을 확인했습니다. 목업은 실제 캡처의 국소 합성이며 Unity 실행 결과가 아닙니다. 야간 여장은 원래 들판 패치로 기존 실루엣을 지우고 색 곱셈을 적용했습니다. 위에서 본 파공은 인접 들판 패치로 소실을 표현했습니다.

K-123의 `fortress_states.png`와 북쪽 성벽 상태 아이콘을 확인했습니다. 따뜻한 회색 석재와 적갈색 위험 표식의 방향은 일치합니다. 지도는 양피지 UI이므로 월드 석재와 색상값을 동일하게 만들지 않았고 K-123 파일도 수정하지 않았습니다.

일반적인 생성 그림의 픽셀 격자 불일치·부드러운 가장자리·과도한 색 수를 피하기 위해 생성 잔해를 원본 성벽의 실제 색으로 정리하고 이진 알파와 정수 배율을 사용했습니다. 참고: https://www.spritefusion.com/pixel-snapper/how-to-fix-ai-pixel-art

Unity 실행·Play·실제 적용 캡처는 수행하지 않았습니다. 최종 장면의 가독성과 새 파공 상태의 규칙은 연결 후 확인해야 합니다.

검증 중 생긴 `_browserqa/`, `_browserqa_cdp/`, `browser_stderr.txt`는 에셋이 아닙니다. 자동 승인 검토가 정리용 삭제 명령을 차단하여 남았으며 커밋에서 제외해야 합니다. 브라우저 이미지 디코딩과 효과 렌더링 확인 결과는 `browser_verification.json`에 있습니다.
