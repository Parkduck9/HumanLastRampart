# 게임용 정적 데모 격자 6종

- 작성자 Codex / T-CX-030
- 사용자: 병사후면3종 일단 데모에 사용, 후속정적모델에서 프레임을 생성할 예정. 최종외형·애니메이션 승인과 구분.
- 제작 순서: 궁수·총병·대포병 후면 → 오우거·사다리 고블린·마법사 정면. 기존 PNG를 균일한 칸으로 배치하며 외형·장비·색을 새로 그리지 않는다.
- PNG각256×384 투명1열1행, 프레임0 하나뿐. 발 기준점(128,352), 정규화피벗(0.5,32/384), 비율2/3. SheetLayout.Make(1,1,0.5f,32f/384f,256f/384f).
- animated=false·fps=0. 걷기/공격/시전 프레임은 없고 동일 포즈를 복제하지 않았다. 게임은 frame0 고정과 캐릭터별1×1 레이아웃으로 연결해야 한다. 고블린의4×2 레이아웃을 그대로 쓰면 안 된다.

## 정렬과 확인

원본 알파32 이상 몸/장비영역의 바깥 여백을 제외하고 최근접 균일축척으로 배치한다. 아래쪽 갈색 부츠의10·90%색픽셀위치로 발 중심을 추정했다. 공통칸/발기준점은 같지만 발중심 추정은 데모값이므로 실제Game에서 확인한다. 장비까지 칸에 들어오게 비율을 유지하며 스케일을 줄였다. 실제게임키·오우거크기는 별도 세계스케일이며 이 그림규격이 공격/이동계산을 바꾸지 않는다.

PNG6개 크기·투명·칸 내부여백/잘림없음·발피벗·원본해시불변·팔레트신규색없음·저장픽셀일치 검사 통과(qa.json). build_sheets.py와 manifest/개별JSON에 원본·축척·좌표·해시 기록. 기존원본·Game·상대Art폴더 변경 없음.

preview.html은 이미지내장정적6종·소형32/48/64·배경전환. 실제Unity UV/피벗/스케일/화면확인은Claude 담당이며 아직 검증하지 않았다.
