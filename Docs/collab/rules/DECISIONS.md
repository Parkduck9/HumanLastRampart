## D-018 함정·지형·회수 요구 방향 (F1~F3, R1·R2)
- 날짜: 2026-10-13 (대체 기간)
- 내용: 아래는 **요구 방향 확정**이다. 데이터 형태·API·수치는 아직 승인되지 않았다(C-008 r1~r4는 제안·요구 기록).
  - 함정은 적이 다가오면 자동 발동하는 일회용이다. 터진 함정만 소비된다
  - 승리 후 터지지 않은 함정은 **회수할지 말지 플레이어가 고른다**. 자동 회수·삭제하지 않는다. 회수한 함정은 아이템으로 보관해 다시 설치할 수 있다
  - 실제 함정 위치와 플레이어 지도 기록은 따로 둔다. 격렬한 전투로 **낮은 확률**로 미발동 함정이 근처로 움직일 수 있고, 지도 기록은 자동으로 고쳐지지 않는다
  - 성에서 회수 경로를 정해 병력을 보낸다. 확인하지 못한 함정이 경로에 있으면 터져 병력을 잃을 수 있다. 근처에서 확인하면 지도 기록을 고치고 회수할 수 있다
  - R1 지형: **기본 지형 4개, 4전투 = 1사이클**. 정비 중 병력을 투입해 정해진 범위 안에서 지형 일부를 편집(통로 폭·굴곡). 자유 맵 제작은 제외
  - R2 회수 표현: 병력 얼굴이 들어간 **원형 아이콘이 지도 위를 이동**, 여러 부대 동시 파견, 지도에 폭발 표시, 오른쪽 **접이식 사건 보고서**
  - 안전하게 돌아온 부대는 낮은 확률로 아이템 또는 골드를 추가로 얻는다
  - **성 내부 실시간 전투는 이번 범위에서 제외**
  - 정비 중 함정 판매·환불은 첫 마일스톤에서 제외(F3). 매설된 함정을 회수 없이 순간 이동하는 방식은 쓰지 않는다
  - 4번째 전투 뒤의 진행(다음 사이클·승리 엔딩)은 후속 설계에서 정한다
- 대체 대상: D-017의 E3(최소 두 전투 후 메인 복귀) 중 전투 수와 마지막 처리 부분
