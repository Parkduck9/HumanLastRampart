## D-008 Git 운영
- 날짜: 2026-10-13
- 내용:
  - 두 AI 모두 `develop` 한 브랜치에서 작업하고 브랜치를 전환하지 않는다.
  - 최초 develop 전환은 초기 준비 단계에서 Claude가 1회만 수행한다.
  - main 반영은 브랜치 전환 없이 승인된 커밋까지 fast-forward로만 하며, 승인은 커밋 묶음 단위다.
  - Git 쓰기는 요청 → 조정 담당 허가 → 시작 → 종료 순서로 한다.
- 승인 근거: 사용자 답변 (2026-10-13 대화)
- 관련: RULES 10장
