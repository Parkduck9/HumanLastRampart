작성: Claude / 카드 K-050 / 2026-10-16 · 상태: **요청 1판 (사용자 확정 전)**
쓰는 곳: 5번 스토리 화면 `Game/Assets/_Project/Story/StoryPlayer.cs` — 지금은 코드로 그린 임시 도트 모양이다. 그림이 오면 같은 자리에 바꿔 끼운다.
기준: 슬롭 배제 정의 `Docs/GDD/UI_NoSlop.md`(K-047) — 한 점 = 화면 3px(1080 기준), 1px 선 금지, 깎은 귀(도트 계단 모서리), 색 역할 표(종이 `#e8d9b5` · 잉크 `#3a2a1e` · 나무 `#3b2a1f` · 황동 `#d5b16b`/`#f5d99c`). 사용자 참고: **옥토패스 트래블러의 손그림 말풍선 테두리**.

## 공통 규격

- 투명 RGBA PNG, 점 필터, 밉맵 없음, 무압축. **그림 한 점 = 1화소로 그리고 게임에서 3배로 붙인다**(정수 배율).
- 9칸 늘이기 그림은 README에 경계(왼쪽·아래·오른쪽·위 화소)를 적는다.
- 그림 안에 글자를 넣지 않는다(이름·대사는 코드가 쓴다).

## 인물 그림 (별도 카드 제안)

- 지금은 기존 전투 시트의 앞모습 한 칸(256×384)을 2배로 세운다: 장교 = `hero_walk_run_grid` 12번 칸, 궁수 = `archer_static`, 마법사 = `wizard_front_chestnut`.
- 스토리용 **상반신 초상 시트**(인물마다 표정 4칸: 보통·웃음·놀람·결의, 256×384 칸 격자 그대로)가 있으면 도구에서 칸만 고르면 바로 쓰인다. 주인공은 **장교 훈련을 받고 고향에 돌아온 장교, 장교 옷 차림**.

## 배경

- 지금 임시 이야기는 메인 배경(`ScreenArt/main.png`)과 패배 배경(`defeat.png`)을 쓴다. 스토리 전용 배경이 생기면 도구에서 장면 배경으로 바로 끌어다 놓으면 된다.
