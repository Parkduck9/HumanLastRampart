# 전투 설계 — 1번 성벽 화면 · 2번 지도 모드 (Battle)

- 상태: **제안 r1 — 사용자 결정 대기** (승인 전에는 이 문서로 구현하지 않는다)
- 작성: Claude (1·2번 전투 담당) / 작성일: 2026-10-13 / ROADMAP P1-C09·C10·C11
- 근거: FirstRead(1·2번 화면 설명), D-004·D-013·D-014·D-015·D-017~D-025, CONTRACTS C-003~C-016, PERF_PROTOTYPE(D-024 구조)
- 이 문서가 정하는 것: 전투 화면에서 플레이어가 무엇을 보고, 무엇을 누르고, 무엇이 승패를 가르는지 (1회차 범위)
- 정하지 않는 것: 정확한 밸런스 수치(시험 플레이로 조정), 최종 그림·연출

> 아래 **[B숫자]** 표시는 사용자가 정해야 하는 질문이다. 10장에 모아 두었다 (B1~B10).

## 1. 한 판의 전투 흐름

```
[5 스토리] ─▶ 전투 시작 ─▶ ┌──────────── 실시간 진행 ────────────┐
                           │ 1번 성벽 화면 ◀─ M ─▶ 2번 지도 모드 │
                           │ (원근, D-025)        (직교, D-025)   │
                           └───────────────────────────────────┘
                              │ 모든 웨이브 처치 [B2]      │ 성벽 붕괴 [B1]
                              ▼                            ▼
                         승리 → [4 결과]              패배 → [5 패배 엔딩] → [0 메인] (D-014)
```

- 전투는 **한 씬(Battle) 안에서** 1번과 2번을 오간다 (ARCHITECTURE 2.2). 지도 모드에서도 전투는 계속된다 [B4].
- 전투 시작 정보는 `BattleSetup`(C-005), 끝나면 `BattleResult`(C-006)를 만든다. 패배면 결과 화면을 건너뛴다(D-014).

## 2. 전장 구성

| 요소 | 내용 (1회차 제안) |
|---|---|
| 성벽 | 좌우로 긴 성벽. **구간 5개**(왼쪽 끝·왼쪽·성문·오른쪽·오른쪽 끝)로 나누고 구간마다 내구도. 구간 수는 `CampaignStartDef`(D-015 D3)에서 정한다 |
| 성벽 위 지점(Post) | 병사·대포가 서는 자리. 구간마다 2~3개. 배치는 정비 화면에서 정한다(D-015 D5) |
| 들판 | 성벽 앞 넓은 땅. 적은 멀리서 나타나 성벽으로 걸어온다. 지형 4종이 전투마다 바뀐다(D-018, P1-C14 지형 4개) |
| 함정 | 정비에서 설치한 일회용 함정. 적이 다가오면 자동으로 터진다(C-008, D-018) |
| 카메라 | 1번: 성벽 위 병사 바로 뒤의 낮은 원근 카메라, 주인공을 따라 좌우 이동. 2번: 들판을 기울여 내려다보는 직교 카메라 |

## 3. 1번 성벽 화면 (P1-C09)

### 3.1 주인공
- **성벽 위를 좌우로 걷는다.** A/D(또는 ←/→)로 이동하고, 카메라가 따라간다(PerfLab에서 확인한 느낌).
- 장교 복장의 지휘관이다(FirstRead). 1회차에는 **직접 싸우지 않고 지휘만** 한다 [B3]. 아이템 강화는 다음 마일스톤에서 정한다.

### 3.2 병사·대포와 상호작용
- 주인공이 지점 가까이 가면 머리 위에 **[E] 안내**가 뜬다. E를 누르면 그 지점의 작은 설정 창이 열린다. **창이 열려 있어도 전투는 계속된다.**

| 설정 | 내용 | 근거 |
|---|---|---|
| 표적 우선순위 | 체력 비율 낮은 적(기본) / 높은 적 / 특수 적 먼저. 지점별로 다음 전투까지 유지 | D-019, C-011 |
| 대포 조준 거리 (대포 지점만) | 가까이 / 중간 / 멀리 중 하나. 그 거리대의 적 무리에 자동으로 쏜다 [B6] | FirstRead "대포 설정" |

- 설정은 즉시 적용되고 `CampaignState.Targeting`에 기록된다(C-004, C-011).

### 3.3 아군 공격 (자동)
- **궁수 분대:** 사거리 안의 적을 표적 규칙대로 골라 화살을 쏜다 (PerfLab 구조 그대로, D-024).
- **대포:** 정해진 거리대의 적이 가장 많이 모인 곳에 포탄을 쏴 범위 피해를 준다. 재장전이 길다.
- **병력 손실:** 병사는 성벽 위에 있어 적과 직접 싸우지 않는다. 대신 **성벽 구간이 피해를 받으면 그 구간의 병사도 피해량에 비례해 일부 쓰러진다** [B10]. 그래야 이긴 전투에서도 4번 결과 화면에 "잃은 병력"이 생긴다(FirstRead). 그 밖의 손실은 함정 회수 사고(C-016)뿐이다.

### 3.4 적 행동
- 들판 뒤쪽에서 웨이브 단위로 나타나 성벽 쪽으로 걷는다(지형에 따라 길을 따라감 — 흐름장, D-024 구조에 추가).
- 성벽에 닿으면 멈춰서 **그 앞 구간을 공격**한다(고블린 곤봉 공격 동작, 3번째 프레임이 타격).
- 특수 적은 일반 적과 섞여 온다. 강하고 성벽에 큰 피해를 준다 [B7].

### 3.5 화면 표시 (HUD)
| 위치 | 내용 |
|---|---|
| 위쪽 가운데 | 웨이브 진행(현재/전체), 남은 적 수 |
| 위쪽 가로 막대 | 성벽 구간 5개의 내구도 (구간 위치 그대로 배치, 위험하면 빨갛게) |
| 아래 오른쪽 | 특수 공격 준비 상태(재사용 대기 원형 게이지) + [M] 지도 |
| 주인공 근처 | [E] 상호작용 안내 |
| F8 | 성능 표시(C-014) |

## 4. 2번 지도 모드 (P1-C10)

### 4.1 열기·닫기
- **M 키** 또는 오른쪽 아래 버튼. 카메라가 위로 올라가며 직교 지도 시점으로 바뀐다(약 0.5초). 다시 M이나 Esc로 돌아온다.
- 지도 모드에서도 **전투는 그대로 진행**된다 [B4]. 주인공은 제자리에 서 있다.

### 4.2 특수 공격 (1회차: 포격 1종 [B5])
1. 지도에서 포격 버튼을 고른다(재사용 대기가 끝났을 때만).
2. 마우스를 움직이면 **착탄 범위 원**이 따라다닌다. 클릭하면 그 지점에 포격 예약.
3. 약 2초 뒤 포탄이 떨어져 범위 안의 적에게 피해를 준다. 함정은 포격으로 터지지 않는다(C-008 — 함정은 적 접근으로만 발동).
4. 재사용 대기(예: 20초)가 시작된다.

- FirstRead의 전략: "포격으로 적을 함정 쪽으로 몰거나, 강한 적이 나오면 포격을 멈추고 함정 근처로 유도"는 **포격 범위의 적이 잠시 옆으로 밀려나는 효과**로 표현하는 것을 제안한다 [B5].

### 4.3 망원경 (돋보기)
- 지도 모드에서 **마우스 오른쪽 버튼을 누르고 있으면** 마우스 위치에 원형 확대 렌즈가 생긴다.
- 렌즈 안에서는 적이 크게 보이고, **특수 적이면 이름과 체력 막대**가 뜬다.
- 망원경으로 한 번 확인한 특수 적은 지도에 **표시 아이콘**이 붙어 계속 따라다닌다 [B8].
- 일반 지도 시점에서는 특수 적과 일반 적이 구분되지 않는다(멀리서는 다 비슷해 보임) [B8].

### 4.4 함정 표시
- 지도에는 플레이어가 설치 때 **남긴 표시**만 보인다(D-018, C-008 r5). 실제 위치가 움직였어도 표시는 그대로다.

## 5. 승패와 결과

| 구분 | 조건 (제안) | 다음 |
|---|---|---|
| 승리 | 이번 전투의 **모든 웨이브의 적을 처치** [B2] | 결과 화면(4번). 보상·손실 반영은 결과 화면에서 한 번(D-017 E1) |
| 패배 | 성벽 구간 하나라도 **내구도 0 → 적이 성 안으로 침입** [B1] | 패배 엔딩 → 메인(D-014). 성 내부 전투 없음(D-018) |

- `BattleResult`(C-006)에 담는 것: 승패, 끝난 전투 번호·실행 ID, 처치 수(일반/특수), 성벽 구간별 피해, 잃은 병력(분대·영웅 ID별), 소비한 함정, 움직인 함정 위치, 획득 골드.
- 골드: 처치한 적의 `EnemyDef` 보상 합계 (D-015 D2 골드 하나).

## 6. 1회차 전투 범위 (P1-C11)

### 6.1 적
| 적 | 역할 | 그림 |
|---|---|---|
| 곤봉 고블린 (일반) | 걸어와서 성벽 공격. 체력 낮음 | Codex 고블린 시트(걷기·공격 4+4) |
| 특수 적 1종 [B7] | 체력 매우 높음, 성벽 피해 큼, 느림. 망원경으로 확인 | 새로 필요 |

### 6.2 아군 무기
| 무기 | 방식 |
|---|---|
| 활 (궁수 분대) | 자동, 단일 대상, 표적 우선순위 적용 |
| 대포 (대포 지점) | 자동, 조준 거리대의 밀집 지점에 범위 피해 [B6] + 2번 지도 포격(특수 공격) |

### 6.3 전투 4번 (지형 4개, D-018)
| 전투 | 지형 | 적 규모 (동시 최대, 제안 [B9]) | 특수 적 |
|---|---|---|---|
| 1 | 지형 1 | 일반 1,000 | 없음 (조작 익히기) |
| 2 | 지형 2 | 일반 3,000 | 1마리 |
| 3 | 지형 3 (지형 1 모양 복사, I4) | 일반 8,000 | 3마리 |
| 4 | 지형 4 (지형 2 모양 복사, I4) | 일반 20,000 | 6마리 |

- 4번째 승리 후 정비 → 메인(D-022 I5). 성능 목표(아군 1만·적 5만, D-020)는 구조가 이미 감당하므로 1회차는 단계적으로 늘린다.
- 시작 병력·골드·성벽 내구도는 시험 플레이로 맞춘다(`CampaignStartDef`, Claude 작성).

### 6.4 함정 1종
- 일회용 폭발 함정 (D-018). 적이 반경 안에 들어오면 터져 범위 피해. 가격·반경·피해는 시험 플레이로 조정.

## 9. 1회차에서 빼는 것

- 주인공 직접 전투·스킬, 아이템 강화 (다음 마일스톤)
- 마법 특수 공격 [B5], 다른 무기(석궁·총·뇌뢰 등 — FirstRead 후보)
- 병사가 적에게 맞아 죽는 근접 교전, 성 내부 전투(D-018 제외)
- 지형 편집·회수 파견 지도(D-021 G5)
