## 1. 한 판의 전투 흐름

```
[0 메인] ─게임 시작─▶ 난이도 선택(쉬움/현실) ─▶ [5 스토리] ─▶ 전투
                                                         │
   ┌──────────────── 실시간 ────────────────┐            │
   │ 1번 성벽 화면 (원근) ◀─ M ─▶ 2번 지도 모드 (직교) │ ◀──┘
   │                        쉬움: 지도에서 시간 멈춤     │
   │                        현실: 지도에서도 시간 흐름   │
   └──────────────────────────────────────┘
        │ 모든 웨이브 처치                │ 성벽 하나라도 뚫림
        ▼                                 ▼
   승리 → [4 결과]                   패배 → [5 패배 엔딩] → [0 메인]
```

- [확정] 난이도 2가지(B4). 게임 시작을 누르면 고르는 창이 뜬다. 고른 난이도는 그 판 내내 유지한다 [Q8].
- [확정] 승리: 모든 웨이브 처치(B2). 패배: 4장.

## 2. 전장 구성 — 성 4면 방어 [확정 B8]

```
                 북쪽 들판 (적)
          ┌──────── 북벽 ────────┐
 서쪽     │                      │     동쪽
 들판   서벽        성 안        동벽   들판
 (적)     │                      │     (적)
          └──────── 남벽 ────────┘
                 남쪽 들판 (적)
     모서리 = 탑 (주인공이 다음 벽으로 넘어가는 곳 [Q2])
```

| 요소 | 내용 |
|---|---|
| 성벽 4개 | 북·동·남·서. 벽마다 **체력**과 **배치 병력**이 있다 |
| 벽 위 배치 | 벽마다 **대포 5문**[확정 B6], 궁수·총병 분대 지점 여러 개. 배치는 정비 화면에서(D-015 D5) |
| 들판 4방향 | 적은 네 방향 멀리서 나타나 성으로 온다. 방향별 규모가 다르고 전투마다 바뀐다 |
| 날씨·시간 | 날씨 4종(맑음·흐림·비·안개) + 밤/낮 [확정 B8], 적용 방식 [Q4][Q5] |
| 함정 | 일회용, 적 접근 시 자동 폭발(D-018) |

## 3. 1번 성벽 화면 (P1-C09)

### 3.1 주인공 [확정 B3]
- 성벽 위를 걸으며 지휘한다. A/D로 이동, 카메라(원근 낮은, D-025)가 따라간다. 1회차는 직접 싸우지 않는다.
- 벽 끝(모서리 탑)에서 옆 벽으로 이어서 걸어간다 [Q2].

### 3.2 병사 3종 — 계속 자동으로 쏜다 [확정 B5]
| 병사 | 특징 (제안) |
|---|---|
| 궁수 (화살) | 사거리 중간, 연사 보통, 단일 대상. 표적 우선순위 적용(D-019) |
| 총병 (총) | 사거리 짧음, 한 발 피해 큼, 재장전 김. 단일 대상 |
| 대포 | 벽마다 5문. **지도에서 정한 지점으로 계속 포격**(범위 피해) [확정 B6] |

- 지점 가까이에서 **E** → 그 지점 설정 창: 궁수·총병은 표적 우선순위(D-019). 대포 지점은 "지도에서 조준" 버튼(2번 지도로 바로 이동).
- 1회차에 세 종류를 모두 넣을지 [Q7].

### 3.3 적 행동 [확정 B10]
1. 네 방향 멀리서 나타나 성벽으로 걸어온다(지형 따라 — 흐름장).
2. **초반: 사다리를 든 적**이 벽에 사다리를 걸면 그 자리로 올라온다.
3. **이후: 벽 앞에 쓰러진 적의 시체가 쌓이고**, 더미가 벽 높이에 가까워지면 적이 **시체 더미를 밟고 올라온다.**
4. 올라온 적은 그 벽의 병사를 공격해 **병력을 줄인다** [Q6].
5. 땅에 있는 적은 벽 자체를 공격해 **벽 체력을 줄인다.**
- 특수 적(오우거형) [확정 B7]: 덩치 크고 느리고 체력이 매우 높다. 벽 체력에 큰 피해.
- 시체 더미는 FirstRead의 "포격으로 적을 유도"와도 이어진다 — 한 곳에 많이 죽이면 그곳에 더미가 빨리 쌓이는 위험이 생긴다.

### 3.4 화면 표시 (HUD)
| 위치 | 내용 |
|---|---|
| 위쪽 | 웨이브 진행, 남은 적 수, 날씨·시간 아이콘 |
| 화면 가장자리 4곳 | **방향별 경고**: 북·동·남·서 벽의 체력과 병력 비율(70% 손실이 패배선), 그쪽 적 규모 |
| 아래 오른쪽 | 마법사 특수 공격 준비 상태 + [M] 지도 |
| 주인공 근처 | [E] 상호작용 안내 |

## 4. 승패 [확정 B1·B2·B10]

| 구분 | 조건 |
|---|---|
| 승리 | 이번 전투의 모든 웨이브 처치 |
| 패배 | **어느 한 성벽이라도** ① 체력 0 이 되거나 ② **그 벽 배치 병력의 70% 이상이 죽으면**(뚫림) [Q1] |

- 이긴 전투에서도 올라온 적에게 병사가 죽으므로 4번 결과 화면에 "잃은 병력"이 생긴다(r1의 B10 고민 해결).
- `BattleResult`(C-006): 승패, 벽별 체력 피해, 분대·영웅별 손실, 처치 수(일반/특수), 소비·이동 함정, 골드.

## 5. 2번 지도 모드 (P1-C10)

### 5.1 열기·닫기·시간 [확정 B4]
- M 키 → 직교 지도 시점(D-025). **쉬움: 지도가 열린 동안 전투 시간 정지. 현실: 계속 흐름.**
- 지도는 성 전체와 네 방향 들판을 보여 준다.

### 5.2 대포 조준 [확정 B6]
- 벽 하나를 고르면 그 벽의 대포 5문이 표시된다. 대포를 고르고 들판의 지점을 찍으면, **그 대포는 지점을 바꿀 때까지 그곳으로 계속 쏜다.**
- 사거리 밖은 찍을 수 없다. 지점 근처의 적 밀집도에 따라 효과가 달라진다.

### 5.3 마법사 특수 공격 [확정 B5]
- 마법사 1명이 대규모 마법을 쓴다. 후보: **강풍**(적을 밀어냄 — 함정으로 유도), **불벽**(지나가는 적에게 지속 피해·길 막기), **폭발**(범위 큰 피해). 이펙트가 있는 것 중에서 고른다.
- 지도에서 마법을 고르고 범위를 찍어 쓴다. 쓰고 나면 재사용 대기.
- 1회차에 넣을 마법 [Q3].

### 5.4 망원경 — 멀리서 오는 적 확인 [확정 B8]
- 지도에서 마우스 오른쪽을 누르고 있으면 확대 렌즈. **멀리서 오는 적의 방향·규모, 특수 적**을 확인한다.
- **날씨·밤**이 먼 곳을 가린다(안개·밤일수록 지도에 먼 적이 흐리거나 안 보임) → 망원경이 필요해진다 [Q5].
- 확인한 적 무리에는 지도에 방향·규모 표시가 붙는다.

### 5.5 함정 표시
- 설치 때 남긴 표시만 보인다(D-018).

## 11. 확인 질문

| ID | 질문 | Claude 제안 |
|---|---|---|
| **Q0** | **FirstRead에 "적들이 정면에서 다가오고"라고 되어 있는데, 이번 답은 상하좌우 4면이다.** FirstRead는 사용자 파일이라 Claude가 고칠 수 없다 | 사용자가 FirstRead를 "사방에서" 등으로 고쳐 주거나, "4면 방어로 바꾼다"고 확인해 주면 D-026에 근거로 남긴다 |
| Q1 | 패배 판정 단위 | **벽 4개 각각이 단위.** r1의 "벽 하나를 5구간으로 나누기"는 없앤다 (벽 체력 하나 + 그 벽 병력 70%) |
| Q2 | 주인공이 4면을 어떻게 오가나 | **성벽을 한 바퀴 이어서 걷는다**(모서리 탑에서 자연스럽게 꺾임). 먼 벽은 지도에서 클릭해 바로 이동하는 빠른 이동도 제공 |
| Q3 | 1회차 마법 | **폭발 1개**(범위 큰 피해, 구현이 가장 단순). 강풍·불벽은 다음 |
| Q4 | 날씨·밤낮을 언제 정하나 | **전투마다 정해짐**(4전투가 서로 다르게, 예: 맑은 낮 → 흐린 낮 → 비 오는 밤 → 안개 밤). 전투 중 변화는 다음 |
| Q5 | 날씨·밤낮 효과 | 1회차는 **시야만**(안개·밤일수록 먼 적이 안 보여 망원경 필요). 비로 총 명중이 떨어지는 등 전투 효과는 다음 |
| Q6 | 올라온 적과 병사의 싸움 | 1회차는 **수치형**: 올라온 적 1마리가 초당 병사 몇 명을 쓰러뜨리고, 병사들도 올라온 적을 처치(개별 근접 애니메이션 없이). 근접 연출은 다음 |

| Q8 | 난이도를 판 도중에 바꿀 수 있나 | **판 내내 고정**(메인에서 새로 시작할 때만 선택) |
