# 스토리 제작 툴 최소 기능 제안 r1

- 상태: **제안 — C-009/툴 범위 사용자 승인 후 구현**
- 작성자: Codex / T-CX-013·CY1-X3·P1-X06 / 2026-10-13
- 위치: Story/Editor/, HLR.Story.Editor(에디터 전용, Core·Story 참조).

기존 Unity 정의 에셋을 선택해 스토리 ID·종류·줄 목록을 편집하는 작은 툴을 만든다. 왼쪽은 줄 순서 목록, 오른쪽은 선택한 줄의 이름·대사·초상·배경·줄 종류다. 줄 추가/삭제/위아래 이동, Undo/Redo, 저장 전 검사, 정적 미리보기를 첫 범위로 추천한다. 그래프 편집·분기·음성·번역·이벤트 호출은 제외한다.

검사는 빈/중복 스토리 ID·LineId, 빈 대사, 잘못된 Kind, 패배 엔딩의 ForecastHint를 찾고 줄 위치를 보여 준다. 오류가 있으면 제작 데이터 완성 표시를 하지 않는다. 검사는 데이터 변경을 대신하지 않는다. 저장은 사용자가 버튼을 눌러 Unity 에셋에 반영하며 미리보기로 런타임 Campaign을 바꾸지 않는다.

날씨 힌트 미리보기는 사용자가 고른 시험 시드·전투 번호와 규칙으로 계산하고 ‘시험 예보’로 구분한다. 실제 판의 예보를 새로 추첨하거나 저장하지 않는다. 툴의 에셋 작성은 Codex Data/Story 아래에 한정하고 Core/App 정의나 카탈로그 연결을 자동으로 덮어쓰지 않는다.

완료 기준: 줄 순서 보존·Undo·재열기 동일, 오류 위치/수정 후 검사 해제, 선택 초상/배경 반영, 런타임 재생과 동일한 줄 순서, 에디터 전용 코드가 플레이어 빌드에서 제외됨. C-009 승인 뒤 실제 데이터와 함께 검증한다.
