| 항목 | 내용 |

| 열기 | M 키 → 직교(원근 없는) 지도 시점. Esc·M으로 닫기 |
| 시간 | **쉬움: 지도가 열린 동안 전투 정지 / 현실: 계속 흐름** |
| 전체 명령 | 지도의 "전체 명령"으로 4면 표적 명령을 한 번에. 성벽 명령은 지워짐(D-031 K3), 내린 시각 규칙(D-039) |

| 함정 | 설치 때 남긴 표시만 보임(D-018) |

- **보기:** 위에서 내려다보는 직교 카메라. 마우스 휠로 3단계 확대(전체 → 한 면 → 가까이), A/D/W/S로 이동.
- **적 표시:** 들판 전체에서 고블린(2.4m)은 몇 픽셀이라 그림 대신 **점**으로 그린다. 오우거 등 특수 적은 큰 빨간 표시. 아군은 파란 점, 대포는 번호 아이콘.
- **날씨:** 안개·밤에는 시야(25·30m) 너머 적 점을 지운다(1번 화면과 같은 규칙). 망원경으로 확인한 무리는 보인다. 흐림이면 방향별 규모 숫자를 숨긴다.

## 3. 상세 규칙 (구현에 필요한 빈칸)

### 3.1 대포 조준
- 대포 사거리 = 무기 정의(`weapon_cannon` 90m, 성벽 기준). 지도에 사거리 원 표시, 밖은 찍을 수 없음.
- 조준점 근처 반경 = 무기 범위(4m)에 퍼짐(거리별)을 더한 범위에 떨어진다. 명중률·퍼짐은 지금 규칙 그대로(D-028 C7).
- **조준점 근처에 적이 없을 때 (M2):** 추천 — **쉰다**(쏘지 않음, 아이콘에 "대기"). 다른 안 — 그래도 계속 쏜다(낭비지만 길목 차단).
- 조준점이 없는 대포는 지금처럼 그 벽 앞 밀집한 곳(C16-3).
- **다음 전투로 이어지나 (M6):** 추천 — **전투마다 처음으로**(지형이 전투마다 바뀜, D-018). 저장 데이터 변경 없음.

### 3.2 마법 (폭발·불바다)
- 수치는 정의 데이터 그대로: 폭발 반경 12m·피해 150·재사용 40초 / 불바다 반경 10m·초당 20·8초·재사용 50초.
- **마법사 위치·사거리 (M3):** 추천 — 마법사는 성 안 어디서나 쓰고, **성벽에서 150m 안**까지 찍을 수 있다(들판 끝 320m 전체는 아님 → 멀리 오는 적은 대포·망원경 몫).
- **시전 지연 (M4):** 추천 — 폭발은 찍고 **1초 뒤** 터진다(바닥에 원 표시 → 적이 움직이므로 예측이 필요). 불바다는 즉시 시작.
- 불바다 피해에는 날씨 배율(비 0.1·소나기 0.5)을 곱한다 — 이미 계산 준비됨(CY2-C4).
- 마법으로 성벽 가까이에서 죽은 적도 시체 더미에 쌓인다(FirstRead "포격으로 적을 유도"와 연결).
- **마법사 참가 (M7):** 지금 시작 데이터의 마법사는 배치 지점이 없어 전투 참가 목록에 들어가지 않는다(결과의 영웅 항목 0). 추천 — **마법사·주인공은 배치 지점 없이도 항상 참가**(App 전투 준비 규칙 변경, Claude). 참가하면 결과 화면 '영웅 상태'에 나온다. 1회차에는 영웅이 다치지 않는다(성벽 위 싸움에 영웅은 끼지 않음).

### 3.3 망원경
- 오른쪽 버튼을 누르고 있는 동안 커서 위치에 렌즈. **렌즈 반경 40m 안**의 적은 날씨와 상관없이 보이고, 그 적이 속한 **무리**(웨이브의 같은 방향·같은 출발 묶음)를 "확인됨"으로 표시한다.
- 확인된 무리: 지도에 "북쪽 약 320 · 오우거 1" 같은 표시가 전투 끝까지 남는다. 1번 화면·지도에서 시야 밖이어도 보이고, **먼 거리 명중 감소가 없다**(Battle.md 6.4).
- **렌즈 크기 (M5):** 추천 40m. 크면 망원경이 너무 쉬워지고, 작으면 찾기 어렵다.

### 3.4 쉬움에서 지도를 연 동안 (M8)
- 정해진 대로 **전투 시간은 멈춘다**. 추천 — 멈춘 동안에도 **조준·마법·전체 명령은 내릴 수 있다**(시간이 다시 흐를 때 적용). 마법 재사용 대기도 멈춘다.

### 3.5 지도 화면 크기 (M1)
- 추천 — **3단계 확대**: 전체(성+네 들판, 약 700m) / 한 면(약 250m) / 가까이(약 100m). 처음 열면 지금 바라보던 성벽 쪽 '한 면'.

## 5. 데이터 약속 영향

- **Core 변경 없음.** 대포 조준점·마법 대기·망원경 확인은 전투 안에서만 쓴다.
- M7을 고르면 **App의 전투 준비 규칙**(참가 영웅 고르기)이 바뀐다 — C-005 문구 보완(참가 = 배치된 영웅 + 마법사·주인공). Codex 결과 반영(영웅 Hp·생존)은 이미 처리 가능.
- 함정 표시는 함정 연결(Phase 3, P1-C14 후속 R1~R3) 때.
