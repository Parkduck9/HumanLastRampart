# 전투 중 함정 (CY4-C1) — 설계 제안 r1

- 작성: Claude / 2026-10-14 / 바퀴 4
- 상태: **제안** — T1~T5 사용자 결정 뒤 구현
- 근거: FirstRead 3번 화면(함정 설치, 포격으로 적을 함정으로 유도), D-018(일회용·적 접근 자동 폭발·낮은 확률 이동), C-008 r1~r5, P1-C14(C-004 v1.2·C-005·C-006·C-007 v1.1), Battle.md 5.5
- Codex 정비 함정 설치 화면(CY4-X1)과 **설치 지점(T1)을 같이 쓴다**

## 1. 흐름
1. 정비에서 함정을 사서 설치 지점에 놓는다 (Codex).
2. 전투 준비(BattleSetup)에 **그 전투 지형의 함정**만 실제 위치로 들어온다 (C-005 v1.1, App).
3. 전투 중 살아 있는 적이 발동 거리 안에 들어오면 **자동 폭발** → 피해 거리 안 모든 적에게 피해 한 번. 함정은 사라진다 (일회용).
4. 결과(BattleResult)에 터진 함정 `ConsumedTrapIds`, 자리가 바뀐 함정 `TrapMoves`를 담는다 (C-006 v1.1). 결과 화면이 반영한다 (Codex, C-007 v1.1).

## 3. 구현 (Claude)
- 정의: `TrapDef` 수치(T2), `TrapSlotDef` 64개(T1, Data/Combat).
- 전투: 함정 목록을 전투 복사본에 두고 매 프레임(작업 끝난 뒤) 발동 거리 안 적을 공간 격자로 찾는다(함정 수가 적어 메인 스레드). 피해는 마법과 같은 사건 줄(HitEvent) — 보상·시체 더미 그대로. 폭발 효과는 마법 폭발 재사용.
- 결과: ConsumedTrapIds 중복 없이, TrapMoves는 T4.
- 확인: 배치 시험(함정 위로 적이 지나가면 1번만 터지고 소비, 다른 지형 함정은 안 터짐, 결과 목록), 사진, 대포로 적을 함정 쪽으로 모는 측정(CY4-C2).

## 4. Codex와 맞출 것
- 정비 화면은 T1 지점 정의(`TrapSlotDef`, `Definitions.All<TrapSlotDef>()` 중 현재 지형)를 읽어 지도에 그린다.
- 결과 반영(C-007 v1.1): 소비 함정 제거, TrapMoves 실제 위치 적용(지도 표시는 그대로).

## r2 — 사용자 답변 반영 (2026-10-14)
사용자: "함정 놓는 자리는 칸으로 나눠서 넓게(언덕 같은 곳은 불가능), 폭탄은 점화식으로 내가 직접 누르는 게 더 재밌을 것, 성벽 강화 말고 함정을 많이 사서도 통과할 수 있게 넉넉히 살 수 있되 대장장이가 많이 없어 재고는 상점에서 조금씩 생성, 나머지는 추천안"

### 바뀐 것
- **T1 → 칸 배치:** 정해진 16곳 대신 성벽 앞 넓은 구역을 칸으로 나눈다. 지형마다 '놓을 수 없는 칸'(언덕·바위 등)이 있다. 한 칸에 함정 하나.
- **발동 → 점화식:** 적이 다가와도 저절로 터지지 않는다. 플레이어가 직접 눌러 터뜨린다.
- **사기 → 재고:** 함정은 넉넉히 살 수 있게 값을 낮추고, 상점 재고가 정비 때마다 조금씩 생긴다(대장장이가 적음).
- **그대로(추천안):** T3 땅에 묻혀 안 보임·터질 때 효과, T4 낮은 확률 이동, T5 적만 피해, T2 피해 수치(피해 거리 6m·피해 300).
