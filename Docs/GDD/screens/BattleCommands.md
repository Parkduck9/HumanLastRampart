# 전투 명령 겹침 규칙 (P1-C16)

- 상태: **승인 r1** (2026-10-14, D-039 — C16-1~C16-5 추천대로)
- 작성: Claude / 2026-10-14 / 바퀴 1 CY1-C2
- 근거: Battle.md 3.1-1·5.1-1(D-027·D-028·D-030), C-011 r2(`TargetingSettings`), D-031 K3("전체 명령은 성벽 명령을 지운다, 겹침 규칙은 이후 문서화")

## 1. 이미 정해진 것 (바꾸지 않음)

| 상황 | 결과 | 근거 |
|---|---|---|
| 전체 명령(지도) | 4면 모두 그 명령. 성벽마다 따로 내린 명령은 **모두 지운다** | D-031 K3, C-011 |
| 전체 명령 뒤 성벽 명령 | 그 성벽만 성벽 명령을 따른다 | Battle.md 5.1-1 |
| 다음 전투 | 마지막 설정을 그대로 가져간다 | C-011 (D-013 Q5) |

## 2. 새로 정할 것 — 명령이 "가는 중"일 때

명령하기(①)는 즉시 적용된다. 하지만 **전령(②)은 달려가는 시간이 있다.** 소리 지르기(③)는 즉시이지만 **잘못 들을 수 있다.** 그래서 "옛 명령이 새 명령보다 늦게 도착하는" 일이 생긴다.

### 예시
1. 북쪽 성벽에 서서 동쪽으로 **전령**을 보낸다: "체력 낮은 적부터" (도착까지 20초)
2. 10초 뒤 동쪽이 급해져 **소리 지르기**로 "오르는 적부터"를 외친다 → 동쪽이 바로 따른다
3. 20초째 전령이 도착해 "체력 낮은 적부터"를 전한다 → **동쪽은 어떤 명령을 따라야 할까?**

### 추천 규칙: "나중에 **내린** 명령이 이긴다" (C16-1)
- 모든 명령에 **내린 시각**을 붙인다. 성벽은 지금 따르는 명령의 내린 시각을 기억한다.
- 명령이 도착하면(전령 도착·소리 들림·직접 명령) **지금 명령보다 나중에 내린 것일 때만** 바꾼다.
- 위 예시: 전령 명령(0초에 내림)은 소리 명령(10초에 내림)보다 오래되어 **무시된다.** 화면에 "동쪽: 전령 명령이 더 새 명령에 밀려 무시됨"을 짧게 띄운다.
- 전체 명령도 같다. 전체 명령보다 먼저 출발한 전령은 도착해도 무시된다(C16-4).
- 소리를 **잘못 들은** 성벽도 그 소리를 낸 시각을 받는다. 그 성벽의 더 오래된 명령은 덮이고, 더 새 명령은 그대로 남는다.

> 다른 방법 — "나중에 **도착한** 명령이 이긴다": 단순하지만, 위 예시처럼 옛 명령이 새 명령을 덮어써서 플레이어가 "분명 바꿨는데 왜 돌아갔지?"를 겪는다. 추천하지 않는다.

## 3. 그 밖의 겹침

| ID | 상황 | 추천 | 다른 선택 |
|---|---|---|---|
| C16-1 | 옛 명령이 새 명령보다 늦게 도착 | **내린 시각 기준** (2장) | 도착 시각 기준 |
| C16-2 | 전령으로 뛰는 병사 | **뛰는 동안 쏘지 않는다.** 병력 수(70% 패배 판정)에는 원래 성벽 소속으로 그대로 센다. 전달 후 제자리로 돌아와 다시 쏜다 | 병력 수에서도 빼기 (패배가 빨라짐) |
| C16-3 | 대포와 표적 명령 | **대포는 표적 명령을 따르지 않는다.** 지도에서 찍은 지점을 계속 포격한다(Battle.md 3.2). 지점을 아직 안 찍었으면 그 벽 앞에서 **적이 가장 많이 모인 곳**을 자동으로 쏜다 | 대포도 표적 명령을 따름 (지도 조준과 충돌) |
| C16-4 | 전체 명령을 내렸는데 전령이 가는 중 | **전령은 계속 가지만, 도착하면 명령은 무시된다** (내린 시각이 더 이름). 알림 표시 | 전령을 즉시 되돌림 (그림·동작이 더 필요) |
| C16-5 | 같은 성벽으로 전령을 여러 명 | **제한 없음.** 각각 가장 가까운 병사가 나가며, 도착 순서와 상관없이 C16-1로 정리된다 | 성벽마다 동시에 1명만 (두 번째 부르기는 거절) |

- 같은 명령을 다시 내리면 결과는 같고 내린 시각만 갱신된다.
- 전투가 끝날 때 가는 중이던 명령은 버린다. 다음 전투에는 성벽이 **실제로 따르던** 명령만 이어진다(C-011).
- 소리를 "못 들음"(옆 10%·맞은편 30%)이면 아무것도 바뀌지 않는다. 알림은 "동쪽이 듣지 못함".

## 4. 데이터 약속 영향

- **Core 변경 없음.** `TargetingSettings`(C-011)는 "지금 따르는 명령"만 저장한다. 내린 시각·가는 중인 명령·전령 상태는 **전투 안(Combat)에서만** 쓰는 값이라 저장하지 않는다.
- 전투가 끝날 때 Combat이 `TargetingSettings`를 최종 상태로 갱신한다(C-011 r2 그대로).

## 5. 구현 위치 (승인 후, 바퀴 2 예정)

- Combat: 명령 대기열(소리 — 즉시·실패 판정 / 전령 — 이동 시간 후 / 직접 — 즉시), 성벽별 "지금 명령 + 내린 시각", `SoldierFireJob`의 우선순위를 성벽별 명령으로 바꾸기.
- 지금 실제 전투(CY1-C1)는 모든 성벽이 고정 순서(성벽 위 → 오르는 적 → 체력 비율 낮은 적)로 쏜다. 명령이 들어오면 "오르는 적부터"·"체력 낮은 적부터" 등으로 바뀐다.
