# 코덱스 긴 작업 목록 (클로드 없이 돌리기)

> 2026-10-20 작성. 클로드 사용량이 적을 때 코덱스가 오래 일할 수 있게 카드 지시문을 미리 써 두었다.
> 지시문은 `Tools/CodexCards/briefs/K-0NN.md`(영어 — AI끼리 글), 공통 규칙은 `COMMON.md`.
> 코덱스는 그림만 만든다(D-074). 게임에 연결하는 것은 클로드 몫이라, 결과는 검토 페이지로만 나온다.

## 돌리는 법
파워셸에서 (유니티는 꺼도 켜도 상관없다 — 카드 폴더는 따로다):
```
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\CodexCards\run-cards.ps1 -Cards K-071,K-072,K-082
```
- 창을 하나 더 열어 다른 줄을 동시에 돌려도 된다(두 줄까지 해 봤음).
- 카드마다: 카드 폴더 만들기 → 코덱스 실행 → 카드 가지에 커밋 → 개발 가지에 합치기까지 자동. 합치기를 빼려면 `-NoMerge`.
- 크레딧이 떨어지면 "크레딧 부족으로 멈춤"이 찍힌다. 그 카드는 채운 뒤 같은 명령으로 다시 돌리면 이어서 한다.
- 결과는 `_HTML/` 아래 검토 페이지(카드마다 이름이 지시문 첫 줄에 있음)와 `Docs/References/codex_k0nn_v1/`.
